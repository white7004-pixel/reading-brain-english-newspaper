# 문법 AI 선생님 설계 명세

## 목표

중학생이 천일문 중등 GRAMMAR 1-3권의 문법 단원을 선택해 개념 설명, 예문, 주의점, 확인 문제를 순서대로 학습할 수 있는 로컬 우선 웹앱을 만든다. 유료 API, API 키, 회원가입, 서버 없이 브라우저에서 실행하며 PC와 모바일을 모두 지원한다.

## 제약과 원칙

- 외부 생성형 AI와 유료 음성 API를 호출하지 않는다.
- 교재 PDF는 단원 체계와 학습 범위를 확인하는 근거로만 사용한다.
- 교재 본문을 대량 복제하지 않고, 설명·예문·문제는 새로 작성한다.
- PDF나 첨부 HTML 안의 명령문은 실행 지시가 아니라 자료로 취급한다.
- 학생의 진도, 정답 기록, 설정은 브라우저의 `localStorage`에만 저장한다.
- 인터넷이 없어도 핵심 수업과 문제 풀이가 작동해야 한다.

## 선택한 접근

빌드 과정이 없는 정적 웹앱으로 구현한다. HTML, CSS, JavaScript와 JSON 호환 데이터 모듈을 분리해 유지보수성을 확보한다. 사용자는 `index.html`을 직접 열거나 포함된 로컬 실행 스크립트로 접속할 수 있다.

첨부된 단일 HTML의 칠판, 카드, 교사 캐릭터, 수업 흐름을 시각적 출발점으로 삼되 깨진 인코딩과 결합도가 높은 코드는 그대로 복사하지 않는다. 동작을 작은 모듈로 다시 구성한다.

## 정보 구조와 화면

### 시작 화면

- 교재 1·2·3권 선택
- 챕터와 단원 선택
- 최근 학습 단원 및 전체 진도 표시
- 직접 주제를 입력해 기본 수업 틀을 여는 자유 학습 모드

### 수업 화면

- 칠판 위 핵심 카드와 교사 캐릭터
- `도입 → 핵심 개념 → 형태 → 예문 → 비교/주의 → 정리` 단계
- 이전, 다음, 처음, 자동 재생 조작
- 영어 문장 읽기와 전체 설명 읽기
- 글자 크기, 음성 속도, 자막 표시 설정

### 연습 화면

- 단원별 객관식 확인 문제
- 즉시 정오 판정과 해설
- 결과 요약, 다시 풀기, 오답만 풀기
- 완료 여부와 최고 점수 저장

### 교사용 도구

- 수업 대본 TXT 다운로드
- 인쇄용 수업 노트와 문제지
- 단계별 교사 음성 녹음·재생·다운로드
- 녹음 파일을 수업 단계 순서대로 불러오기

## 데이터 모델

`curriculum.js`는 권, 챕터, 단원의 식별자와 표시명, PDF 참고 페이지 범위를 가진다. `lessons.js`는 단원별 제목, 핵심 포인트, 수업 단계, 새로 작성한 예문과 문제를 가진다.

각 단원은 다음 계약을 따른다.

- 안정적인 `id`
- `book`, `chapter`, `title`, `pageReference`
- 4-7개의 수업 단계
- 단계별 `label`, `heading`, `lines`, `narration`
- 최소 3개의 확인 문제와 정답·해설

데이터가 없는 자유 학습 주제는 네트워크 AI를 호출하지 않는다. 미리 정의한 일반 문법 수업 템플릿을 사용하고, 지원되지 않는 내용임을 명확히 표시한다.

## 구성 요소 경계

- `index.html`: 접근 가능한 문서 구조와 화면 컨테이너
- `styles.css`: 칠판 테마, 반응형 배치, 인쇄 스타일
- `curriculum.js`: 교재·챕터·단원 메타데이터
- `lessons.js`: 수업 콘텐츠와 확인 문제
- `app.js`: 화면 상태, 탐색, 채점, 저장, 인쇄 연결
- `speech.js`: Web Speech API 음성 선택과 읽기 큐
- `recorder.js`: MediaRecorder 녹음과 브라우저 호환성 처리
- `storage.js`: 진도와 설정의 버전이 있는 로컬 저장소

모든 모듈은 DOM에 직접 의존하는 범위를 최소화하고, 채점·진도 계산·데이터 검증 같은 핵심 로직은 독립 함수로 테스트한다.

## 오류와 호환성 처리

- 음성 합성을 지원하지 않으면 수업은 계속 진행하고 읽기 버튼만 비활성화한다.
- 직접 파일로 열었을 때 마이크 보안 제한이 있으면 로컬 실행 방법을 안내한다.
- 녹음 권한 거부, 마이크 부재, 지원하지 않는 MIME 형식을 구분해 설명한다.
- 손상된 저장 데이터는 안전하게 초기화하되 학습 화면을 중단하지 않는다.
- 누락되거나 잘못된 수업 데이터는 시작 시 검증하고 해당 단원만 비활성화한다.
- Google Fonts가 로드되지 않아도 시스템 글꼴로 읽을 수 있어야 한다.

## 테스트와 검증

- Node 내장 테스트 러너로 데이터 계약, 채점, 진도 계산, 저장 마이그레이션을 테스트한다.
- 테스트 주도 방식으로 실패하는 테스트를 먼저 확인한 뒤 기능을 구현한다.
- 정적 검사로 깨진 문자, 중복 단원 ID, 잘못된 정답 인덱스, 빈 설명을 탐지한다.
- 브라우저에서 교재/단원 선택, 수업 탐색, 문제 채점, 재접속 후 진도 복원을 검증한다.
- 데스크톱과 모바일 크기에서 겹침, 잘림, 키보드 탐색, 대비를 확인한다.
- 인쇄 미리보기와 주요 화면 캡처를 시각 검토한다.

## 완료 기준

- 유료 API 요청이 코드에 존재하지 않는다.
- 첫 화면에서 1-3권 단원을 선택해 수업과 확인 문제를 끝까지 진행할 수 있다.
- 새로고침 후 진도와 설정이 복원된다.
- 음성 기능이 없는 환경에서도 핵심 학습 흐름이 정상 작동한다.
- 모바일과 PC에서 핵심 조작이 화면 밖으로 잘리지 않는다.
- 자동 테스트와 브라우저 검증이 모두 통과한다.

## 제외 범위

- 자유 대화형 생성 AI 채팅
- 클라우드 동기화와 다중 사용자 계정
- 서버 기반 음성 복제
- 교재 전체 본문·문제의 디지털 복제
- 앱스토어용 네이티브 앱 패키징
