# 문법 AI 선생님 시장 출시형 강의 경험 설계

## 목표

현재의 정적인 전신 교사 이미지와 얼굴 위 입 모양 오버레이를 제거하고, 동일한 실사형 3D 한국인 강사가 설명·필기·핵심 강조와 자연스럽게 연결되는 모바일 앱 수준의 수업 경험을 만든다. 기존 98개 단원, 로컬 실행, 음성, 녹음, 퀴즈, 진도 기능은 유지한다.

## 제품 원칙

- 교사 애니메이션보다 문법 이해가 항상 우선이다.
- 화면의 교사, 음성, 포인터, 필기는 하나의 강의 상태를 공유한다.
- 움직임은 짧고 절제하며 반복적으로 시선을 빼앗지 않는다.
- 교사는 본문과 겹치지 않는 전용 영역을 사용한다.
- 외부 유료 API나 런타임 네트워크 없이 로컬에서 동작한다.
- 모션 축소, 음성 미지원, 느린 기기에서도 핵심 학습 기능은 동일하게 제공한다.

## 캐릭터 시스템

동일한 실사형 3D 한국인 여성 강사를 허리 위 구도의 투명 PNG 프레임으로 제작한다. 네이비 재킷, 아이보리 블라우스, 금색 포인터, 정면에서 약간 수업 화면을 바라보는 자세를 유지한다.

필수 프레임은 다음 네 개다.

1. `teacher-neutral.png`: 눈을 뜨고 입을 다문 기본 자세
2. `teacher-talk-soft.png`: 같은 얼굴과 자세에서 입을 살짝 연 상태
3. `teacher-talk-open.png`: 같은 얼굴과 자세에서 자연스럽게 발음하는 상태
4. `teacher-blink.png`: 기본 자세에서 자연스럽게 눈을 감은 상태

모든 프레임은 얼굴, 머리, 의상, 손, 포인터 위치가 일치해야 한다. 입이나 눈 외의 영역이 흔들리는 프레임은 사용하지 않는다. 기존 전신 이미지 위에 CSS 입 모양을 붙이는 방식은 제거한다.

## 음성·표정 동기화

교사 상태는 `idle`, `speaking`, `paused` 세 가지로 관리한다.

- `idle`: 기본 프레임을 표시하고 4–7초 사이의 불규칙한 간격으로 눈을 한 번 깜빡인다.
- `speaking`: 음성 시작 이벤트에서 말하기를 시작하고, 기본·살짝 열린 입·열린 입 프레임을 120–190ms 간격으로 불규칙 교체한다.
- `paused`: 현재 프레임을 기본 프레임으로 즉시 되돌린다.

음성 종료, 취소, 단계 변경, 홈 이동, 퀴즈 진입 시 말하기 타이머를 반드시 정리한다. `prefers-reduced-motion: reduce`에서는 프레임 교체와 눈 깜빡임을 사용하지 않는다.

## 강의 필기와 포인터

각 단계의 설명을 의미 단위 1–3줄로 분리한다. 줄은 위에서 아래로 나타나며 현재 음성과 맞는 줄만 `active` 상태가 된다.

- 등장 전: 흐린 회색, 낮은 투명도
- 현재 줄: 진한 네이비, 금색 필기 밑줄, 약한 확대
- 완료 줄: 정상 네이비, 강조는 유지하되 확대 제거

브라우저가 `SpeechSynthesisUtterance.onboundary`를 제공하면 글자 경계를 이용해 현재 줄을 전환한다. 지원하지 않으면 전체 글자 수에 비례한 시간 계산으로 줄을 전환한다.

포인터는 교사의 손과 카드의 현재 설명 줄 사이를 잇는 별도 CSS 레이어로 구현한다. 현재 줄이 바뀔 때 250ms 이내로 이동하고, 핵심 `mark`가 있으면 그 위치를 우선 가리킨다. 모바일에서는 긴 포인터를 숨기고 현재 줄 왼쪽에 금색 포인터 점을 표시한다.

## 화면 구조

### 데스크톱

- 왼쪽 26%: 교사 전용 스테이지
- 오른쪽 74%: 실사 장면과 필기 카드
- 하단: 재생, 이전·다음, 읽기 컨트롤
- 오른쪽 보조 패널: 7단계 순서와 음성 도구

교사와 카드가 절대 겹치지 않도록 그리드로 분리한다. 말풍선은 현재 단계의 짧은 격려 한 문장에만 사용하고, 실제 설명은 필기 카드에서 진행한다.

### 모바일

- 카드 상단: 실사 문법 이미지
- 카드 본문: 현재 설명과 강조
- 카드 하단 왼쪽: 교사의 상반신을 작은 전용 프레임에 표시
- 하단 고정 컨트롤: 이전, 재생·일시정지, 다음

교사 프레임은 본문 높이를 침범하지 않고 최대 화면 너비의 28%를 사용한다. 390px 화면에서 가로 스크롤과 글자 가림이 없어야 한다.

## 디자인 시스템

- 본문: `Noto Sans KR`, `Pretendard`, `Malgun Gothic` 순서의 로컬 폴백
- 문법 공식·기억법: 손글씨 효과를 과도하게 사용하지 않고 굵은 교재형 고딕을 기본으로 한다.
- 네이비는 설명과 구조, 샴페인 골드는 현재 위치와 핵심에만 사용한다.
- 붉은색은 오답에만 사용하며 아이콘과 문구를 함께 제공한다.
- 카드 모서리, 그림자, 버튼 높이, 터치 영역을 하나의 토큰 체계로 통일한다.
- 버튼의 최소 터치 영역은 44×44px, 본문 대비는 WCAG AA 이상을 유지한다.

## 코드 구조

- `js/teacher-avatar.js`: 프레임 프리로드, 상태 전환, 말하기·눈 깜빡임 타이머 관리
- `js/lesson-choreography.js`: 설명 줄 분리, 음성 경계와 활성 줄 연결, 폴백 시간 계산
- `js/speech.js`: `onstart`, `onboundary`, `onend`, `onerror` 이벤트 전달
- `js/app.js`: 단계 변경 시 아바타와 필기 연출을 시작·정리하는 조정자 역할만 담당
- `index.html`: 교사 스테이지, 포인터 레이어, 필기 줄 컨테이너 제공
- `styles.css`: 출시형 그리드, 상태별 필기, 포인터, 모바일 고정 컨트롤, 모션 축소 처리

각 모듈은 타이머와 DOM 상태를 명시적으로 정리할 수 있는 `stop()` 또는 `destroy()` 인터페이스를 제공한다.

## 오류와 폴백

- 캐릭터 프레임 로딩 실패: 기본 교사 이미지 한 장만 표시
- 음성 합성 미지원: 재생 버튼을 비활성화하지 않고 시간 기반 필기 연출만 실행
- 음성 경계 이벤트 미지원: 글자 수 기반 폴백 사용
- 탭 비활성화: 애니메이션과 타이머 일시정지
- 단계 빠른 이동: 이전 단계의 모든 음성·프레임·필기 타이머 즉시 취소
- 모션 축소: 기본 캐릭터와 전체 설명을 즉시 표시

## 검증

- 아바타 상태 전환에서 타이머가 중복 생성되지 않는지 단위 테스트한다.
- 음성 시작·경계·종료·오류 이벤트가 강의 상태로 전달되는지 테스트한다.
- 줄 분리, 현재 줄 계산, 시간 기반 폴백을 단위 테스트한다.
- 1·2·3권 대표 단원에서 교사와 카드가 겹치지 않는지 브라우저로 확인한다.
- 390×844, 768×1024, 1440×900 화면에서 가로 스크롤과 잘림을 검사한다.
- 빠른 단계 이동, 자동 수업 일시정지, 홈 이동, 퀴즈 진입 후 입 모양이 멈추는지 검사한다.
- 모션 축소 환경에서 애니메이션 없이 모든 텍스트가 보이는지 검사한다.
- 이미지 4개의 얼굴·의상·포인터 위치 일관성을 육안 검사한다.

## 완료 기준

- 기존 CSS 입 모양 오버레이가 완전히 제거된다.
- 같은 강사로 보이는 네 개의 일관된 투명 프레임이 로컬 자산으로 포함된다.
- 음성 재생 중에만 자연스러운 말하기 프레임이 움직인다.
- 현재 설명 줄과 핵심 표현이 음성 흐름에 맞춰 강조된다.
- 교사와 학습 콘텐츠가 데스크톱·모바일 모두에서 겹치지 않는다.
- 기존 98개 단원, 퀴즈, 진도, 녹음, 인쇄 기능의 회귀 테스트가 모두 통과한다.
