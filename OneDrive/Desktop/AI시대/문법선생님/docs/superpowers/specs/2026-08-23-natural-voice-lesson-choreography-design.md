# 자연스러운 AI 음성과 수업 연출 동기화 설계

## 목표

초등학생이 혼자 수업을 들어도 설명, 판서, 화면 전환을 안정적으로 따라갈 수 있게 한다. ElevenLabs로 미리 생성한 자연스러운 한국어 교사 음성을 기본으로 사용하고, 교사의 핵심 설명과 칠판의 핵심 문구가 같은 원본 데이터에서 나오도록 한다.

성공한 수업은 다음 리듬을 지킨다.

`핵심 발화 → 같은 핵심 판서 → 1.5초 확인 → 쉬운 설명과 예문 → 문장 사이 0.7초 호흡 → 요약 → 2.5초 복습 → 다음 단계`

## 현재 문제

- 브라우저 기본 음성이 일정한 리듬으로 읽어 문장 의미에 맞는 호흡과 강조가 부족하다.
- 설명문과 칠판 문구가 별도로 구성되어 핵심 표현이 정확히 일치하지 않을 수 있다.
- 판서는 고정 문자 속도로 진행되어 실제 음성의 발화 시점과 어긋난다.
- 음성과 판서가 끝난 뒤 약 0.9초 만에 다음 단계로 이동하여 읽고 이해할 시간이 부족하다.
- 일시정지가 음성, 판서, 대기 타이머를 하나의 학습 위치로 묶어 관리하지 않는다.

## 선택한 접근

수업 단계를 작은 연출 큐로 나누는 큐 기반 수업 엔진을 사용한다. 각 큐는 발화, 판서, 호흡, 강조와 전환 정보를 함께 가진다. 전체 단계를 한 덩어리로 읽지 않고 큐별 MP3를 재생하므로 실제 음성 길이를 기준으로 판서와 전환을 제어할 수 있다.

단순히 기존 속도와 타이머만 늘리는 방식은 설명과 판서 불일치를 해결하지 못하므로 사용하지 않는다. 98개 수업의 타임코드를 사람이 직접 작성하는 방식도 유지 비용이 크므로 사용하지 않는다.

## 수업 큐 모델

각 단계는 다음 역할을 가진 큐의 배열이다.

```js
{
  kind: 'core' | 'explain' | 'example' | 'question' | 'summary',
  narration: '학생에게 들려줄 한두 문장',
  boardLines: ['같은 핵심에서 추출한 판서'],
  emphasis: ['강조할 핵심어'],
  pauseAfterMs: 700 | 1500 | 2000 | 2500
}
```

한 큐의 설명은 최대 두 문장으로 제한한다. 칠판에는 설명 전체를 옮기지 않고 핵심어, 공식, 대표 예문만 최대 세 줄까지 표시한다.

### 큐 순서

1. `core`: 핵심 개념을 말하고 같은 핵심을 판서한다.
2. 핵심 판서가 끝난 상태로 1.5초 동안 유지한다.
3. `explain`: 쉬운 말과 생활 비유로 이유를 설명한다.
4. `example`: 영어 예문과 한국어 의미를 연결한다.
5. `question`: 학생에게 질문한 뒤 2초 동안 생각할 시간을 준다.
6. `summary`: 한 문장으로 정리한 뒤 2.5초 동안 전체 판서를 복습한다.

## 단일 원본 원칙

교사 설명과 칠판 내용은 같은 의미 단위에서 생성한다. 핵심 큐에는 `narration`과 `boardLines`를 함께 저장하며, 콘텐츠 검증기가 판서의 핵심어가 발화문에도 포함되는지 확인한다.

예를 들어 다음 두 문장은 하나의 핵심 큐에 속한다.

- 설명: “be동사는 존재하거나 어떤 상태임을 나타내요.”
- 판서: “be = 존재하다 · 상태이다”

표현을 완전히 똑같이 반복할 필요는 없지만, 문법 용어와 핵심 의미는 반드시 일치해야 한다. 보충 설명은 칠판에 모두 복제하지 않는다.

## ElevenLabs 음성 생성

98개 수업의 각 큐에 대해 MP3를 한 번 생성하여 로컬 자산으로 저장한다. 브라우저에는 API 키를 포함하지 않는다.

### 음성 스타일

- 따뜻하고 차분한 한국인 여성 교사
- 초등학생에게 일대일로 설명하는 말투
- 현재보다 약 10~15% 느린 속도
- 핵심 용어를 조금 천천히 강조하되 과장하지 않음
- 문장 끝을 급하게 닫지 않고 자연스럽게 호흡
- 질문은 학생이 생각할 수 있도록 열린 억양으로 마무리

음성 생성 프롬프트와 모델 설정은 모든 큐에 공통으로 적용하고, 문장 부호와 의미 단위로 호흡을 유도한다.

### 기본 호흡 규칙

| 상황 | 대기 시간 |
|---|---:|
| 일반 문장 사이 | 0.7초 |
| 영어 예문과 한국어 설명 사이 | 0.8초 |
| 핵심 판서 완료 후 | 1.5초 |
| 질문 후 생각할 시간 | 2초 |
| 단계 전환 전 복습 | 2.5초 |

MP3의 실제 재생 종료가 모든 타이머보다 우선한다. 음성이 재생 중이면 다음 큐나 단계로 넘어가지 않는다.

## 재생 및 판서 동기화

수업 엔진은 한 번에 하나의 큐만 실행한다.

1. 큐의 MP3를 불러온다.
2. 음성이 시작되면 현재 문장 자막과 교사 말하기 애니메이션을 시작한다.
3. 핵심어가 발화되는 구간에 맞춰 해당 판서 줄을 표시한다.
4. 음성이 끝날 때까지 기다린다.
5. 남은 판서를 완성하고 큐의 `pauseAfterMs`만큼 화면을 유지한다.
6. 다음 큐를 실행한다.

사전 생성 음성에는 큐 단위 길이를 메타데이터로 기록한다. 판서 줄이 여러 개인 경우 음성 길이를 문장 또는 의미 단위 비율로 나눠 등장 시점을 계산한다. 장기적으로 정확한 타임스탬프를 얻을 수 있으면 같은 인터페이스에 단어 정렬 정보를 추가할 수 있지만, 첫 구현 범위에는 포함하지 않는다.

자막은 현재 발화 중인 문장만 보여 준다. 칠판은 현재 단계 안에서 누적되어 단계가 끝날 때 전체 핵심을 복습할 수 있게 한다.

## 학생 제어

- 자동 수업 중에도 `일시정지/계속`, `이전`, `다시 듣기`를 항상 사용할 수 있다.
- 일시정지는 MP3, 판서 애니메이션, 호흡 타이머를 같은 큐 위치에서 멈춘다.
- 계속하기는 중단된 큐의 같은 위치에서 재개한다.
- 속도는 `느리게`, `추천`, `보통` 세 단계로 제공하며 기본값은 `추천`이다.
- 속도 변경은 음성 재생률, 판서 속도와 호흡 시간을 함께 조정한다.
- 자동 진행을 꺼도 현재 단계의 음성 재생과 판서는 정상 작동한다.
- 단계 전환 직전에는 “다음 내용으로 넘어갑니다” 상태를 표시한다.

## 실패 처리

- MP3 파일이 없거나 재생에 실패하면 동일한 큐의 텍스트를 브라우저 음성으로 읽는다.
- 대체 음성에서도 동일한 판서 순서와 호흡 규칙을 유지한다.
- 음성 실패 때문에 자동 진행이 멈추거나 큐가 중복 실행되지 않게 한다.
- 사용자가 빠르게 단계 이동을 반복하면 이전 큐의 음성, 판서와 모든 타이머를 정리한다.
- 모션 감소 설정에서는 판서 애니메이션을 즉시 완료하되 학습용 호흡 시간은 유지한다.

## 생성 파이프라인

기존 ElevenLabs 생성 스크립트를 큐 구조에 맞게 확장한다.

- 98개 수업을 큐 단위 생성 명세로 변환한다.
- 대본과 음성 설정의 해시를 매니페스트에 기록한다.
- 승인된 동일 해시의 MP3는 다시 생성하지 않는다.
- 바뀐 큐만 선택적으로 재생성한다.
- API 오류는 큐별로 격리하여 나머지 수업 생성을 계속한다.
- 생성 결과에는 파일 경로, 음성 길이, 대본 해시와 설정 해시를 기록한다.

API 키는 로컬 환경 변수로만 읽고 브라우저 코드, 대본, 로그와 생성 매니페스트에는 기록하지 않는다.

## 테스트 및 검증

자동 테스트는 다음 계약을 검증한다.

- 98개 수업 모두 필수 큐 순서를 가진다.
- 각 큐는 최대 두 문장이고 판서는 최대 세 줄이다.
- 핵심 큐의 문법 용어와 핵심 의미가 설명과 판서 양쪽에 존재한다.
- 일반 문장, 판서 확인, 질문과 단계 전환의 권장 호흡 시간이 적용된다.
- MP3가 끝나기 전에 다음 큐나 화면으로 넘어가지 않는다.
- 일시정지 후 동일한 큐와 재생 위치에서 이어진다.
- 다시 듣기는 현재 큐를 처음부터 중복 타이머 없이 재생한다.
- MP3가 없거나 실패하면 브라우저 음성으로 한 번만 대체된다.
- 단계 변경 시 이전 음성, 판서와 타이머가 모두 정리된다.
- 모바일 화면에서 칠판과 핵심 조작 버튼이 동시에 접근 가능하다.
- 전체 교재 선택, 퀴즈, 진도 저장과 인쇄의 기존 흐름이 유지된다.

브라우저 테스트에서는 실제 로컬 MP3 fixture를 사용하여 재생 종료, 일시정지, 재개와 단계 전환 순서를 검증한다. 외부 ElevenLabs API는 생성 스크립트의 요청 경계까지만 테스트하고 실제 호출은 자동 테스트에서 수행하지 않는다.

## 범위 제외

- 실시간 ElevenLabs API 호출
- 브라우저에 API 키 저장
- 모든 단어의 수동 타임코드 작성
- 입 모양을 음소 단위로 맞추는 립싱크
- 수업별로 서로 다른 교사 목소리 제공

이 항목들은 안정적인 큐 기반 수업이 완성된 뒤 필요성이 확인되면 별도 설계한다.
