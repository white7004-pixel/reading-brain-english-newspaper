# 문법 AI 선생님 일타강사 콘텐츠 개편 설계

## 목표

제공된 천일문 중등 GRAMMAR 1·2·3 PDF의 목차상 98개 문법 단원을 모두 앱에 표시하고, 한 번 들어도 이해되는 강의형 설명과 실사 비유 자료를 결합한다.

## 콘텐츠 원칙

- PDF의 문법 범위와 단원 순서는 빠짐없이 반영한다.
- 교재 본문·예문·문제를 대량 복제하지 않고 설명과 문장을 새로 작성한다.
- 설명 정확성과 이해 속도를 농담보다 우선한다.
- 농담은 자연스러운 한 줄을 일부 단원에만 사용한다.
- 학생을 낮추거나 불안을 조장하지 않고 틀린 이유와 수정 방법을 알려 준다.
- 중학생이 이해할 수 있는 어휘를 사용하되 시험에 필요한 문법 용어는 정확히 제시한다.

## 단원별 수업 구조

모든 단원은 다음 7단계를 제공한다.

1. `10초 핵심`: 단원의 역할을 한 문장으로 설명한다.
2. `실사 비유`: 실생활 장면과 문법 구조를 연결한다.
3. `형태 공식`: 주어·동사·목적어·보어를 색상과 화살표로 표시한다.
4. `대표 예문`: 독창적인 예문 2-3개와 자연스러운 해석을 제공한다.
5. `시험 함정`: 자주 틀리는 선택지와 틀린 이유를 비교한다.
6. `기억 공식`: 시험 직전에 떠올릴 한 줄 공식을 제공한다.
7. `확인 문제`: 최소 3문제와 즉시 해설을 제공한다.

각 단계에는 `heading`, `lines`, `narration`, `visualKey`가 있으며, 영어 핵심 부분은 색상 강조를 사용한다.

## 일타강사 말투

- 첫 문장에서 핵심을 말한다.
- 추상적인 정의 뒤에는 바로 일상 비유를 붙인다.
- “왜 이 답이 되는지”와 “왜 다른 답은 안 되는지”를 함께 설명한다.
- 예: “수동태는 카메라의 초점을 행동한 사람에서 행동을 받은 대상으로 옮기는 문법이에요.”
- 격려는 짧고 구체적으로 한다. 예: “be동사만 찾았으면 절반은 이미 해결했어요.”

## 실사 비주얼 체계

약 12개의 고품질 실사형 이미지를 문법군별로 제작하고 여러 단원에서 재사용한다.

- 상태와 동작: 정지 인물과 움직이는 인물
- 시간선: 과거·현재·미래를 잇는 장면
- 완료: 끝난 과제와 현재 결과
- 조동사: 허가·가능·의무 표지
- 수동태: 행동 주체와 초점 대상
- 부정사·동명사: 계획과 실제 활동
- 분사: 감정을 일으키는 대상과 느끼는 사람
- 비교: 높이·속도·거리 비교
- 접속사: 갈림길과 연결 다리
- 관계사: 사람·사물과 추가 설명 카드
- 가정법: 현실과 상상 장면의 분할 화면
- 문장 형식·특수 구문: 역할이 표시된 무대 장면

이미지는 텍스트 없이 제작하고 앱에서 접근 가능한 설명 문구를 제공한다. 모바일에서는 이미지가 문법 카드 위를 가리지 않도록 카드 내부 상단에 배치한다.

## 데이터 변경

`js/lessons.js`의 공통 생성 문구를 단원별 콘텐츠 데이터로 교체한다. 모든 단원은 다음 필드를 갖는다.

- `hook`: 10초 핵심
- `analogy`: 실사 비유 설명
- `formula`: 구조 공식
- `examples`: 영문·해석·강조 대상 배열
- `trap`: 오답과 교정 이유
- `memory`: 한 줄 기억 공식
- `visualKey`: 실사 이미지 키
- `quiz`: 정답과 오답 이유가 포함된 문제 배열

`js/visuals.js`는 `visualKey`와 이미지 경로·대체 텍스트를 연결한다.

## 화면 변경

- 수업 카드 상단에 실사 비유 이미지를 표시한다.
- 문장 성분은 네이비·골드·코랄·블루 색상 칩으로 구분한다.
- 시험 함정 단계는 정답·오답을 좌우 비교한다.
- 기억 공식은 골드 테두리의 별도 카드로 표시한다.
- 교사 말풍선은 길지 않게 2-4문장으로 제한한다.
- 기존 3D 교사, 음성, 녹음, 진도, 인쇄 기능을 유지한다.

## 검증

- 98개 단원이 모두 7단계, 예문 2개 이상, 문제 3개 이상을 갖는지 자동 검사한다.
- 중복 예문, 빈 해석, 잘못된 정답 인덱스, 깨진 한글을 검사한다.
- 모든 `visualKey`가 실제 로컬 이미지와 대체 텍스트에 연결되는지 검사한다.
- 모바일·데스크톱에서 이미지와 문법 카드가 겹치지 않는지 브라우저로 검증한다.
- 1·2·3권에서 각각 대표 단원 하나를 끝까지 재생하고 문제 풀이·진도 저장을 확인한다.

## 완료 기준

- PDF 목차의 98개 문법 단원이 모두 선택 가능하다.
- 모든 단원의 설명이 주제별로 구체적이며 공통 문구 반복에 의존하지 않는다.
- 모든 단원에 핵심, 비유, 공식, 예문, 함정, 기억 공식, 문제가 있다.
- 12개 내외의 실사 비주얼이 해당 문법군에 정확히 연결된다.
- 기존 무료·로컬 실행 원칙과 모든 기능이 유지된다.
