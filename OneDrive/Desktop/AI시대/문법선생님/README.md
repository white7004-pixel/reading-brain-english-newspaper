# 문법 AI 선생님

천일문 중등 GRAMMAR 1·2·3의 단원 체계를 바탕으로 만든 무료 로컬 문법 수업 웹앱입니다. 외부 생성형 AI, 유료 API, 회원가입, 서버 저장을 사용하지 않습니다.

## 바로 실행하기

학습과 문제 풀이는 `index.html`을 Chrome 또는 Edge로 열면 바로 사용할 수 있습니다.

교사 음성 녹음까지 사용하려면 PowerShell에서 다음 명령을 실행하세요.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/serve.ps1
```

그다음 브라우저에서 <http://127.0.0.1:4173>을 여세요. 최초 녹음 시 마이크 권한을 허용해야 합니다.

## 주요 기능

- 1·2·3권, 36개 챕터, 92개 단원 선택
- 도입 → 핵심 → 형태 → 예문 → 정리 수업 흐름
- 단원별 확인 문제와 즉시 해설
- 브라우저 기본 음성으로 수업 읽기
- 단계별 교사 음성 녹음·재생·다운로드
- 수업 대본 TXT 저장과 인쇄용 레이아웃
- 브라우저에 학습 진도·최고 점수·설정 자동 저장
- 모바일과 PC 반응형 화면

## 데이터와 개인정보

학습 기록은 현재 브라우저의 `localStorage`에만 저장됩니다. 외부 서버로 전송되지 않습니다. 설정의 `진도 초기화` 버튼을 누르면 저장된 기록을 지울 수 있습니다.

## 교재 사용 원칙

제공된 PDF에서는 단원 제목과 참고 쪽수만 확인했습니다. 수업 설명, 예문, 확인 문제는 앱용으로 새로 작성했으며 교재 본문을 대량 복제하지 않았습니다.

## 테스트

Node.js가 설치되어 있다면 다음 명령으로 데이터 계약, 채점, 저장, 오프라인 안전성 검사를 실행할 수 있습니다.

```powershell
npm test
```

브라우저 검증은 로컬 서버가 실행 중인 상태에서 다음 명령을 사용합니다.

```powershell
npm run test:browser
```

## 브라우저 제한

- 음성 합성 목소리는 운영체제와 브라우저에 설치된 무료 음성을 사용하므로 기기마다 다릅니다.
- 마이크 녹음은 보안 정책 때문에 `file:` 주소에서 제한될 수 있습니다. 이 경우 위의 로컬 서버 실행법을 사용하세요.
- Safari 일부 버전에서는 녹음 파일 형식이 다를 수 있습니다.
