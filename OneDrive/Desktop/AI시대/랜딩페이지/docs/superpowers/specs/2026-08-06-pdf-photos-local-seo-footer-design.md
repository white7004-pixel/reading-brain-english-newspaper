# PDF 사진·지역 SEO·1·2관 하단 정보 개선 디자인

## 목표

리딩브레인 커리큘럼 설명 PDF에 포함된 실제 학원 사진을 선별하여 랜딩페이지의 신뢰도를 높인다. 동시에 이전 `readingbrain.pages.dev` 사이트에서 확인된 정확 일치 지역 검색어 신호를 현재 공식 도메인에 자연스럽게 반영하고, 1관과 2관의 주소 및 전체 교육 범위를 하단에 정확히 표시한다.

## 사진 선별 원칙

- PDF 슬라이드 전체를 이미지로 사용하지 않고, PDF 내부의 원본 사진을 추출한다.
- 실제 학원 서가, 1:1 수업, 북토킹, 중고등 수업, 학생 발표, 학부모 설명회, 캠프·동기부여 활동을 우선한다.
- 외부 방송 캡처, 유튜브 화면, 문서 스크린샷, 저해상도 세로 영상 캡처는 제외한다.
- 학생 사진은 사용자가 제공한 공식 커리큘럼 자료에 이미 포함된 사진만 사용한다.
- 이미지 파일은 의미가 드러나는 영문 파일명으로 `images/heidi/`에 저장하고, 문맥에 맞는 한국어 대체 텍스트를 제공한다.

## 사진 적용 위치

1. 학원 시설·수업 현장 갤러리
   - 실제 영어원서 서가
   - 1:1 원서정독 수업
   - 1:1 북토킹
   - 중고등 특목 수업
   - 학생 발표·설명 활동
   - 미래입시전략 비교과 수업
   - 학부모 정기설명회
   - 캠프·동기부여 활동
2. 기존 섹션 구조와 카드 수는 유지하고, 중복되거나 일반적인 기존 사진을 우선 교체한다.
3. 성과 증빙 이미지와 학부모 후기 이미지는 이번 작업에서 변경하지 않는다.

## 추천 대상 및 재원 사례 영역

`무엇이 궁금하세요?` 섹션의 사립초·국제학교·리터니·유학·주재원 안내 다음, `왜 리딩브레인인가요?` 앞에 `이런 학생에게 추천합니다` 영역을 배치한다. 상담 분야를 본 방문자가 자신의 상황을 확인한 뒤 학원의 차별점을 읽는 흐름으로 연결한다.

- 사립초·국제학교·리터니·유학·주재원 자녀
- 특목고·자사고 진학을 준비하는 학생
- 유명 대형학원의 단체수업과 획일적인 진도에 만족하지 못한 학생
- 자신의 수준에 맞는 빠른 개별 진도가 필요한 학생
- 중3까지 고3 수능영어 수준을 완성하고 싶은 학생
- 비문학 독해 훈련으로 공부그릇과 학습 속도를 키우고 싶은 학생

목록 아래에는 다음 재원 사례를 별도의 증거 문장으로 표시한다.

`현재 초6·중1 재원생 중 이미 고3 수능영어 수준을 완성했거나 성인 TOEFL 교재를 학습하는 사례가 있습니다.`

이 문장은 모든 학생에게 동일한 결과를 보장하는 표현이 아니라 현재 재원 사례임을 명확히 한다.

## 지역 SEO 설계

- 문서 제목에 `리딩브레인영어학원`과 `일직동영어학원`을 정확한 붙여쓰기 형태로 포함한다.
- 메타 설명에는 일직동 위치, 1관·2관, 원서정독·미국교과·중고등 특목·입시영어 범위를 한 문장으로 요약한다.
- 첫 화면의 보조 문구, 오시는 길, 하단 정보에 `광명 일직동영어학원 리딩브레인`을 자연스럽게 배치한다.
- 정확 일치 키워드는 페이지 전체에서 문맥에 맞게 제한적으로 사용하고 숨김 텍스트나 반복 나열은 사용하지 않는다.
- 기존 canonical, robots, sitemap은 공식 도메인 `https://www.readingbrain.co.kr/` 기준을 유지한다.
- `meta keywords`는 추가하지 않는다. 이전 사이트에는 존재하지만 검색 품질에 도움이 되는 핵심 요소로 보지 않는다.

## 1·2관 정보 설계

오시는 길과 하단에 다음 정보를 각각 독립적으로 표시한다.

- `1관 [원서관] 경기 광명시 양달로10번길 7, 1층`
- `2관 [중고등특목관] 경기 광명시 양달로10번길 9, 1층`

구조화 데이터에도 두 교육관을 별도 하위 조직으로 표현하고 각 주소를 연결한다. 챗봇의 위치 답변도 두 관을 함께 안내하도록 수정한다.

## 하단 교육 범위 문구

기존 `상위 1% 영어몰입교육 · 초/중/고 1:1 원서 교육 전문`을 다음과 같이 교체한다.

`원서정독 · 미국교과 · 영자신문 · 중고등 특목 · 입시영어 통합교육`

이 문구는 원서교육만 운영하는 학원으로 오해되는 것을 막고 PDF에서 확인한 실제 커리큘럼 범위를 반영한다.

## 이전 도메인 처리

현재 코드에서 가능한 공식 도메인 SEO 개선을 먼저 적용한다. 이전 `readingbrain.pages.dev`의 기존 색인 신호를 공식 도메인으로 통합하려면 Cloudflare Pages 프로젝트에서 공식 도메인으로 영구 리디렉션하는 별도 배포 설정이 필요하다. 해당 외부 프로젝트 접근 권한이 확인되기 전에는 이전 사이트를 변경하지 않는다.

## 검증 기준

- 선택한 모든 이미지가 PDF에서 추출된 원본이며 프로젝트 내부에 존재한다.
- 갤러리 이미지 링크와 대체 텍스트가 모두 유효하다.
- 제목과 메타 설명에 `일직동영어학원`이 정확히 포함된다.
- canonical, robots, sitemap이 공식 도메인을 유지한다.
- 화면 하단과 오시는 길에 두 관의 명칭과 주소가 정확히 표시된다.
- 구조화 데이터 JSON이 유효하고 두 관 주소를 포함한다.
- 챗봇 위치 답변에 1관과 2관이 모두 포함된다.
- 데스크톱 및 모바일 화면에서 갤러리와 하단 정보가 깨지지 않는다.
- 추천 대상 영역이 국제학교·유학·주재원 안내 뒤에 표시되고 여섯 대상과 재원 사례 문장을 모두 포함한다.
