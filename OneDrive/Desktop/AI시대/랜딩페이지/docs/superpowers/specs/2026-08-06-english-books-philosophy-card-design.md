# 영어원서 교육철학 카드 이미지 교체 디자인

## 목표

홈페이지의 교육철학 섹션에서 “모든 아이에게 원서가 필요합니다” 카드의 기존 학원 내부 사진을 영어 원서가 가득한 사진으로 교체한다. 카드 문구와 시각 이미지가 즉시 연결되어야 한다.

## 이미지 디자인

- 실제 사진처럼 자연스러운 영어 원서 서가를 정면에 가깝게 보여준다.
- 다양한 크기와 색상의 어린이·청소년 영어 원서가 화면을 풍성하게 채운다.
- 따뜻하고 차분한 학원 도서공간의 자연광과 목재 질감을 사용한다.
- 카드의 가로형 크롭에서도 책이 충분히 보이도록 중앙부에 핵심 피사체를 배치한다.
- 사람, 로고, 워터마크, 읽기 어려운 생성형 문구, 한국어 문구는 넣지 않는다.

## 적용 범위

- 새 이미지는 프로젝트의 `images/` 폴더에 별도 파일로 저장한다.
- `index.html`에서 해당 카드의 이미지 경로와 대체 텍스트만 변경한다.
- 카드 레이아웃, 링크, 제목, 설명 및 다른 이미지는 변경하지 않는다.

## 검증 기준

- 새 이미지가 배포 가능한 로컬 파일로 존재한다.
- 해당 카드만 새 이미지를 참조한다.
- 이미지 대체 텍스트가 영어 원서 서가라는 내용을 정확하게 설명한다.
- 기존 홈페이지 검증 스크립트와 이미지 경로 점검을 통과한다.
