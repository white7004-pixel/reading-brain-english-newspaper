## 구조

기존 방식을 그대로 따른다. 새 파일을 만들지 않는다.

| 무엇 | 어디에 |
|---|---|
| 마크업 | `index.html` — `<section class="stage-explorer" id="stage-explorer">` |
| 단계 자료 | 같은 섹션 안 `data-*` 속성. 별도 JSON 파일을 만들지 않는다 |
| 모양 | `redesign.css` §25 |
| 동작 | `redesign.js` 끝에 IIFE 하나 추가 (`workMore` 토글과 같은 꼴) |

**놓을 자리:** `#diagnostic`(레벨 테스트 진단 시스템) **바로 앞**.
"이 단계가 무엇인가"를 먼저 만져 보고, 그다음 "그래서 어떻게 진단하는가"로 넘어간다.

## 동작

- `<input type="range" min="0" max="2" step="1">` 하나. 값이 바뀌면 패널을 다시 그린다.
- 단계 이름 3개는 `<button>`. 누르면 슬라이더 값이 바뀐다.
- 자료는 각 단계를 `<div class="stage-data" hidden>` 로 **HTML 에 미리 넣어 둔다.**
  자바스크립트는 `hidden` 만 토글한다. 자바스크립트가 죽어도 내용은 페이지에 남는다.
- 사진은 `loading="lazy"`. 첫 단계만 바로 받고 나머지는 눌렀을 때 받는다.

## 접근성

- 슬라이더는 `<input type="range">` 라 키보드 좌우 화살표가 기본 동작한다.
- 슬라이더에 `aria-label="원서 단계 선택"`, 패널에 `aria-live="polite"` — 바뀐 내용을 읽어 준다.
- 단계 버튼에 `aria-pressed`.
- 포커스 링은 이미 넣은 §23 규칙이 그대로 적용된다 (커밋 `ac744cad4`).
- 본문 글자는 §24 기준을 따른다 — 읽는 문단 15px, 상세 14px.

## 검사 방법

`tmp/functest.js` 에 항목을 더한다.

1. 슬라이더를 0→1→2 로 옮기면 보이는 패널이 정확히 하나이고 그때마다 바뀐다
2. 단계 버튼을 누르면 슬라이더 값과 `aria-pressed` 가 같이 따라간다
3. 키보드 화살표로 움직여진다
4. 자바스크립트를 끈 상태에서 세 단계 내용이 모두 페이지에 있다
5. 390px 에서 가로 스크롤이 생기지 않는다
6. 사진이 깨지지 않는다 (`stageBroken 0`)

## 하지 않는 것 (YAGNI)

- 학년 대응표 — 자료가 없다. 나중에 원장님이 주시면 축을 하나 더 붙인다.
- 책마다 AR 지수 표시 — 확인할 방법이 없다. 반 배정 기준(2.0 / 4.0)만 쓴다.
- 수능 독해와의 연결 — 근거가 적혀 있지 않다. 별도 과제(B안)로 남긴다.
- 애니메이션 전환 효과 — 슬라이더가 이미 움직임을 준다.
- 결과 저장·공유 — 상담 신청이 목적지다.
