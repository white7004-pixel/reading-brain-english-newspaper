# 메인 헤더 중성 오버레이 설계

## 목표

메인 헤더 영상 위의 파란색 계열을 제거하여 원본 영상의 색감을 살리고, 왼쪽 흰색 문구의 가독성은 유지한다.

## 시각 처리

- 기존 남색 그라데이션을 중성 검정 그라데이션으로 교체한다.
- 데스크톱에서는 왼쪽 텍스트 영역만 약 42% 검정으로 어둡게 하고 중앙부터 빠르게 투명해지게 한다.
- 모바일에서는 좁은 화면의 문구 가독성을 위해 왼쪽 약 48% 검정에서 오른쪽 투명으로 전환한다.
- 파랑, 남색 또는 다른 색조를 오버레이에 사용하지 않는다.
- 영상 파일, 재생 순서, 자동재생 및 반복 동작은 변경하지 않는다.

## 검증 기준

- `.hero-overlay`의 배경에 파란색 RGB 값이 남지 않는다.
- 오버레이 오른쪽 끝은 완전히 투명하다.
- 브라우저에서 영상이 원래 색감으로 표시되고 흰색 문구를 읽을 수 있다.
- 영상은 일시정지되지 않고 재생 시간이 증가한다.
