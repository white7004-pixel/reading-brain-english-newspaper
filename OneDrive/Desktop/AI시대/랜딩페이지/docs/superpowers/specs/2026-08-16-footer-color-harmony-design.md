# 하단 상담예약·오시는 길 컬러 조화 디자인

## 목표

페이지 하단의 상담예약 배너에서 기존 핑크 인상을 제거하고, 오시는 길 영역까지 리딩브레인의 네이비·골드·아이보리 브랜드 팔레트로 자연스럽게 연결한다. 구조, 문구, 링크, 반응형 배치는 변경하지 않는다.

메인 히어로에는 AI 시대 영어독서의 의미를 바로 전달하는 한국어 브랜드 메시지를 추가한다.

## 메인 히어로 메시지

- 기존 영문 상단 문구 `ORIGINAL BOOKS TO ACADEMIC EXCELLENCE`를 `AI 시대를 리드하는 영어독서의 힘`으로 교체한다.
- 기존 큰 제목 `원서로 사고력을 키우고, 입시에서 결과로 증명합니다.`와 설명 문구는 유지한다.
- 상단 문구의 기존 배지 스타일, 애니메이션, 여백 구조를 재사용하되 한국어 가독성에 맞게 자간을 확인한다.
- 현재 축약된 강점 배지 3개를 과거의 다음 5개 문구로 복원한다.
  - `AI 시대 사고력 · 문해력 · 집중력`
  - `사립초 · 국제학교 · 특목자사고`
  - `유학 · 리터니 · 주재원 자녀`
  - `1:1 원서정독 밀착코칭`
  - `중등에 가장 빠른 수능 1등급 완성`
- 배지는 데스크톱에서 자연스럽게 줄바꿈되고 모바일에서 화면 너비를 넘지 않아야 한다.

## 선택 방향

A안인 **네이비 × 골드**를 적용한다.

- 브랜드 네이비: `#0C354D`
- 보조 네이비: `#164D69`
- 브랜드 골드: `#B89A62`
- 브랜드 아이보리: `#F6F2E9`
- 기본 흰색: `#FFFFFF`

## 상담예약 배너

- 배경은 브랜드 네이비에서 보조 네이비로 이어지는 절제된 그라데이션을 사용한다.
- 기존 핑크색 상담예약 버튼은 브랜드 골드 배경과 흰색 글자로 변경한다.
- 전화 버튼은 흰색 또는 아이보리 배경과 네이비 글자를 사용한다.
- 인스타그램 버튼은 투명 배경과 반투명 흰색 테두리를 유지해 정보 위계를 보존한다.
- 호버 상태는 각 버튼의 기본 색보다 약간 진하게 조정하고 기존 이동 효과를 유지한다.

## 오시는 길

- 섹션 배경은 따뜻한 브랜드 아이보리를 유지한다.
- 지도 컨테이너에는 옅은 골드 계열 테두리와 네이비 계열의 낮은 불투명도 그림자를 적용한다.
- 위치 정보 카드는 흰색 배경을 유지하되, 기존 회색 테두리를 따뜻한 골드 계열 테두리로 바꾼다.
- 위치 아이콘은 옅은 네이비 배경과 브랜드 네이비 글자로 변경한다.
- 카드 제목과 링크는 브랜드 네이비·버건디의 기존 의미 체계를 유지해 가독성과 링크 인지성을 보존한다.

## 반응형 및 접근성

- 기존 그리드와 모바일 스택 구조는 변경하지 않는다.
- 버튼과 본문 텍스트는 배경 대비가 충분하도록 유지한다.
- 색상 외에도 버튼 형태, 테두리, 글자 굵기가 상호작용과 정보 구분을 계속 전달해야 한다.

## 검증

- 메인 히어로 상단에 새 한국어 메시지가 정확히 표시되고 기존 제목·설명이 유지되는지 확인한다.
- 복원한 강점 배지 5개가 데스크톱과 모바일에서 잘리지 않고 표시되는지 확인한다.
- 데스크톱과 모바일 폭에서 상담예약 배너와 오시는 길이 끊김 없이 이어지는지 확인한다.
- 핑크색 버튼이 제거되고 지정한 네이비·골드·아이보리 팔레트만 사용되는지 확인한다.
- CTA 버튼의 기본·호버 상태와 지도 및 위치 카드의 테두리·그림자를 확인한다.
- 문구, 링크, 레이아웃 및 기능에 회귀가 없는지 확인한다.
