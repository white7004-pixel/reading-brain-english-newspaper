# 메인 헤더 네이비·와인 타이포그래피 설계

## 목표

메인 헤더의 과도한 밝은 빨강을 줄이고 네이비와 와인을 역할별로 사용하여 차분하고 고급스러운 인상을 만든다.

## 색상 체계

- 메인 제목의 기본 문구는 흰색을 유지한다.
- 메인 제목 강조 문구 `평생 쓰는 영어`에는 와인 `#8F1D2C`를 사용한다.
- 하단 핵심 제목 세 개에는 네이비 `#17324D`를 사용한다.
- 상단 배지와 예약 버튼은 기존 와인 계열을 유지하여 행동 요소임을 구분한다.
- 본문, 설명, 자격 태그는 흰색 또는 기존 연한 회색을 유지한다.

## 범위

`index.html`과 `new_styles.css`의 메인 헤더 타이포그래피 색상만 변경한다. 영상, 중성 오버레이, 자동재생 및 레이아웃은 변경하지 않는다.

## 검증 기준

- `.hero-title em`의 계산된 색상이 `rgb(143, 29, 44)`이다.
- `.hero-proof-item strong`의 계산된 색상이 `rgb(23, 50, 77)`이다.
- 메인 제목의 나머지 문구는 흰색이다.
- 영상 재생 시간이 계속 증가하며 미디어 오류가 없다.
