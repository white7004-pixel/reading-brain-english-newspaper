# TLP 학습심리검사 카드 삭제 디자인

## 목표

랜딩페이지의 `레벨 테스트 진단 시스템`에서 TLP 학습심리검사 카드를 삭제한다.

## 변경 범위

- `index.html`의 `학습심리검사` 카드 전체를 제거한다.
- 카드에 포함된 `TLP · 진단 4` 문구와 설명, 검사 항목 목록을 함께 제거한다.
- 스터디포스 국어 독해력 훈련 카드와 TQ 독해력 진단 테스트 카드는 유지한다.
- 나머지 진단 카드의 순서와 내용은 변경하지 않는다.

## 레이아웃

- 기존 CSS 그리드가 남은 카드 수에 맞춰 자동 배치되므로 별도 구조 변경은 하지 않는다.
- 데스크톱과 모바일에서 빈 카드나 불필요한 간격이 생기지 않는지 확인한다.

## 검증

- `index.html`에 `TLP · 진단 4`와 해당 학습심리검사 설명이 남아 있지 않아야 한다.
- `TQ 독해력 진단 테스트`와 스터디포스 프로그램 카드는 그대로 존재해야 한다.
