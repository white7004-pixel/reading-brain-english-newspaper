검색 노출과 순위는 검색엔진이 결정하므로 특정 순위를 보장하지 않는다. 기술 SEO, 콘텐츠 일치도, 지역 업체 정보, 색인 가능성을 개선하는 것이 이 작업의 범위다.

- 기존 `EducationalOrganization`·`LocalBusiness` 데이터에 `alternateName`, `description`, `sameAs`, `hasOfferCatalog`를 보강한다.
- 별도의 `WebSite` 항목으로 사이트명 `리딩브레인 영어학원`과 대체명 `일직동 영어학원 리딩브레인`을 제공한다.
- 페이지에 표시한 FAQ와 동일한 `FAQPage` 데이터를 추가한다.
- 주소, 전화번호, 운영시간처럼 확인된 사실만 사용한다.
- 후기 평점이나 학교와의 공식 제휴 관계는 추가하지 않는다.

## 크롤링과 색인

- `robots.txt`는 모든 검색로봇을 허용하고 절대 URL 사이트맵을 유지한다.
- `sitemap.xml`의 대표 URL은 `https://www.readingbrain.co.kr/`로 유지한다.
- canonical, Open Graph, Twitter 제목과 설명을 새 검색 제목에 맞춘다.
- 배포 후 운영 URL의 상태 코드, robots, sitemap, JSON-LD, 단일 H1을 검증한다.

## 검색엔진 등록

- 네이버 서치어드바이저와 Google Search Console의 소유 확인 값은 임의로 생성하지 않는다.
- 계정 연결 또는 소유 확인 토큰을 받은 뒤 사이트맵 제출과 URL 수집·색인 요청을 진행한다.
- 반영은 검색로봇 재수집 이후 이루어지며 즉시 노출 또는 순위를 보장하지 않는다.

## 검증 기준

- title과 description이 고유하며 지정한 핵심 검색어를 자연스럽게 포함한다.
- H1은 하나만 존재한다.
- 학교명과 목적별 검색 문구가 사용자에게 보이는 본문에 각각 한 번 이상 존재한다.
- JSON-LD가 유효한 JSON이며 화면 콘텐츠와 일치한다.
- robots.txt와 sitemap.xml이 운영 도메인에서 200으로 응답한다.
- 기존 영상, 헤더 디자인, 예약 링크와 모바일 레이아웃이 정상 동작한다.
