# 리딩브레인 1:1 입시관리시스템 영상 섹션 디자인

## 목표

EDUNAP의 1:1 입시관리 프로그램 소개 영상을 리딩브레인 랜딩페이지에 추가해, 진로 설계부터 내신·수행평가·고교 선택·대학 입시까지 이어지는 관리 체계를 방문자가 빠르게 이해하도록 한다.

## 배치

`중·고등 특목 2관` 프로그램 소개 다음에 독립 섹션으로 배치한다. 중고등 입시 프로그램 설명에서 실제 관리 시스템으로 자연스럽게 이어지고, 페이지의 기존 상담 흐름은 유지한다.

## 콘텐츠 구성

- 섹션 제목: `리딩브레인 1:1 입시관리시스템`
- 소개 문구: `진로 설계부터 내신·수행평가·고교 선택·대학 입시까지, 학생 한 명의 목표에 맞춰 관리합니다.`
- 제공된 2분 3초 분량의 16:9 MP4 영상을 원본 내용 그대로 사용한다.
- 영상 아래에 다음 네 가지 핵심 영역을 간결하게 요약한다.
  1. 진로·목표 설계
  2. 내신·수행평가 관리
  3. 고교 선택 전략
  4. 대학 입시 로드맵
- 영상에 등장하는 마인드뷰, 파인드림, 유튜북, 에버컨, 수행비서, 내신체인저, 고교백서, 대학로의 상세 설명은 영상에 맡기고, 페이지에서는 중복되는 긴 설명을 추가하지 않는다.

## 시각 디자인

- 기존 랜딩페이지의 네이비, 버건디, 아이보리, 골드 색상 체계를 그대로 사용한다.
- 섹션은 영상이 중심이 되는 넓은 16:9 프레임과 네 개의 요약 카드로 구성한다.
- 영상 프레임은 기존 카드의 모서리, 테두리, 그림자 표현과 맞춘다.
- 요약 카드는 데스크톱에서 4열, 태블릿에서 2열, 모바일에서 1열로 배치한다.
- 장식용 신규 이미지나 아이콘은 추가하지 않고 숫자와 타이포그래피로 정보 구조를 만든다.

## 영상 동작 및 접근성

- 사용자가 재생 버튼을 눌러 재생하는 방식으로 제공하며 자동재생하지 않는다.
- 브라우저 기본 영상 컨트롤을 제공한다.
- `playsinline`을 적용해 모바일에서 페이지 흐름을 유지한다.
- 영상이 지원되지 않을 경우 안내 문구와 직접 재생 링크를 제공한다.
- 영상의 목적을 설명하는 접근성 레이블을 제공한다.

## 파일 처리

- 제공된 외부 MP4를 사이트의 로컬 미디어 폴더로 복사해 안정적으로 제공한다.
- 원본 파일은 변경하지 않는다.
- 파일명은 영문 소문자와 하이픈으로 정리한다.

## 검증 기준

- 섹션이 중·고등 특목 프로그램과 다음 콘텐츠 사이에서 자연스럽게 연결된다.
- 데스크톱과 360px 모바일 화면에서 영상 비율과 카드 레이아웃이 깨지지 않는다.
- 재생, 일시정지, 탐색, 음량 조절이 정상 작동한다.
- 영상 파일을 찾지 못하는 상황에서도 대체 안내가 표시된다.
- 기존 페이지의 다른 영상, 프로그램 카드, 상담 버튼 동작에 영향을 주지 않는다.
