# 커리큘럼 실제 교재 이미지 디자인

## 목표

랜딩페이지의 커리큘럼 설명에 실제 사용 교재 표지를 연결해 학습 단계와 수업 내용을 한눈에 이해할 수 있게 한다. 기존 수업 사진과 문구는 유지하며, 교재 이미지는 보조 증거 자료로 추가한다.

## 적용 교재

- 초등 문법: `문법이 쓰기다` 시리즈
- 중고등 문법: `천일문 Grammar 1·2·3`
- 중고등 리딩: `Reading Tutor` 시리즈
- 영자신문·논픽션: `NE Times`, `Reading Explorer`, `Wonderful World`
- 고등 독해: `마더텅` 고등 독해 시리즈
- 고등 문법: `마더텅` 고등 문법, `필통` 등 실제 사용 교재
- 성인 iBT TOEFL 수준: `Hackers APEX Reading for TOEFL iBT`

해커스 일반 문법 교재는 사용하지 않는다.

## 이미지 출처와 처리

- 출판사 또는 공식 판매처에서 교재명과 판본을 확인할 수 있는 실제 표지 이미지를 우선 사용한다.
- 표지를 새로 그리거나 AI로 유사 표지를 생성하지 않는다.
- 외부 이미지를 직접 링크하지 않고 프로젝트의 `images/` 아래에 로컬 자산으로 저장한다.
- 원본 비율과 표지 디자인을 왜곡하지 않는다. 카드 표시용 크기 최적화만 수행한다.
- 판본이 여러 개인 경우 현재 판매 중인 대표 판본을 선택하되, 특정 학년이나 개정판을 페이지 문구에서 단정하지 않는다.

## 배치 방식

### 중고등 특목 2관

기존 수업 사진 아래에 교재 라인 영역을 추가한다. 한 영역 안에서 다음 네 그룹을 짧은 라벨과 함께 구분한다.

1. 초등 문법 — 문법이 쓰기다
2. 중고등 문법 — 천일문 Grammar 1·2·3
3. 단계별 리딩 — Reading Tutor
4. 고등 독해·문법 — 마더텅과 필통

각 그룹은 대표 표지 1~3권을 겹친 콜라주로 보여준다. 데스크톱에서는 2열, 모바일에서는 1열로 쌓는다. 교재명을 이미지에 새로 합성하지 않고 HTML 라벨과 대체 텍스트로 제공한다.

### 영자신문·논픽션반

기존 수업 사진은 유지하고 그 아래에 `수업 교재` 콜라주를 추가한다. `NE Times`, `Reading Explorer`, `Wonderful World` 대표 표지를 한 묶음으로 보여 주며, 기존 Basic·Inter 반 설명보다 먼저 배치해 수업 내용과 시각 자료가 바로 연결되게 한다.

### 성인 iBT TOEFL 수준

추천 대상 섹션의 현재 재원 사례 문장 가까이에 `Hackers APEX Reading for TOEFL iBT` 실제 표지를 배치한다. 이 이미지는 모든 학생의 동일한 성과를 보장하는 자료가 아니라 현재 학습 가능한 상위 교재 수준의 예시임을 짧은 캡션으로 명시한다.

## 시각 규칙

- 기존 네이비·와인·크림 계열 디자인을 유지한다.
- 교재 표지는 흰색 또는 옅은 크림색 받침 위에 배치하고, 약한 그림자와 작은 회전만 사용한다.
- 표지 글자가 잘리는 강한 크롭, 과도한 원근 변형, 장식성 필터는 사용하지 않는다.
- 콜라주의 높이는 카드 설명보다 과하게 커지지 않도록 제한한다.
- 모바일에서도 각 그룹의 최소 한 권은 제목을 식별할 수 있는 크기를 확보한다.

## 접근성과 성능

- 모든 교재 이미지에 과정과 교재명이 포함된 구체적인 `alt`를 제공한다.
- 화면 밖 이미지는 지연 로딩한다.
- 가능한 경우 WebP로 최적화하되, 표지 글자가 흐려지지 않는 품질을 유지한다.
- 외부 CDN이나 판매처 이미지 URL에 런타임 의존하지 않는다.

## 검증 기준

- 지정된 모든 교재 그룹이 정확한 과정에 표시된다.
- 해커스 일반 문법 교재는 표시되지 않는다.
- 기존 수업 사진, 링크, 설명, 카드 순서는 유지된다.
- 데스크톱과 모바일에서 표지가 겹쳐 알아볼 수 없거나 카드 밖으로 넘치지 않는다.
- 이미지 경로가 모두 로컬 파일을 가리키며 누락 파일이 없다.
- 성인 TOEFL 이미지는 성과 보장이 아닌 상위 학습 수준 예시라는 캡션과 함께 표시된다.
