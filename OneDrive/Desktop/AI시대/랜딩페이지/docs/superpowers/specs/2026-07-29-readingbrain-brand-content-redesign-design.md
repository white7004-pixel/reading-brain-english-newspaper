# 리딩브레인 브랜드·콘텐츠 리디자인 명세

## 1. 목표

리딩브레인 랜딩페이지를 실제 학원 현장과 교육철학이 중심이 되는 프리미엄 영어원서 아카데미 사이트로 개편한다.

첫 화면에서 초·중등 학부모가 다음 내용을 바로 이해해야 한다.

- 영어는 시험을 위해 암기하는 과목이 아니라 충분한 노출을 통해 체득하는 언어다.
- 영어원서는 AI 시대에 필요한 글로벌 문해력, 사고력, 집중력, 끈기와 생각하는 힘을 기른다.
- 해외에 가지 않아도 리딩브레인에서 영어에 몰입하는 환경을 경험할 수 있다.
- 이렇게 쌓인 영어는 한국식 입시 성과에 연결되며, 입시 이후 대학·유학·글로벌 비즈니스에서도 계속 사용할 수 있다.

## 2. 핵심 대상

주요 고객은 영어의 장기적인 역량과 한국 입시 성과를 함께 원하는 초·중등 학부모다.

상위권·유학 지향 고객만을 대상으로 한 폐쇄적인 인상은 피한다. 대신 현재 수준과 관계없이 영어원서 노출을 시작하고, 장기적으로 입시와 글로벌 진로까지 연결할 수 있다는 가능성을 보여준다.

## 3. 브랜드 방향

브랜드 인상은 “원서가 가득한 클래식한 미국 명문 아카데미”로 정의한다.

### 색상

- 딥 네이비 `#0C354D`: 신뢰, 지성, 교육 전문성
- 버건디 `#8B1E24`: 열정, 성취, 핵심 강조
- 아이보리 `#F6F2E9`: 책과 도서관의 온기, 넓은 배경
- 뮤트 골드 `#B89A62`: 수상, 성과, 프리미엄 포인트
- 본문용 짙은 잉크색 `#18242D`: 긴 글의 가독성

권장 비중은 네이비 60%, 아이보리 30%, 버건디 8%, 골드 2%다. 골드는 성과나 인증처럼 가치가 높은 요소에만 사용한다.

밝은 청록색, 형광색, 다채로운 키즈 컬러는 제거한다. 버건디는 주요 버튼, 숫자, 핵심 문장에 제한적으로 사용한다.

## 4. 메시지 체계

### 메인 카피

**입시를 넘어, 평생 쓰는 영어.**

### 메인 서브카피

**AI 시대의 글로벌 문해력과 생각하는 힘은 영어원서에서 시작됩니다.**

### 설명 카피

영어는 외우는 과목이 아니라 충분히 노출되어 체득하는 언어입니다.  
해외에 가지 않아도 리딩브레인에서 영어로 읽고 생각하는 환경을 만듭니다.  
그렇게 쌓인 영어는 입시 1등급을 넘어, 해외 대학과 글로벌 비즈니스까지 이어집니다.

### 보조 섹션 카피

- 원서로 키운 영어는 입시에서 증명되고, 세계에서 사용됩니다.
- 해외에 가지 않아도, 영어로 생각하는 아이가 됩니다.
- 시험이 끝난 뒤에도 살아 있는 영어를 만듭니다.

“대치동에서 입증”이나 “입시 1등급”처럼 실적을 뜻하는 문장은 실제로 공개 가능한 근거와 사례가 있는 범위에서만 사용한다. 확인되지 않은 보편적 성공이나 결과 보장은 표현하지 않는다.

## 5. 첫 화면

기존의 세 영상을 하나의 시네마틱 시퀀스로 유지한다.

- 첫 번째 원본 영상은 전체 재생 중 정확히 한 번만 노출한다.
- 짧은 첫 영상을 길이에 맞추기 위해 반복하지 않는다.
- 영상 1 → 영상 2 → 영상 3 순서를 유지한다.
- 영상 사이에는 부드러운 크로스페이드를 적용한다.
- 영상 위에는 네이비 그라데이션을 사용해 카피 가독성을 확보한다.
- 모션 감소 환경에서는 실제 학원 사진 포스터를 표시한다.

메인 카피, 서브카피, 짧은 설명, 상담 행동 버튼의 네 단계만 남겨 첫 화면의 메시지 밀도를 낮춘다.

## 6. 실제 학원 미디어

장식용 이모지와 AI 생성·스톡 이미지 느낌의 사진은 제거한다.

각 교육 내용에는 의미가 연결되는 리딩브레인 실제 사진이나 영상을 배치한다.

- 영어원서·레벨 큐레이션: 원서 서가와 학생 독서 사진
- 1:1 밀착지도: 실제 개별 수업 사진
- 미국교과·논픽션: 실제 수업 및 워크북 사진
- AR TEST·레벨 성장: 시험 환경과 리포트 사진
- 발표·스피치: 실제 발표 또는 콘테스트 영상
- 학원 소개·상담: 학원 내부와 상담 현장 사진

프로그램 미디어 카드는 해당 내용을 설명하는 공식 네이버 블로그, 카카오 소식, 유튜브 또는 네이버플레이스 페이지로 연결한다. 관련 게시물이 없으면 억지로 연결하지 않고 확대 이미지 또는 섹션 내 설명으로 처리한다.

전화, 위치, 운영시간처럼 기능을 나타내는 이모지는 사진으로 대체하지 않는다. 통일된 단색 SVG 아이콘이나 텍스트 라벨로 바꾼다.

## 7. 학부모 리뷰

네이버플레이스에서 확인 가능한 리뷰 264개 중 사진이 있고 내용이 구체적인 후기를 우선 사용한다.

후기 카드는 4~6개로 구성하며 다음 주제를 고르게 보여준다.

- 편안한 상담과 체계적인 커리큘럼
- 원서, 라이팅, 스피치 등 4대 영역의 균형
- 아이의 학습 속도에 맞춘 개별 지도
- 저학년부터 꾸준히 즐겁게 다닌 경험
- 학생 관리와 행사·이벤트 만족

리뷰 원문은 의미를 바꾸지 않는 범위에서 짧게 발췌한다. 작성자명은 일부 마스킹하거나 “네이버 방문자 리뷰”로 통일하고, 프로필 사진은 사용하지 않는다.

리뷰 사진은 해당 리뷰 또는 네이버플레이스에서 공개된 학원 관련 사진만 사용한다. 각 카드는 리딩브레인 네이버플레이스 리뷰 페이지로 연결하고 “네이버 방문자 리뷰” 출처를 표시한다.

## 8. 페이지 구성

1. 헤더 및 시네마틱 실제 학원 영상
2. 교육철학: AI 시대에 영어원서가 필요한 이유
3. 해외에 가지 않아도 가능한 영어 노출 환경
4. 실제 수업 기반 프로그램 소개
5. AR TEST와 월별 성장 추적
6. 원서 역량에서 입시·대학·글로벌 진로로 이어지는 로드맵
7. 실제 사진이 포함된 학부모 리뷰
8. 리딩브레인 블로그·소식·네이버플레이스
9. 상담 및 위치

현재 페이지의 유용한 프로그램 정보는 유지하되, 같은 주장의 반복은 줄인다.

## 9. 반응형·접근성

- 모바일에서도 메인 카피와 얼굴·책·수업 장면이 겹치지 않도록 영상 초점을 조절한다.
- 사진에는 내용 중심의 대체 텍스트를 제공한다.
- 외부 콘텐츠 링크에는 출처와 이동 목적을 명확히 표시한다.
- 영상은 음소거 자동재생과 `playsinline`을 유지한다.
- 모션 감소 설정을 존중한다.
- 네이비와 버건디 텍스트·버튼은 배경과 충분한 명도 대비를 확보한다.

## 10. 검증 기준

- 첫 번째 영상이 한 시퀀스에서 한 번만 재생된다.
- 장식용 이모지와 AI·스톡 이미지가 실제 학원 미디어 또는 단색 기능 아이콘으로 교체된다.
- 모든 외부 미디어 카드의 링크가 해당 공식 콘텐츠로 연결된다.
- 리뷰 카드가 네이버 출처를 표시하고 개인정보를 과도하게 노출하지 않는다.
- 데스크톱과 모바일에서 카피 및 사진의 가독성이 유지된다.
- 메인 카피가 첫 화면에서 스크롤 없이 보인다.
- 사이트 전체에서 정의된 네이비·버건디·아이보리·골드 체계가 일관되게 사용된다.
- 배포 후 `readingbrain.co.kr`과 `www.readingbrain.co.kr`에서 최신 페이지가 제공된다.
