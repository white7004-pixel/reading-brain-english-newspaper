# 미국교과수업 커리큘럼 로드맵 설계

## 목표

리딩브레인 랜딩페이지의 `미국 공교육 교과 (ChildU)` 프로그램에 참고 사이트의 학습 체계를 반영한다. 방문자가 입문 준비과정과 MyPath 네 단계를 한눈에 이해하고, 학생 수준에 맞춘 미국 학년 기반 수업이라는 점을 파악할 수 있어야 한다.

## 반영 범위

- 기존 미국교과 프로그램 카드의 소개, 대상, 과목 구성은 유지한다.
- MyUse는 초급·중급 학생을 위한 입문 준비과정으로 간결하게 소개한다.
- MyPath는 다음 네 단계의 순차 로드맵으로 표시한다.
  1. Pathfinder: 기초 문해력과 핵심 개념 형성
  2. Adventurer: 학년 수준 독해와 교과 어휘 확장
  3. Trailblazer: 복합 지문 분석과 근거 기반 표현
  4. Homesteader: 고난도 학술 문해력과 독립적 사고·쓰기
- 단계 하단에는 `진단평가 → 개인별 학습경로 → 수업·평가 → 데이터 기반 조정`의 반복 학습 흐름을 제시한다.

## 콘텐츠 원칙

- 참고 사이트에서 확인되는 공식 단계명과 미국 학년 기반 맞춤 학습 구조를 사용한다.
- 확인되지 않은 단계별 학년, 기간, 점수 또는 성과 수치를 새로 만들지 않는다.
- 리딩브레인에서 실제 운영 중인 1:1 밀착 지도와 Language Arts, Math, Science, Social Studies 구성을 연결한다.
- MyUse와 MyPath의 역할을 혼동하지 않도록 준비과정과 본과정을 시각적으로 구분한다.

## 화면 구성

기존 미국교과 프로그램 카드 내부에 전용 커리큘럼 블록을 추가한다. 상단에는 MyUse 준비과정 안내를 작은 강조 박스로 배치하고, 아래에는 네 개의 MyPath 단계 카드를 화살표 흐름으로 연결한다. 데스크톱에서는 네 단계를 가로로, 모바일에서는 세로로 배치한다.

각 단계 카드는 영문 단계명, 한국어 핵심 설명, 학습 목표를 포함한다. 기존 네이비·버건디·아이보리 색상 체계와 카드 모서리, 타이포그래피를 그대로 사용한다.

## 접근성과 반응형

- 구조를 장식용 그래픽에 의존하지 않고 HTML 텍스트로 제공한다.
- 모바일에서는 카드가 읽기 순서대로 한 열에 표시되며 가로 스크롤을 만들지 않는다.
- 색상 외에도 제목, 번호, 문구로 준비과정과 본과정을 구분한다.
- 모션 감소 환경에서는 추가 애니메이션을 사용하지 않는다.

## 검증 기준

- 미국교과 카드 안에서 MyUse와 MyPath 네 단계가 모두 확인된다.
- 단계 순서와 명칭이 참고 사이트의 커리큘럼 구조와 일치한다.
- 기존 프로그램 정보와 링크가 유지된다.
- 데스크톱과 360px 모바일 화면에서 텍스트가 겹치거나 잘리지 않는다.
- HTML 구조 검사 및 기존 로컬 검증 스크립트가 통과한다.
