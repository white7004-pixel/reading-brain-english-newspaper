# 메인 헤더 원서 영상 디자인

## 목표

메인 헤더에서 리딩브레인의 핵심인 영어 원서, 실제 원서 학습, 디지털 연계 학습을 첫 화면에서 즉시 전달한다. 기존 헤더의 문구와 전환 요소는 유지하면서 이미지 슬라이드쇼를 실제 학원 영상으로 교체한다.

## 선택된 시각 방향

- 레이아웃: A1 시네마틱 왼쪽 정렬
- 장면 순서:
  1. 원서 도서관 — `62717138-ABFA-44CA-A0A7-92092D0865A9.mp4`
  2. 원서 학습 클로즈업 — `A81C60BE-2058-46DC-9D95-9710EB502BBF.MP4`
  3. 원서 × 디지털 학습 — `73499095-46C3-45B3-958B-5B5A4CC1D8B6.mp4`
- 장면 전환: 약 0.8초의 부드러운 크로스페이드
- 반복: 세 번째 장면에서 첫 번째 장면으로 돌아갈 때도 동일한 크로스페이드 적용

## 화면 구성

영상은 헤더 전체를 채우는 배경으로 재생한다. 왼쪽에는 진하고 오른쪽으로 갈수록 옅어지는 어두운 그라데이션을 배치해 텍스트 가독성을 확보하면서 책장과 학습 장면이 보이도록 한다.

현재 헤더의 다음 요소는 내용과 순서를 유지한다.

- `Reading Is The Only Way` 라벨
- 메인 제목과 설명
- 대상 및 프로그램 인증 배지
- 상담 예약 및 교육철학 버튼
- 하단 핵심 가치 세 항목
- 스크롤 안내

## 영상 처리

세 원본 영상은 브라우저에서 각각 전환하지 않고, 하나의 웹용 MP4로 합성한다. 단일 파일을 사용하면 전환 시 검은 화면이나 네트워크 지연이 발생할 가능성을 줄일 수 있다.

- 영상 코덱: H.264
- 오디오: 제거
- 재생 속성: `autoplay`, `muted`, `loop`, `playsinline`
- 화면 채움: `object-fit: cover`
- 데스크톱과 모바일에서 중요한 피사체가 보이도록 중심 위치를 조정
- 웹 성능을 위해 해상도와 비트레이트를 헤더 배경 용도에 맞게 최적화

## 대체 동작과 접근성

- 영상의 첫 장면을 포스터 이미지로 제공해 로딩 전 빈 화면을 방지한다.
- 영상 자동 재생이 차단되거나 파일 로딩이 실패하면 포스터 이미지를 유지한다.
- `prefers-reduced-motion: reduce` 환경에서는 영상을 재생하지 않고 포스터 이미지만 표시한다.
- 장식용 배경 영상이므로 음성과 조작 버튼은 제공하지 않는다.

## 반응형 동작

- 데스크톱: 기존 헤더 높이와 왼쪽 텍스트 구조를 유지한다.
- 태블릿·모바일: 세로 화면에 맞춰 영상을 중앙 크롭하고, 텍스트 가독성을 위해 그라데이션 농도를 조금 높인다.
- 작은 화면에서도 상담 버튼과 주요 문구가 첫 화면에 우선 노출되도록 기존 반응형 간격을 유지한다.

## 검증 기준

- 세 장면이 지정된 순서로 재생된다.
- 모든 장면 전환과 마지막-첫 장면 전환이 부드럽다.
- 데스크톱과 모바일에서 제목 및 버튼이 명확히 읽힌다.
- 기존 헤더 문구와 링크가 유지된다.
- 모션 감소 설정에서 정지 이미지가 표시된다.
- 공개 도메인에서 영상과 포스터가 HTTP 200으로 응답한다.
- 운영 사이트의 배포 HTML이 로컬 수정본과 일치한다.
