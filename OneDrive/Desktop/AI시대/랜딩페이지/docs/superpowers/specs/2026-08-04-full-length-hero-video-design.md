# 메인 헤더 영상 3개 전체 재생 설계

## 목표

선택된 원본 영상 세 개를 지정된 순서대로 겹침이나 잘림 없이 전부 이어 붙인다. 합성 영상은 메인 헤더에서 무음 자동재생되고, 마지막 영상이 끝나면 처음부터 반복된다.

## 영상 구성

1. `62717138-ABFA-44CA-A0A7-92092D0865A9.mp4`
2. `A81C60BE-2058-46DC-9D95-9710EB502BBF.MP4`
3. `73499095-46C3-45B3-958B-5B5A4CC1D8B6.mp4`

각 원본은 처음부터 끝까지 사용한다. 영상 사이에 크로스페이드, 검은 화면 또는 고정된 공백을 넣지 않는다. 서로 다른 원본 규격은 1280×720, 30fps, 정사각 픽셀로 정규화한 후 순서대로 연결한다. 출력은 H.264, yuv420p, 무음 MP4로 생성하고 빠른 웹 시작을 위해 `faststart`를 적용한다.

## 페이지 동작

메인 헤더는 합성 영상 하나를 `autoplay muted loop playsinline`으로 재생한다. 기존 포스터, 자동재생 복구 로직, 수동 재생 대체 버튼, 모션 감소 환경의 포스터 대체 동작은 유지한다.

## 오류 처리

원본 파일, `ffmpeg`, `ffprobe`가 없거나 인코딩에 실패하면 빌드 스크립트는 즉시 실패한다. 검증 스크립트는 출력 코덱·해상도·오디오 유무·총 길이·HTML 재생 속성을 검사한다.

## 검증 기준

- 합성 영상 길이는 세 원본 길이 합계와 0.25초 이내로 일치한다.
- 출력은 H.264 1280×720이고 오디오 스트림이 없다.
- 브라우저에서 영상이 일시정지되지 않고 재생 시간이 실제 증가한다.
- 오류 오버레이와 영상 오류가 없고 수동 재생 버튼은 자동재생 중 숨겨진다.
