# AR TEST 카드 개선 설계

## 목표

레벨 테스트 진단 시스템의 AR TEST 카드를 확장해 방문자가 AR 지수의 의미와 리딩브레인의 활용 방식을 정확히 이해하도록 한다.

## 반영 범위

- 기존 AR TEST 카드만 수정한다.
- 라하잉글리시 블로그의 공개 설명을 참고하되 블로그 링크와 블로그 이미지는 사용하지 않는다.
- 리딩브레인 자체 보유 이미지 `images/students-test-environment.jpg`를 카드 상단의 넓은 이미지로 표시한다.
- 스터디포스 독해훈련과 TQ TEST 카드는 이번 변경에서 수정하지 않는다.

## 콘텐츠 구성

- AR 지수는 학생 점수가 아니라 영어 원서의 난이도임을 명확히 설명한다.
- 문장 길이, 어휘 수와 난이도 등을 바탕으로 산출되는 지표라고 소개한다.
- `AR 2.5`를 미국 초등학교 2학년 5개월 수준의 도서 난이도 예시로 제공한다.
- 학생의 읽기 수준 진단과 도서 난이도를 구분해 표현한다.
- 리딩브레인 활용 흐름을 `읽기 수준 진단 → 적정 원서 선정 → 이해도 확인 → 성장 추적`으로 표시한다.
- 확인되지 않은 성과 수치와 결과 보장 표현은 제거한다.

## 화면 구성

AR TEST 카드 상단에 가로형 시험 현장 사진을 배치한다. 사진 아래에 제목, 핵심 정의, AR 2.5 예시 박스, 네 단계 활용 흐름을 순서대로 둔다. 카드 전체는 외부 페이지로 연결하지 않으며 이미지와 텍스트에도 링크를 설정하지 않는다.

기존 진단 카드의 네이비·버건디·아이보리 색상과 모서리 스타일을 유지한다. 모바일에서는 네 단계 흐름을 한 열로 표시한다.

## 접근성과 검증

- 이미지에 구체적인 대체 텍스트를 제공한다.
- AR 정의와 예시는 이미지에 의존하지 않고 HTML 텍스트로 제공한다.
- AR TEST 카드 내부에 `look_laha` 또는 네이버 블로그 링크가 없어야 한다.
- 360px 화면에서 텍스트와 단계가 겹치거나 가로로 넘치지 않아야 한다.
- 기존 TQ TEST 및 다른 진단 카드의 링크와 내용은 유지한다.
