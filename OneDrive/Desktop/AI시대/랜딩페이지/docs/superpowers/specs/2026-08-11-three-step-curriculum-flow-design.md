# 리딩브레인 3단계 학습 과정 개편 설계

## 목적

현재 5단계인 `리딩브레인 학습 과정`을 진단, 맞춤 설계, 성장 확인의 3단계로 단순화해 상담 전환에 필요한 핵심 흐름을 빠르게 이해할 수 있게 한다.

## 범위

- `index.html`의 `#curriculum` 섹션을 5개 카드에서 3개 카드로 교체한다.
- 카드 클릭 시 열리는 `curriculum-detail.html`의 단계별 상세 표시가 새 3단계 내용과 일치하도록 한다.
- 기존 레이아웃, 색상, 반응형 동작, 새 창 상세보기 방식은 유지한다.
- 다른 프로그램, 진단검사 소개, FAQ 섹션은 변경하지 않는다.

## 확정 콘텐츠

### STEP 01 종합 진단

- 핵심 문구: `AR TEST · 중고등특목영어 TEST · TQ TEST · 학습심리검사`
- 목적: 네 가지 검사를 한 단계에서 진행해 학생의 영어 수준, 독해력, 목표 과정, 학습 성향을 종합적으로 파악한다.

### STEP 02 맞춤 설계

- 핵심 문구: `1:1 학습 로드맵을 통한 개인별 커리큘럼 설정`
- 목적: 진단 결과를 바탕으로 학생별 목표와 학습 순서를 정하고 개인 커리큘럼을 설정한다.

### STEP 03 성장 확인

- 핵심 문구: `연 10회 정기고사로 성장 추적`
- 목적: 정기고사 결과로 성장을 확인하고 다음 학습 계획에 반영한다.

## 구현 원칙

- 기존 3단계와 4단계였던 `원서 정독`, `아웃풋` 카드는 학습 과정 흐름에서 제거한다.
- 카드 번호와 `data-step`, 상세 링크 쿼리를 1~3으로 연속 정렬한다.
- 각 카드의 제목, 요약, 설명, 핵심 포인트를 같은 의미로 맞춰 메인 카드와 상세 화면 사이의 불일치를 없앤다.
- 기존 CSS 구조로 3개 카드가 자연스럽게 표시되므로 별도 시각 디자인 변경은 하지 않는다.

## 검증

- 자동 검증 스크립트가 카드가 정확히 3개인지 확인한다.
- 1단계에 네 가지 검사명이 모두 포함되는지 확인한다.
- 2단계에 `1:1 학습 로드맵`과 `커리큘럼 설정`이 포함되는지 확인한다.
- 3단계에 `정기고사 10회`가 포함되는지 확인한다.
- 제거 대상인 기존 4·5단계 링크가 학습 과정 섹션에 남지 않는지 확인한다.
- 로컬 브라우저에서 데스크톱 화면과 상세보기 연결을 확인한다.
