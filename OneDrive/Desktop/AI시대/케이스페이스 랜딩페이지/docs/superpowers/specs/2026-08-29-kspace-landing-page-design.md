# 케이스페이스 오피스앤스터디 랜딩페이지 설계

## 배경

케이스페이스 오피스앤스터디(K-SPACE OFFICE & STUDY)는 경기도 안산시 단원구 광덕3로 178(고잔동, 화승타운) 6층에서 운영 중인 공유오피스·스터디룸(프라이빗 독서실) 업체다. 현재 별도의 랜딩페이지가 없고, 당근/네이버플레이스에만 정보가 흩어져 있다. 방문객이 시설을 이해하고 네이버예약으로 바로 넘어갈 수 있는 세련된 단일 페이지가 필요하다.

## 목적 / 핵심 전환

페이지의 가장 중요한 목표는 **네이버예약 페이지로의 이동**이다(방문 예약 없이 온라인에서 가격·사진 확인 후 바로 예약/결제까지 이어지는 구조). 보조 전환으로 전화 상담(010-2646-0326 / 010-5295-0326)과 카카오톡 채널 상담을 제공한다.

### 의도적으로 사용하지 않는 데이터

구글드라이브의 "ROOM" 스프레드시트에서 실제 입주자 개인정보(이름·전화번호·계약 조건·현재 계약 단가)를 발견했다. 이는 내부 운영 자료이므로 **페이지에 절대 노출하지 않는다**. 정확한 현재 요금은 하드코딩하지 않고 네이버예약 링크로 유도한다(사용자 지시사항과도 일치).

- 파일 구조:
  ```

  script.js          (갤러리 라이트박스, 스무스 스크롤, FAQ 아코디언 등 경량 인터랙션)
  ```
