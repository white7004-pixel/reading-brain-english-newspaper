# 논픽션랩 Knowledge Quest

초등 학습자가 약 3분 안에 영어 논픽션을 읽고 핵심을 찾은 뒤, 이해 퀴즈와 지식 지도로 학습을 연결하는 Next.js 앱입니다. 콘텐츠는 별도의 Studio 검수·승인·발행 절차를 통과한 버전만 학습자 화면에 공개됩니다.

## 주요 화면

- 오늘: 이어 읽기 또는 오늘의 추천 퀘스트 한 가지를 제시합니다.
- 지식 지도: 완료·추천·잠김 상태와 퀘스트 연결을 세로 경로로 보여 줍니다.
- 탐험: 검색, 분야, AR, 컬렉션 필터로 기존 라이브러리와 퀘스트를 함께 찾습니다.
- 나: 주간 읽기 시간, 퀴즈 이해도, 핵심 찾기, 분야 분포와 현재 AR 수준을 보여 줍니다.

학습 흐름은 `읽기 → 핵심 찾기 → 퀴즈 → 결과 → 지식 지도`입니다. 중단한 읽기 페이지와 퀴즈 진입 상태는 이 기기의 `localStorage`에 저장됩니다.

## Content Studio

`/studio`에서 본문, 어휘, 퀴즈, 출처와 퀘스트 메타데이터를 편집합니다. 퀘스트 준비도는 호기심 질문, 지식 한 줄, 사진·출처, 지도 위치, 학습 자료, 근거 출처, 연령 검토, 모바일 미리보기의 8개 항목을 표시합니다. 8/8은 품질 준비 상태일 뿐이며 사실·출처, 영어·AR, 연령 적합성 검수와 최종 승인을 우회하지 않습니다.

대표 사진은 로컬 파일과 한국어 대체 텍스트를 사용하고, 제작자·원본 페이지·라이선스 정보를 읽기 화면에 표시합니다. 이번 단계에서 시드 사진 출처는 Studio에서 읽기 전용입니다.

## 오프라인 동작

서비스 워커 v3는 앱 셸과 대표 퀘스트 사진 일부만 사전 저장합니다. 성공한 동일 출처 GET 응답만 런타임 캐시하며 Studio 경로, 외부 페이지, Range 요청과 실패 응답은 저장하지 않습니다. 이미 열린 퀘스트를 강제로 새 워커로 교체하지 않고 다음 탐색 시 업데이트를 적용합니다.

## 개발과 검증

```powershell
npm install
npm run dev
npm run verify
```

`npm run verify`는 Vitest, TypeScript, 프로덕션 빌드와 Playwright 모바일·데스크톱 여정을 실행합니다.

## 이번 마일스톤 범위 밖

나머지 85개 글의 사진 큐레이션, 전체 100개 글의 완전한 관계 지도, 클라우드 계정·동기화, 구독·Play Billing, Android 패키징은 후속 작업입니다.
