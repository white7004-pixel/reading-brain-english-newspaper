# 논픽션랩 제품 설계

- 작성일: 2026-08-17
- 제품명: 논픽션랩 (Nonfiction Lab)
- 슬로건: 매일 3분, 영어로 세상을 읽다
- 앱스토어 표기안: 논픽션랩: 3분 배경지식 영어
- 상태: 사용자 승인 완료

## 1. 제품 정의

논픽션랩은 매일 3분 분량의 수준별 영어 논픽션을 읽으며 영어 독해력과 배경지식을 함께 키우는 전 연령 학습 서비스다. 초등 1~2학년의 첫 논픽션 읽기부터 국제학교·사립초 학생, 중고등학생, 수능 학습자와 성인의 전문지식 확장까지 지원한다.

제품의 핵심 차별점은 하나의 지식 주제를 여러 읽기 난이도로 다시 구성한다는 점이다. 사용자는 자신의 읽기 수준에서 시작해 같은 주제의 더 깊은 글로 이동할 수 있다.

## 2. 제품 원칙

1. 한 번의 핵심 학습은 약 3분 안에 끝난다.
2. 영어 능력과 배경지식 성장을 동시에 설계한다.
3. 학년보다 읽기 수준을 우선하되, 난이도와 연령 적합성을 별도로 관리한다.
4. AI가 만든 초안은 교사·편집자 검수 후에만 공개한다.
5. 원문을 복제하지 않고 여러 신뢰 자료를 바탕으로 독자적인 교육 콘텐츠를 만든다.
6. 초등 저학년에게 쉽지만 고등학생과 성인에게 유치하지 않은 경험을 제공한다.

## 3. 대상 사용자

### 학습자

- 초등 1~2학년: 그림, 오디오와 3~5개의 짧은 문장으로 시작한다.
- 초등 고학년·국제학교·사립초 학생: 교과 연계 지식과 영어 독해를 함께 확장한다.
- 중고등학생: 학술 어휘, 수능·모의고사 빈출 소재와 독해 유형을 학습한다.
- 성인: 인문, 철학, 경제, 기술, 자기계발과 전문지식을 영어로 읽는다.

### 연결 사용자

- 보호자: 자녀 프로필, 권장 난이도, 학습 현황과 취약 어휘를 관리한다.
- 교사·편집자: AI 초안, 사실, 출처, 영어 난이도와 연령 적합성을 검수한다.
- 관리자: 사용자, 콘텐츠 버전, 오류 신고, 발행 이력과 권한을 관리한다.

고등학생과 성인은 보호자 연결 없이 독립 계정으로 사용할 수 있다. 보호자와 교사 연결은 선택 기능이다.

## 4. 온보딩과 레벨 설정

사용자는 가입할 때 다음 중 하나를 선택한다.

1. 보유한 AR 지수를 직접 입력한다.
2. 약 3분의 어휘·문장·독해 테스트로 시작 수준을 추정한다.
3. 테스트를 건너뛰고 가장 쉬운 수준부터 시작한다.

프로필에는 사용자가 입력한 외부 AR 지수와 논픽션랩이 학습 결과로 추정한 권장 난이도를 별도 값으로 보관하고 표시한다. 사용자는 언제든 수치를 수정하거나 다시 테스트할 수 있다.

ATOS/AR 계열 난이도는 읽기 어려움을 나타내는 참고 척도로만 사용한다. 앱에서 공식 인증 점수를 표시하거나 상업적으로 활용하려면 권리 및 라이선스를 별도로 확인한다. 공식 산정이 아닌 값은 `논픽션랩 추정 난이도`라고 명시한다.

## 5. 콘텐츠 체계

### 분야

- 자연·과학: 동물, 환경, 우주, 생명, 물리, 기술
- 사회·세계: 역사, 지리, 경제, 정치, 법, 세계문화
- 인문·철학: 인간, 윤리, 사고법, 고전, 철학자와 핵심 사상
- 예술·체육: 미술, 음악, 건축, 디자인, 영화, 스포츠 과학과 인물
- 자기계발: 습관, 시간관리, 목표, 집중, 공부법, 의사소통, 리더십
- 진로·전문지식: 의학, 공학, 경영, 심리, 미디어, AI, 금융
- 시험·학술 독해: 수능·모의고사 빈출 소재, 논문과 과학잡지의 핵심 개념

### 자료와 저작 원칙

TED, 공식 유튜브 채널, 뉴스, 논문, 과학잡지, 시험 지문 및 논픽션 도서에서 주제와 사실을 조사한다. 원문을 그대로 전재하거나 단순 축약하지 않는다. 핵심 개념을 교차검증한 뒤 독자적인 3분 교육 지문으로 작성하고 출처, 저자 또는 기관, 발행일, 원문 링크를 기록한다.

영상은 제공자가 허용한 공식 임베드 기능만 사용한다. 유료 기사, 도서와 시험 자료는 이용 조건을 확인하며 허가되지 않은 본문을 저장하거나 노출하지 않는다.

### 콘텐츠 메타데이터

각 지문에는 다음 정보가 필요하다.

- 제목, 요약, 분야와 세부 주제
- 읽기 난이도와 난이도 산정 방식
- 관심 연령 및 아동 적합성
- 예상 읽기 시간과 단어 수
- 핵심 어휘, 학습 목표와 독해 유형
- 오디오, 이미지와 영상 임베드 정보
- 출처 목록과 검수 이력
- 발행 상태, 버전과 수정 이력

## 6. 콘텐츠 제작과 검수

콘텐츠 상태는 다음 순서로 이동한다.

`아이디어 → 자료 수집 → AI 초안 → 사실 검수 → 영어·난이도 검수 → 연령 적합성 및 권리 확인 → 최종 승인 → 발행`

AI 초안 상태의 콘텐츠는 학습자에게 노출하지 않는다. 검수자는 사실 정확성, 서로 다른 출처 간 일치 여부, 문법, 목표 난이도, 문제와 정답의 타당성, 아동 적합성, 출처와 이용 조건을 확인한다. 오류 신고가 접수되면 관리자는 콘텐츠를 즉시 비공개로 전환할 수 있으며 모든 수정 이력을 남긴다.

## 7. 핵심 학습 경험

한 번의 학습 흐름은 다음과 같다.

`흥미로운 질문 → 3분 영어 논픽션 → 문장별 오디오·어휘 도움 → 이해 퀴즈 → 배경지식 확장 → XP·연속 학습 보상 → 연결 주제 추천`

저학년 콘텐츠는 그림, 큰 글자, 짧은 페이지와 읽어주기를 강조한다. 상위 수준에서는 개념 정의, 논리 구조, 그래프, 출처 비교와 수능형 문항을 추가한다. 사용자는 같은 주제의 쉬운 버전 또는 심화 버전으로 이동할 수 있다.

## 8. 혼합형 홈과 탐색

홈 화면은 개인화된 `오늘의 3분 지식`을 가장 큰 행동으로 제시한다. 그 아래에서 관심 분야와 새로운 분야를 탐색할 수 있다. 탐색 화면은 분야, 읽기 난이도, 관심 연령과 예상 시간 필터를 제공한다.

추천 비율의 기본값은 다음과 같다.

- 관심 분야 및 최근 학습과 관련된 콘텐츠: 70%
- 사용자의 지식 범위를 넓히는 새로운 분야: 30%

비율은 고정된 노출 보장이 아니라 추천 후보를 구성하는 목표값이다. 콘텐츠 품질, 연령 적합성, 중복 방지와 학습 필요가 우선한다.

## 9. 개인화와 난이도 조절

추천 엔진은 현재 권장 난이도, 관심 분야, 완료율, 이해 퀴즈 정답률, 읽기 속도, 오디오·번역·힌트 사용량, 복습 결과와 최근 주제 중복을 사용한다.

한두 번의 결과로 난이도를 크게 바꾸지 않는다. 여러 학습 결과에서 일관된 성공 또는 어려움이 확인될 때 권장 난이도를 0.1~0.3 단위로 조절한다. 수준 하향은 실패로 표현하지 않고 더 잘 이해하기 위한 맞춤 추천으로 안내한다.

## 10. 정보 구조

하단 기본 탐색은 네 영역으로 구성한다.

- 홈: 오늘의 3분 지식, 연속 학습, 현재 권장 난이도, 관심 분야
- 탐험: 전 분야 지식 도서관과 필터
- 학습: 진행 중인 글, 저장한 글, 어휘와 복습
- 나: AR 정보, 성장 기록, 관심 분야, 연결 계정과 설정

보호자와 편집자 기능은 역할에 따라 별도 대시보드로 제공한다.

## 11. 디자인 시스템

승인된 디자인 방향은 `현대적인 지식 탐험`이다.

- 기본색: 깊은 포레스트 그린
- 강조색: 밝은 라임
- 배경: 따뜻한 오프화이트와 연한 세이지
- 형태: 넓은 여백, 둥근 카드, 큰 핵심 행동 버튼
- 활자: 앱 UI는 선명한 산세리프, 긴 영어 지문은 읽기 좋은 세리프 선택 가능
- 분위기: 저학년에게 친근하면서 성인에게도 유치하지 않은 절제된 게임성

듀오링고처럼 다음 학습 행동을 명확히 하고, 시각적 지식 앱처럼 개념과 연결 관계를 카드와 일러스트로 전달한다. 특정 서비스의 캐릭터, 화면 구조나 브랜드 표현을 복제하지 않는다.

## 12. 데이터 흐름과 오프라인 처리

학습 이벤트는 `읽기 시작 → 페이지 진행 → 지원 기능 사용 → 퀴즈 응답 → 완료` 순서로 기록한다. 추천 갱신은 완료된 학습과 검증된 이벤트를 기준으로 수행한다.

현재 열어 둔 지문과 필요한 오디오는 가능한 범위에서 기기에 저장한다. 연결이 끊겨도 읽기를 계속할 수 있고, 결과는 로컬 대기열에 저장한 뒤 연결 회복 시 중복 없이 동기화한다. 동기화 실패는 학습 기록을 삭제하지 않고 재시도 상태로 남긴다.

## 13. 개인정보와 아동 안전

- 초등 저학년은 보호자가 가입과 초기 설정을 대신할 수 있다.
- 아동 계정에는 광고, 공개 프로필, 사용자 간 메시지를 제공하지 않는다.
- 추천과 학습에 필요하지 않은 개인정보는 수집하지 않는다.
- 보호자 연결, 계정 복구와 데이터 삭제 흐름을 명확히 제공한다.
- 출시 대상 국가의 아동 개인정보 및 보호자 동의 요건은 출시 전 법률 검토한다.

## 14. 오류 처리

- 출처 또는 정답 오류: 신고 접수, 관리자 검토, 즉시 비공개 가능, 수정 후 재승인
- 오디오·영상 실패: 텍스트 학습은 계속 가능하고 다시 시도 기능 제공
- 레벨 추정 불가: 안전한 시작 범위를 추천하고 추가 테스트 제안
- 동기화 실패: 로컬 학습 결과 보존, 자동 재시도 및 상태 표시
- 보호자 연결 오류: 학습자 기록을 유지한 채 연결만 재시도

## 15. 검증 기준

### 제품 검증

- 신규 사용자가 도움 없이 레벨 설정 또는 건너뛰기를 완료한다.
- 홈에서 오늘의 학습을 즉시 찾고 시작할 수 있다.
- 핵심 학습이 목표 시간인 약 3분 안에 완료된다.
- 같은 주제의 쉬운 글과 심화 글을 명확히 구분할 수 있다.

### 콘텐츠 검증

- 모든 발행 콘텐츠에 검수자, 출처와 버전이 존재한다.
- 퀴즈의 정답과 해설이 지문 및 출처와 일치한다.
- 읽기 난이도와 관심 연령이 별도로 검토된다.
- 저학년, 고학년과 성인 표본 사용성 테스트를 수행한다.

### 기술 검증

- 오프라인 읽기 후 결과가 중복 없이 동기화된다.
- 학습자와 보호자·편집자 권한이 분리된다.
- 콘텐츠 비공개 전환이 모든 학습 화면에 빠르게 반영된다.
- 추천 난이도 변경 이유를 기록하고 되돌릴 수 있다.

## 16. 초기 출시 범위

초기 제품은 모바일 웹/PWA로 출시하고 사용성과 학습 데이터를 검증한 뒤 iOS·안드로이드 앱으로 확장한다.

초기 범위에는 학습자 온보딩, AR 입력 또는 레벨 테스트, 오늘의 3분 지식, 지식 탐색, 영어 리딩·오디오·어휘, 이해 퀴즈, 기본 보상, 학습 기록, 보호자 연결, 콘텐츠 검수·발행이 포함된다.

학교·학원 단위의 복잡한 반 편성, 결제 요금제, 공개 커뮤니티, 실시간 채팅과 고급 경쟁 기능은 후속 단계로 둔다.

## 17. 후속 구현 순서

1. 디자인 토큰과 모바일 앱 셸
2. 학습자 온보딩 및 프로필
3. 오늘의 학습과 탐색 홈
4. 3분 리딩, 오디오, 어휘와 퀴즈
5. 학습 기록, 보상과 기본 개인화
6. 콘텐츠 스튜디오와 검수 워크플로
7. 보호자 대시보드
8. 오프라인 동기화, 접근성, 보안과 출시 검증
