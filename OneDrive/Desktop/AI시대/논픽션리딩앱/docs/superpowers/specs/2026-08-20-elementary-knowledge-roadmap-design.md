# 초등 학년별 논픽션 지식 로드맵 설계

## 목표

초등 1~6학년 학습자가 각 학년에서 알아야 할 논픽션 지식을 학년별·분야별로 연속해서 탐색할 수 있게 한다. 모든 데이터와 화면은 프로젝트 내부에서 동작하며 외부 AI, 유료 API, 원격 데이터베이스를 사용하지 않는다.

## 범위

- 대상: 한국 초등 1~6학년
- 분야: 과학, 역사, 사회, 세계문화, 예술, 철학·자기계발
- 난이도 표기: 한국 학년 권장 기준과 AR 지수를 함께 표시
- 상태: `읽기 가능`과 `준비 중`을 구분
- 기존 공개 글과 일치하는 주제는 바로 읽기 화면으로 연결
- 향후 중·고등 과정으로 확장할 수 있는 데이터 구조 사용

## 데이터 구조

`lib/knowledge-roadmap.ts`에 정적 TypeScript 데이터로 저장한다. 각 로드맵 항목은 다음 정보를 가진다.

- 고유 ID
- 한국 학년(1~6)
- 분야
- 한국어 지식 주제명
- 짧은 학습 목표
- 권장 AR 최솟값과 최댓값
- 학년 내 표시 순서
- 연결된 공개 글 ID(선택)

별도 서버나 생성 호출 없이 빌드에 포함되며, TypeScript 타입 검사로 누락과 잘못된 값을 잡는다. 앱 콘텐츠 자체는 임시 파일이 아니라 버전 관리되는 로컬 데이터에 저장한다.

## 화면 구성

기존 탐색 화면 상단에 `학년별 지식 로드맵` 영역을 추가한다.

1. 초1~초6 학년 탭을 가로로 제공한다.
2. 선택한 학년의 필수 지식을 분야별 묶음으로 표시한다.
3. 각 항목에 분야, 주제, 학습 목표, `초등 N학년`, `AR X.X~Y.Y`를 표시한다.
4. 연결된 공개 글이 있으면 `읽기 시작` 버튼을 제공한다.
5. 아직 글이 없으면 비활성 상태의 `준비 중` 표시를 제공한다.
6. 기존 검색·분야·난이도 필터와 글 목록은 로드맵 아래에 그대로 유지한다.

## 콘텐츠 구성 원칙

- 각 학년은 여섯 분야를 고르게 포함한다.
- 같은 지식이 여러 학년에 반복될 때는 학습 목표의 깊이가 달라야 한다.
- AR 범위는 영어 문장과 어휘 난이도의 권장치이며 한국 학년 기준을 대체하지 않는다.
- 로드맵은 학습 순서를 안내하지만 사용자의 읽기를 제한하지 않는다.
- 초기 버전은 학년당 12개, 총 72개 지식 항목을 제공한다.

## 동작과 데이터 흐름

탐색 화면은 로드맵 데이터에서 선택 학년에 해당하는 항목을 가져와 순서대로 렌더링한다. `articleId`가 있는 항목은 현재 공개 글 목록에서 글을 찾아 기존 `onOpen` 흐름을 호출한다. 연결 글이 없거나 게시되지 않은 경우에는 준비 중 상태로 유지한다.

## 오류 처리

- 중복 ID, 범위를 벗어난 학년, 잘못된 AR 범위는 테스트에서 실패시킨다.
- 연결된 글 ID가 존재하지만 공개 글에서 찾을 수 없으면 읽기 버튼을 노출하지 않는다.
- 선택 학년의 항목이 비어 있으면 안내 문구를 표시한다.

## 검증

- 로드맵 데이터가 1~6학년 각각 12개 항목을 갖는지 검사
- 각 학년에 모든 분야가 포함되는지 검사
- ID 고유성, 학년 범위, 표시 순서, AR 범위 유효성 검사
- 연결된 글이 있을 때만 읽기 동작이 가능한지 컴포넌트 테스트
- 학년 탭 전환 시 해당 학년 항목만 표시되는지 테스트
- 기존 탐색 필터와 학습 흐름 회귀 테스트

## 비용 원칙

구현과 실행 모두 로컬 파일, 기존 Next.js 앱, 기존 테스트 도구만 사용한다. 외부 AI 생성, 유료 API, 원격 저장소 호출은 하지 않는다.

## 핵심단어·핵심문장 찾기 활동

모든 공개 지문에는 기존 핵심 어휘 목록과 하나의 핵심문장을 정답 데이터로 저장한다. 핵심문장은 반드시 해당 지문의 문장과 정확히 일치해야 하며 편집실에서 발행할 때 공개 읽기 데이터에 보존한다.

읽기 화면에서는 학습자가 `핵심 찾기` 활동을 열고 핵심단어와 핵심문장을 직접 고른다. 핵심단어는 본문에 이미 표시되는 어휘 중에서 선택하며, 핵심문장은 현재 페이지의 문장 단위 버튼 중 하나를 선택한다. `정답 확인`을 누르기 전에는 정답을 노출하지 않는다. 확인 후 선택 결과와 올바른 핵심단어·핵심문장을 화면에 표시하고 다시 시도할 수 있게 한다.

채점은 지문에 저장된 로컬 데이터만 비교하며 네트워크나 생성형 AI를 호출하지 않는다. 핵심문장이 현재 페이지에 없으면 해당 페이지에서는 문장 선택을 허용하되 정답 확인 결과에 올바른 문장을 안내한다.
