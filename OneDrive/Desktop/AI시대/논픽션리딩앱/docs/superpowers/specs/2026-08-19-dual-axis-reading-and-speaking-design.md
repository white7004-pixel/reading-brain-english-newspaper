# 학년 지식 × AR 맞춤 읽기·말하기 학습 설계

## 목표

논픽션랩의 추천 기준을 영어 난이도 하나에서 두 축으로 확장한다.

- 영어 난이도는 미국 학년 대응 AR 수준을 사용한다.
- 배경지식은 한국 교육과정의 초등학교 3~6학년 범위를 사용한다.
- 기본 추천은 학생의 한국 학년에서 필요한 지식을 현재 AR 수준의 영어로 읽게 한다.
- 학생은 필요하면 학년별 또는 AR별 목록을 따로 탐색할 수 있다.
- 읽기 속도, 단어 발음 듣기, 선택 낭독 녹음과 보상을 한 학습 흐름 안에 제공한다.
- 녹음 파일은 저장하지 않고 현재 화면에서만 재생한 뒤 자동 폐기한다.
- 추상 배너 대신 논픽션 주제에 맞는 실사형 대표 이미지를 사용하되 스튜디오 승인을 거친다.

## 범위

첫 릴리스는 한국 교육과정 초3~초6을 대상으로 한다. 과학, 사회·역사, 문화·예술, 철학·사고, 자기계발, 세계문화 영역을 기존 `KnowledgeDomain`과 연결한다. 한국 학년은 지식의 적합성을 뜻하고 AR은 영어 문장의 난이도를 뜻한다. 두 값은 서로 대체하지 않는다.

기존 AR 1 지문 85편은 한 번에 자동 변환하지 않는다. 구조와 검증 규칙을 먼저 적용하고, 스튜디오의 작업 대기열에서 배치 단위로 확장·검토·발행한다. 확장 전 지문도 계속 읽을 수 있지만 `legacy-length` 상태로 표시하여 추천 우선순위를 낮춘다.

## 콘텐츠 모델

### 주제와 영어 변형 분리

새 `KnowledgeTopic`은 한국 학년의 배경지식 단위를 나타낸다.

- `id`
- `grade`: `3 | 4 | 5 | 6`
- `subject`: 교과 또는 지식 영역
- `curriculumLabel`: 관리자가 확인할 수 있는 교육과정 연결 설명
- `titleKo`
- `learningGoalKo`
- `essentialQuestionKo`

각 `Article`은 하나의 `topicId`에 연결되며 다음 메타데이터를 가진다.

- `grade`: 한국 학년
- `topicId`: 배경지식 주제
- `ar`: 미국 AR 영어 난이도
- `lengthStatus`: `legacy | standard`
- `heroImage`: 생성·검토된 대표 이미지 정보

같은 `topicId`를 가진 여러 글은 동일한 배경지식을 서로 다른 AR 난이도로 설명한다. 추천은 먼저 학생 학년과 주제를 고른 뒤, 학생 AR에 가장 가까운 발행 글을 선택한다. 정확히 일치하는 변형이 없으면 같은 학년·주제 안에서 가장 가까운 AR을 사용하고 그 사실을 화면에 표시한다.

### 표준 지문 길이

AR 1 표준 글은 다음 조건을 모두 충족해야 한다.

- 최소 2페이지
- 전체 12문장 이상
- 페이지당 5~7문장 권장
- 전체 160~220단어
- 문장당 최대 단어 수와 어휘 수는 AR 밴드 검증 규칙을 따른다.
- 퀴즈 4문항: 내용 이해 2, 추론 1, 어휘 1

화면의 줄 수는 기기 너비에 따라 달라지므로 저장·검증 기준으로 사용하지 않는다. 스튜디오 미리보기에는 모바일 기준 예상 줄 수만 참고 정보로 보여준다.

## 학습자 경험

### 탐색

홈과 탐색 화면은 세 경로를 제공한다.

1. `맞춤 학습`: 한국 학년과 현재 AR을 함께 사용한다.
2. `학년별`: 초3~초6의 주제 순서로 탐색한다.
3. `AR별`: 기존처럼 영어 난이도로 탐색한다.

카드에는 `초5 배경지식 · AR 2.3`처럼 두 기준을 함께 표시한다. 프로필에서 한국 학년과 AR을 각각 변경할 수 있다.

### 읽기 속도

읽기 화면이 활성화된 동안 본문 읽기 시간만 누적한다. 다음 시간은 제외한다.

- 단어 설명 창이 열린 시간
- 발음 재생 시간
- 단어 또는 페이지 녹음 시간
- 브라우저 탭이나 앱이 백그라운드인 시간
- 사용자가 읽기 화면을 떠난 시간

모든 페이지를 읽은 뒤 다음 식으로 WPM을 계산한다.

`WPM = 반올림(본문 단어 수 / 실제 읽기 초 × 60)`

실제 읽기 시간이 10초 미만이면 비정상 기록으로 보고 WPM을 저장하지 않는다. 학습 시도에는 `readingActiveSeconds`, `wordsPerMinute`를 저장한다. 결과 화면은 이번 WPM을, 프로필은 최근 기록과 유효 기록의 평균을 보여준다.

### 발음 듣기

어려운 단어 팝업에 `발음 듣기`를 추가한다. 우선 브라우저의 Web Speech API로 영어 음성을 재생하여 별도 음원 비용을 만들지 않는다. 지원되지 않거나 음성 로딩에 실패하면 발음기호는 계속 제공하고 명확한 안내를 표시한다. 재생 이벤트는 기존 `audio_play` 분석 이벤트와 단어 정보를 함께 기록한다.

### 선택 녹음

단어 팝업에는 `따라 말하기`, 각 읽기 페이지에는 `이 페이지 낭독하기`를 제공한다. 구현은 `MediaRecorder`를 사용한다.

- 시작 전에 마이크 권한을 요청한다.
- 거부되거나 지원되지 않으면 읽기와 퀴즈는 그대로 진행된다.
- 녹음 중에는 경과 시간과 중지 버튼을 보여준다.
- 녹음 후 현재 화면에서 한 번 이상 재생할 수 있다.
- 단어 팝업 닫기, 페이지 이동, 글 종료 또는 컴포넌트 해제 시 object URL과 Blob 참조를 즉시 폐기한다.
- IndexedDB, localStorage, 서버 또는 분석 이벤트에는 음성 데이터를 저장하지 않는다.
- 음성 정확도 자동 평가는 하지 않는다.

## XP 보상

한 학습 시도의 보상은 다음과 같다.

- 퀴즈 완료: 25 XP
- 퀴즈 만점: 추가 10 XP
- 단어 녹음: 단어당 2 XP, 글당 최대 8 XP
- 페이지 녹음: 페이지당 5 XP, 글당 최대 10 XP
- 모든 페이지 녹음: 추가 5 XP

최소 2초 이상 녹음된 항목만 완료로 인정한다. 같은 시도에서 같은 단어나 페이지를 반복 녹음해도 한 번만 보상한다. 녹음 원본 대신 `recordedWordKeys`, `recordedPageIndexes`의 완료 여부만 세션 메모리에 유지하고, 시도 완료 시 개수와 `speakingXpAwarded`만 저장한다. 퀴즈 완료 시 한 번 계산하여 새로 고침이나 중복 제출로 XP가 반복 지급되지 않게 기존 attempt ID 중복 방지를 사용한다.

## 스튜디오 경험

### 교육과정과 변형 관리

스튜디오는 다음 항목을 편집·검증한다.

- 한국 학년, 교과 영역, 주제, 학습 목표
- 연결된 AR 변형 목록과 빠진 난이도
- 페이지 수, 문장 수, 단어 수, 퀴즈 구성
- 동일 주제의 변형 간 핵심 사실 일치 여부
- 기존 짧은 글의 확장 대기 상태

발행 검증은 표준 길이, 주제 연결, AR 밴드, 출처, 언어·연령 검토를 모두 통과해야 한다. 기존 발행 글은 마이그레이션 중 즉시 차단하지 않고 `legacy-length` 배지와 확장 작업으로 관리한다.

### 실사형 대표 이미지

대표 이미지는 자동 생성 어댑터를 통해 만들되 관리자가 `대표 이미지 생성`을 눌렀을 때만 외부 생성 요청을 보낸다. 초안 저장이나 화면 렌더링만으로 생성 요청을 보내지 않아 비용을 통제한다.

생성 프롬프트에는 제목, 핵심 개념, 학년, 시각 주제와 다음 고정 조건을 포함한다.

- 사실적인 교육 사진 또는 고품질 논픽션 다큐멘터리 사진 스타일
- 어린이에게 안전하고 선정적이지 않은 장면
- 이미지 안의 글자, 로고, 워터마크 금지
- 실제 특정인을 닮게 만들지 않음
- 본문에서 확인되지 않은 사실이나 시대 요소를 추가하지 않음

`HeroImage`는 생성 상태, 임시 URL, 승인된 자산 URL, 대체 텍스트, 프롬프트, 생성 시각, 승인자와 승인 시각을 보관한다. 생성 결과는 미리보기 상태이며 `approved`가 되기 전에는 학습자 화면에 노출하지 않는다. 생성 실패 시 재시도 버튼과 기존 시각 테마 대체 화면을 유지한다. 재생성은 기존 승인 이미지를 덮어쓰지 않고 새 후보를 만든다.

## 데이터 마이그레이션

학습자 상태 스키마를 다음 버전으로 올린다.

- 프로필에 `koreanGrade` 추가
- 학습 시도에 `readingActiveSeconds`, `wordsPerMinute`, `recordedWordCount`, `recordedPageCount`, `speakingXpAwarded` 추가

기존 프로필의 학년은 알 수 없으므로 첫 실행에 한 번 선택하도록 하고, 선택 전에는 AR별 추천을 유지한다. 기존 attempt의 새 필드는 `undefined`로 보존하여 과거 기록을 삭제하지 않는다.

스튜디오 글은 주제·학년·대표 이미지 필드를 추가한다. 기존 글은 자동으로 임의 학년에 배정하지 않고 `curriculum-unassigned` 작업 대기열로 보낸다.

## 오류 및 개인정보 처리

- 마이크 권한 거부는 학습 실패가 아니다.
- 녹음 Blob과 object URL은 화면 전환 시 반드시 해제한다.
- 음성 데이터나 음성에서 추출한 정보는 분석·저장·업로드하지 않는다.
- Web Speech API가 없으면 발음기호를 대체 수단으로 유지한다.
- 대표 이미지 생성 키가 없거나 요청이 실패하면 스튜디오에 오류를 표시하되 글 편집은 계속할 수 있다.
- 승인 이미지가 없으면 기존 테마 기반 대체 배너를 표시한다.

## 테스트 전략

### 단위 테스트

- WPM 계산과 10초 미만 기록 제외
- 읽기 타이머의 일시 정지·재개
- 말하기 XP 상한과 중복 방지
- 학년과 AR의 이중 추천 및 가까운 AR 대체
- 학습자·스튜디오 상태 마이그레이션
- 표준 길이와 퀴즈 구성 검증

### 컴포넌트 테스트

- 단어 발음 재생 성공·실패
- 마이크 권한 허용·거부·미지원
- 단어 및 페이지 녹음 완료 상태
- 페이지 이동과 화면 종료 시 object URL 해제
- 결과 화면의 WPM과 XP 세부 내역
- 학년별·AR별·맞춤 탐색 전환
- 스튜디오 이미지 생성·재생성·승인·실패 상태

### 브라우저 테스트

- 초5와 AR 2.3 프로필이 맞춤 글을 추천받는 흐름
- 두 페이지를 모두 읽은 뒤에만 퀴즈로 이동하는 흐름
- 선택 녹음 후 추가 XP가 한 번만 지급되는 흐름
- 새로 고침 뒤 WPM 기록은 남고 음성은 남지 않는지 확인
- 승인된 대표 이미지만 학습자 화면에 표시되는지 확인

## 구현 순서

1. 콘텐츠·학습자 스키마와 순수 계산 함수
2. 학년 선택과 이중 추천
3. 읽기 타이머와 WPM 기록
4. 단어 발음 재생
5. 임시 녹음과 XP 보상
6. 스튜디오 교육과정·AR 변형 관리
7. 대표 이미지 생성·승인 흐름
8. 기존 85편의 단계적 확장 및 학년 주제 배정

각 단계는 테스트 우선으로 구현하고, 기존 데이터와 학습 흐름이 유지되는지 단계마다 검증한다.
