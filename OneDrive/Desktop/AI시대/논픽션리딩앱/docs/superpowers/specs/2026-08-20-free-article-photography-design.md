# 신규 AR 1 지문 무료 실사 대표 사진 설계

## 목표와 범위

신규 AR 1 7차 배치 15편에 생성형 이미지 API를 사용하지 않는 실사 대표 사진을 연결한다. 사진은 홈 추천 카드, 탐색 목록 카드, 읽기 화면 상단에 표시한다. 이번 작업은 15편 파일럿이며, 같은 구조를 이후 나머지 지문에 확장할 수 있어야 한다.

## 사진 공급 원칙

- Wikimedia Commons에서 CC BY, CC BY-SA 또는 퍼블릭 도메인으로 명시된 사진만 사용한다.
- 각 파일 설명 페이지와 API 메타데이터를 함께 확인한다.
- 사진은 앱의 `public/article-images/ar1-batch-07/`에 내려받아 외부 핫링크에 의존하지 않는다.
- 인물의 얼굴이나 민감한 장소가 중심인 사진, 어린이에게 부적절한 사진, 워터마크나 홍보 문구가 들어간 사진은 제외한다.
- 글의 핵심 개념을 직접 보여주는 사진을 우선하고, 단순한 장식 사진은 피한다.
- 같은 사진을 여러 글에 중복 사용하지 않는다.
- 원본 비율을 보존하며 카드와 배너에서는 CSS `object-fit: cover`로 자른다. 원본 자체를 편집해 2차 저작물을 만들지 않는다.

## 데이터 모델

공개 글 데이터에 선택적 `heroImage`를 추가한다.

```ts
type ArticleHeroImage = {
  src: string;
  altKo: string;
  sourcePageUrl: string;
  title: string;
  creator: string;
  licenseName: string;
  licenseUrl: string;
  isModified: false;
};
```

`LibrarySeed`, 스튜디오 초안, 공개 `Article` 변환 과정에서 이 값을 보존한다. 기존 글은 필드가 없어도 정상 동작한다. 사진 메타데이터는 15편의 시드와 분리된 매니페스트에 글 ID별로 관리하여 긴 본문 파일을 더 복잡하게 만들지 않는다.

## 화면 표시

### 홈 추천 카드

기존 테마 배경 영역을 대표 사진으로 교체한다. 사진이 없는 글은 현재 `visualTheme` 배너를 그대로 사용한다. 카드의 텍스트 대비를 위해 텍스트와 사진이 겹치면 일정한 어두운 오버레이를 적용한다.

### 탐색 목록 카드

기존 별표 썸네일 영역에 대표 사진을 표시한다. 장식용 배경이 아니라 글 내용을 전달하므로 한국어 대체 문구를 제공한다.

### 읽기 화면

상단 테마 배너를 넓은 대표 사진으로 교체하고, 바로 아래에 사진 제목·작가·라이선스를 작은 출처 문구로 표시한다. 작가 또는 라이선스를 누르면 원문 파일 페이지와 라이선스 페이지가 새 탭에서 열린다. 사진이 없거나 로딩에 실패하면 기존 테마 배너로 되돌아간다.

## 사진 선정과 수집 흐름

1. 각 글의 제목, 핵심 개념, `visualTheme`로 Commons 후보를 찾는다.
2. 후보의 파일 설명 페이지에서 실제 사진 여부, 정확성, 어린이 적합성을 확인한다.
3. API `imageinfo`와 `extmetadata`로 작가, 라이선스, 라이선스 URL, 원본 URL을 기록한다.
4. 표시 폭에 충분한 Commons 썸네일을 내려받아 로컬 자산으로 저장한다.
5. 글별 한국어 대체 문구를 작성하고 매니페스트에 연결한다.
6. 자동 검증과 브라우저 시각 검증을 수행한다.

## 오류 처리

- `heroImage`가 없으면 기존 `visualTheme`가 유일한 표시 경로가 된다.
- 이미지 요청이 실패하면 같은 화면에서 테마 배너로 전환한다.
- 메타데이터가 불완전하거나 허용 라이선스가 아니면 해당 사진은 등록하지 않는다.
- 사진 한 장을 찾지 못해도 다른 글이나 앱 전체의 빌드를 막지 않되, 15편 파일럿 완료 검증은 누락 ID를 보고한다.

## 테스트

### 단위 테스트

- 15편 모두 서로 다른 로컬 이미지와 완전한 출처 메타데이터를 가진다.
- 이미지 경로는 `public/article-images/ar1-batch-07/`의 실제 파일과 대응한다.
- 라이선스 이름과 URL은 허용 목록에 포함된다.
- 시드에서 스튜디오 초안과 공개 글로 변환할 때 `heroImage`가 보존된다.
- 기존 이미지 없는 글은 스키마와 변환을 계속 통과한다.

### 컴포넌트 테스트

- 홈, 탐색, 읽기 화면이 대표 사진과 대체 문구를 표시한다.
- 읽기 화면이 작가·라이선스 링크를 표시한다.
- 이미지가 없거나 로딩에 실패하면 테마 배너를 표시한다.

### 브라우저 검증

- 데스크톱과 모바일 너비에서 카드 사진과 읽기 배너의 크롭을 확인한다.
- 텍스트 가독성, 사진 찌그러짐, 깨진 이미지, 출처 링크를 확인한다.

## 완료 기준

- 신규 15편 모두 고유한 실사 사진을 가진다.
- 생성형 이미지 API나 유료 이미지 API를 호출하지 않는다.
- 사진 자산과 출처 메타데이터가 저장소에 함께 남는다.
- 세 화면에서 사진이 보이고 실패 시 기존 테마가 유지된다.
- 전체 단위 테스트, 타입 검사, 프로덕션 빌드와 브라우저 검증이 통과한다.
