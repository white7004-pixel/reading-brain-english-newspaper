# 논픽션랩 콘텐츠 검수·승인 스튜디오 설계

- 작성일: 2026-08-17
- 상태: 사용자 승인 완료
- 대상 릴리스: 학습자 MVP 다음 단계

## 1. 목표

한 명의 편집자가 3분 영어 논픽션 콘텐츠를 작성하고, 사실·출처, 영어·AR, 연령 적합성을 순서대로 검수한 뒤 승인·발행할 수 있는 콘텐츠 스튜디오를 만든다. 검수가 끝나지 않은 콘텐츠는 학습자 앱에 노출하지 않는다.

첫 버전은 단일 편집자 운영에 집중한다. 다만 데이터에는 작성자, 검수자, 승인자를 별도 필드로 보존해 향후 역할 분리형 협업으로 확장할 수 있게 한다.

## 2. 범위

### 포함

- `/studio` 전용 콘텐츠 운영 화면
- 상태별 콘텐츠 대시보드와 목록
- 콘텐츠 작성·수정
- 단계별 검수 체크리스트
- 학습자용 모바일 미리보기
- 최종 승인, 발행, 발행 취소
- 콘텐츠 버전과 검수 기록
- 승인된 발행 콘텐츠만 학습자 앱에 제공

### 제외

- 여러 편집자의 로그인과 권한 관리
- 서버 데이터베이스와 실시간 협업
- AI를 이용한 자동 초안 생성
- 외부 출처의 자동 수집·스크래핑
- 출판사 라이선스 계약 관리

이 기능들은 후속 단계에서 현재 데이터 인터페이스를 유지한 채 추가한다.

## 3. 정보 구조

스튜디오는 학습자 화면과 분리된 `/studio` 진입점으로 제공한다.

### 대시보드

- 초안, 검수 중, 승인 대기, 발행 완료 수
- 최근 수정 콘텐츠
- 다음 검수가 필요한 콘텐츠

### 콘텐츠 목록

- 상태, 분야, 논픽션랩 추정 AR, 권장 연령 필터
- 제목과 주제 검색
- 최근 수정순 정렬
- 새 콘텐츠 생성

### 콘텐츠 편집

- 기본 정보, 난이도, 학습 내용, 어휘, 퀴즈, 출처, 미디어 편집
- 자동 임시 저장과 명시적 저장 상태 표시
- 단계별 검수 영역
- 학습자 모바일 미리보기
- 승인 및 발행 관리

## 4. 콘텐츠 데이터

각 콘텐츠는 다음 정보를 가진다.

### 기본 정보

- 고유 ID와 버전
- 영어 제목과 한국어 제목
- 영어 요약과 한국어 요약
- 분야와 세부 주제
- 상태와 최종 수정 시간

### 난이도와 대상

- 논픽션랩 추정 AR
- AR 산정 메모
- 권장 최소·최대 연령
- 예상 읽기 시간(초)
- 아동 주의 요소

논픽션랩 추정 AR은 공식 ATOS 인증 점수로 표시하지 않는다. 읽기 난이도와 연령 적합성은 별도 항목으로 검수한다.

### 학습 내용

- 배경지식 학습 목표
- 영어 본문
- 핵심 문장
- 핵심 개념 설명

### 어휘

- 단어
- 발음 표기
- 쉬운 영어 뜻
- 한국어 뜻
- 본문 맥락에 맞는 예문

### 퀴즈

- 내용 확인, 추론, 어휘 중 문제 유형
- 질문과 선택지
- 정답
- 해설
- 근거가 되는 본문 구간

### 출처와 미디어

- 기관 또는 저자
- 자료명
- 발행일
- 원문 URL
- 논문, 뉴스, 잡지, 시험 자료, 영상 등 자료 유형
- 출처가 뒷받침하는 사실 메모
- 이미지 주소 또는 임베드가 허용된 영상 주소
- 사용 조건 확인 메모

원문을 저장하거나 복제하지 않는다. 출처를 교차 확인해 독립적인 교육 지문으로 재구성한다. 영상은 제공자가 허용한 공식 임베드 기능만 사용한다.

### 운영 기록

- 작성자, 검수자, 승인자
- 각 검수 단계의 완료자와 완료 시간
- 수정 사유와 수정 이력
- 승인 버전과 현재 편집 버전
- 발행 및 발행 취소 시간

## 5. 상태와 워크플로

콘텐츠 상태는 다음 순서로만 이동한다.

`초안 → 사실·출처 검수 완료 → 영어·AR 검수 완료 → 연령 적합성 검수 완료 → 최종 승인 → 발행`

- 앞 단계가 끝나지 않으면 다음 단계를 완료할 수 없다.
- 어느 단계에서든 콘텐츠를 수정하면 영향을 받는 현재 단계와 이후 단계의 완료 기록을 해제한다.
- 최종 승인 후 발행 버튼이 활성화된다.
- 발행 후 수정은 새 편집 버전에서 진행한다. 기존 발행 버전은 새 버전이 승인·발행될 때까지 유지한다.
- 발행 취소는 학습자 앱에서 해당 콘텐츠를 즉시 제외하지만 버전과 검수 기록은 보존한다.

## 6. 단계별 검수 기준

### 사실·출처 검수

- 출처가 한 개 이상 존재한다.
- 핵심 사실이 신뢰할 수 있는 출처와 일치한다.
- 원문 URL과 발행 정보가 유효하다.
- 출처별로 뒷받침하는 사실이 기록되어 있다.
- 원문 복제가 아닌 독립적 재구성이다.
- 미디어의 사용 또는 임베드 조건을 확인했다.

### 영어·AR 검수

- 문법과 문장 구조가 정확하다.
- 설정한 난이도에 어휘와 문장 길이가 적절하다.
- 목표 읽기 시간이 3분 이내다.
- 어휘 설명이 본문 맥락과 일치한다.
- 모든 퀴즈에 정답, 해설, 본문 근거가 있다.

### 연령 적합성 검수

- 권장 연령에 주제와 표현이 적합하다.
- 저학년 콘텐츠는 짧은 문장과 구체적 설명을 사용한다.
- 폭력, 공포, 성인 주제 등 주의 요소를 표시한다.
- 철학, 예술, 자기계발 콘텐츠의 핵심 개념을 왜곡하거나 지나치게 단순화하지 않는다.

### 최종 승인

- 모든 필수 입력과 앞 단계의 체크리스트가 완료됐다.
- 모바일 학습자 미리보기를 확인했다.
- 승인자 이름과 승인 시간이 기록된다.
- 승인된 현재 편집 버전만 발행할 수 있다.

## 7. 학습자 앱 연동

콘텐츠 저장소는 편집 중인 항목과 학습자에게 제공할 발행 버전을 분리한다. 학습자 앱은 `published` 상태이면서 승인 버전이 존재하는 항목만 조회한다.

초기 로컬 구현에서는 버전이 있는 브라우저 저장소를 사용한다. 스튜디오와 학습자 앱은 같은 공개 콘텐츠 조회 인터페이스를 사용해 이후 서버 데이터베이스로 교체해도 화면 코드를 크게 바꾸지 않게 한다.

발행 취소 시 공개 조회 결과에서 즉시 제외한다. 이미 완료한 학습 기록은 삭제하지 않고 제목과 콘텐츠 ID를 포함한 기록으로 유지한다.

## 8. 오류 처리와 데이터 보호

- 필수 입력이 없으면 해당 검수 단계의 완료 버튼을 비활성화하고 누락 항목을 표시한다.
- 저장 실패 시 편집 중인 폼을 유지하고 재시도할 수 있게 한다.
- 발행 실패 시 기존 발행 버전을 유지한다.
- 손상되거나 지원하지 않는 저장 데이터는 안전한 초기 스키마로 복구하되 기존 원본은 별도 백업 키에 보존한다.
- 출처 URL 형식과 영상 제공자를 검사하고 허용되지 않은 임베드는 차단한다.
- 삭제 대신 보관 또는 발행 취소를 기본 동작으로 사용한다.

## 9. 시각 디자인

기존 논픽션랩의 포레스트 그린, 라임 포인트, 따뜻한 오프화이트 배경을 유지한다. 학습자 화면보다 정보 밀도를 높이되 모바일에서도 핵심 작업이 가능하게 한다.

- 상태는 색상과 텍스트를 함께 사용한다.
- 왼쪽에는 콘텐츠 정보, 오른쪽에는 검수 진행률과 미리보기를 배치하는 반응형 레이아웃을 사용한다.
- 작은 화면에서는 편집, 검수, 미리보기를 탭으로 전환한다.
- 위험한 발행 취소 동작은 확인 절차를 둔다.
- 키보드 탐색, 명확한 포커스, 충분한 대비를 제공한다.

## 10. 테스트 기준

### 도메인 테스트

- 검수 단계를 건너뛸 수 없다.
- 출처가 없으면 사실 검수를 완료할 수 없다.
- 불완전한 퀴즈가 있으면 영어·AR 검수를 완료할 수 없다.
- 본문 수정 시 관련 검수 단계와 이후 승인이 해제된다.
- 승인된 현재 버전만 발행할 수 있다.
- 발행 후 수정해도 기존 발행 버전은 유지된다.

### UI 테스트

- 대시보드의 상태별 수가 실제 데이터와 일치한다.
- 필터와 검색으로 콘텐츠를 찾을 수 있다.
- 누락 항목이 해당 입력 영역에 표시된다.
- 모바일 미리보기가 실제 학습자 리더와 같은 공개 데이터를 사용한다.

### 통합 테스트

- 초안 생성부터 검수, 승인, 발행까지 완료할 수 있다.
- 미승인 콘텐츠는 학습자 홈과 탐색에 나타나지 않는다.
- 발행 후 학습자 앱에 나타난다.
- 발행 취소 후 추천과 탐색에서 사라진다.
- 새 편집 버전이 승인되기 전에는 이전 발행 버전이 계속 제공된다.

## 11. 완료 조건

- 한 명의 편집자가 샘플 콘텐츠를 작성하고 모든 검수 단계를 완료할 수 있다.
- 모든 단계의 완료자, 완료 시간, 수정 이력이 저장된다.
- 승인·발행되지 않은 콘텐츠는 학습자 앱에 노출되지 않는다.
- 발행 취소와 새 버전 편집이 기존 학습 기록을 손상하지 않는다.
- 기존 학습자 앱의 단위 테스트, 타입 검사, 프로덕션 빌드, 모바일 E2E가 계속 통과한다.
