# 제한시간 낭독 녹음과 초1~고3·AR 12점대 확장 설계

## 목표

학습자가 페이지의 원어민 오디오를 들은 뒤 제한시간 안에 직접 낭독을 녹음하고, 녹음 시간과 제한시간 준수 여부를 확인할 수 있게 한다. 콘텐츠 모델과 탐색 구조는 초등 1학년부터 고등 3학년까지 12개 학년과 AR 0.x부터 12.x까지 13개 구간을 지원한다. 아직 콘텐츠가 없는 구간은 정상적인 준비 중 상태로 표시한다.

발음 정확도나 누락 단어를 자동 평가하는 기능, 서버 업로드, 교사에게 녹음을 전송하는 기능은 이번 범위에 포함하지 않는다.

## 사용자 흐름

각 본문 페이지의 학습 순서는 다음과 같다.

1. 학습자가 원어민 오디오를 재생한다.
2. 오디오 재생이 끝나면 낭독 연습을 시작할 수 있다.
3. 시작 버튼을 누르면 3초 준비 카운트다운 후 마이크 녹음이 시작된다.
4. 녹음 중에는 남은 시간과 경과 시간을 함께 표시한다.
5. 학습자가 완료 버튼을 누르거나 제한시간이 끝나면 녹음을 종료한다.
6. 결과 화면에 실제 녹음 시간, 제한시간, 제한시간 준수 여부, 완료 상태를 표시한다.
7. 학습자는 녹음을 재생하거나 다시 녹음할 수 있다.
8. 낭독 결과가 만들어진 뒤 기존 핵심 찾기와 다음 학습 단계로 진행한다.

원어민 오디오가 없는 콘텐츠에서는 브라우저 음성 합성 재생이 끝난 뒤 같은 흐름을 제공한다. 오디오를 재생할 수 없는 환경에서는 안내를 표시하되, 콘텐츠 설정에 따라 낭독 연습을 직접 시작할 수 있게 한다.

## 녹음과 저장

녹음은 브라우저의 `MediaRecorder`와 `getUserMedia`를 사용하는 클라이언트 기능으로 구현한다. 녹음 파일은 외부 서버로 전송하지 않는다.

- 최신 녹음 파일은 글 ID와 페이지 번호를 키로 하여 IndexedDB에 저장한다.
- 같은 글과 페이지에서 다시 녹음하면 기존 파일을 교체한다.
- 학습 상태와 완료 시도 기록에는 바이너리 파일이 아니라 녹음 시간, 제한시간, 제한시간 준수 여부, 완료 시각만 저장한다.
- 저장 실패 시에도 현재 세션에서 녹음 재생과 다시 녹음은 가능하게 유지하고, 로컬 저장 실패를 안내한다.
- 녹음 URL은 사용 후 해제하여 메모리 누수를 막는다.

## 제한시간 정책

콘텐츠는 `oralReadingLimitSeconds` 선택 필드를 가질 수 있다. 값이 없으면 권장 학년의 기본값을 사용한다.

| 학년 | 기본 제한시간 |
|---|---:|
| 초1~초2 | 90초 |
| 초3~초4 | 75초 |
| 초5~초6 | 60초 |
| 중1~중3 | 50초 |
| 고1~고3 | 45초 |

Studio 제작 화면에서 콘텐츠별 제한시간을 양의 정수 초 단위로 수정할 수 있다. 콘텐츠에 권장 학년도 없으면 안전한 기본값 60초를 사용한다.

제한시간 안에 사용자가 완료 버튼을 누르거나 마지막 순간까지 녹음이 정상 저장되면 `withinLimit`을 참으로 기록한다. 제한시간 자동 종료도 완료된 낭독으로 인정하되 결과 화면에서 “제한시간을 모두 사용했어요”라고 구분한다. 권한 거절, 녹음 장치 오류, 빈 녹음은 완료로 기록하지 않는다.

## 학년 모델

학년은 다음 12개 고정 식별자를 사용한다.

- `elementary-1` ~ `elementary-6`
- `middle-1` ~ `middle-3`
- `high-1` ~ `high-3`

표시 이름은 초1~초6, 중1~중3, 고1~고3이다. `Article`과 `StudioArticle`에 권장 학년 필드를 추가한다. 기존 `interestBand`, 나이 범위, AR 값은 유지하며 학년과 AR을 서로 독립적인 축으로 취급한다.

기존 콘텐츠에 학년 정보가 없으면 현재 `interestBand`와 AR 값을 기반으로 표시용 권장 학년을 유도하되, 원본 데이터는 임의로 덮어쓰지 않는다.

학년은 추천과 탐색을 위한 메타데이터일 뿐 학습 접근 권한으로 사용하지 않는다. 예를 들어 초등 1학년 학습자의 현재 AR이 4점대라면 초등 1학년 추천 목록에 묶이지 않고 AR 4.x 콘텐츠를 직접 열어 학습할 수 있어야 한다.

## AR 모델

탐색 및 제작 대상 AR 구간은 다음 13개다.

- `ar0` = 0.1~0.9
- `ar1` = 1.0~1.9
- 이후 같은 규칙으로 `ar11`까지 구성
- `ar12` = 12.0~12.9

콘텐츠에는 기존처럼 정확한 소수 AR 값인 `difficulty.value`를 저장한다. 구간은 필터, 빈 상태, 제작 현황 표시를 위한 파생값이다. 사용자 직접 입력과 콘텐츠 제작 유효 범위의 상한은 12.9로 통일한다.

현재 AR1 중심 제작 규칙은 그대로 보존한다. AR2 이상 콘텐츠가 아직 없다는 이유로 공개 콘텐츠 검증이나 앱 시작이 실패하지 않게 한다. 향후 각 구간의 문장 길이와 단어 수 기준을 별도로 추가할 수 있도록 구간 메타데이터를 확장 가능한 구조로 둔다.

## 화면 구성

### 리더

- 원어민 오디오 버튼 아래에 낭독 연습 상태 영역을 둔다.
- 상태는 대기, 준비 카운트다운, 녹음 중, 결과, 오류로 명확히 구분한다.
- 녹음 중에는 접근 가능한 라이브 타이머와 녹음 중 표시를 제공한다.
- 결과에는 녹음 재생, 다시 녹음, 결과 요약을 제공한다.
- 마이크 권한 안내에는 브라우저 설정을 확인한 뒤 재시도할 수 있는 버튼을 제공한다.

### 학년·AR 탐색

- 기존 초등 학년 로드맵을 12개 학년 탐색 구조로 확장한다.
- 학년 선택은 초등·중등·고등 그룹으로 나누어 모바일에서도 지나치게 긴 탭 행을 피한다.
- 학년 화면과 독립된 `AR별 도서` 진입점을 제공한다.
- `AR별 도서`에서는 AR 0.x~12.x 구간 카드를 바로 선택할 수 있다.
- AR 구간을 선택하면 해당 구간의 공개 콘텐츠를 보여주고, 도서 카드를 누르면 추가 단계 없이 학습을 시작한다.
- 학습자의 등록 학년과 콘텐츠 권장 학년이 달라도 클릭이나 학습 시작을 차단하지 않는다.
- 학습자의 현재 AR이 있으면 해당 AR 구간을 먼저 강조하되 다른 모든 구간도 계속 선택할 수 있다.
- 선택한 학년과 AR 조합에 공개 콘텐츠가 없으면 “콘텐츠 준비 중”과 현재 선택값을 표시한다.

### Studio

- 권장 학년 선택 필드
- 정확한 AR 값 입력 필드(0.1~12.9)
- 학년 기본값을 보여주는 낭독 제한시간 필드
- 직접 설정값을 지우면 학년 기본값으로 복귀하는 동작

## 데이터 구조

주요 새 타입은 다음과 같다.

```ts
type GradeLevel =
  | "elementary-1" | "elementary-2" | "elementary-3"
  | "elementary-4" | "elementary-5" | "elementary-6"
  | "middle-1" | "middle-2" | "middle-3"
  | "high-1" | "high-2" | "high-3";

type OralReadingResult = {
  articleId: string;
  pageIndex: number;
  durationMs: number;
  limitSeconds: number;
  withinLimit: boolean;
  stoppedByLimit: boolean;
  completedAt: string;
};
```

`Article`에는 선택 필드 `gradeLevel`과 `oralReadingLimitSeconds`를 추가한다. 기존 저장 데이터 호환을 위해 학습 시도 기록의 새 낭독 필드도 선택 필드로 추가한다. Studio 저장소와 공개 스키마는 이전 버전 데이터에 필드가 없어도 읽을 수 있어야 한다.

## 오류와 개인정보 보호

- 마이크 권한은 사용자가 낭독 시작을 눌렀을 때만 요청한다.
- 권한 거절과 장치 부재를 구분 가능한 사용자 메시지로 변환한다.
- 녹음 중 페이지를 나가면 녹음을 안전하게 중단하고 스트림 트랙을 닫는다.
- 녹음 데이터는 외부로 전송하지 않는다는 안내를 낭독 영역에 표시한다.
- 지원하지 않는 브라우저에서는 앱 전체가 중단되지 않고 낭독 기능만 사용할 수 없게 한다.

## 테스트

- 학년 12개와 AR 13개 구간의 순서, 범위, 경계값을 단위 테스트한다.
- 초등 1학년 학습자가 AR 4.x 구간을 선택하고 해당 도서를 바로 시작할 수 있는지 테스트한다.
- 권장 학년 불일치가 콘텐츠 노출이나 학습 시작을 차단하지 않는지 테스트한다.
- 학년별 기본 제한시간과 콘텐츠별 재정의를 단위 테스트한다.
- 마이크 시작, 3초 준비, 타이머 감소, 수동 종료, 자동 종료, 재녹음을 가짜 타이머와 MediaRecorder 대역으로 컴포넌트 테스트한다.
- 권한 거절, 빈 녹음, 지원하지 않는 브라우저의 복구 화면을 테스트한다.
- 녹음 메타데이터의 저장과 기존 학습 기록 호환성을 테스트한다.
- Studio에서 학년, AR, 제한시간을 편집하고 검수 무효화 규칙이 적용되는지 테스트한다.
- 브라우저 테스트에서 오디오 완료 후 낭독 연습, 결과 확인, 핵심 찾기 진입까지 검증한다.
- 전체 Vitest, TypeScript 검사, Next.js 빌드, 관련 Playwright 테스트를 실행한다.

## 구현 경계

이번 구현은 로컬 녹음과 완료 여부 기록까지만 포함한다. 음성 인식, 발음 점수, 교사 피드백, 클라우드 동기화, 녹음 공유, 초1~고3 실제 콘텐츠 제작은 후속 범위다.
