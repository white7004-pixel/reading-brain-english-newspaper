# 학습자 읽기 레벨 재설정 설계

- 작성일: 2026-08-18
- 상태: 사용자 승인 완료
- 대상 릴리스: 학습자 MVP 후속 개선

## 1. 목표

학습자가 온보딩 이후에도 언제든 읽기 레벨을 다시 정할 수 있게 한다. 방법은 두 가지이며 학습자가 고른다.

- 3분 레벨 테스트를 다시 본다.
- 자신의 AR 지수를 직접 선택한다.

레벨을 바꿔도 지금까지 쌓은 학습 기록은 그대로 유지한다.

## 2. 현재 문제

프로필 화면의 `레벨 다시 확인하기` 버튼은 `onClick` 없이 렌더링만 된다. 눌러도 아무 일도 일어나지 않으므로, 온보딩을 한 번 지나가면 레벨을 바꿀 방법이 학습 데이터 전체 삭제밖에 없다.

온보딩의 레벨 판정 흐름을 그대로 재사용할 수도 없다. `Onboarding`의 완료 처리는 `createDefaultLearnerState().profile`을 기반으로 프로필을 새로 만들기 때문에, 재설정에 사용하면 이름·연속 학습일·XP가 초기화된다.

## 3. 범위

### 포함

- 레벨 판정 로직을 순수 모듈로 분리
- 온보딩과 프로필이 함께 쓰는 레벨 선택 컴포넌트
- 학습 기록을 보존하는 레벨 갱신 함수
- 프로필 화면의 재설정 진입점 연결

### 제외

- 온보딩 화면 구성 변경
- 레벨 테스트 문항 개편
- AR 입력을 선택형 UI로 교체
- 서버 동기화

## 4. 구조

### `lib/placement-test.ts`

온보딩에 인라인으로 있던 문항과 계산을 옮긴다.

- `PLACEMENT_QUESTIONS`: 문항, 선택지, 정답, 문항별 레벨
- `estimateDifficulty(answers)`: 맞힌 문항 중 가장 높은 레벨을 반환하고, 맞힌 문항이 없으면 `0.5`
- `AR_ENTRY_MIN`, `AR_ENTRY_MAX`, `isValidArEntry(value)`: 직접 선택 값의 유효 범위

화면에 의존하지 않는 순수 모듈이므로 단위 테스트로 판정 규칙을 고정한다.

### `components/level-check.tsx`

레벨을 정하는 두 경로를 담고 결과값만 돌려주는 재사용 컴포넌트다.

- 입력: 취소 처리, 결과 처리, 화면 문구
- 출력: `{ enteredAr, estimatedDifficulty }` 한 쌍
- 학습자 프로필 구조를 알지 못한다. 저장도 하지 않는다.

이 경계 덕분에 온보딩과 프로필이 같은 흐름을 공유하면서도 서로의 상태 처리 방식에 묶이지 않는다.

### `components/onboarding.tsx`

환영 화면과 관심 분야 선택은 그대로 두고, 테스트·입력·결과 화면을 `LevelCheck`에 위임한다. 학습자가 보는 동작은 바뀌지 않는다.

### `lib/learner-store.ts`

`updateLearnerLevel(state, level)`를 추가한다. 레벨 필드만 바꾸고 나머지 상태는 그대로 돌려주는 순수 함수다.

### `components/profile-screen.tsx`

`레벨 다시 확인하기`가 `LevelCheck`를 연다. 완료하면 상위로 레벨을 전달하고 프로필 화면으로 돌아온다.

### `components/learner-app.tsx`

전달받은 레벨로 `updateLearnerLevel`을 호출하고 저장한 뒤 화면 상태를 갱신한다.

## 5. 레벨 값 규칙

추천 로직은 `estimatedDifficulty ?? enteredAr` 순서로 목표 난이도를 읽는다. 따라서 두 값이 동시에 남아 있으면 직접 선택한 값이 반영되지 않는다.

**한쪽을 정하면 다른 쪽을 비운다.**

- 테스트로 정하면 `estimatedDifficulty`만 남기고 `enteredAr`은 `null`
- 직접 선택하면 `enteredAr`만 남기고 `estimatedDifficulty`는 `null`

온보딩의 기존 완료 처리와 같은 규칙이다.

## 6. 화면 흐름

프로필 → `레벨 다시 확인하기` → 방법 선택

- 3분 레벨 테스트: 문항 진행 → 결과 확인 → 적용
- AR 직접 선택: 값 입력 → 적용

어느 단계에서든 취소하면 레벨을 바꾸지 않고 프로필로 돌아온다.

## 7. 데이터 보존

레벨을 바꿔도 다음 값은 변하지 않는다.

- 완료한 콘텐츠 목록과 학습 시도 기록
- XP와 연속 학습일, 마지막 학습 날짜
- 이름과 관심 분야
- 저장한 단어

## 8. 테스트 기준

### 도메인 테스트

- 모든 문항을 맞히면 가장 높은 문항 레벨을 반환한다.
- 맞힌 문항이 없으면 `0.5`를 반환한다.
- 유효 범위를 벗어난 AR 값은 적용할 수 없다.
- `updateLearnerLevel`은 학습 기록, XP, 연속 학습일, 관심 분야를 보존한다.
- `updateLearnerLevel`은 반대편 레벨 필드를 `null`로 비운다.

### UI 테스트

- 프로필의 `레벨 다시 확인하기`가 레벨 선택 흐름을 연다.
- 테스트 경로를 마치면 추정 난이도가 프로필에 반영된다.
- 직접 선택 경로를 마치면 입력한 AR 지수가 프로필에 반영된다.
- 취소하면 기존 레벨이 유지된다.
- 레벨을 바꾼 뒤에도 완료한 지식 개수가 그대로다.

### 통합 테스트

- 온보딩의 기존 세 경로가 이전과 동일하게 동작한다.
- 수업을 완료한 뒤 레벨을 바꿔도 완료 기록과 XP가 유지된다.

## 9. 완료 조건

- 프로필에서 테스트 또는 직접 선택으로 레벨을 다시 정할 수 있다.
- 레벨 변경이 추천 결과에 즉시 반영된다.
- 레벨 변경이 기존 학습 기록을 손상하지 않는다.
- 기존 단위 테스트, 타입 검사, 프로덕션 빌드, E2E가 계속 통과한다.
