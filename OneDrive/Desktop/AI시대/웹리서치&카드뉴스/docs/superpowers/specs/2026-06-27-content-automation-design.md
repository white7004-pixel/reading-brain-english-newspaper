# 리딩브레인 영어학원 — 콘텐츠 자동화 시스템 설계

**날짜:** 2026-06-27
**작성자:** 샬롯원장 (Charlotte Kim)
**프로젝트:** 웹리서치 & 카드뉴스 자동화

---

## 1. 프로젝트 개요

리딩브레인 영어학원(광명시)의 SNS 콘텐츠(카카오채널 소식 + 카드뉴스)를 매주 월/수/금 자동으로 생성·저장하는 시스템.

**핵심 목표:**
- 웹 리서치 → 블로그 글 2000자 + 카드뉴스 5장 이미지 자동 생성
- 카카오채널 비즈니스에 임시저장
- 원장님께 카톡 알림 발송

## 2. 교육 철학 & 콘텐츠 방향

**리딩브레인 핵심 철학:**
- "영어를 넘어 세상을 읽는 힘을 기르는 곳"
- 스티븐 크라센 언어습득론 기반 (읽기 = 유일한 방법)
- Bilingual(이중언어자) 양성 목표
- 1:1 프리미엄 밀착지도 / 파닉스 → 수능 9단계 커리큘럼
- 학원에 의존하지 않는 영어 독립 추구
- 슬로건: "최상위 1%를 리드하는 리딩브레인"

**글쓰기 스타일 (샬롯원장 블로그 기준):**
- 오프닝: "안녕하세요. 영어를 넘어 세상을 읽는 힘, 광명 리딩브레인 영어학원입니다 :)"
- 학부모 공감형 질문으로 본문 시작
- 구분선: ━━━━━━━━━━ + ▶ 섹션 헤더
- 연구·논문 인용으로 신뢰도 강화 (교수명, 대학명, 연구 수치 포함)
- ✅ 체크리스트형 핵심 정리
- 따뜻한 CTA로 마무리 (상담 유도)
- 지역 SEO: 제목에 [일직동영어학원] 또는 [광명영어학원] 태그
- 톤: 학부모 대상, 존댓말, 따뜻하고 전문적

## 4. 전체 아키텍처

```
[Windows 작업 스케줄러]
        ↓ 월/수/금 오전 9:00
[main.js 실행]
        ↓
[1단계] 웹 리서치 (Playwright)
   → 당일 테마 키워드로 네이버·구글 자동 검색
   → 최신 교육 뉴스·논문·블로그 내용 수집
        ↓
[2단계] 콘텐츠 생성 (Claude API)
   → 블로그 글 2000자 생성 (샬롯원장 스타일 + 리딩브레인 철학 반영)
   → 카드뉴스 5장 카피 생성
        ↓
[3단계] 카드뉴스 이미지 생성 (Playwright)
   → HTML 템플릿에 카피 삽입
   → 스크린샷 → PNG 5장 저장
        ↓
[4단계] 카카오채널 비즈니스 자동화 (Playwright)
   → business.kakao.com 자동 로그인
   → 글·이미지 업로드 → 임시저장
        ↓
[5단계] 카톡 알림 발송
   → "✅ 콘텐츠 임시저장 완료" 메시지 발송
```

## 5. 카드뉴스 디자인 스펙

**구성 (5장):**
1. **표지** — 브랜드 헤더 + 메인 카피 + 해시태그
2. **본문 1** — 핵심 내용 소제목 + 포인트 3개
3. **본문 2** — 핵심 내용 소제목 + 포인트 3개
4. **본문 3** — 핵심 내용 소제목 + 포인트 3개
5. **CTA** — 마무리 문구 + 전화번호 + 카카오채널 안내

**디자인 스펙:**
- 사이즈: 1080×1080px (인스타그램 정사각형 호환)
- 컬러: 딥네이비(#1B2B5E) + 골드(#C9A84C) + 화이트(#FFFFFF)
- 폰트: Noto Sans KR (Bold 제목 / Regular 본문)
- 출력: PNG 5장

## 7. 카카오 연동

### 카카오채널 비즈니스 자동화 (Playwright)
1. business.kakao.com 접속
2. 카카오 계정 자동 로그인 (.env에서 읽기)
3. 채널 관리자 → 소식 작성
4. 블로그 2000자 입력
5. 카드뉴스 이미지 5장 업로드
6. [임시저장] 클릭 → 완료 확인

### 카톡 완료 알림 메시지 형식
```
✅ 리딩브레인 콘텐츠 준비 완료

📅 YYYY-MM-DD (월) | 영어원서·문해력

📝 블로그 글: 임시저장 완료
🖼️ 카드뉴스: 5장 생성 완료

👉 카카오채널 비즈니스에서 확인 후 발행해주세요!
⏰ 생성 시각: 오전 9:03
```

**알림 발송 방법:** 카카오 메시지 API (나에게 보내기) 사용
- 별도 비즈 심사 불필요
- 카카오 개발자 앱 등록 후 REST API 키 발급
