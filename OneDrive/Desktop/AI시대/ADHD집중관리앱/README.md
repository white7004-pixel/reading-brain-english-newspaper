# 몽글

중고등학생부터 성인까지 사용하는 로컬 우선 ADHD 집중·일정·메시지 예약 PWA입니다. 고정된 다섯 탭, 한 번에 한 가지 집중, 루틴, 일정 구조, 메시지 초안을 Studio 3D 인터페이스와 몽글 캐릭터로 제공합니다.

## 시작하기

```powershell
cd web
npm install
npm run dev
```

## 검증

```powershell
cd web
npm run test:run
npm run build
npm run e2e
```

세부 검증 기준은 `docs/testing/monggle-pwa-foundation.md`를 참고하세요.
