# 몽글 PWA 검증 가이드

## 로컬 실행

```powershell
cd web
npm install
npm run dev
```

## 자동 검증

```powershell
cd web
npm run test:run
npm run build
npm run e2e
```

단위·컴포넌트 테스트는 로컬 데이터, 메시지 정책, Studio 3D 테마, 캐릭터 상태를 검증한다. Playwright는 모바일·데스크톱에서 다섯 탭 유지, 캐릭터와 하단 메뉴의 비충돌, 운영체제 움직임 줄이기 적용을 검증한다.

## 캐릭터와 접근성

몽글은 화면 가장자리의 세 안전 지점만 순환하며 포인터 입력과 키보드 포커스를 받지 않는다. 설정의 `몽글 캐릭터 표시`를 끄면 새로고침 후 숨겨진다. 앱 또는 운영체제에서 움직임 줄이기를 사용하면 캐릭터는 이동하지 않고 정지한다.

## 데이터와 메시지 제약

할 일, 예약 초안, 설정은 기기 안에 저장되며 외부 AI API나 유료 크레딧을 사용하지 않는다. Slack, Telegram, KakaoWork는 향후 공식 연동 자격이 준비되면 자동 발송할 수 있다. 카카오톡은 일반 채팅 자동 예약 발송을 제공하지 않으므로 예약 시간 알림 후 사용자가 직접 전송한다.
