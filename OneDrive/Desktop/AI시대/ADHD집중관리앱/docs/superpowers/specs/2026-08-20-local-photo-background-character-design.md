# 로컬 사진 배경과 개인 몽글 캐릭터 디자인

## 목표

사용자가 자신의 사진을 앱 배경과 프로필에 적용하고, 원본 사진 또는 로컬에서 합성한 몽글 스타일 캐릭터 중 하나를 선택할 수 있게 한다. 사진 처리와 저장은 전부 사용자 기기 안에서 수행하며 외부 AI API, 서버 업로드, 유료 크레딧을 사용하지 않는다.

## 기본 동작

- 사진을 등록하지 않거나 적용을 취소하면 승인된 `monggle-3d-approved-v1.png`를 계속 표시한다.
- 업로드만으로 현재 캐릭터나 배경을 덮어쓰지 않는다. 미리보기에서 `적용`을 눌러야 변경된다.
- `기본 몽글로 돌아가기`는 개인 캐릭터 선택만 해제하고 저장된 사진 삭제 여부를 별도로 묻는다.
- 사진 처리 실패, 지원하지 않는 형식, 저장 공간 부족 시 기본 몽글을 표시하고 핵심 기능은 계속 사용할 수 있다.

## 사용자 흐름

1. 설정에서 `배경 꾸미기` 또는 `내 캐릭터 만들기`를 연다.
2. JPG, PNG, WebP 사진을 선택한다.
3. 앱은 형식과 12MB 제한을 검사하고 긴 변을 최대 2048px로 축소한다.
4. 사용자는 `원본 사진` 또는 `몽글 스타일`을 선택한다.
5. 몽글 스타일이면 `몽글 구름 슈트`, `세련된 Studio 3D`, `부드러운 라벤더 피규어` 중 하나를 선택한다.
6. 적용 위치를 `배경`, `프로필`, `둘 다` 중 선택한다.
7. 배경 미리보기에서 밝기, 블러, 보라색 오버레이 강도를 조절한다.
8. `적용`을 누르면 선택과 결과물이 기기에 저장된다.

## 로컬 캐릭터 합성

캐릭터화는 생성형 이미지 모델이 아니라 결정적인 로컬 합성이다. 앱에 포함된 MediaPipe 호환 인물 분리 모델이 사람 마스크를 만들고, Canvas 2D가 축소 사진, 마스크, 3D 프레임, 조명, 의상 레이어를 합성한다. 얼굴은 원본을 유지하고 신체 주변과 표면 표현만 몽글 스타일로 바꾼다.

세 프리셋은 동일한 분리 결과를 사용하고 합성 자산과 색상만 다르게 한다. 결과는 같은 입력과 설정에서 항상 같아야 하며 네트워크 연결 여부에 영향을 받지 않는다. Canvas 필터 지원이 부족한 브라우저에서는 필수 합성만 적용하고 선택적 블러·색상 필터는 CSS 표시 효과로 대체한다.

## 배경 시스템

기본 배경은 `Studio 보라색`, `라벤더 유리`, `밤하늘`, `차분한 책상` 네 가지다. 사용자 사진 배경은 원본 또는 캐릭터화 결과를 선택할 수 있다. 배경 이미지는 앱 셸 뒤에 한 번만 렌더링하며 다섯 탭 사이에서 재마운트하지 않는다.

가독성 보호를 위해 사용자 이미지 위에 별도의 표면 오버레이를 둔다. 밝기, 블러, 보라색 오버레이는 허용 범위 안에서만 조절하며 텍스트·카드·내비게이션 대비는 기존 테마 토큰을 유지한다. 배경 이미지가 로드되지 않으면 `Studio 보라색`으로 대체한다.

## 데이터 모델과 저장

IndexedDB에 다음 레코드를 둔다.

- `PhotoAsset`: 원본을 축소한 Blob, MIME 형식, 크기, 생성 시각
- `CharacterRender`: 소스 사진 ID, 프리셋, 결과 Blob, 생성 시각
- `AppearanceSettings`: 배경 소스, 프로필 소스, 밝기, 블러, 오버레이, 적용 상태

원본 파일 이름과 파일 시스템 경로는 저장하지 않는다. 활성 설정은 존재하는 자산 ID만 참조해야 한다. 자산 삭제 시 참조 중인 배경과 프로필은 기본값으로 원자적으로 복구한다.

## 개인정보와 수명 주기

- 사진 Blob, 마스크, 결과물은 외부 서버로 전송하지 않는다.
- 분석·오류 로그에는 이미지 데이터, 파일명, 얼굴 특징을 포함하지 않는다.
- PWA 데이터 지우기 또는 `개인 사진 모두 삭제` 시 원본, 임시 마스크, 결과물, 관련 설정을 삭제한다.
- 처리 중 생성한 Canvas와 Object URL은 완료·취소·오류 때 즉시 해제한다.
- 사진 권한은 파일 선택 시에만 사용하고 카메라 상시 권한은 요청하지 않는다.

## 오류 처리

- 지원하지 않는 형식 또는 12MB 초과: 저장 전에 이유와 허용 형식을 안내한다.
- 인물 미검출: 원본 배경 적용은 허용하고 캐릭터화만 다시 촬영 안내와 함께 중단한다.
- 모델 로드 실패: 원본 사진 적용과 기본 배경은 계속 제공한다.
- 저장 공간 부족: 새 결과를 저장하지 않고 현재 활성 배경·캐릭터를 유지한다.
- 손상된 자산 참조: 기본 Studio 배경과 기본 몽글로 자동 복구한다.

## 접근성과 성능

- 처리 단계와 오류는 텍스트로 표시하고 색상만으로 상태를 구분하지 않는다.
- 미리보기 선택, 슬라이더, 적용·취소·삭제는 키보드와 스크린리더로 조작할 수 있다.
- 움직임 줄이기 설정은 개인 캐릭터에도 기존과 동일하게 적용한다.
- 원본을 디코딩한 직후 2048px 이하로 줄여 메모리 사용을 제한한다.
- 인물 분리는 사용자 동작 후 한 번만 수행하고 탭 이동 시 다시 실행하지 않는다.

## 검증 기준

- 사진을 선택만 하고 취소하면 현재 배경과 캐릭터가 바뀌지 않는다.
- 사진이 없는 신규 사용자에게 기본 몽글이 표시된다.
- 원본/몽글 스타일과 배경/프로필/둘 다 조합이 새로고침 후 유지된다.
- 오프라인 상태에서도 이미 설치된 모델로 캐릭터 합성이 동작한다.
- 삭제 후 관련 IndexedDB Blob과 설정 참조가 남지 않는다.
- 모바일 320px 화면에서도 미리보기와 적용 버튼이 겹치지 않는다.
- 전체 단위·컴포넌트·Playwright 테스트와 PWA 빌드가 통과한다.

## 제외 범위

실시간 카메라 필터, 얼굴 형태 재생성, 생성형 3D 모델, 신원 인식, 사진 공유, 클라우드 동기화, 외부 AI API는 포함하지 않는다. 이 기능은 사진에서 사람을 분리하고 승인된 시각 레이어를 합성하는 로컬 꾸미기 기능이다.
