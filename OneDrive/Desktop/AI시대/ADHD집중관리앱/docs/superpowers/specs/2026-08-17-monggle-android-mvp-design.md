# Monggle Android MVP 설계

작성일: 2026-08-17  
대상: 성인 ADHD 사용자를 위한 게임형 일정·행동 실행 앱

## 1. 목표

Monggle은 할 일을 기록하는 데서 끝나지 않고, 사용자가 다음 행동을 잊지 않고 실제로 시작해 그날의 핵심 과제를 완료하도록 돕는다. 캐릭터 몽글이가 상황에 맞춰 말을 걸고, 홈 화면과 잠금 화면에서 즉시 타이머를 시작할 수 있게 한다.

첫 번째 버전의 성공 기준은 다음과 같다.

- 카카오톡과 카카오워크의 메시지를 Android 공유 기능으로 투두에 저장할 수 있다.
- Google Calendar의 `#할일` 일정을 중복 없이 투두로 가져올 수 있다.
- 일반 Google Calendar 일정을 앱에서 조회하고, 앱에서 만든 일정을 Google Calendar에 생성·수정·삭제할 수 있다.
- 앱, 홈 위젯, 잠금 화면 알림 중 어디서든 핵심 투두의 타이머를 시작할 수 있다.
- 미완료 투두가 있으면 방해 금지 시간을 제외하고 2시간마다 몽글이가 상기시킨다.
- 투두 완료가 경험치, 일일 퀘스트, 몽글이 반응과 수집형 보상으로 이어진다.

## 2. 범위

### 2.1 첫 번째 버전에 포함

- Android 네이티브 앱
- 투두 생성, 편집, 완료, 보관
- 공부, 자기계발, 운동, 휴식, 생활 활동 분류
- 일정 조회·생성·편집·삭제
- 집중 타이머와 시간 종료 알림
- 카카오톡·카카오워크 공유 텍스트 가져오기
- Google Calendar 연동
- 홈 화면 위젯과 잠금 화면 알림
- 몽글이 캐릭터 이동, 상황별 대사, 상기 알림
- 경험치, 레벨, 하루 퀘스트 3개, 수집형 보상
- 강한 게임형 시각 디자인

### 2.2 후속 버전으로 분리

- 한글·영어 동기부여 명언
- 영어 단어, 고사성어, 속담 선택 학습
- 기억력·주의력·계산·언어 두뇌게임
- 캐릭터 방 꾸미기 확장
- Google Calendar 이외의 외부 앱 직접 연동

후속 기능은 첫 번째 버전의 데이터 모델을 깨지 않고 별도 모듈로 추가한다.

## 3. 기술 선택

Kotlin과 Jetpack Compose로 Android 네이티브 앱을 구현한다.

- UI: Jetpack Compose
- 로컬 저장: Room
- 설정: DataStore
- 백그라운드 동기화: WorkManager
- 캘린더 접근: Android Calendar Provider
- 홈 위젯: Glance App Widget
- 타이머: 포그라운드 서비스, 시스템 알람, 지속 알림
- 의존성 주입: Hilt
- 비동기 처리: Kotlin Coroutines와 Flow

별도 서버는 사용하지 않는다. 사용자의 투두, 공유 원문, 집중 기록은 기기에 저장한다. Google 계정은 Android 시스템에서 이미 동기화된 캘린더를 사용한다.

## 4. 사용자 흐름

### 4.1 공유 메시지를 투두로 만들기

1. 사용자가 카카오톡 또는 카카오워크에서 메시지를 선택한다.
2. `공유` 메뉴에서 Monggle을 선택한다.
3. Monggle이 Android `ACTION_SEND` 인텐트의 텍스트를 받는다.
4. 확인 화면에서 제목, 마감일, 예상시간, 활동 분류를 제안한다.
5. 날짜나 시간이 불확실하면 사용자가 직접 확인해야 저장할 수 있다.
6. 저장하면 원문, 출처 앱, 수신 시각을 함께 기록한다.

카카오톡과 카카오워크의 기존 채팅을 백그라운드에서 읽지 않는다. 알림 접근 권한과 접근성 권한도 요구하지 않는다.

### 4.2 Google Calendar와 동기화

- 제목이 `#할일`로 시작하거나 이를 독립 태그로 포함한 일정만 투두로 가져온다.
- 앱에는 `#할일`을 제거한 제목을 표시한다.
- 원본 이벤트 ID와 캘린더 ID를 저장하여 중복 생성을 막는다.
- 외부에서 `#할일` 일정의 제목·시간이 바뀌면 연결된 투두를 갱신한다.
- 외부에서 원본이 삭제되면 투두를 삭제하지 않고 `원본 일정 삭제됨` 상태로 보관한다.
- Monggle에서 투두를 완료해도 원본 `#할일` 일정은 수정하지 않는다.
- 일반 일정은 오늘·주간 일정에 읽기 전용으로 표시한다.
- Monggle에서 만든 일반 일정은 Google Calendar에도 만들며, 앱에서 수정·삭제하면 연결된 이벤트에도 반영한다.
- 외부 앱이 만든 일반 일정은 첫 번째 버전에서 Monggle로 수정하지 않는다.

기본 시간대는 `Asia/Seoul`이지만 이벤트에 지정된 실제 시간대와 종일 일정 여부를 보존한다.

### 4.3 다음 행동과 타이머

1. 홈, 투두 상세, 위젯 또는 잠금 화면에서 `바로 시작`을 누른다.
2. 5, 10, 15, 25, 45분 또는 직접 입력으로 시간을 정한다.
3. 타이머가 시작되면 현재 행동과 남은 시간을 지속 알림에 표시한다.
4. 시간이 끝나면 소리와 진동으로 한 번 알린다.
5. 응답이 없으면 5분 뒤 한 번만 다시 알린다.
6. 사용자는 `완료`, `5분 연장`, `더 작게 나누기`, `잠시 쉬기`, `오늘 다시 배치` 중 하나를 선택한다.

앱 종료와 기기 재시작 뒤에도 종료 예정 시각을 기준으로 타이머 상태를 복원한다. 여러 타이머를 동시에 실행하지 않는다.

### 4.4 몽글이 상기 알림

- 오늘의 미완료 투두가 있을 때 기본 2시간 간격으로 알린다.
- 마감 1시간 전에 별도 긴급 알림을 한 번 보낸다.
- 집중, 두뇌게임, 휴식 타이머가 실행 중이면 정기 상기 알림을 미룬다.
- 오늘 할 일을 모두 완료하면 남은 상기 알림을 취소한다.
- 기본 방해 금지 시간은 23:00~07:00이다.
- 사용자는 간격을 1, 2, 3, 4시간으로 바꾸거나 `오늘은 그만`을 선택할 수 있다.
- 알림에는 `바로 시작`, `완료`, `10분 후`, `작게 나누기` 행동을 제공한다.

상기 메시지는 처음에는 부드럽고 마감이 가까워지면 구체적으로 행동을 촉구한다. 미완료를 이유로 경험치를 차감하거나 비난하는 문구는 사용하지 않는다.

## 5. 화면 구성

### 5.1 홈

- 레벨, 경험치, 연속 달성
- 오늘의 퀘스트 3개
- 다음 행동 한 개와 즉시 시작 버튼
- 오늘 일정과 다음 일정까지 남은 시간
- 일정 사이에 끝낼 수 있는 짧은 투두 추천
- 활동 영역별 오늘의 균형
- 화면을 돌아다니며 말을 거는 몽글이

### 5.2 투두 확인

공유받은 문장에서 추출한 제목, 마감일, 예상시간, 활동 분류와 원문을 보여준다. 사용자가 수정한 뒤 저장한다.

### 5.3 오늘·주간 일정

투두와 일반 일정을 시각적으로 구분해 시간순으로 표시한다. 새 일정이 기존 일정과 겹치면 저장 전에 충돌을 알리되 저장을 차단하지 않는다.

### 5.4 집중

현재 행동과 남은 시간만 강조한다. 강한 게임형 홈과 달리 집중 중에는 캐릭터 이동, 배경 효과와 불필요한 정보를 줄인다.

### 5.5 목표와 보상

활동 영역별 진행률, 경험치, 레벨, 일일 퀘스트와 획득한 몽글이 꾸미기 보상을 보여준다.

### 5.6 설정과 가져오기 기록

캘린더 선택, 동기화 상태, 상기 간격, 방해 금지 시간, 알림 소리, 테마, 캐릭터, 공유 가져오기 성공·중복·오류 기록을 관리한다.

## 6. 홈 화면과 잠금 화면

두 가지 홈 위젯을 제공한다.

- 빠른 집중 위젯: 가장 중요한 투두 하나, 예상시간, `바로 시작`, `완료`
- 일정 연결 위젯: 다음 일정까지 남은 시간과 그 안에 끝낼 수 있는 투두 추천

잠금 화면에는 Android 알림으로 현재 행동, 남은 시간과 실행 버튼을 표시한다. Android 버전과 제조사 정책상 잠금 화면에서 전체 앱 UI나 자유롭게 이동하는 캐릭터를 직접 실행할 수는 없으므로, 캐릭터 아이콘·대사·행동 버튼을 알림 형태로 제공한다. 민감한 알림 내용 숨기기 설정도 제공한다.

## 7. 게임화와 시각 방향

시각 방향은 강한 게임형을 사용한다.

- 홈과 보상 화면은 진한 색, 높은 대비, 경험치와 퀘스트를 적극적으로 표현한다.
- 활동 종류에 따라 카드 색과 배경 효과를 바꾼다.
- 시작, 완료, 레벨업, 보상 획득 순간에만 큰 애니메이션과 햅틱을 사용한다.
- 집중 화면과 정보 입력 화면에서는 움직임과 장식을 줄인다.
- `애니메이션 줄이기`와 효과음·햅틱 끄기를 제공한다.

투두 완료 시 경험치를 주고 일일 퀘스트 진행도를 올린다. 보상의 중심은 몽글이 의상과 소품 수집이다. 연속 기록이 끊겨도 이미 획득한 경험치와 보상은 잃지 않는다.

## 8. 데이터 모델

### Task

- ID, 제목, 메모, 활동 분류
- 마감 시각, 예상시간, 우선순위
- 상태: 예정, 진행 중, 완료, 보관
- 출처: 직접 입력, 공유, 캘린더
- 원본 텍스트와 출처 패키지
- Google 캘린더 ID와 이벤트 ID
- 생성·수정·완료 시각

### Schedule

- ID, 제목, 시작·종료 시각, 종일 여부
- 장소, 메모, 알림
- 소유 주체: Monggle 또는 외부
- Google 캘린더 ID와 이벤트 ID
- 동기화 상태와 마지막 수정 시각

### FocusSession

- 연결된 투두 ID
- 계획 시간, 시작·종료 시각, 실제 집중시간
- 종료 사유와 완료 여부

### Goal, DailyQuest, Reward

- 목표와 연결된 투두
- 일일 퀘스트 조건과 진행도
- 경험치, 레벨, 보상 해금 정보

### ImportRecord, CalendarSyncState

- 공유 원문 해시와 처리 결과
- 마지막 캘린더 동기화 시각과 오류

## 9. 구성 요소 경계

- `tasks`: 투두 규칙과 저장
- `calendar`: Calendar Provider 조회·쓰기와 동기화
- `sharing`: Android 공유 인텐트 수신과 확인
- `focus`: 단일 타이머 상태 머신과 복원
- `reminders`: 정기 상기, 마감, 타이머 알림 예약
- `widget`: 홈 위젯 상태와 동작
- `character`: 몽글이 상태와 상황별 대사
- `gamification`: 경험치, 퀘스트, 보상 계산
- `schedule`: 일정 화면과 충돌 감지

각 모듈은 저장소 인터페이스를 통해 통신한다. UI는 Calendar Provider나 Room을 직접 호출하지 않는다.

## 10. 권한과 개인정보

- 캘린더 기능을 활성화할 때만 캘린더 읽기·쓰기 권한을 요청한다.
- Android 13 이상에서는 알림 권한을 기능 설명 뒤 요청한다.
- 정확한 알람 권한이 필요한 Android 버전에서는 타이머 기능을 처음 사용할 때 안내한다.
- 카카오톡과 카카오워크 계정 자격 증명은 수집하지 않는다.
- 공유 원문과 행동 기록은 로컬에만 저장하며 사용자가 삭제할 수 있다.
- 캘린더 권한을 거부해도 로컬 투두·타이머·게임화 기능은 계속 동작한다.

## 11. 오류 처리

- 캘린더 권한 거부: 연결 해제 상태와 설정 바로가기 표시
- 캘린더 계정 동기화 중단: 기존 데이터를 유지하고 마지막 성공 시각 표시
- 중복 공유: 원문 해시와 최근 기록을 비교하여 저장 전 경고
- 날짜 해석 불확실: 사용자 확인 없이는 마감일을 확정하지 않음
- 일정 충돌: 충돌 대상을 표시한 뒤 사용자 선택으로 저장
- 캘린더 쓰기 실패: 로컬 일정을 `재시도 필요` 상태로 보존
- 타이머 알람 제한: 지속 알림과 WorkManager를 보조 경로로 사용하고 제한 상태 안내
- 기기 재시작: 종료 예정 시각과 실행 상태를 읽어 알람과 알림 복구

## 12. 테스트 전략

- 투두, 경험치, 퀘스트와 상기 시각 계산 단위 테스트
- Room 마이그레이션과 저장소 통합 테스트
- 공유 인텐트의 일반 텍스트, 빈 텍스트, 긴 텍스트, 중복 테스트
- `#할일` 판별, 수정, 삭제, 중복, 종일 일정, 반복 일정, 시간대 동기화 테스트
- Monggle 소유 일정과 외부 소유 일정의 쓰기 권한 경계 테스트
- 타이머 시작, 연장, 완료, 프로세스 종료, 기기 재시작 테스트
- 23:00~07:00 방해 금지 경계와 2시간 상기 취소 테스트
- 위젯과 알림 행동 버튼의 상태 일치 테스트
- 권한 거부, 오프라인, 캘린더 없음, 알림 차단 상태 테스트
- 실제 Android 기기에서 카카오톡·카카오워크 공유 대상 노출과 제조사별 알람 동작 확인
- 접근성 검사: 글자 크기, 색 대비, 터치 영역, 애니메이션 줄이기

## 13. 출시 기준

- 핵심 흐름에 치명적 오류가 없다.
- 같은 캘린더 이벤트나 공유 메시지로 중복 투두가 생성되지 않는다.
- 타이머 종료와 5분 재알림이 화면이 꺼진 실제 기기에서 동작한다.
- 방해 금지 시간에는 정기 상기 알림이 울리지 않는다.
- 캘린더 권한 없이도 앱의 핵심 로컬 기능을 사용할 수 있다.
- 집중 중 게임 효과가 타이머 조작과 현재 행동 인지를 방해하지 않는다.
