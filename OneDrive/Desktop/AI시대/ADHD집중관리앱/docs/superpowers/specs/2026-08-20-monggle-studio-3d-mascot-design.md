# 몽글 Studio 3D UI와 상주 캐릭터 디자인

## 목표

기존 몽글의 고정된 5개 탭과 ADHD 친화적 정보 구조는 유지하면서, 시각 표현을 유치하지 않은 프리미엄 `Studio 3D` 스타일로 개선한다. 승인된 몽글 캐릭터는 모든 주요 화면에서 사용자의 진행을 방해하지 않는 동반자로 존재한다.

## 시각 방향

- 주조색은 기존 보라색을 유지하되 진한 바이올렛, 라벤더, 펄 화이트, 소량의 실버로 정리한다.
- 배경에는 실제 스튜디오 조명처럼 부드러운 명암과 깊이를 적용한다.
- 카드에는 반투명 유리, 내부 하이라이트, 여러 단계의 그림자를 사용한다.
- 3D 효과는 핵심 카드와 캐릭터에 집중하고 모든 요소를 입체화하지 않는다.
- 캐릭터·게임 앱처럼 보이는 원색, 굵은 외곽선, 점수·레벨 표현은 사용하지 않는다.
- 사용자 유형이 바뀌어도 레이아웃, 탭 순서, 디자인 언어는 바뀌지 않는다.

## 승인 캐릭터

원본 자산은 `web/public/assets/mascot/monggle-3d-approved-v1.png`에 저장한다. 몽글은 펄 화이트 구름 질감, 보라색 눈, 세련된 헤어 실루엣, 실버 액세서리를 가진 성별 중립 3D 동반자다. 귀엽지만 유아용으로 보이지 않고 중고등학생과 성인이 함께 사용할 수 있어야 한다.

이미지는 UI에서 원본 비율을 유지하고 콘텐츠 크기에 따라 72–128px로 표시한다. 캐릭터를 단순히 뒤집으면 액세서리 방향도 반전되므로 좌우 이동 시 이미지 반전은 사용하지 않는다.

## 캐릭터 동작 시스템

`MonggleCompanion`은 앱 셸에 한 번만 배치되어 탭 이동에도 유지된다. 동작은 CSS transform과 opacity만 사용해 레이아웃 재계산을 피한다.

상태는 다음 네 가지다.

1. `resting`: 화면 우측 하단 안전 영역에 머물며 아주 약하게 호흡한다.
2. `wandering`: 콘텐츠가 없는 가장자리의 사전 정의된 지점 사이를 18–28초 간격으로 천천히 이동한다.
3. `reacting`: 집중 시작, 할 일 완료, 루틴 완료, 메시지 예약 저장 때 1–2초 동안 가까이 와서 짧게 반응한다.
4. `hidden`: 입력창, 날짜 선택기 또는 작은 화면에서 주요 버튼과 충돌하면 축소하거나 숨는다.

무작위 좌표를 사용하지 않고 상단 우측, 중앙 좌측, 하단 우측의 안전 지점만 순환한다. 캐릭터의 `pointer-events` 기본값은 `none`으로 하여 버튼이나 입력을 막지 않는다. 탭 바, 주요 CTA, 폼 필드와 최소 16px 간격을 유지한다.

## 접근성과 사용자 제어

- OS의 `prefers-reduced-motion` 또는 앱의 `reducedMotion`이 켜지면 `wandering`과 호흡 애니메이션을 중지하고 `resting` 정지 이미지로 표시한다.
- 설정에는 `몽글 캐릭터 표시` 토글을 추가하며 기본값은 켜짐이다.
- 캐릭터는 장식 요소이므로 기본적으로 빈 대체 텍스트를 사용한다. 상태 안내가 필요할 때는 기존 토스트나 텍스트 영역이 메시지를 담당한다.
- 움직임은 초당 빠른 반복이나 번쩍임을 사용하지 않는다.

## 구성 요소와 데이터 흐름

- 테마 토큰은 표면, 유리, 입체 그림자, 라벤더 광원 토큰을 추가한다.
- `MonggleCompanion`은 현재 경로, `reducedMotion`, `mascotVisible`, 짧은 반응 이벤트만 입력으로 받는다.
- 기능 화면은 캐릭터 내부 상태를 직접 변경하지 않고 `companionEvent`를 발행한다.
- 반응 이벤트가 없어지면 캐릭터는 자동으로 `resting`을 거쳐 `wandering`으로 돌아간다.
- 캐릭터 설정은 기존 로컬 설정 저장소에 저장하며 외부 서버나 AI API를 사용하지 않는다.

## 성능과 오류 처리

- 첫 화면에 필요한 승인 PNG는 정적 자산으로 제공하고 브라우저 캐시 및 PWA 프리캐시에 포함한다.
- 이미지 로딩 실패 시 캐릭터 영역 자체를 숨겨 핵심 기능 사용에 영향이 없게 한다.
- 애니메이션은 transform과 opacity로 제한하고 동시 애니메이션은 캐릭터 한 개만 허용한다.
- 저사양 환경과 배터리 절약을 위해 캐릭터 이동 중 그림자 애니메이션은 하지 않는다.

## 검증 기준

- 320px부터 1440px까지 캐릭터가 입력, 주요 CTA, 하단 탭을 가리지 않는다.
- 다섯 탭을 이동해도 캐릭터가 재마운트되어 튀지 않는다.
- `reducedMotion`과 캐릭터 표시 설정이 새로고침 후에도 유지된다.
- 키보드만으로 모든 기능을 사용할 수 있고 캐릭터가 포커스 순서에 들어오지 않는다.
- 전체 단위·컴포넌트 테스트, PWA 빌드, 모바일 브라우저 검증을 통과한다.

## 제외 범위

이번 단계에서는 실시간 3D 엔진, WebGL 모델, 음성, 캐릭터 의상 구매, 레벨 시스템을 만들지 않는다. 승인된 렌더 이미지와 가벼운 2D 합성 애니메이션으로 시각적 3D 효과를 제공한다.
