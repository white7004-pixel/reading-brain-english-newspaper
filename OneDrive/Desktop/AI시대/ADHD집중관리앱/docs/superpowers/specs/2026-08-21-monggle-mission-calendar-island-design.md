# 몽글 필수 미션·Google Calendar·성장하는 섬 설계

> 2026-08-22 결정: Google Calendar 첫 연동은 읽기 중심의 최소 권한 단계로 제공한다. 사용자의 확인 없이 Google Calendar 원본 일정이나 이벤트를 생성·수정·삭제하지 않는다. 아래의 쓰기 동기화는 후속 선택 기능으로 분리한다.

## 목적

몽글의 핵심 목적은 ADHD로 인해 하루가 산만해지더라도 사용자가 직접 정한 오늘의 필수 미션을 빠뜨리지 않고 모두 완료하도록 돕는 것이다. 앱은 필수 미션의 수를 제한하거나 임의로 삭제하지 않는다. 계획, 알림, 재배치, 집중 실행, 복귀 지원과 게임 보상은 모두 이 목표를 지원해야 한다.

이 기능은 ADHD의 치료나 완치를 주장하지 않는다. 시작, 시간감각, 지속, 복귀와 같은 실행 기능을 실제 생활 미션을 통해 반복적으로 지원하고 훈련하는 제품 경험을 제공한다.

## 제품 원칙

1. 사용자가 필수 미션을 직접 선택하고 최종 확정한다.
2. 확정된 필수 미션은 사용자가 직접 완료하거나 필수 지정을 해제하기 전까지 유지한다.
3. 화면에는 항상 지금 실행할 한 가지와 바로 할 수 있는 첫 행동을 우선 표시한다.
4. 시간 종료만으로 완료 처리하지 않고 사용자의 명시적인 확인을 요구한다.
5. 자정은 실패 경계가 아니다. 미완료 미션은 오늘 연장 완료 모드에서 계속 유지한다.
6. 자동화는 사용자의 부담을 줄이되, 사용자가 잠근 시간과 필수 상태를 변경하지 않는다.
7. 게임은 현실 미션 수행을 강화하는 짧은 보상층이며 별도의 무한 소비 콘텐츠가 아니다.
8. 오프라인, 동기화 장애, 인증 만료가 발생해도 로컬 미션과 게임 진행도를 보존한다.

## 전체 아키텍처

### 로컬 우선 몽글 앱

PWA와 Capacitor 네이티브 셸이 필수 미션, 실행 기록, 완료 상태, 알림 정책, 섬 성장 상태를 로컬 데이터베이스에 저장한다. 사용자는 네트워크 연결 없이 미션을 확인하고 실행하고 완료할 수 있다.

핵심 모듈은 다음과 같이 분리한다.

- `mission`: 필수 확정, 첫 행동, 상태 전이, 날짜 연장
- `scheduler`: 빈 시간 탐색, 시간 잠금, 자동 재배치, 되돌리기
- `calendar-sync`: 로컬 변경 대기열, 외부 이벤트 매핑, 충돌 해결
- `nudges`: 푸시, 잠금화면·위젯 강조, 앱 진입 우선 표시
- `execution`: 집중 타이머, 예상 시간과 실제 시간, 중단과 복귀
- `world`: 재료, 건설 단계, 구역, 해금, 영구 진행도
- `coaching`: 실행 기록을 기반으로 첫 행동과 예상 시간 및 알림 간격 개인화

각 모듈은 도메인 규칙을 순수 함수로 제공하고, 저장소·Google API·네이티브 알림 같은 외부 의존성은 어댑터를 통해 연결한다.

### 동기화 서버

작은 서버가 Google OAuth, 갱신 토큰의 암호화 보관과 free/busy 조회만 담당한다. 후속 쓰기 연동을 켤 때에만 증분 동기화 토큰, 중복 방지와 충돌 기록을 추가한다. 전체 게임 상태나 민감한 로컬 실행 기록을 서버의 필수 데이터로 만들지 않는다.

### Google Calendar

첫 연동은 Google Calendar의 바쁨/여유 정보만 읽어 몽글 내부 미션 배치에 사용한다. 연결 과정에서 보조 캘린더나 이벤트를 만들지 않으며, Google Calendar 원본을 생성·수정·삭제하지 않는다. 앱 화면에는 연결 계정, 마지막 조회 시각, 사용 중인 권한, 연결 해제를 명확히 표시한다.

초기 구현은 Google의 `calendar.events.freebusy` 범위를 우선 사용한다. 사용자가 선택 가능한 캘린더 목록이나 기본 시간대가 필요할 때만 `calendar.calendarlist.readonly` 또는 `calendar.calendars.readonly`를 추가한다. 상세 이벤트 제목과 본문은 수집·저장하지 않는다. 공개 배포 전에는 OAuth 동의 화면과 Google 검증 요건을 별도로 완료한다.

후속 쓰기 연동은 별도의 명시적 동의 뒤에만 켤 수 있다. 이때 앱 전용 `몽글 필수 미션` 보조 캘린더를 만들고 `calendar.app.created` 범위를 추가하며, 다른 캘린더는 계속 읽기 전용으로 유지한다.

## 필수 미션 생명주기

### 확정

사용자는 오늘 반드시 완료할 미션을 개수 제한 없이 선택한다. 확정 전에 각 미션의 제목, 예상 소요시간, 첫 행동, 희망 시간과 시간 잠금 여부를 검토한다. 앱은 과부하 가능성을 알려줄 수 있지만 미션을 제거하거나 다음 날로 넘기지 않는다.

### 배치

스케줄러는 Google의 바쁜 시간, 사용 가능한 시간대, 미션의 예상 소요시간과 순서를 사용해 몽글 내부 배치안을 만든다.

- 시간 잠금 미션은 자동 이동하지 않는다.
- 잠기지 않은 미션은 새 일정과 충돌하면 다음 빈 시간으로 자동 이동한다.
- 자동 이동 후 새 시간과 `되돌리기` 동작을 알린다.
- 잠긴 미션이 충돌하면 앱은 이동하지 않고 선택을 요청한다.
- 자동 재배치는 몽글 내부 미션 시간만 바꾸며, 변경 전후와 `되돌리기`를 함께 표시한다.

### 실행

기본 실행 화면은 현재 미션 하나, 첫 행동, 예상 소요시간, 3분 시작 버튼만 강조한다. 사용자는 `3분만 시작`, `5분 후 다시 알림`, `일정 다시 잡기`를 선택할 수 있다. 시작 후에는 시각 타이머와 단계별 체크를 제공한다.

### 완료 판정

예정 종료 시각이 지나면 다음 선택지를 표시한다.

- `완료했어요`
- `지금 마무리 중`
- `아직 못 했어요 · 다음 시간 재배치`

사용자가 `완료했어요`를 선택할 때만 미션과 게임 보상을 완료 처리한다. Google 이벤트 시간이 끝난 사실만으로는 완료하지 않는다.

### 미완료와 날짜 변경

자정이 지나도 미션은 원래 필수 묶음에 남고 `오늘 연장 완료 모드`로 전환된다. 벌점, 연속 기록 초기화, 자동 이월은 없다. 화면은 남은 미션 수와 지금 처리할 하나를 표시하며 완료할 때까지 같은 원칙으로 재배치와 알림을 계속한다.

## 단계형 알림

알림 강도는 다음 순서로 높인다.

1. 일반 푸시 알림
2. 잠금화면과 홈 위젯에서 현재 미션 강조
3. 앱을 열면 다른 화면보다 현재 필수 미션을 우선 표시

각 단계는 방해 금지 시간과 사용자가 설정한 알림 간격을 지킨다. 응답하지 않은 알림을 무한히 쌓지 않고 최신 현재 미션 상태 하나만 유지한다. 보호자나 친구에게 미완료 사실을 전송하지 않는다.

## Google Calendar 읽기 중심 연동

### 첫 출시 데이터 경계

Google에서는 캘린더 ID, 바쁨 구간, 조회 범위, 시간대와 마지막 조회 시각만 사용한다. 이벤트 제목, 설명, 참석자와 위치는 가져오지 않는다. 몽글 미션은 로컬 저장소에만 남으며 Google 이벤트와 매핑하지 않는다. 완료 상태의 원본도 몽글이다.

### 배치 규칙

- Google의 바쁨 구간과 겹치는 잠금 미션은 이동하지 않고 충돌 선택을 요청한다.
- 잠기지 않은 미션은 다음 빈 구간으로 옮길 수 있지만 적용 전에 새 시간을 보여준다.
- 적용한 자동 재배치는 한 단계 되돌릴 수 있다.
- Google 조회 실패나 연결 해제는 기존 로컬 배치를 변경하지 않는다.
- Google Calendar의 변경이나 삭제는 몽글 미션을 삭제·완료·필수 해제하지 않는다.

### 조회와 오류 처리

앱은 필요한 시간 범위의 free/busy 정보를 요청하고 짧은 유효기간으로 로컬 캐시한다. 네트워크가 없으면 마지막으로 성공한 조회 결과의 시각을 표시하되, 오래된 정보로 자동 재배치를 적용하지 않는다. 다시 연결되면 최신 바쁨 구간으로 새 배치안을 계산하며 기존 로컬 미션 상태는 유지한다.

인증 만료, 할당량 초과, 네트워크 오류가 발생하면 동기화 상태를 명확히 표시하고 재시도한다. 이 오류는 로컬 미션 실행, 완료 또는 섬 성장에 영향을 주지 않는다.

### 후속 선택형 쓰기 동기화

사용자가 별도 동의로 쓰기 연동을 켠 경우에만 앱 전용 보조 캘린더와 몽글 미션을 안정적인 ID로 연결한다. 이 단계에서는 몽글에서 만든 이벤트만 생성·수정·삭제하고, 사용자의 다른 캘린더는 수정하지 않는다. Google에서 앱 전용 이벤트를 직접 이동하면 사용자 지정 잠금으로 간주하며, 이벤트 삭제가 로컬 필수 미션 삭제로 전파되지 않게 한다. 증분 동기화 토큰 만료 시 원격 캐시와 매핑만 재구성하고 로컬 필수 상태와 완료 기록은 보존한다.

## 성장하는 3D 몽글 아일랜드

사용자는 빈 섬에서 시작한다. 필수 미션을 완료할 때마다 재료와 성장 에너지를 얻고, 오늘의 필수 미션을 모두 완료하면 큰 건축 단계가 진행된다. 섬은 매일 초기화하지 않으며 장기적으로 영구 성장한다.

### 네 구역

- `집중 정원`: 미션을 확인한 뒤 첫 행동을 빠르게 시작한 경험으로 성장
- `시간의 숲`: 예상 시간과 실제 시간을 비교하고 시간감각을 학습한 경험으로 성장
- `완성 마을`: 집중 세션과 단계별 완료 및 최종 완료로 성장
- `귀환 항구`: 놓친 미션에 복귀하거나 자정 이후 연장 완료한 경험으로 성장

정확한 수행보다 알아차림과 복귀를 보상한다. 미션 한 개 완료 시 식물, 재료, 에너지를 즉시 지급한다. 하루 필수 미션 전체 완료 시 건물, 구역, 주민 또는 스토리의 큰 단계를 해금한다. 첫 섬을 완성하면 새로운 테마 섬을 개방한다.

### 게임 안전장치

- 보상 연출은 짧게 끝낸다.
- 월드 탐색은 미션 사이에 짧은 시간만 제공하고 다음 행동으로 돌아가는 버튼을 우선한다.
- 랜덤 뽑기, 확률형 보상, 결제 압박, 무한 미니게임을 포함하지 않는다.
- 미완료 벌점이나 연속 기록 초기화를 사용하지 않는다.
- 실제 미션 완료나 복귀 행동 없이 핵심 성장 재화를 반복 획득할 수 없게 한다.

## 개인화

앱은 사용자의 시작 지연, 예상 시간, 실제 시간, 중단, 복귀, 알림 응답을 로컬에서 집계한다. 이 기록을 사용해 다음 미션의 기본 예상시간, 첫 행동 크기, 권장 집중 세션, 알림 간격을 조정한다. 개인화 이유를 사용자에게 설명하고 설정에서 초기화하거나 비활성화할 수 있게 한다.

개인화는 필수 미션을 삭제하거나 중요도를 낮추는 데 사용하지 않는다.

## 단계별 구현

### 1단계: 필수 미션 실행 엔진

필수 확정, 첫 행동, 시간 잠금, 현재 한 가지, 직접 완료, 단계형 알림, 날짜 연장 완료 모드와 오프라인 저장을 구현한다. 기존 Today, Focus, nudge, widget 기능을 새 미션 상태 모델에 연결한다.

### 2단계: Google Calendar 읽기 중심 연동

OAuth와 최소 권한 서버, free/busy 조회, 로컬 자동 재배치와 되돌리기, 오래된 가용성 보호, 연결·오류 UI를 구현한다. 개발용 Google 계정으로 검증한 뒤 공개 OAuth 검증을 별도 출시 작업으로 진행한다. 앱 전용 캘린더 쓰기와 양방향 증분 동기화는 후속 선택 기능으로 둔다.

### 3단계: 성장하는 섬과 적응형 실행 훈련

영구 월드 상태, 네 구역, 미션별 보상, 전체 완료 건축, 새 섬 해금과 개인화 계산을 구현한다. 초기 버전은 승인된 3D 렌더 자산과 가벼운 애니메이션을 사용하고, 실시간 3D 엔진 도입은 성능과 제작비 검증 후 별도 결정한다.

## 검증 기준

### 도메인 테스트

- 확정한 필수 미션이 재시작, 오프라인, 날짜 변경 후에도 유지된다.
- 시간 경과나 Google 이벤트 종료만으로 완료 처리되지 않는다.
- 사용자의 명시적 완료만 보상과 월드 성장을 발생시킨다.
- 시간 잠금 미션은 자동 이동하지 않는다.
- 잠기지 않은 미션은 충돌 후 다음 빈 시간으로 이동하고 되돌릴 수 있다.
- Google 이벤트 삭제가 필수 미션 삭제로 전파되지 않는다.
- 자정 이후에도 미완료 미션이 같은 필수 묶음으로 유지된다.
- 미션·전체 완료·복귀 보상이 중복 지급되지 않는다.

### 동기화 테스트

- 첫 연결과 가용성 새로고침이 Google 이벤트를 생성·수정·삭제하지 않는다.
- 상세 이벤트 제목, 설명, 참석자와 위치를 저장하지 않는다.
- 오래된 캐시나 조회 실패로 자동 재배치를 적용하지 않는다.
- 재연결 후 최신 바쁨 구간으로 다시 계산해도 로컬 완료 기록이 유지된다.
- 인증 실패나 API 오류 중에도 로컬 미션과 월드 진행이 정상 작동한다.

### UI와 접근성 테스트

- 모바일과 데스크톱에서 현재 미션이 가장 높은 시각 우선순위를 가진다.
- 잠금화면·위젯·앱이 동일한 현재 미션 상태를 표시한다.
- 키보드와 스크린리더로 확정, 시작, 완료, 재배치를 수행할 수 있다.
- 움직임 줄이기 설정에서 3D 보상 애니메이션을 축소하거나 정지한다.
- 브라우저 자동화로 핵심 미션 확정부터 전체 완료와 섬 성장까지 검증한다.
