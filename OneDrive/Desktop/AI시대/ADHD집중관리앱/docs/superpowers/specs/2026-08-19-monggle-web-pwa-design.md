# Monggle 웹 PWA 설계

## 목표

기존 Monggle Android 기획과 시각 프로토타입을 모바일 우선 웹 앱으로 구현한다. 사용자가 할 일을 기록하는 데서 끝나지 않고 다음 행동을 즉시 시작하고 완료하도록 돕는 것이 핵심이다. 서버와 유료 API 없이 브라우저 안에서 동작하는 설치형 PWA로 제공한다.

## 범위와 제약

웹 앱은 기존 Android 코드를 대체하지 않는다. 저장소의 `web/` 폴더에 별도 구현한다.

웹에서 동일하게 구현할 수 없는 Android 기능은 다음처럼 대체한다.

- 잠금 화면 위젯: 앱 내부 `한눈` 화면
- 카카오톡·카카오워크 공유 인텐트: 메시지 붙여넣기와 텍스트 분석
- Google Calendar Provider: `.ics` 일정 가져오기·내보내기
- 앱 차단: 집중 모드의 방해 금지 체크리스트
- 완전한 백그라운드 알림: 앱이 열려 있을 때 타이머 알림과 브라우저 알림

서버, 계정, 클라우드 동기화, 유료 API, AI 이미지 생성은 첫 버전에 포함하지 않는다.

## 기술 구조

- React, TypeScript, Vite
- 모바일 설치형 PWA
- IndexedDB 기반 로컬 저장
- 순수 CSS 캐릭터와 테마
- Vitest와 Testing Library
- 브라우저 핵심 흐름 검증

앱은 기능별 모듈로 분리한다.

- `tasks`: 할 일 생성·수정·완료·보류
- `focus`: 단일 집중 타이머와 복원
- `gamification`: XP·레벨·일일 퀘스트·해금
- `schedule`: 일정 표시와 ICS 처리
- `character`: 캐릭터·배경·말풍선
- `settings`: 알림·방해 금지·테마·데이터 관리
- `storage`: IndexedDB 저장과 스키마 마이그레이션

## 화면

하단 탭은 다섯 개다.

1. `홈`: 오늘 할 일, 다음 행동, 일정 빈 시간 추천, XP와 퀘스트
2. `한눈`: 현재 시간, 다음 일정, 가장 중요한 할 일, 짧은 학습 카드
3. `집중`: 원형 타이머, 시작·일시정지·연장·완료
4. `목표`: 레벨, 일일 퀘스트, 누적 집중 시간, 해금 상태
5. `설정`: 테마, 캐릭터, 상기 간격, 방해 금지 시간, 데이터 내보내기·초기화

모바일 기준 너비는 390px이며 데스크톱에서는 중앙의 휴대폰형 프레임으로 표시한다. 기존 `Monggle 프로토타입.dc.html`의 색상, 간격, 타이포그래피, 7종 캐릭터와 7종 배경을 재사용한다.

## 핵심 흐름

### 할 일

사용자는 직접 입력하거나 메시지를 붙여넣어 할 일을 만든다. 메시지 분석은 제목, 예상 시간, 마감 표현을 제안하지만 불확실한 값은 사용자가 확인해야 저장된다. 업무·자기계발·운동·휴식·생활로 분류한다.

### 집중 타이머

5·10·15·25·45분과 직접 입력을 제공한다. 동시에 하나의 타이머만 실행할 수 있다. 시작 시 절대 종료 시각을 저장하여 새로 고침 뒤에도 남은 시간을 복원한다. 완료, 5분 연장, 중단을 제공한다.

### XP와 보상

- 할 일 완료: 20 XP
- 집중 세션 완료: 추가 10 XP
- 일일 퀘스트 완료: 30 XP
- 미완료나 보류에 대한 XP 차감 없음

레벨 요구 XP는 `100 + (현재 레벨 - 1) × 50` 누적 증가 방식이다. 캐릭터와 배경은 레벨, 퀘스트, 누적 집중 시간 조건으로 해금한다.

### 상기

미완료 할 일이 있으면 기본 2시간 간격으로 몽글이가 부드럽게 다음 행동을 제안한다. 23:00~07:00에는 정기 상기를 보내지 않는다. 사용자는 간격을 1·2·3·4시간으로 바꾸거나 오늘만 끌 수 있다.

### 일정

ICS 파일에서 일정을 읽어 오늘·주간 화면에 표시한다. 사용자가 만든 일정은 ICS 파일로 내보낼 수 있다. 외부 캘린더와 실시간 양방향 동기화는 하지 않는다.

## 데이터

브라우저에는 다음 정보를 저장한다.

- 할 일과 상태
- 집중 세션 기록
- 일정
- XP, 레벨, 퀘스트 진행
- 선택한 캐릭터와 배경
- 알림과 방해 금지 설정

초기화 전 확인 단계를 제공한다. JSON 내보내기·가져오기로 백업할 수 있다. 손상된 데이터는 앱 전체를 중단시키지 않고 기본 상태로 복구하며 오류 항목만 제외한다.

## 접근성과 개인정보

- 모든 조작 영역은 최소 46px
- 키보드 포커스 표시
- 움직임 줄이기 설정과 시스템 설정 반영
- 집중 화면에서는 장식 애니메이션 최소화
- 데이터는 외부로 전송하지 않음
- 브라우저 알림 권한은 기능을 처음 켤 때만 요청
- 알림 권한이 없어도 나머지 기능은 정상 작동

## 오프라인과 설치

앱 셸과 정적 자산을 서비스 워커로 캐시한다. 첫 로드 이후 오프라인에서 할 일, 타이머, XP, 캐릭터 기능을 사용할 수 있다. 새 버전이 있으면 사용자가 새로 고침을 선택할 수 있게 안내한다.

## 오류 처리

- IndexedDB 사용 실패: 메모리 모드로 실행하고 경고 표시
- 알림 거부: 앱 내부 알림으로 대체
- ICS 해석 실패: 실패한 일정과 이유 표시
- 타이머 복원 시 종료 시각 경과: 완료 확인 화면 표시
- 중복 메시지 붙여넣기: 최근 항목과 비교해 경고

## 테스트

- 할 일과 XP 규칙 단위 테스트
- 타이머 시작·복원·연장·완료 테스트
- 방해 금지와 상기 시각 테스트
- 저장소 마이그레이션과 손상 데이터 테스트
- ICS 가져오기·내보내기 테스트
- 홈에서 할 일을 만들고 집중 후 완료하는 컴포넌트 테스트
- 새로 고침 뒤 상태 복원 브라우저 테스트
- 모바일과 데스크톱 화면 캡처 검증

## 구현 순서

1. Vite·React·TypeScript·PWA 골격
2. 데이터 모델과 IndexedDB 저장소
3. 앱 셸과 5개 탭
4. 할 일과 메시지 붙여넣기
5. 복원 가능한 집중 타이머
6. XP·퀘스트·해금
7. 캐릭터·배경·상기
8. ICS 일정
9. 설정·백업·오프라인
10. 브라우저 화면 검증

각 단계는 관련 테스트를 먼저 작성하고 통과시킨다. 개발 중에는 관련 테스트만 실행하고 마지막에 전체 검증을 한 번 실행하여 크레딧과 실행 시간을 줄인다.
