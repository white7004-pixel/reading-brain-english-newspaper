# 리딩브레인 학습 웹앱 체크포인트

업데이트: 2026-08-23

## 현재 구현 상태

- 초등학생용 일일 학습 흐름과 세 가지 핵심 학습 섹션이 구현되어 있다.
  1. 패턴영어
  2. 북퀴즈 질문학습
  3. 3단 동사변화 학습
- 학습 카드, 퀴즈, 3회 녹음 연습, 통역 테스트, 오답 복습, 보상 흐름을 제공한다.
- `manifest.webmanifest`와 설치 아이콘을 갖춘 설치형 PWA이다.
- 서비스 워커가 앱 셸과 핵심 학습 데이터를 저장한다.
- 온라인에서 한 번 준비된 앱은 오프라인으로 다시 열 수 있다.
- 오프라인 진도는 `rb-learning-profile-v1`의 `pendingSync`에 먼저 저장된다.
- 연결이 돌아오면 이벤트 ID를 사용하여 진도를 한 번만 서버에 반영한다.
- 음성 파일과 `/api/tts`는 캐시하지 않는다. 오프라인 음성 요청은 학습을 막지 않고 안내 메시지를 표시한다.
- 새 서비스 워커는 학습 도중 강제로 적용하지 않고 사용자가 `업데이트 적용`을 선택할 때 활성화된다.

## 검증 상태

- Node 자동 테스트 26개 통과
- JavaScript 문법 검사 통과
- 실제 Chromium에서 서비스 워커 제어 확인
- 네트워크 차단 후 새로고침해도 앱 본문과 세 학습 섹션 유지
- 360×800 화면에서 가로 넘침과 브라우저 런타임 오류 없음
- 로컬 실행 주소: `http://localhost:4174/`

## 지원 범위

- 설치: Chromium 기반 데스크톱과 Android 브라우저의 PWA 설치 프롬프트
- iOS: 공유 메뉴의 `홈 화면에 추가` 안내
- 오프라인: 앱 실행, 학습 콘텐츠, 코스 상태, 진도와 보상 저장
- 온라인 전용: 로그인 갱신, 서버 진도 동기화, TTS 및 음성 파일 재생

## 다음 권장 작업

1. HTTPS 운영 주소에 배포한다. 로컬호스트 이외의 PWA 설치와 서비스 워커에는 HTTPS가 필요하다.
2. 실제 Android Chrome과 iPhone Safari에서 홈 화면 설치를 확인한다.
3. 한 학생이 오프라인 학습 후 재접속했을 때 교사용 기록에 한 번만 반영되는지 확인한다.
4. 운영 배포 때마다 `service-worker.js`의 `CACHE_VERSION`을 변경한다.

## 저장소 주의사항

- Git 저장소 루트가 사용자 홈 디렉터리여서 다른 프로젝트 변경도 함께 표시된다.
- 이 프로젝트 파일만 명시적으로 선택하고, 다른 폴더의 변경은 수정하거나 커밋하지 않는다.
- 기존 작업 파일에 이전 미커밋 변경이 포함되어 있으므로 자동 커밋하지 않는다.
