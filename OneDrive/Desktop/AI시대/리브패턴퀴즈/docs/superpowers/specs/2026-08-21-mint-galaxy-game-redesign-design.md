# Reading Brain 민트 갤럭시 게임형 리디자인 설계

## 목표

현재 웹앱을 초등학생이 즐겁게 반복 학습할 수 있는 플레이스토어 유료 교육 앱 수준의 모바일 우선 경험으로 전환한다. 기존 로그인, 진도, 점수, 발음, 퀴즈 채점과 학습 데이터는 유지하고 시각 체계와 상호작용만 일관된 게임 디자인 시스템으로 재구축한다.

실제 Android 패키징과 플레이스토어 등록은 범위에 포함하지 않는다.

## 제품 방향

- Reading Brain만의 `민트 갤럭시` 세계관을 사용한다.
- 책 요정 `리브` 한 명이 모든 화면을 안내한다.
- 듀오링고의 짧은 피드백과 명확한 진행 원칙만 참고하며, 색상·캐릭터·레이아웃은 독자적으로 설계한다.
- 외부 3D 엔진, 생성형 이미지 API, 유료 에셋을 사용하지 않는다.
- 3D 표현은 인라인 SVG, CSS 그라데이션, 테두리, 바닥 그림자와 짧은 변형 애니메이션으로 구현한다.

## 색상 시스템

기본 팔레트는 다음과 같다.

- 딥네이비 `#24345B`: 본문, 내비게이션, 강한 대비
- 민트 `#35C6A8`: 진행, 정답, 주요 완료 상태
- 하늘색 `#4DB8FF`: 발음, 정보, 보조 행동
- 별 노랑 `#FFC857`: 점수, 별, 보상, 현재 퀘스트
- 코랄 `#FF6B6B`: 오답과 주의
- 배경 `#F5F8FC`, 표면 `#FFFFFF`, 선 `#DDE5EF`

색상은 의미별로 고정한다. 민트는 성공, 코랄은 오류, 하늘색은 듣기·정보, 노랑은 보상 이외의 용도로 혼용하지 않는다. 본문과 배경은 WCAG AA 대비를 목표로 한다.

## 디자인 시스템

기존에 누적된 화면별 임시 스타일을 공통 토큰과 컴포넌트로 통합한다.

### 토큰

- 색상, 반경, 간격, 테두리, 그림자, 글자 크기, 애니메이션 시간을 CSS 변수로 정의한다.
- 기본 반경은 16·20·28px의 세 단계만 사용한다.
- 버튼과 카드의 바닥 그림자는 4·6·8px의 세 단계만 사용한다.
- 모바일 터치 대상은 최소 56px, 보조 버튼은 최소 48px로 한다.

### 공통 컴포넌트

- `game-surface`: 주요 학습 화면의 흰색 3D 표면
- `quest-card`: 학습 문장과 문제를 담는 카드
- `game-button`: 누르면 바닥 그림자가 사라지며 아래로 이동하는 버튼
- `progress-chip`: 문제 번호, 연속 학습, 상태 표시
- `reward-star`: 점수와 완료 보상
- `mascot-liv`: 리브의 기본·안내·듣기·정답·오답·완료 상태
- `speech-bubble`: 안내와 오류를 표시하는 캐릭터 말풍선

리브의 상태는 여섯 가지로 제한하고 상태 변화는 기존 학습 로직이 제공하는 결과를 받아 표현만 변경한다.

## 화면 설계

### 공통 셸과 내비게이션

- 상단에는 현재 퀘스트 제목, 점수, 연속 학습 상태를 간결하게 표시한다.
- 데스크톱은 왼쪽 탐험 메뉴, 모바일은 `홈·학습·퀴즈·전체` 하단 내비게이션을 사용한다.
- 모바일 안전 영역과 가로 360px부터 태블릿·데스크톱까지 대응한다.

### 패턴 허브

- 학습 경로를 민트 갤럭시의 우주 지도 형태로 표시한다.
- 섹션은 3D 행성 노드로 표현하고 잠김·진행 중·완료 상태를 색과 아이콘으로 함께 구분한다.
- 리브가 오늘의 추천 퀘스트와 이어서 학습할 위치를 안내한다.

### 카드 학습

- 영어 문장을 가장 큰 시각 요소로 중앙에 표시하고 한국어 뜻과 발음을 명확히 분리한다.
- `알아요`, `복습`, `발음`, `이전`, `다음`은 공통 게임 버튼을 사용한다.
- 긴 영어 문장은 글자 크기를 단계적으로 줄이지 않고 최대 너비와 균형 줄바꿈으로 처리한다.

### 퀴즈

- 리브의 말풍선 아래에 문제와 네 개의 입체 선택지를 배치한다.
- 정답은 민트색, 별 효과, 리브의 축하 상태로 표현한다.
- 오답은 코랄색과 짧은 정답 안내를 사용하며 다음 행동을 막지 않는다.
- 선택지는 데스크톱에서 최대 2열, 모바일에서 1열로 표시한다.

### 통역 테스트

- 마이크를 우주 통신기 형태로 표현한다.
- 대기·카운트다운·듣는 중·인식 중·결과 상태를 색, 문구, 리브 표정으로 동시에 전달한다.
- 음성 인식 미지원 환경의 기존 자가 채점 흐름을 유지한다.

### 동사 3단 변화

- 원형·과거형·과거분사를 동일 크기의 3D 블록으로 표현한다.
- 예문은 아래 퀘스트 기록장에 큰 글자로 표시한다.
- 모바일에서는 세 블록을 한 열로 쌓는다.

### 북퀴즈

- 핵심단어와 질문패턴이 동일한 카드와 퀴즈 규칙을 사용한다.
- 현재 제작된 리브 SVG는 공통 캐릭터 컴포넌트로 통합한다.
- 중복 영어와 불필요한 의미 라벨을 표시하지 않는다.

### 포인트 랭킹

- 상위 3명은 우주 시상대, 4~10위는 탐험대 순위표로 표시한다.
- 현재 학생은 민트 테두리와 `나의 순위` 배지로 강조한다.

## 데이터와 상태 경계

- 기존 `state`, 데이터 파일, 로그인·진도·랭킹 API를 유지한다.
- 디자인 컴포넌트는 점수, 진도, 정답 여부를 직접 계산하거나 변경하지 않는다.
- 학습 로직이 결과를 반환하면 UI가 캐릭터·색상·애니메이션 상태로 변환한다.
- 표시 이름과 학생 계정명은 기존 랭킹 모델의 구분을 유지한다.

## 오류 처리

- 네트워크, 발음 재생, 음성 인식 오류는 리브의 말풍선으로 짧고 친절하게 표시한다.
- 오류 색상만으로 상태를 전달하지 않고 아이콘과 문구를 함께 사용한다.
- 데이터가 없을 때 빈 카드 대신 다음 행동을 안내하는 빈 상태를 표시한다.
- 오류가 발생해도 가능한 내비게이션과 재시도 버튼은 유지한다.

## 애니메이션과 성능

- 반응 애니메이션은 기본 120~280ms, 축하 애니메이션은 최대 600ms로 제한한다.
- 이동과 크기 변화는 `transform`과 `opacity`를 우선 사용한다.
- `prefers-reduced-motion`에서는 장식 애니메이션과 흔들림을 제거한다.
- 외부 폰트, 대형 이미지, WebGL, 3D 라이브러리를 추가하지 않는다.

## 접근성

- 모든 조작 요소에 키보드 포커스와 명확한 포커스 링을 제공한다.
- 캐릭터는 장식일 때 보조 기술에서 숨기고, 상태 안내는 별도의 텍스트로 제공한다.
- 정답·오답·잠금 상태는 색상 외에 문구와 아이콘으로 구분한다.
- 본문 최소 16px, 핵심 학습 문장은 모바일 최소 24px를 기준으로 한다.

## 구현 전략

1. 공통 디자인 토큰과 컴포넌트를 별도 최종 디자인 레이어로 만든다.
2. 기존 임시 CSS의 책임을 확인하면서 대체된 규칙을 제거한다.
3. 공통 셸과 내비게이션을 적용한다.
4. 허브와 카드 학습을 전환한다.
5. 퀴즈와 통역 테스트를 전환한다.
6. 동사·북퀴즈·랭킹을 공통 컴포넌트로 통합한다.
7. 모든 화면의 반응형, 접근성, 성능을 검증한다.

구현 중에는 기능 로직 변경과 시각 변경을 같은 단계에서 섞지 않는다. 각 화면은 기존 기능 테스트가 통과한 상태에서 다음 화면으로 진행한다.

## 검증 기준

- 기존 전체 테스트가 통과한다.
- 360, 390, 768, 1024, 1440px에서 가로 넘침이 없다.
- 모든 주요 버튼은 모바일에서 최소 56px 높이다.
- 핵심 문장, 선택지, 한국어 설명이 카드 경계를 벗어나지 않는다.
- 정답·오답·듣기·잠김·완료 상태가 색상 없이도 구분된다.
- 키보드만으로 주요 학습 흐름을 완료할 수 있다.
- 움직임 최소화 설정에서 장식 애니메이션이 실행되지 않는다.
- 첫 화면과 주요 화면이 외부 유료 에셋 없이 정상 표시된다.
- 기존 로그인, 저장, 발음, 채점, 랭킹 기능의 동작이 유지된다.

## 제외 범위

- Android APK/AAB 패키징과 플레이스토어 등록
- 결제, 광고, 구독
- 새로운 학습 콘텐츠 제작
- 서버 인증 구조 변경
- 외부 3D 엔진과 유료 에셋 도입
