## A. 통역 테스트 — 섹션 최종 클리어

### A.1 목표

한글을 보고 영어로 바로 말할 수 있는지 확인하는 마지막 관문. 카드 학습으로 익힌 표현이 실제로 입에서 나오는지를 재고, 통과하면 그 섹션이 **최종 클리어**된다.

### A.2 잠금과 클리어 규칙

- **잠금 해제**: 해당 섹션의 카드 진도가 100% (`mastered === total`)일 때만 통역 테스트에 들어갈 수 있다.
- **클리어**: 섹션 문장 중 **80% 이상**을 통역 성공하면 섹션 클리어.
- 클리어한 섹션은 허브 카드와 사이드바에 `클리어` 상태로 표시한다. 섹션 상태는 기존 `new` / `learning` / `done` 에 `cleared` 가 더해져 4단계가 된다.

### A.3 한 문장의 진행

```
한글 제시 → 3·2·1 카운트다운 → 마이크 자동 ON(최대 8초)
   → 인식 결과 채점 → 판정 + 정답 표시 + 정답 발음 → 다음 문장
```

- 판정이 `재도전`이면 그 문장을 한 번 더 시도한다(문장당 재도전 1회).
- 학생이 흐름을 끊고 싶으면 `일시정지` / `그만두기` 로 빠져나올 수 있다.

### A.4 채점

음성 인식 결과와 정답 문장을 정규화한 뒤 단어 단위로 비교한다.

정규화: 소문자화 → 구두점 제거 → 축약형 전개(`I'm` → `i am`, `don't` → `do not` 등) → 관사(`a`/`an`/`the`) 제거 → 공백 정리.

일치율 = (정답 단어 중 인식 결과에 있는 단어 수) / (정답 단어 수), 순서는 보지 않는다.

| 일치율 | 판정 | 처리 |
|---|---|---|
| 0.8 이상 | `통과` | 다음 문장 |
| 0.5 이상 0.8 미만 | `재도전` | 같은 문장 1회 더 (재도전에서 0.8 미만이면 실패) |
| 0.5 미만 | `실패` | 정답 보여주고 다음 문장 |

아이 발음을 오인식하는 경우가 많으므로 기준을 느슨하게 잡았다. 순서를 보지 않는 것도 같은 이유다.

### A.5 브라우저 지원

`SpeechRecognition` / `webkitSpeechRecognition` 이 없거나 마이크 권한이 거부되면 **자가 채점 폴백**으로 전환한다: 카운트다운 후 정답을 보여주고 학생이 `말했어요` / `못 했어요` 를 직접 누른다. 테스트 자체가 막히지 않게 하는 것이 목적이다.

### A.6 컴포넌트

`interpretation-model.js` (신규, 순수 모듈, DOM 없음):

| 함수 | 역할 |
|---|---|
| `normalizeAnswer(text)` | 정규화된 단어 배열 |
| `scoreAttempt(spoken, expected)` | `{ ratio, verdict }` — verdict 는 `pass`/`retry`/`fail` |
| `summarizeRun(results, passRate)` | `{ total, passed, percent, cleared }` |
| `isSectionUnlocked(section)` | 카드 100% 여부 |

화면: 새 뷰 `#interpretView`, 모드바에 `통역 테스트` 추가. 저장: `rb-cleared` 에 클리어한 섹션 키 배열.

## B. 블래스트 게임 연장

현재는 목숨 3, 정답 5개마다 웨이브 상승, 낙하 시간 `5.5 - (wave-1)*0.4`(최저 1.5초)라 웨이브 11이면 1.5초까지 떨어져 금방 끝난다.

패턴·동사·북퀴즈 세 게임에 흩어져 있는 같은 수치를 상수 하나로 모으고 다음처럼 조정한다.

| 항목 | 지금 | 바꿀 값 |
|---|---|---|
| 목숨 | 3 | 5 |
| 웨이브 승급 | 정답 5개 | 정답 8개 |
| 낙하 시작 | 5.5초 | 6.5초 |
| 낙하 하한 | 1.5초 | 2.2초 |
| 웨이브당 감소 | 0.4초 | 0.25초 |
| 보너스 목숨 | 없음 | 3웨이브마다 +1 (최대 5) |

체감 플레이 시간이 대략 3배가 된다.

## C. 모바일 · 태블릿 대응

- **사이드바**: 1000px 이하에서 상단 고정 헤더 + 왼쪽 슬라이드 드로어로 전환(햄버거 버튼, 배경 딤, ESC/바깥 클릭으로 닫기). 섹션을 고르면 자동으로 닫힌다.
- **허브**: 그리드를 태블릿 2열 / 모바일 1열로. `hub-toolbar` 는 좁아지면 세로로 쌓아 그룹 탭이 잘리지 않게 한다(현재 잘림 버그).
- **카드**: 좁은 화면에서 `aspect-ratio` 대신 최소 높이 기반으로 바꿔 글자가 넘치지 않게 한다.
- **블래스트**: 아레나 높이를 `vh` 기반으로, 보기 버튼을 2열 그리드로.
- **터치**: 모든 조작 요소 최소 44px.
- **한글 줄바꿈**: `word-break: keep-all` 로 `I like / want / have 패 턴` 처럼 음절이 끊기는 문제를 잡는다.

## E. 듀오링고식 학습 경로

허브의 섹션 카드 그리드를 잠금이 걸린 **학습 경로**로 바꾼다.

- **유닛**: 섹션 6개를 한 유닛으로 묶는다. 기초 패턴 23개 → 4유닛, Training 800 42개 → 7유닛. 유닛 헤더에 `UNIT n · 01 – 07` 과 `n / 6 클리어` 를 적는다.
- **노드**: 섹션 하나가 지그재그로 놓인 원형 노드. 진도가 링으로 차오르고, 클리어하면 체크, 잠기면 자물쇠가 뜬다. 지금 붙어야 할 칸에는 `지금 여기` 배지가 붙고 살짝 위아래로 움직인다.
- **잠금 규칙** (`applyPathState`): 첫 섹션은 항상 열림, 그 뒤는 **바로 앞 섹션을 클리어**해야 열린다. 다만 **이미 진도가 있는 섹션은 순서와 무관하게 열어 둔다** — 경로를 도입하면서 기존 학생의 진도를 되돌리지 않기 위해서다.
- 유닛은 첫 섹션이 열려 있을 때 열린 것으로 본다.
- 카드 학습 마지막 장에서 다음 섹션으로 자동 이동하던 동작은 **잠긴 섹션으로는 넘어가지 않도록** 막았다. 마지막 카드에 머물면서 통역 테스트 안내 배너를 띄운다.
- 사이드바 네비게이터도 같은 잠금 상태를 따른다(잠긴 행은 비활성 + 자물쇠, 클리어한 행은 체크).

## D. 비주얼 정리 — 이모지와 그라디언트

두 가지만 손본다. 레이아웃과 문구는 그대로 둔다.

- **이모지 제거**: 모드바 아이콘(🏠🃏✏️🔗⚡🔁🏆), 목숨 표시(❤️🖤), 그 밖의 UI 이모지를 전부 걷어내고 `currentColor` 를 쓰는 인라인 SVG 라인 아이콘으로 교체한다. 카드 뒷면 삽화용 `_EMOJI_MAP` 은 학습 콘텐츠이므로 건드리지 않는다.
- **그라디언트·글로우 축소**: 배너·버튼·진도바·링에 걸린 다색 그라디언트와 색진 그림자를 단색과 중립 그림자로 내린다. 강조색(골드)은 한 화면에 한 곳만 쓰는 것을 원칙으로 한다.

### D.2 듀오링고풍 마감

귀여움은 색을 밝히는 대신 **형태**로 만든다. 그라디언트를 다시 늘리지 않는다.

- 눌리는 3D 립 버튼: 아래쪽에 짙은 단색 그림자(`0 4px 0`)를 깔고, 누르면 그만큼 내려앉는다.
- 굵은 테두리(2–3px)와 큰 라운드(12 / 16 / 20px), 통통한 진도바(12px).
- 경로 노드는 립이 달린 원형 버튼.

### D.3 색 조정

처음 넣은 밝은 하늘색(`#2aa7e0`)은 면적이 넓은 곳(이어하기 배너·모드바)에 쓰이자 눈에 부담이 컸다. 브랜드 색 안으로 되돌린다.

| 자리 | 바꾼 색 |
|---|---|
| 이어하기 배너 · 모드바 활성 · 섹션 칩 | 네이비 `--ink` |
| 진도바 · 클리어 상태 | 차분한 초록 `#3f9e7c` |
| 강조 배지 · 링 | 골드 `#e8ab24` |
| 오답 · 목숨 | 와인 `#c2494f` |
