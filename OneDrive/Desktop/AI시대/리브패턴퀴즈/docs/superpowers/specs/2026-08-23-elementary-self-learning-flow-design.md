# 초등 영어 혼자학습 흐름 개편 설계

## 1. 목표

초등학교 1~6학년 학생이 보호자나 교사의 도움 없이 앱을 열고, 주어진 영어 자료를 학습하고, 퀴즈와 말하기 연습을 거쳐 하루 학습을 끝낼 수 있게 한다. 기존 세 학습 섹션과 자료는 유지하면서 화면 전환, 오답 복습, 저장과 복귀를 하나의 일관된 경험으로 만든다.

핵심 성공 조건은 다음과 같다.

- 학생이 홈에서 한 번의 선택으로 약 10분 학습을 시작한다.
- 정답이나 오답을 선택하면 피드백 후 다음 문제로 정확히 한 번 이동한다.
- 중간에 앱을 닫아도 마지막 완료 지점부터 이어서 학습한다.
- 음성 재생, 녹음 또는 음성 인식이 실패해도 학습이 중단되지 않는다.
- 휴대전화와 태블릿에서 카드와 글자가 잘리거나 한쪽으로 쏠리지 않는다.

## 2. 대상과 운영 원칙

- 대상: 초등학교 1~6학년
- 사용 방식: 학생 혼자 학습
- 기본 학습 시간: 하루 약 10분
- 콘텐츠 원칙: 프로젝트에 이미 제공된 자료만 사용하며 새로운 교재 문장을 임의로 추가하지 않는다.
- 진행 원칙: 메뉴 선택은 최소화하고, 학습에 들어간 뒤에는 다음 행동을 화면이 안내한다.
- 실패 원칙: 오답이나 발음 인식 실패로 별, 생명 또는 학습 기회를 차감하지 않는다.

## 3. 콘텐츠 구조

최상위 학습 섹션은 기존 구성을 유지한다.

### 3.1 패턴영어

- 자료: `data/expressions.js`
- 분량: 표현 1,189개, 주제 65개
- 기존 단계: Seed 120개, Leaf 120개, Brain 949개
- 기존 섹션과 학습 맵을 유지한다.
- 기본 코스: 표현 카드 5개 → 듣기 → 퀴즈 5문제 → 3회 녹음 연습 → 통역 테스트 → 오답 복습 → 보상

### 3.2 북퀴즈 질문학습

- 자료: `data/bookquiz.js`
- 분량: 핵심 단어 21개, 질문 표현 22개
- 핵심 단어와 질문 패턴을 구분하되 하나의 연속 코스로 연결한다.
- 기본 코스: 핵심 단어 학습 → 단어 듣기 → 단어 퀴즈 → 질문 패턴 학습 → 질문 퀴즈 → 오답 복습 → 보상
- 단어 화면의 음성 버튼은 `단어 듣기`, 질문 화면은 `표현 듣기`로 표시한다.

### 3.3 3단 동사변화 학습

- 자료: `data/verbs.js`
- 분량: 전체 158개, 초등 61개, 중등 54개, 고등 43개
- 기본 초등 코스에는 초등 61개를 사용한다.
- 중등과 고등 자료는 삭제하지 않고 심화 학습으로 잠가 둔다.
- 기본 코스: 뜻과 원형 학습 → 원형·과거형·과거분사 듣기 → 세 형태 순서대로 말하기 → 빈칸 퀴즈 → 오답 복습 → 보상

## 4. 홈과 내비게이션

홈의 최우선 행동은 `오늘의 10분 학습`이다. 중단 기록이 있으면 버튼 문구를 `이어서 학습하기`로 바꾸고 정확한 중단 지점으로 이동한다.

홈에는 다음 항목만 우선 노출한다.

- 오늘의 10분 학습 또는 이어서 학습하기
- 패턴영어
- 북퀴즈 질문학습
- 3단 동사변화 학습
- 오늘의 학습 시간, 완료 단계, 정답률
- 연속 학습일, 획득한 별과 배지

설정, 학년 변경, 기록 초기화처럼 학생이 실수로 바꾸면 안 되는 기능은 보호자 확인 화면 뒤에 둔다. 학습 중에는 전체 메뉴를 숨기고 종료, 진행률, 현재 단계만 보여준다.

## 5. 공통 학습 상태 흐름

모든 퀴즈는 동일한 상태 전이를 사용한다.

1. 문제와 선택지를 표시한다.
2. 학생의 첫 선택만 받으며 즉시 모든 선택지를 잠근다.
3. 정답 또는 오답 피드백과 정답을 표시한다.
4. 현재 결과와 다음 문제 위치를 저장한다.
5. 약 1초 뒤 다음 문제를 정확히 한 번 생성한다.
6. 단계의 마지막 문제라면 다음 문제 대신 단계 완료 화면을 연다.

정답이면 초록색 상태, 짧은 칭찬, 별 획득을 보여준다. 오답이면 선택한 답과 정답을 함께 표시하고 정답 음성을 재생한다. 오답 및 `모르겠어요` 항목은 코스 마지막 복습 대기열에 한 번만 추가한다.

공통 도움 기능은 다음과 같다.

- 다시 듣기: 횟수 제한 없음
- 단계 힌트: 핵심 단어 → 첫 글자 → 전체 정답
- 모르겠어요: 정답을 학습하고 다음 문제로 이동
- 잠시 나가기: 현재 단계와 문제 위치 저장
- 이어서 하기: 저장된 위치로 복귀

## 6. 통역 테스트 전 3회 녹음 연습

3회 녹음은 패턴영어의 통역 테스트 직전에 제공한다.

1. 영어 문장을 보고 원어민 음성을 들은 뒤 따라 말한다.
2. 핵심 단어 힌트만 보고 말한다.
3. 한글 뜻만 보고 영어로 말한다.

각 회차에서 녹음, 다시 녹음, 내 목소리 듣기를 제공한다. 음성 인식 결과는 참고용 별점으로만 표시하며 다음 단계 진입을 막는 통과 점수로 사용하지 않는다. 세 회차를 완료하면 통역 테스트 시작 버튼을 연다.

마이크 권한을 거부하거나 녹음 기능을 사용할 수 없으면 학생은 원어민 음성을 듣고 `연습했어요`를 눌러 계속할 수 있다. 기능 실패를 오답으로 처리하지 않는다.

## 7. 학년군별 표현 방식

학년군에 따라 별도 메뉴를 만들지 않는다. 같은 세 학습 섹션 안에서 화면 밀도와 도움 수준을 조절한다.

- 1~2학년: 큰 글자, 한 화면 한 행동, 그림·음성·단어 중심, 힌트 상시 노출
- 3~4학년: 짧은 문장과 기본 패턴, 핵심 단어 강조, 힌트 선택 제공
- 5~6학년: 문장 확장과 상황 통역, 힌트는 요청할 때만 표시

가입 또는 최초 실행에서 학년을 선택한다. 학년 선택은 콘텐츠를 삭제하거나 갈라놓지 않고 기본 난이도와 도움 표시만 결정한다.

## 8. 저장과 복귀

저장 상태는 학생별로 구분하며 다음 정보를 포함한다.

- 선택한 학년
- 현재 학습 섹션과 세부 단계
- 현재 콘텐츠 ID와 문제 번호
- 단계별 완료 여부
- 오답 복습 대기열
- 획득 별, 배지, 연속 학습일
- 녹음 연습 회차 완료 여부

문제 답변 직후와 단계 완료 직후 저장한다. 재실행 시 이미 처리한 문제를 다시 점수 처리하지 않는다. 저장 데이터가 손상되면 해당 코스의 마지막 완료 단계로 되돌리고 학생에게 쉬운 안내를 보여준다.

## 9. 보상

- 정답: 별 획득
- 10분 코스 완료: 완료 배지와 보물상자 연출
- 연속 학습: 3일, 7일, 14일 배지
- 오답 재도전 성공: `다시 도전 성공` 보상
- 오답: 별이나 생명 차감 없음

첫 출시에서는 복잡한 상점이나 캐릭터 꾸미기를 제외한다. 보상은 학습 완료를 확인하는 짧은 피드백으로 제한한다.

## 10. 아동 개인정보와 녹음

- 마이크 권한은 녹음 연습 진입 시점에만 요청한다.
- 권한을 거부해도 핵심 학습을 계속할 수 있다.
- 녹음은 기본적으로 기기에 임시 저장한다.
- 코스 종료 시 녹음을 자동 삭제한다.
- 첫 출시에서는 녹음 파일 외부 전송, 교사 공유, 음성 복제 기능을 포함하지 않는다.
- 개인정보처리방침과 Play Console 데이터 보안 신고는 실제 앱 동작과 일치해야 한다.
- 첫 출시 수익 모델은 아동 대상 광고보다 광고 없는 유료 앱 또는 보호자 구독을 우선 검토한다.

## 11. 화면과 접근성 기준

- 핵심 행동 버튼의 터치 영역은 최소 48dp 상당을 확보한다.
- 문제, 질문, 정답 선택지는 중앙 정렬하며 긴 문장은 자연스럽게 줄바꿈한다.
- 고정 너비 카드나 절대 위치로 주요 콘텐츠를 배치하지 않는다.
- 작은 휴대전화, 일반 휴대전화, 태블릿 가로·세로 화면을 지원한다.
- 색상만으로 정답과 오답을 구분하지 않고 아이콘과 문구를 함께 사용한다.
- 음성 재생 중 상태, 녹음 중 상태, 자동 이동 대기 상태를 눈에 보이게 표시한다.

## 12. 출시 품질 기준

- 모든 주요 학습 흐름을 처음부터 완료 화면까지 자동 테스트한다.
- 정답, 오답, 모르겠어요 각각이 다음 문제를 한 번만 생성하는지 검사한다.
- 백그라운드 전환, 화면 잠금, 네트워크 단절, 마이크 거부 후 복귀를 검사한다.
- 시작이 2초를 넘으면 진행 상태를 표시한다.
- 충돌, ANR, 중복 음성, 중복 클릭, 화면 잘림을 출시 차단 항목으로 둔다.
- Android 배포 단계에서 Android 16/API 36 이상을 대상으로 패키징한다.
- Google Play 가족 정책, 데이터 보안 신고, 개인정보처리방침을 출시 전에 다시 확인한다.

## 13. 범위 구분

이번 학습 흐름 개편에 포함한다.

- 세 학습 섹션의 정보 구조 정리
- 오늘의 10분 학습과 이어서 하기
- 공통 자동 진행과 오답 복습
- 패턴영어 3회 녹음 연습
- 학년군별 화면 도움 조절
- 저장·복귀와 기본 보상
- 모바일·태블릿 반응형 품질 개선

별도 Android 출시 단계로 분리한다.

- 웹 앱의 Android 패키징
- Play Billing 유료 판매 또는 보호자 구독
- 스토어 등록정보와 스크린샷 제작
- Play Console 가족 정책 및 데이터 보안 제출
- 실기기 배포 테스트

첫 출시 범위에서 제외한다.

- 외부 음성 복제 서비스
- 학생 녹음의 서버 보관 또는 공유
- 광고 기반 보상
- 소셜 채팅과 공개 순위 경쟁

## 14. 검증 시나리오

1. 새 학생이 학년을 선택하고 오늘의 10분 학습을 시작한다.
2. 세 학습 섹션 중 선택한 섹션의 첫 단계가 열린다.
3. 정답·오답·모르겠어요 후 다음 문제로 정확히 한 번 이동한다.
4. 코스 중간에 앱을 닫고 다시 열어 정확한 단계로 복귀한다.
5. 패턴영어에서 세 녹음 회차를 완료하고 통역 테스트를 시작한다.
6. 마이크 권한을 거부해도 통역 테스트까지 진행한다.
7. 오답이 마지막에 다시 출제되고 성공 보상을 받는다.
8. 완료 후 홈의 오늘 기록, 별, 연속 학습일이 갱신된다.
9. 작은 휴대전화와 태블릿에서 카드, 문장, 선택지가 잘리지 않는다.
