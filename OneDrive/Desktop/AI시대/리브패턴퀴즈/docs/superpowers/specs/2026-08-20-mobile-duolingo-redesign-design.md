# 모바일 중심 듀오링고형 UI 개편 디자인

## 목표

기존 학습 기능과 데이터 흐름을 유지하면서 전체 인터페이스를 모바일 중심의 밝고 활기찬 학습 게임 UI로 통일한다. 이미지 생성, 유료 API, 외부 플러그인은 사용하지 않고 현재 저장소의 HTML, CSS, JavaScript, 로컬 자산만 사용한다.

## 디자인 원칙

- 한 화면에는 하나의 핵심 학습 과제를 가장 강하게 보여준다.
- 모바일 터치 영역은 최소 48px을 확보한다.
- 초록은 주요 행동과 완료, 파랑은 정보와 현재 위치, 빨강은 오답과 위험 상태에만 사용한다.
- 버튼은 두꺼운 테두리와 아래쪽 그림자로 눌리는 감각을 제공한다.
- 긴 한국어와 영어 문장은 중앙 정렬과 균형 잡힌 줄바꿈을 기본으로 한다.
- 장식보다 학습 진행 상태와 다음 행동의 명확성을 우선한다.

## 전체 구조

### 모바일

- 상단에는 현재 섹션, 포인트, 연속 학습 정보를 간결하게 표시한다.
- 중앙 콘텐츠는 단일 열과 전체 폭 카드 구조를 사용한다.
- 화면 하단에는 `홈`, `카드`, `퀴즈`, `매칭`, `전체` 고정 내비게이션을 둔다.
- `전체`는 기존 사이드바의 섹션 탐색과 보조 학습 기능을 여는 메뉴 역할을 한다.
- 하단 내비게이션 높이만큼 본문 하단 여백을 확보해 콘텐츠가 가려지지 않게 한다.

### 태블릿과 PC

- 태블릿은 콘텐츠 종류에 따라 1열 또는 2열을 사용한다.
- PC에서는 기존 사이드바 탐색을 유지하되 콘텐츠 최대 폭을 제한해 시선이 퍼지지 않게 한다.
- 모바일 하단 내비게이션은 PC에서 숨긴다.

## 화면별 설계

### 패턴 허브

- 오늘의 목표와 이어서 학습하기를 최상단 핵심 카드로 배치한다.
- 학습 경로는 완료, 현재, 잠김 상태가 색상과 채움으로 즉시 구분되게 한다.
- 섹션 카드는 모바일에서 한 열로 표시하며 제목과 진행률을 짧게 정돈한다.

### 카드 학습

- 학습 카드를 화면의 중심에 크게 배치한다.
- 이전, 뒤집기, 다음 행동은 엄지손가락이 닿기 쉬운 하단에 모은다.
- 발음 듣기는 주요 행동으로 유지하고 단축키 안내는 모바일에서 숨긴다.

### 섹션퀴즈

- 탭, 문제 번호, 범위, 질문, 문제 문장, 선택지를 하나의 중앙축에 배치한다.
- 선택지는 모바일 한 열이며 문구를 가로·세로 중앙 정렬한다.
- 새 문제 버튼은 모바일에서 전체 폭 보조 버튼으로 배치한다.
- 정답과 오답은 색상뿐 아니라 테두리와 눌림 상태로도 구분한다.

### 매칭

- 제목과 안내 문구를 중앙 정렬한다.
- 매칭 카드는 모바일 2열을 기본으로 하되 좁은 화면에서도 문장이 잘리지 않게 한다.
- 선택, 정답, 오답 상태에 명확한 색상과 입체 반응을 적용한다.

### 통역, 블래스트, 복습, 랭킹

- 동일한 카드 반경, 버튼 높이, 상태 색상 체계를 공유한다.
- 게임 화면에서는 불필요한 상단 정보를 줄이고 현재 행동에 집중한다.
- 결과 화면은 점수, 피드백, 다음 행동 순서로 위계를 고정한다.

### 북퀴즈와 동사 학습

- 패턴 학습과 동일한 상단, 카드, 버튼, 상태 디자인 토큰을 사용한다.
- 기존 기능과 데이터 구조는 변경하지 않는다.

## 디자인 토큰

- 배경: 따뜻한 밝은 회색
- 표면: 흰색
- 주요 행동: 선명한 초록
- 보조 정보: 밝고 선명한 파랑
- 오답과 위험: 제한적인 빨강
- 비활성 상태: 중성 회색
- 반경: 카드 18~24px, 버튼 12~16px
- 입체감: 버튼 아래 3~5px 색상 그림자
- 간격: 4px 단위 체계를 기본으로 사용

## 상호작용과 접근성

- 키보드 포커스 표시를 유지한다.
- 색상만으로 상태를 전달하지 않는다.
- 터치 상태와 클릭 상태에서 버튼이 아래로 눌리는 반응을 제공한다.
- `prefers-reduced-motion` 사용자는 큰 이동 애니메이션을 받지 않는다.
- 모바일 안전 영역을 고려해 하단 내비게이션에 `env(safe-area-inset-bottom)`을 적용한다.

## 구현 범위

- `index.html`: 모바일 하단 내비게이션과 필요한 구조적 클래스 추가
- `styles.css`: 디자인 토큰, 공통 컴포넌트, 화면별 반응형 스타일 정비
- `app.js`: 하단 내비게이션과 기존 모드 전환 연결에 필요한 최소 변경
- `tests/`: 내비게이션 구조, 캐시 갱신, 핵심 반응형 규칙 회귀 테스트

기존 데이터 모델, 로그인 API, 학습 진행 저장 방식은 변경하지 않는다.

## 검증

- 기존 Node 테스트 전체 실행
- HTML과 CSS 정적 회귀 테스트 실행
- 모바일, 태블릿, PC 폭에서 핵심 화면 레이아웃 확인
- 퀴즈와 매칭에서 긴 문장 중앙 정렬 확인
- 하단 내비게이션이 콘텐츠를 가리지 않는지 확인
- 기존 모드 전환과 학습 진행 저장 동작 확인

## 완료 기준

- 모바일에서 핵심 학습 모드에 한 번의 탭으로 접근할 수 있다.
- 모든 주요 버튼이 터치하기 쉽고 일관된 입체 스타일을 사용한다.
- 퀴즈와 매칭의 문구가 중앙축에서 벗어나지 않는다.
- 기존 학습 기능과 테스트가 그대로 동작한다.
- 외부 유료 서비스나 크레딧 사용이 없다.
