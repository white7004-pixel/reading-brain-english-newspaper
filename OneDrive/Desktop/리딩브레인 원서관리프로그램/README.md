# 리딩브레인 원서프로그램

책 한 권 = 파일 하나. `books/<slug>.js` 를 만들면 워크시트와 교사용 가이드가 같이 나온다.

```
index.html           책 목록 — 여기서 시작한다
app.html             온라인 학습 — 쉐도잉·단어·테스트·퀴즈·서술형
review.html          첨삭 — 학생이 낸 글을 고쳐 주고 점수·총평을 남긴다
app.css / store.js   온라인 학습 화면과 저장소
worksheets.html      학생용 9장 — 위 [정답 보기] 를 켜면 교사용 정답본
teacher-guide.html   교사용 8장 — 지도 포인트·수업 대사 5장·북토킹·채점표
sheet.css            둘이 같이 쓰는 인쇄 스타일
books/<slug>.js      책 한 권분 내용
books/index.js       책 목록 (slug 한 줄씩)
assets/covers/       원서 표지 (자동으로 받는다)
assets/qr/           쉐도잉 QR (자동으로 만든다)
scripts/             표지·쉐도잉 영상·영영뜻 자동 수집
```

여는 법: `index.html` 을 더블클릭하면 크롬에서 책 목록이 열린다. 인쇄는 Ctrl+P → PDF 저장.
목록은 AR 낮은 순이고, 위 검색창에 제목·작가·AR·렉사일·수상명·리딩브레인 레벨 아무거나 치면 걸러진다.

**책은 주소로 고른다.** 파일을 고칠 필요가 없다.

```
worksheets.html?book=hi-fly-guy
teacher-guide.html?book=hi-fly-guy
```

`?book=` 을 안 붙이면 `charlottes-web` 이 열린다.

지금 들어 있는 책 — 레벨 띠가 셋 다 되는지 이 세 권으로 확인한다.

| slug | 책 | AR | 띠 |
|---|---|---|---|
| `hi-fly-guy` | Hi! Fly Guy | 1.5 | `lv-low` |
| `sarah-plain-and-tall` | Sarah, Plain and Tall | 3.4 | `lv-mid` |
| `charlottes-web` | Charlotte's Web | 4.4 | `lv-high` |

**화면에서 바로 푼다.** 빈칸을 클릭하면 타이핑이 된다. 그대로 인쇄하면 밑줄이라 손으로도 푼다.
같은 파일 하나로 온라인·오프라인 둘 다 된다.

## 새 책 추가하기

1. `books/charlottes-web.js` 를 복사해 이름을 바꾼다
2. 내용을 그 책에 맞게 고친다
3. 표지를 받는다

```bash
python scripts/fetch-cover.py <slug>
```

4. 쉐도잉 영상을 찾고 QR 을 만든다 (`assets/qr/<slug>.png` 까지 같이 나온다)

```bash
python scripts/fetch-shadowing.py <slug>
```

5. 영영 뜻을 사전에서 확인한다 — **보기만 하고 파일은 건드리지 않는다.**
   표에서 책에 쓰인 뜻을 눈으로 고른 뒤 `books/<slug>.js` 에 직접 적는다.

```bash
python scripts/fetch-definitions.py <slug>
```

6. 단어 발음(원어민 녹음)을 받는다. 막히면 잠시 뒤 같은 명령을 다시 돌린다 — 받은 건 건너뛴다

```bash
python scripts/fetch-word-audio.py <slug>
```

7. `books/index.js` 에 slug 를 한 줄 더한다 — 이래야 목록에 뜬다

8. `worksheets.html?book=<slug>` 로 열어 본다. 위쪽에 `⚠ A4 넘침` 이 없어야 한다

9. `app.html?book=<slug>` 로 열어 다섯 탭이 다 도는지 본다

**책 파일에 꼭 있어야 하는 것** — 하나라도 빠지면 그 탭이 빈다.
`vocabulary` `grammar` `comprehension` `quiz` `summaryMap` `mindMap` `ib` `essay` `teaching`

## 책 정보에 반드시 들어가는 것

모든 워크시트와 교사용 가이드 머리에 이 여섯 가지가 늘 같이 찍힌다.

| 항목 | 자리 | 예 |
|---|---|---|
| 표지 이미지 | `cover` | `assets/covers/charlottes-web.jpg` |
| 책 제목 | `title` | Charlotte's Web |
| 시리즈 | `series` | Classic Chapter Book |
| 작가 | `author` | E.B. White |
| AR · Lexile · 리딩브레인 레벨 | `level` | AR 4.4 · 680L · 정독 3단계 |
| 수상 (칼데콧·뉴베리 등) | `awards` | Newbery Honor 1953 |

수상이 없으면 `awards: []` 로 둔다. 없는 상을 지어내지 않는다.

## 단어는 영영 뜻을 같이 넣는다

단어마다 `en`(영영) 과 `ko`(한글) 를 둘 다 채운다. 한 칸에 위아래로 찍힌다 —
영영이 위에 진하게, 한글이 아래 작게. 학생이 **영영을 먼저 읽고 막히면 한글로 확인**하는 순서다.

```js
{ word: "humble", pos: "adj.",
  en: "not proud; not thinking you are better than others",
  ko: "겸손한",
  ex: "Charlotte chose the word {{humble}} for the fair." },
```

영영 뜻은 **그 레벨 아이가 읽을 수 있는 쉬운 말로 새로 쓴다.** 사전 문장을 그대로 옮기지 않는다.
뜻풀이에 그 단어 자체를 쓰지 않는다 (`humble` 을 "being humble" 로 풀면 소용이 없다).

사전 문장을 그대로 쓴 책만 `defSource: "Wiktionary (CC BY-SA)"` 를 적는다. 그러면 1장 아래에
출처 한 줄이 찍힌다. 직접 쉬운 말로 새로 쓴 책은 `defSource: ""` 로 비워 둔다 —
1점대 책은 사전 뜻이 아이에게 너무 어려워서 대부분 직접 쓰게 된다.

## 자동 수집이 어떻게 고르는가

**표지** — Open Library 에서 제목·작가가 맞고 **판본이 가장 많은** 책을 고른다. 판본이 많다는 건
그 책의 대표 표지라는 뜻이다. 못 찾으면 아무것도 바꾸지 않고 알려 준다. 그때는
`assets/covers/<slug>.jpg` 에 직접 넣으면 된다.

**쉐도잉 영상** — 유튜브를 **조회수 높은 순**으로 검색하되, 조회수 1등을 그냥 집지 않는다.
책 제목만 스쳐도 조회수 수억짜리 영상이 먼저 올라오기 때문이다. 두 번 거른다.

1. 영상 제목에 책 제목이 들어 있을 것
2. 낭독·오디오북 계열일 것 (예고편·영화·노래·리뷰는 버린다)

그러고 나서 조회수 순으로 3개를 남긴다. 첫 번째가 워크시트 1장에 찍힌다.
마음에 안 들면 `books/<slug>.js` 의 `shadowing.videos` 순서를 바꾸면 된다.

### 온라인으로 풀고 자동채점, 또는 PDF 로 받아 손으로

같은 `worksheets.html` 하나로 두 가지를 다 한다.

- **온라인** — 위에 이름을 적고 빈칸·줄에 바로 쓴다. Enter 를 누르면 다음 칸으로 간다.
  쓴 것은 이름별로 이 브라우저에 저장돼서 창을 닫았다 열어도 남는다.
  **채점하기**를 누르면 장마다 점수가 붙고, 틀린 칸 옆에 빨간 정답이 나온다.
- **오프라인** — **PDF 다운로드 · 인쇄** → 대상에서 "PDF로 저장". 채점 표시는 인쇄되지 않는다.
  빈 워크시트가 필요하면 먼저 **다시 풀기**로 비운다.

채점은 칸마다 방식이 다르다 (`grade.js`, 확인은 `node grade.js`).

| 장 | 채점 |
|---|---|
| Word Test · Grammar · Exam Grammar | 글자 그대로. 대소문자·문장부호만 봐준다. 문법은 한 글자도 봐주지 않는다 |
| Comprehension · Summary Map | 정답의 핵심 낱말이 80% 이상이면 맞음, 50% 이상이면 **△ 선생님 확인**. 핵심 낱말이 하나뿐인 답(`lonely`, `was not`)은 그 낱말만 써야 맞다 |
| Mind Map · IB Inquiry · Writing | 채점하지 않는다. 정답이 없는 칸이다. 서술형 첨삭은 app.html → review.html 로 |

정답이 여러 개면 책 파일에 `{{hello / a greeting}}` 처럼 `/` 로 적는다.

## 혼자서도 풀 수 있게 하는 장치

선생님이 옆에 붙어 설명해야 풀리는 워크시트는 학원에서 못 쓴다. 세 가지로 막는다.

**AR 에 따라 글자와 여백이 바뀐다.** `books/<slug>.js` 의 `level.ar` 를 보고 자동으로 정해진다.

| 띠 | 기준 | 어떻게 |
|---|---|---|
| `lv-low` | AR 2 미만 | 글자 제일 크게, 칸 넓게, 줄 수 적게 |
| `lv-mid` | AR 4 미만 | 조금 크게 |
| `lv-high` | AR 4 이상 | 기본 |

손으로 정하고 싶으면 `band: "low"` 를 책 파일에 적으면 그게 우선한다.

**지시문은 한글이 크고 영어가 아래.** 아이가 한글을 먼저 읽고 바로 시작한다.

**첫 문항은 이미 풀려 있다.** 단어시험·독해·요약 세 장은 1번 칸에 회색으로 답이 적혀 있고
`보기` 딱지가 붙는다. "이렇게 쓰면 된다" 를 말로 설명하지 않아도 된다.

**쉐도잉은 QR 로.** 1장 오른쪽 위 QR 을 찍으면 낭독 영상이 바로 열린다.
주소를 불러 줄 필요도, 링크를 카톡으로 보낼 필요도 없다.

## 온라인 학습 (app.html)

목록에서 **온라인 학습** 을 누르면 열린다.

| 탭 | 하는 일 |
|---|---|
| 쉐도잉 | 유튜브 낭독 영상 + 내 목소리 **녹음**. 여러 회차면 버튼으로 고른다 |
| 단어학습 | **Word → Sentence → Test** + Word Box (아래). 단어 시험도 여기 Test 에 있다 |
| 북퀴즈 | 10문제 객관식 → 자동 채점, 틀린 문제는 영어 해설을 읽어 주고 한국어 설명은 단추로 |
| AI 북토크 | AI 와 그 책 이야기를 영어로 2~3분 |
| 서술형 | 단계별로 쓰고 자동 저장. 조건은 글을 보고 ☑ 로 바뀐다. 제출하면 선생님에게 간다 |

이름을 적어야 저장된다. 점수는 탭 위 숫자로 바로 보인다.

### 단어학습 (리딩터치 Vocabulary 방식)

라하영어 리딩터치 앱의 단어학습과 같은 흐름이다. **앞 단계를 끝내야 다음 단계가 열린다** (🔒).

| 단계 | 하는 일 |
|---|---|
| **Word** | 한 장씩 그림 · 단어 · 뜻. 🔊 원어민 발음을 듣고 🎤 **Start** 로 따라 말하면 *Excellent! / Great! / Good! / Try again* 이 뜬다. 🗣️ **듣고 따라** 는 발음을 들려준 뒤 바로 마이크를 연다. 끝까지 넘기면 Sentence 가 열린다 |
| **Sentence** | 위에 한국어 해석, 아래 영어 문장 빈칸. A·B·C 중 골라 채우면 바로 맞고 틀림이 보이고 문장을 읽어 준다. 끝까지 풀면 Test 가 열린다 |
| **Test** | 뜻→단어 · 소리→뜻 · 단어→뜻 · 그림→단어 를 섞어 푼다. 제출하면 **Reading Report(리딩 리포트)**(Score · 유형별 점수 · 걸린 시간 · 문항표)가 나오고 인쇄할 수 있다 |
| **📦 Word Box** | 공부한 단어 모음. 전체 · 최근(7일) · 알고 있는 · 모르는 어휘 네 칸, 단어마다 🔊 와 뜻 보기. **TEST** 로 고른 단어만 다시 시험 |

- 책 파일 `vocabulary` 에 `ex_ko`(예문 해석)와 `pic`(그림 이모지)를 적는다. `pic` 이 없는 단어는 그림 문제 대신 뜻 문제가 된다.
- 발음 평가는 크롬·엣지 음성인식이 알아들은 말로 어림한다 (`grade.js` 의 `rateSay`). 소리는 구글 서버로 간다.
- 저장: Test 점수는 `test` 칸(score/total), 단어별 알아요 1 · 몰라요 0 과 단계는 `learn` 칸 — 학생 관리 점수판이 그대로 돈다.
  Word Box 에서 일부 단어만 푼 시험은 책 점수에 넣지 않는다.

**꼭 http 로 열어야 한다.** 파일을 더블클릭해서 여는 `file://` 에서는 브라우저가 마이크를 막아
녹음이 안 된다. 폴더에서 아래 한 줄이면 된다.

```bash
python -m http.server 8777
```

그 다음 `http://localhost:8777/` 로 연다.

## 발음은 원어민 녹음으로

브라우저가 읽어 주는 음성(TTS)은 컴퓨터마다 다르다. **영어 음성이 안 깔린 컴퓨터에서는
한국어 음성이 영어를 읽어 버려서** 발음이 엉망이 된다. 그래서 단어는 소리 파일을 미리 받아 둔다.

```bash
python scripts/fetch-word-audio.py <slug>
```

위키미디어 공용(Wikimedia Commons)의 **사람이 직접 녹음한** 발음을 받아
`assets/audio/<slug>/` 에 넣고, 책 파일의 그 단어에 `audio` 경로를 적는다.
화면에서는 그 단어 버튼에 `원어민` 딱지가 붙는다.

- 위키미디어가 **429(너무 잦은 요청)** 로 막으면 잠시 뒤 **같은 명령을 다시 돌린다.**
  이미 받은 단어는 건너뛰고 못 받은 것만 다시 시도한다.
- 녹음이 없는 단어와 **예문 문장**은 브라우저 음성으로 읽는다. 이때도 **영어 음성만** 골라 쓰고,
  영어 음성이 하나도 없으면 소리를 내지 않고 안내문을 띄운다 — 한국어 음성으로 읽느니 안 읽는 게 낫다.
- 윈도우 **설정 → 시간 및 언어 → 음성** 에서 English (United States) 를 추가하면 예문도 읽힌다.
  크롬으로 열면 Google US English 가 잡혀서 더 낫다.

### 해설 음성 (무료 — 마이크로소프트 엣지 목소리)

북퀴즈에서 틀리면 해설을 **한국어(일타강사 말투) → 영어** 순서로 읽어 준다.
화면에도 두 가지가 같이 보이고, 해설 상자의 `🔊 한국어 설명` / `🔊 English` 로 따로 들을 수 있다.

목소리는 **마이크로소프트 엣지의 '소리내어 읽기' 신경망 목소리**로 미리 mp3 를 만들어 둔다.
브라우저 음성은 컴퓨터마다 달라서 같은 해설도 다르게 들리기 때문이다.
**가입·카드·API 키가 없고 크레딧도 쓰지 않는다.**
(2026-09-23 까지는 타입캐스트를 썼으나 크레딧이 떨어져 402 를 돌려주었다. 2026-10-01 에 옮겼다.)

```bash
node scripts/make-tts.mjs --dry           # 몇 개 만들지만 세어 보기
node scripts/make-tts.mjs                 # 만들기
node scripts/make-tts.mjs --limit 20      # 20개만 만들어 보기

# 목소리·빠르기를 바꾸고 싶으면 (안 넣으면 영어 Jenny, 한국어 SunHi)
set RB_VOICE_EN=en-US-AriaNeural
set RB_VOICE_KO=ko-KR-JiMinNeural
```

- 결과는 `assets/tts/*.mp3` 와 `assets/tts/index.json`(문장 → 파일) · `voices.json`(파일 → 목소리).
  파일 이름이 문장의 sha1 이라 다시 만들어도 제자리를 덮어쓴다.
- 이미 만든 문장은 건너뛴다. 해설을 고치거나 목소리를 바꾸면 그 문장만 다시 만든다.
- 한 문장 평균 **14KB** 쯤이다 (48kbps · 24kHz · 모노).
- mp3 가 없는 문장은 브라우저 음성으로 읽는다 — 음성 파일이 없어도 화면은 그대로 돌아간다.

## 서버와 로그인 — 웹앱 서비스로 쓰기

`config.js` 가 비어 있으면 로그인 없이 그 브라우저에만 저장한다 (지금까지 방식).
서버 주소를 넣으면 이렇게 바뀐다.

- 학생은 **아이디 + PIN 6자리**로 로그인한다. 집·학원 어느 컴퓨터에서 열어도 한 것이 그대로 있다.
- 선생님은 **이메일 + 비밀번호**로 로그인해 `teacher.html` 에서 학생을 만들고(PIN 은 이때 한 번만 보인다),
  PIN 재발급·사용 중지를 하고, 책마다 단어테스트·북퀴즈·워크시트 점수를 한 표로 본다.
- 첨삭(`review.html`)은 모든 학생이 낸 글을 서버에서 가져온다.
- 학생에게는 교사용 가이드·첨삭·워크시트 정답 보기가 안 보인다. 교사용 가이드 주소를 쳐도 막힌다.
- PIN 을 5번 틀리면 10분 잠긴다. 잠긴 학생은 학생 관리 표에 빨갛게 뜬다.

서버 규칙은 전부 `supabase/001_readingbrain.sql` 한 파일이다. 표는 브라우저에서 직접 못 건드리고,
그 파일의 함수로만 드나든다. 확인은 `npm install` 뒤 `npm test`.

### 서버 연결 (처음 한 번)

1. supabase.com 에서 새 프로젝트를 만든다 (Region: Seoul). **원서 프로그램 전용**으로 따로 만든다.
2. SQL Editor 에 `supabase/001_readingbrain.sql` 을 통째로 붙여넣고 Run.
3. Authentication › Users › **Add user** 로 선생님 계정을 만든다 (Auto Confirm 켜기).
4. SQL Editor 에서 그 계정을 선생님으로 올린다.
   ```sql
   insert into public.teachers (id, name)
   select id, '원장' from auth.users where email = '선생님이메일@example.com';
   ```
5. Authentication › Sign In / Providers 에서 **Allow new users to sign up 을 끈다.**
   (켜 둬도 선생님 표에 없으면 아무것도 못 하지만, 모르는 계정이 쌓이지 않게.)
6. Project Settings › API 의 **Project URL** 과 **anon (publishable) key** 를 `config.js` 에 넣는다.
   `service_role` 키는 절대 넣지 않는다.

### AI 북토크 (온라인 학습 › 북퀴즈 다음 탭)

학생이 AI 와 그 책 이야기를 **영어로 2~3분** 한다. 🎤 로 말하면 크롬이 글자로 받아 보내고, AI 답은 영어 음성으로 읽는다.

- AI 는 책 장면을 묻고(세부 내용) → 왜·어떻게 → 학생 생각·자기 경험 순서로 넓혀 간다.
- 틀리거나 "I don't know" 라고 하면 책의 맞는 답을 한 문장으로 알려 주고, 다시 말해 보게 한다.
- 학생 말에 영어 실수가 있으면 **이렇게 말하면 더 자연스러워요** 로 고친 문장을 보여 준다.
- 매 질문마다 책 문장 패턴으로 만든 **이렇게 말해 보세요** 틀(빈칸)을 준다.
- 3분이 되면 AI 가 마무리하고, 선생님용 한국어 한 줄 정리가 학생 관리 표(AI 북토크 n회, 마우스를 올리면 정리)에 쌓인다.

**책마다 따로 쓸 것이 없다.** AI 에게 주는 "책 노트"는 워크시트 데이터(요약지도·독해·퀴즈·단어·문법·논술 표현·IB 질문)에서
자동으로 만든다 (`supabase/functions/book-talk/talk.mjs`). 책 원문은 보내지 않는다.

모델은 Claude Opus 5(`claude-opus-5`), 대화라 effort `low` 로 빠르게 한다. 안전 분류기가 거절하면
서버가 다른 모델로 다시 돌리는 `fallbacks: "default"` 를 켜 두었다. 학생 한 명당 **하루 60턴**(3분 대화 대여섯 번)까지만 부른다 — AI 는 부를 때마다 요금이 든다.

연결 (서버 연결을 마친 뒤):
1. SQL Editor 에 `supabase/002_book_talk.sql` 실행
2. console.anthropic.com 에서 API 키를 만들고 Supabase 비밀값으로 넣는다: `supabase secrets set ANTHROPIC_API_KEY=...`
3. `supabase functions deploy book-talk --no-verify-jwt` (학생은 Supabase 계정이 없어서 함수 안에서 학생 토큰을 직접 확인한다)

이 컴퓨터에서 시험: `ANTHROPIC_API_KEY` 를 환경 변수로 두고 `npm run dev` 하면 진짜 AI,
키 없이 화면만 보려면 `RB_FAKE_AI=1 npm run dev` (가짜 AI — 독해 문항을 차례로 묻기만 한다).
확인은 `npm test` (AI 는 부르지 않고 무엇을 보내는지만 본다).

말하기는 크롬·엣지에서만 된다. 크롬의 음성 인식은 소리를 구글 서버로 보내 글자로 바꾼다 — 학부모 안내에 한 줄 넣는다.

### AI 첨삭 리포트 (첨삭 › 학생 글 › ✨ AI 첨삭 초안 만들기)

학생이 서술형 탭에서 낸 글을 AI 가 먼저 첨삭하고, **선생님이 확인·수정해서 저장해야** 학생에게 보인다.
롸이팅터치 샘플(첨삭 리포트·Review & Test Sheet·Thinking & Writing Sheet) 구성을 따랐다.

- **리포트**: 01 총평(종합 총평·내용/전개 Advice) · 02 Visual Score(문법·어휘·문장 일관성·내용 전개력 + 그래프) ·
  03 원문 교정 맵 · 04 교정 상세(ORIGINAL → CORRECTED, 분석, TIP) · 05 Deep Dive · 06 Vocab Booster · 07 원어민식 표현 · 08 다음 미션
- **복습 워크시트**: 틀린 문장 다시 쓰기 · 빈칸 지문 완성 · 핵심 단어 뜻 쓰기 / **생각 열기** 질문 3개.
  학생은 온라인으로 풀고 채점하거나(문장이 똑같으면 ✓, 거의 같으면 노란 칸 = 선생님 확인) PDF 로 인쇄한다.
- 선생님 화면에서 점선 글자는 눌러서 바로 고치고, 맞지 않는 교정·단어·표현은 × 로 뺀다. 점수 칸도 고칠 수 있다.
- 기존 "직접 표시하기"(드래그 첨삭)·준거 점수·총평도 그대로 쓸 수 있다. 쓰면 리포트 아래에 같이 보인다.

모델은 Claude Opus 5, 품질이 중요해 effort `medium`, 출력은 정해진 JSON 모양(`supabase/functions/writing-report/report.mjs`).
책 노트는 북토크와 같은 것을 쓴다. 선생님 로그인으로만 부를 수 있다. 한 편에 30초~1분쯤 걸린다.

연결 (AI 키는 북토크와 같은 `ANTHROPIC_API_KEY`): `supabase functions deploy writing-report`
(선생님은 Supabase 계정이 있으므로 `--no-verify-jwt` 를 붙이지 않는다.)
이 컴퓨터에서 화면만 시험: `RB_FAKE_AI=1 npm run dev` → 가짜 AI 가 대문자·마침표만 고친 리포트를 준다.

### 아직 안 한 것

- **녹음**은 여전히 그 브라우저에만 남는다. 선생님이 들어야 하면 Supabase Storage 로 올린다.
- 자동채점은 브라우저에서 한다. 그래서 정답이 `books/*.js` 에 들어 있고, 마음먹은 학생은 개발자 도구로 볼 수 있다.
  시험 성적처럼 중요해지면 채점을 서버 함수로 옮긴다.

## 교사용 가이드 — 읽기만 하면 수업이 되게

`teacher-guide.html?book=<slug>` 로 연다. 수업 대사가 다섯 장이고, 한 줄마다 네 가지가 붙는다.

| 무엇 | 누가 보는가 |
|---|---|
| 따옴표 안 영어 | **그대로 읽는다.** 학생에게 하는 말이다 |
| 그 아래 한국어 | 이때 하는 행동과 그렇게 하는 이유. 선생님만 본다 |
| `아이 답` (초록) | 이 말을 하면 아이에게서 나올 답 |
| `안 나오면` (빨강) | 그 답이 안 나올 때 다음에 던질 말 |

책을 안 읽은 강사도 이 다섯 장만 들고 들어가면 수업이 된다.

**수업 흐름표(시간표)는 넣지 않는다.** 반마다 수업 시간이 달라 맞지 않는다.
대사 줄마다 붙은 분 표시는 순서와 대략의 배분을 보여 주는 용도일 뿐이다.
