## 표지

목록에 표지 주소가 없다. **오픈라이브러리**에서 제목+저자로 찾아 표지 번호만 저장한다.

- 그림을 내려받아 우리 서버에 두지 않는다. `https://covers.openlibrary.org/b/id/<번호>-M.jpg` 주소를 가리키기만 한다.
- 구글 북스는 쓰지 않는다: 키 없는 하루 할당량이 소진되어 429 가 난다(실제 확인). 유료 키가 생기면 바꿀 수 있다.
- `/b/id/` 경로는 오픈라이브러리가 속도 제한을 걸지 않는다(`/b/isbn/` 은 건다).
- **못 찾는 책이 많이 나온다.** JY First Readers·Nobuyoung Storybooks 같은 한국 출판사 리더스는 오픈라이브러리에 없다. 못 찾으면 AR 단계 색 + 제목을 얹은 **책등 그림**을 그린다.
- 같은 제목의 다른 책이 붙을 수 있다. 원장이 고칠 수 있게 표지 번호를 따로 둔다.

### 저작권

표지 그림은 출판사·삽화가의 저작물이다. 검색 결과를 **내려받아 재배포하지 않는다.** 오픈라이브러리가 공개한 주소를 가리키는 것만 한다. (원장이 "이미지는 저작권에 안 걸린다"고 들었다 했으나 사실과 달라 이 방식으로 바꿨고, 원장에게 알렸다.)

요약문은 원장 결정으로 **그대로 공개**한다.

## 유튜브

4,820권에 영상을 자동으로 붙이지 않는다 — 제목만으로 검색하면 엉뚱한 영상이 붙는다.

- 책마다 **[유튜브에서 찾기]** 단추 → `youtube.com/results?search_query=<제목> read aloud` 새 창
- 원장이 고른 영상은 `catalog-pins.js` 에 `{bookNo: "영상번호"}` 로 적으면 그 책에 **임베드**된다
- 임베드는 유튜브 공식 기능이고 영상 주인이 허용한 것만 재생된다 — 문제없다

## 재사용하는 것

조사로 확인한 기존 부품을 그대로 쓴다.

- `app.css` 의 `.top`·`.box`·`.btn`·`.row`·`.count` 와 리포트 틀
- `config.js → store.js → report.js` 순서, 첫 줄 `RB.gate()`
- 이름칸 `#who` 와 `rb1:who` 키
- `index.html` 의 책 카드·AR 칩 모양

`vercel.json`·`store.js`·`report.js`·`app.css` 는 손대지 않는다.
