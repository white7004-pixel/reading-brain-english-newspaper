# 카카오톡으로 학습 리포트 보내기

어머님이 아이의 학습 리포트를 카카오톡에서 바로 열어 보시게 하는 길은 둘이다.
**①은 오늘 쓸 수 있고, ②는 사업자등록과 심사가 필요하다.**

---

## ① 카톡 보내기 단추 — 만들어 두었다. 원장님이 키만 넣으시면 된다

리딩리포트·북디베이트 화면 아래 단추가 **「💬 카카오톡으로 보내기」** 로 바뀐다.
누르면 카카오톡이 열리고, 어머님 대화방을 고르면 이런 카드가 간다:

> **[책 표지 그림]**
> 김○○ 학생의 『Hi! Fly Guy』 READING REPORT
> 리딩브레인 영어학원이 보내 드리는 학습 리포트입니다. 눌러서 바로 보실 수 있어요.
> **[ 리포트 보기 ]**

어머님은 **로그인 없이** 그 자리에서 리포트를 보신다. 카톡 안에서 눌러도 바깥 브라우저로 빠져나가게
이미 되어 있다(`store.js`).

### 원장님이 하실 일 (5분, 비용 0원)

1. `developers.kakao.com` 에 카카오 계정으로 로그인
2. **내 애플리케이션 › 애플리케이션 추가하기** — 앱 이름 "리딩브레인", 회사명 "리딩브레인영어학원"
3. 만들어진 앱 › **앱 키** 에서 **JavaScript 키** 를 복사 (REST API 키 아님, JavaScript 키다)
4. 같은 앱 › **플랫폼 › Web 플랫폼 등록** 에 아래 둘을 등록
   - `https://readingbrain-books.vercel.app`
   - `http://localhost:8778` (학원 컴퓨터에서 시험해 볼 때)
5. `config.js` 의 `kakaoKey: ""` 안에 3번 키를 붙여 넣는다

> **이 키는 공개돼도 되는 키다.** 등록한 도메인에서만 동작하도록 카카오가 잠가 준다
> (Supabase 의 anonKey 와 같은 성격). 반대로 **REST API 키·Admin 키는 절대 브라우저에 두지 않는다.**

키를 넣지 않으면 단추는 지금처럼 「🔗 공유 링크 복사」 로 움직인다. 아무것도 망가지지 않는다.

### 이 방법의 한계

보내는 사람이 **선생님 카톡**이다. 학원 채널 이름으로 저절로 나가는 것이 아니라,
선생님이 수업 끝에 단추를 한 번 누르셔야 한다.

---

## ② 학원 채널에서 자동 발송 (알림톡) — 준비가 필요하다

어머님이 학원 카카오톡 채널을 추가해 두면, 수업이 끝날 때 **학원 이름으로** 리포트가 자동으로 간다.
선생님이 누르지 않아도 된다.

### 필요한 것

| 무엇 | 얼마나 걸리나 | 비용 |
|---|---|---|
| 사업자등록증 | 이미 있으시다 | — |
| 카카오톡 채널 개설 (`business.kakao.com`) | 당일 | 0원 |
| 알림톡 발송 대행사 계약 (NHN 토스트·알리고·솔라피 등) | 1일 | 충전식 |
| 알림톡 **템플릿 심사** | 영업일 2~3일 | 0원 |
| 발송 서버 | 만들어야 한다 (아래) | Vercel 무료 구간 |
| 건당 발송료 | — | 약 7~15원 |

### 왜 서버가 필요한가

알림톡은 **발송 키(REST API 키)** 로 보낸다. 그 키가 브라우저에 있으면 누구나 학원 이름으로
아무에게나 메시지를 보낼 수 있다. 그래서 키는 반드시 서버에만 둔다.
지금 이 사이트는 서버가 없으므로, **발송만 담당하는 작은 함수 하나**(`api/send-report.js`)를
Vercel 에 두고 거기서 대행사 API 를 부른다. 키는 Vercel 환경변수에 넣는다 — 코드에 적지 않는다.

### 템플릿 문구 (심사에 낼 초안)

알림톡은 **정해 둔 틀** 안에서만 보낼 수 있다. 변수는 `#{}` 로 적는다.

```
[리딩브레인영어학원]

#{학생이름} 학생의 오늘 학습 리포트가 도착했습니다.

· 책: #{책제목}
· 단어 테스트: #{단어점수}
· 북퀴즈: #{퀴즈점수}
· 낭독 정확도: #{낭독정확도}

아래 버튼을 눌러 자세한 내용을 확인해 주세요.
```
버튼: `리포트 보기` → 링크형

> 심사에서 자주 막히는 것: 광고 문구(「등록 문의」 「할인」 같은 말)를 넣으면 알림톡이 아니라
> **친구톡**으로 분류되어 반려된다. 위 초안에는 광고가 없다.

### 한 가지 더 — 링크를 짧게

지금 리포트 링크는 내용이 통째로 주소에 들어 있어 **822자**다. 알림톡 버튼에는 들어가지만
보기 좋지 않다. 이때는 리포트를 Supabase 에 저장하고 `.../r/AB12CD` 같은 짧은 주소를 주는 편이 낫다.
(원장님이 "짧은 링크" 를 고르시면 그때 만든다. 지금은 안 해도 ①은 그대로 돌아간다.)

---

## 순서 제안

1. **오늘** — ①의 5단계를 하시고 키를 넣으신다. 선생님 한 분이 한 번 보내 보고 확인한다.
2. 한두 주 써 보고, "선생님이 매번 누르는 게 번거롭다" 하면 ②로 간다.
3. ②를 시작하실 때 채널 개설과 대행사 계약만 해 주시면, 발송 서버와 템플릿은 내가 만든다.
