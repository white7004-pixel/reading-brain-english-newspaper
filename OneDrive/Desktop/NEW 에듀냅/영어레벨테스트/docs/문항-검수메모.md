# 문항 검수 메모 (2026-09-30)

`public/data/items.json` 768문항 — 중1-1~고3-2, 영역 4 × 단원 4 × 4문항. 모두 **검수 전(draft)**. 검수 화면(`review.html`)에서 통과시킨 문항만 시험에 나온다.

## 어떻게 만들었나
- API 키 없이 대화 안에서 도우미가 새로 썼다. 교과서·단어장·모의고사 문장은 쓰지 않았다.
- 정답을 모르는 다른 도우미가 **768문항을 모두 풀어** 정답과 맞춰 봤다 → 768/768 일치. 고친 157문항은 다시 풀어 157/157 일치.
- 고친 것: 단어 표제어가 여러 학기에 겹치던 것(0개로), 중3-2 단어가 수능급이던 것, 독해·듣기 소재가 학기끼리 겹치던 것, 유명 심리 실험 소재(모의고사와 비슷해 보일 위험), 듣기 대본의 우리말 지명(영어 음성이 어색하게 읽음).
- 단어는 **능률 목록 없이 학년 수준 낱말**로 썼다. 능률 Day 목록을 주시면 그 범위로 다시 맞춘다.

## 문항 번호 읽는 법
검수 화면의 문항 번호 `영역-학기단계-단원-순서` (예: `reading-14-3-3` = 독해 · 중3 2학기 · 3단원 · 셋째 문항). 학기단계 9=중1-1, 10=중1-2 … 14=중3-2, 15=고1-1 … 20=고3-2.

## 보실 때 표시해 둔 것

### 문법
- 중1-2 3단원 문장 전환: 가주어 It ~ to부정사 — 학교에 따라 중1-2에 아직 안 배웠을 수 있음
- 중1-1 2단원 틀린 것 고르기: "I am knowing her name." — 상태동사 진행형을 가르치는 시기가 학교마다 다름
- 중2-1 4단원 문장 전환(so → because): 오답 when 이 답처럼 읽히지 않는지
- 중2-2 2단원 문장 전환: want 대신 ask + 목적어 + to / 틀린 것 고르기의 맞는 문장 "heard someone singing"(지각동사 -ing) 이 같은 단원에서 배우는지
- 중3-1 2단원 틀린 것 고르기: 틀린 문장 "had been lived" — 과거완료진행을 더 직접 겨냥할지
- 중3-2 1단원 틀린 것 고르기: has 와 would 혼용 / 3단원 빈칸 오답 "She heard" 는 쉼표로 두 절을 이어서만 틀림
- 고1-1 1단원 어순: 오답 gets 는 어순이 아니라 수일치 오답 / 4단원 어순 "Having been warned twice…" 오답 둘이 어색해 쉬움
- 고1-2 1단원 어순(혼합가정법): 오답 "would be not" 은 순수 재배열이 아님
- 고2-1 3단원 빈칸 "It was in 2019 ___": when 을 뺐고 that 하나가 답
- 고2-2 3단원 어순 "if you want to": 쉬움 / 4단원 문장 전환과 틀린 것 고르기가 둘 다 삽입절 who 구조
- 고3-2 1단원 빈칸 "Were the Earth…": 오답이 쉬움 / 2단원 "It was not until … that": 오답 when

### 단어
- 고2-2 `vocab-18-4-2` circumvent, 고3-1 `vocab-19-4-2` ostensible — 학기보다 많이 어려움. `vocab-18-1-1` deprive, `vocab-18-3-3` scrutinize 도 약간 어려움
- 중3-2 1단원 tradition · reduce · pollution — 중3-2 치고 약간 쉬움

### 독해
- 사실 확인: 펭귄 아빠가 두 달 넘게 굶음(`reading-10-4-2`) / 상어 500종 이상 / 조정 2km 약 6분 / 오리도 뇌 반쪽씩 잠 (중1~중2-1) · 아홀로틀 다리 재생(`reading-16-1-3`) · 포크의 역사 연대(`reading-15-3-1`)
- 문장 삽입 정답이 하나뿐인지: `reading-13-3-2` 얼음 창고(③도 되는지) · `reading-18-3-3` 다양한 연습(②) · `reading-19-3-4` 단조 음악(③ vs ④)
- 중3-1 4단원 빈칸: 정답이 긴 구("wanted by many but made in small numbers")
- 중3-2 `reading-14-3-3`(소리 없이 나는 올빼미 깃털), `reading-14-4-1`(세 작물 함께 심기): 어휘가 중3-2 상단
- 잘 알려진 연구를 새로 쓴 것: `reading-14-2-3` 접시 색 · `reading-20-2-2` 체스 전문가 · `reading-19-4-4` 새가 먹이 상자 여는 법을 따라 배우기 — 기출처럼 보이면 바꾸기
- 중2-1 4단원 "지칭 대상"은 유형 목록에 없어 `세부 정보`로 두었고, 가리키는 말은 [It] 처럼 괄호로 표시
- 고등 함축 의미 문항은 밑줄 대신 [ ] 로 표시
- 고등 지문 평균 문장 길이가 기준(16~21단어)보다 조금 긴 편
