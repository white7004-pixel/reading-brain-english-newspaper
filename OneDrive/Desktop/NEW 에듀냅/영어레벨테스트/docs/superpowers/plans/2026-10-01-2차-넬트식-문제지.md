**Interfaces — Produces:**

- `validateForm(it, stage = 1)` — stage 2 면 영역은 S2_AREAS, 수준은 STAGES2, 선택지 수 choiceCount, 정답 0..n-1, `'선택지 N개'` 문구는 그 수로. 쓰기(sentence)는 지금 쓰기 규칙. 1차는 지금과 같다.
- `usableForm(list, stage = 1)`
- `stage2Levels(log)` → `{ vocab, grammar, reading, listening, writing }` 각 `{ level, steps: [{ level, correct, total }] }`. log 항목 `{ area, level, correct, kind }`. writing = area 'sentence'. 단계는 STAGES2 순서로, 그 단계 문항이 있으면 `correct*3 >= total*2` 일 때 통과하고 다음 단계로, 처음 못 넘은 단계에서 멈춘다(첫 단계부터 못 넘으면 `'중1 수준 아래'`). 문항이 하나도 없는 영역은 `{ level: null, steps: [] }`. steps 는 문항이 있는 단계 모두(멈춘 뒤 단계도 정답률은 낸다).
- `kindTally(log, area)` → `[{ kind, correct, total }]` 문제지 순서(처음 나온 순서)
- `stage2Est(level)` → 리포트 est: `null`→`null`, `'… 수준 아래'`→`{ step: 9, unit: 0 }`, 통과 L → `{ step: levelStep(L) + 2, unit: 0 }` (중2 통과 → 중3 1학기 1단원 전 = step 13, 고2 통과 → step 19)

test('stage2Levels: 단계마다 3분의 2, 처음 못 넘은 단계에서 멈추고 정답률은 모두 낸다', () => {

test('kindTally 와 stage2Est', () => {
