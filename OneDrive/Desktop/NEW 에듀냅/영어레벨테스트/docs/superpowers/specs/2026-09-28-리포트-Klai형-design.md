# 영어레벨테스트 리포트 — Klai형으로 다시 짜기 (설계서)

원 설계서 `2026-09-24-영어레벨테스트-design.md` 의 **5장(리포트)·5.1(예상 진도)·7장(학원 설정의 pace)** 을 이 문서로 바꾼다. 나머지(척도·문항·엔진·AI 글)는 그대로다.

## 0. 한 줄

원장님이 보여 주신 Klai 분석지(표지 + 영역별 쪽)의 **틀**을 따르되, 근거 없는 등급·평균 대신 **학년 수준·100점 환산 점수·영역별 주 횟수로 계산한 고3 과정 완료 시점**으로 채운다. Klai 의 문구·그림은 그대로 가져오지 않고 구성만 참고한다.

## 1. 정한 것 (원장님, 2026-09-28)

1. 등급·평균·상위 % 자리 → **학년 수준** ("중3 2학기 수준 · 학년보다 2학기 앞섬"). 응시 기록이 쌓이면 평균·상위 % 를 나중에 더한다.
2. 진도 설정 → **영역별 주 횟수·요일**. 주 2회가 기본 속도(한 해 3학기). 시험 기간 4·6·9·11월은 진도에서 뺀다.
3. 점수 칸 → **100점 환산 점수** (중1 1학기 시작 0점 ~ 고3 과정 끝 100점).
4. 목표 → **고3 과정 완료 시점**.

## 2. 쪽 구성

학부모용: 표지 1쪽 + 응시한 영역마다 1쪽(단어·문법·독해·듣기 순). 원장용: 1쪽. 응시하지 않은 영역은 쪽을 만들지 않고 표지 점수표에 "응시하지 않음"(또는 건너뛴 까닭)으로 적는다.

색: Klai 의 빨강 자리에 **학원 대표 색**(`--brand`, 없으면 에듀냅 올리브 `#03392A`), 검정·회색은 그대로 보조색. 글꼴은 지금 `style.css` 것.

### 2.1 표지

1. **머리 띠** — 왼쪽 학원 로고(없으면 학원 이름), 오른쪽 학원 색 띠에 "영어 레벨테스트 결과".
2. **정보 줄 4칸** — 시험(영어 레벨테스트) · 이름(성+OO) · 학원(학년) · 응시일.
3. **테스트 결과 칸 3개** — 전체 수준(영역 위치 평균의 학기 이름) · 학년 대비("2학기 앞섬" / "학년 수준" / "1학기 뒤") · 고3 과정 완료 예상("고2 12월", 가장 느린 영역 기준).
4. **총평** 2~3문장 — AI, 실패하면 틀 문장. 눌러서 고칠 수 있다.
5. **영역별 점수표** — 영역 · 현재 수준(학기·단원) · 학년 대비 · 점수(`43 / 100`). 맨 아래 전체 줄(점수 평균, 반올림).
6. **막대 비교** — 범례 "본인 · 지금 학년". 전체 한 벌 + 영역마다 한 벌. 본인 막대 길이 = 점수, 학년 막대 길이 = `gradePos` 를 같은 식으로 환산한 점수, 옆 글 = "중3 2학기 · 46점".

### 2.2 영역별 쪽 (영역마다 같은 틀)

머리: "영역별 분석 · 1. 단어" + 오른쪽 작게 "수업 시작일 2026-08-12".

1. **테스트 결과**
   - 막대 2개: "고3 과정이 끝나는 고3 2월까지 남은 기간 — 4년 6개월"(회색) / "우리 학원 진도로 고3 과정까지 걸리는 기간 — 3년 2개월"(검정). 길이는 긴 쪽을 100% 로. 걸리는 기간이 남은 기간보다 길면 막대 끝에 "학교 졸업 뒤" 표시.
   - 칸 2개: 현재 수준("중3 2학기 2단원") · 학년 대비("2학기 앞섬").
2. **진도 설정** — "주 2회 (화·목)". 작게 "주 2회일 때 한 해 3학기씩 나아갑니다. 시험 기간(4·6·9·11월)은 빼고 셉니다."
3. **목표: 고3 과정 완료** — 중1 1학기 → 고3 과정 끝 가로줄 위에 ▲**지금 학년**, 학원 색 말풍선 **본인**, 끝에 "고3 과정 완료 · 고2 12월 예상". 이미 끝났으면 "고3 과정 수준에 도달했습니다".
4. **학습 로드맵** — 시간선 점: 시작(수업 시작일, 지금 수준) → 학기 하나를 넘을 때마다 점("중3 3월 / 고1 1학기 수준") → 완료 점(학원 색 강조, "고3 과정 완료"). 점이 5개를 넘으면 Klai 처럼 두 줄로 꺾는다(ㄹ자). 점은 최대 10개 — 넘으면 시작·완료는 두고 사이를 고르게 솎는다.

### 2.3 원장용 쪽

지금 `sheet2` 그대로: 영역별 문항표 · 흔들린 구간 · 다음 시작 단원 · 교재명(여기에만) · 지도 방향 3개. 머리 띠만 표지와 같은 모양으로 바꾼다.

## 3. 숫자 (전부 `public/core/progress.js`, 순수 함수)

- `position(est)` — 지금과 같다: 단계 + 단원/4 (단원 모름 = 2단원).
- `score(est)` = `round((position − 9) / (END − 9) × 100)`, 0~100 으로 자름. `END = 21`.
- `gradePos(grade, date)` = `currentStep(grade, date) + 0.5` (지금 학년의 학기 한가운데). 초등은 9 보다 작게 나오므로 막대에서는 0 으로 자른다.
- **학년 대비** = `round(position − gradePos)` 학기 → `+n` "n학기 앞섬", `0` "학년 수준", `−n` "n학기 뒤".
- **속도** — `PACE_PER_WEEK = 1.5` 학기/년·(주 1회). 주 n회 → 한 해 1.5n 학기. 한 해 공부하는 달 = 8 (4·6·9·11월 뺌) → **공부하는 달 하나에 `1.5n / 8` 학기**.
- **로드맵 걷기** `roadmap({ est, perWeek, start, grade })` — 수업 시작일의 달부터 한 달씩 넘기며, 그 달이 4·6·9·11월이 아니면 위치에 `1.5n/8` 을 더한다. 위치의 정수 부분(학기)이 바뀔 때마다 점 `{ month: 'YYYY-MM', when: '중3 3월', level: '고1 1학기' }`. 위치가 `END` 에 닿으면 완료 점을 찍고 멈춘다. 최대 120달 — 넘으면 마지막 점을 "고3 졸업 이후"로 끝낸다. 결과 `{ points, months, done }` (`months` = 시작부터 완료까지 달 수, 시험 달 포함).
- **남은 기간** `monthsLeft(grade, start)` = 수업 시작 달부터 **고3 2월**까지 달 수, 두 달 모두 셈 (학년은 3월에 오른다). 초등은 그만큼 길다.
- **기간 글** `ym(n)` = "3년 2개월", "8개월".
- **달 이름** `monthLabel(grade, start, 'YYYY-MM')` = 그때 학년 + 월 ("중3 3월"). 고3 2월을 넘으면 "고3 졸업 이후".
- **전체 완료** = 영역 중 `months` 가 가장 큰 것.
- `perWeek` 가 없거나 1~6 밖이면 2.

지금의 `project()`·`DEFAULT_PACE`·연도별 표·비관/낙관 줄은 없앤다.

## 4. 진도 설정 칸 (`public/index.html` · `app.js`)

- **학원 설정**: 영역마다 요일 체크(월~토). 고른 요일 수 = 주 횟수. 기본 화·목. `elt:academy.plan = { vocab: ['화','목'], grammar: [...], reading: [...], listening: [...] }`. `pace` 칸은 뺀다.
- **학생 시작 화면**: 접힌 칸 "이 학생 진도" — 수업 시작일(기본 오늘) + 영역별 요일(학원 기본값으로 채움). 요일을 하나도 안 고른 영역은 막는다("요일을 하나 이상 골라 주세요").
- 세션·결과에 `start: 'YYYY-MM-DD'`, `plan: { vocab: [...], ... }` 를 싣는다. `pace` 는 싣지 않는다. 예전 결과(`plan` 없음)는 모두 화·목·시작일=응시일로 본다.

## 5. AI 총평 (`summary.js` · `lib/comment.js`)

- `commentFacts` 의 `overall` = 전체 완료 달 이름("고2 12월") 또는 "고3 과정 완료", `pace` 자리는 글 "영역별 주 2~3회" 로 바꾼다. 영역마다 `score` 를 더한다.
- 서버 검사(`checkComment` 입력 검사)가 새 모양을 받도록 맞춘다. 숫자는 코드가 만들고 AI 는 받은 것만 쓴다 — 지금과 같다.
- 틀 문장도 새 사실로 쓴다: "단어는 중3 2학기 수준(46점)으로 학년보다 2학기 앞서 있습니다. 주 2회 진도로 고2 12월에 고3 과정을 마칠 것으로 예상합니다."

## 6. 인쇄·저장 (`report.html` · `report.js`)

- 단추 셋: **학부모용 인쇄/PDF**(표지+영역 쪽), **원장용 인쇄/PDF**(원장 쪽), **표지 PNG**.
- 인쇄 때는 `body` 에 `print-parent` / `print-director` 를 붙여 다른 쪽을 숨기고 `print()` 후 뗀다. 쪽마다 `@page A4`, `break-after: page`.
- 한 쪽이 A4 를 넘으면 그 쪽만 글자를 줄인다(지금 방식).
