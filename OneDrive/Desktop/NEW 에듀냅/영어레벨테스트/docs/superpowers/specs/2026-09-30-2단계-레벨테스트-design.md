# 영어레벨테스트 — 1차·2차 두 단계로 (설계서)

원 설계서 `2026-09-24-영어레벨테스트-design.md` 의 시험 흐름 앞에 **1차(초등~중1 고정 문제지)** 를 붙이고, 2차(지금의 적응형) 뒤에 **쓰기 블록** 을 붙인다. 척도·적응 엔진·768문항·리포트 설계(`2026-09-28-리포트-Klai형-design.md`)는 그대로 두고, 이 문서가 말하는 곳만 바꾼다.

## 0. 한 줄

원장님이 보여 주신 KLAI 1차·2차 문제지의 **구성**(영역 순서, 지문 하나에 두 문항, 모름, 문항별 시간 제한, 칸에 직접 쓰기)을 따르되, 문항은 모두 새로 쓴다. 모든 학생이 1차를 보고 **80점 이상이면 2차** 로 간다.

## 1. 정한 것 (원장님, 2026-09-30)

1. 흐름: 모두 1차 → **80점 이상** 이면 2차. 80점 미만은 1차 결과지로 끝.
2. 1차 13~46번: 독해 → 파닉스 → 문법 객관식 → 어형 쓰기 → 영작. **1~12번은 듣기 자리** — 원장님이 서울시교육청 중1~고3 듣기를 바탕으로 나중에 만든다. 이번에는 비워 둔다.
3. 1차 문제지는 **A·B 두 세트를 번갈아** 낸다.
4. 2차 = **지금 적응형(768문항) + KLAI식 쓰기 블록**. 리포트의 "어느 학년 몇 단원까지"는 그대로 적응형에서 나온다.
5. 80점 미만 학생 결과지: **영역별 초등 학년 수준** 과 추천 시작 수준.
6. KLAI 문항·지문은 옮기지 않는다. 구성만 참고한다.

## 2. 흐름

```
이름·학년 입력 → 1차 (세트 A 또는 B, 34문항) → 채점
   ├ 80점 미만 → 1차 결과지 (끝)
   └ 80점 이상 → "2차로 넘어갑니다" → 2차 적응형 4영역 → 2차 쓰기 블록 11문항 → 결과지
```

- 세트 고르기: 이 기기에서 마지막으로 낸 세트(`elt:lastSet`)의 반대. 처음이면 A. (학생 이름을 성+OO 로만 받아 학생별 기억은 하지 않는다.)
- 2차 쓰기 블록은 1차와 같은 세트 글자를 쓴다(1차 A → 쓰기 A).
- 2차 적응형 시작 학기는 지금처럼 학년 기준(`startStep`)이다. 초등 학생이 통과하면 중1-1 부터.
- 진행은 지금처럼 `elt:session` 에 두어 새로고침해도 이어진다. 세션에 `stage`(1 · 2 · 'write'), `set`, 1차 답 기록을 더한다.

## 3. 1차 문제지 (세트당 34문항)

| 번호 | 영역(area) | 문항 수 | 수준 | 모양 |
|---|---|---|---|---|
| 1~12 | 듣기 | (비움) | — | 원장님이 나중에 |
| 13~31 | 독해 `reading` | 19 | 초3 → 중1 | 지문 10개(9개는 두 문항, 1개는 한 문항). 뒤로 갈수록 길다 — 초3 3~4줄, 중1 100~120단어. 발문은 앞쪽 영어, 뒤쪽 한국어 |
| 32~33 | 파닉스 `phonics` | 2 | 초3~초4 | 밑줄 친 소리가 다른 낱말 고르기 |
| 34~37 | 문법 `grammar` | 4 | 초4 → 중1 | 객관식. 복수형 짝, 대화 빈칸(there is/are, 3인칭 -s, 과거 의문문 등) |
| 38~42 | 어형 쓰기 `form` | 5 | 초5 → 중1 | [낱말]을 알맞은 꼴로 칸 1~2개에 쓴다 |
| 43~46 | 영작 `sentence` | 4 | 초5 → 중1 | 한국어 문장과 주어진 낱말을 보고 한 칸에 한 낱말씩 |

- 문항마다 `level`(초3·초4·초5·초6·중1)을 붙인다. 번호가 커질수록 대체로 어려워진다.
- 두 세트는 영역·번호·수준 배치가 같고 소재와 낱말만 다르다. 두 세트 사이, 그리고 768문항과 소재·표제어가 겹치지 않는지 전체 점검을 한 번 한다.

## 4. 2차 쓰기 블록 (세트당 11문항)

적응형 4영역이 끝난 뒤 이어서 푼다.

| 차례 | area | 문항 수 | 수준 | 다루는 문법 (세트마다 고르게) |
|---|---|---|---|---|
| 1~8 | `form` | 8 | 중2 → 고1 | 불규칙 과거, 과거진행, 수동태, 완료(과거완료·현재완료), 가정법 과거완료, 품사 바꾸기, 관계사, 부정어 도치 |
| 9~11 | `sentence` | 3 | 중3 → 고1 | 분사 수식, 분사구문, 조건절·to부정사 |

- 문항마다 `point`(문법 항목 이름, 예: "수동태")를 붙인다. 결과지의 "틀린 문법 항목"에 쓴다.
- 적응형의 학년·단원 판정에는 넣지 않는다.

## 5. 문항 데이터

파일 하나 `public/data/forms.json`:

```json
{ "stage1": { "A": [ ... ], "B": [ ... ] }, "write2": { "A": [ ... ], "B": [ ... ] } }
```

공통 칸: `id`, `no`(번호), `area`, `level`, `status`('draft' | 'ok' | 'rejected'), `explain_ko`. 2차 쓰기는 `point` 도.

**객관식** (`reading` · `phonics` · `grammar`): 768문항과 같이 `question`, `choices`(4개), `answer`(0~3). 독해는 `passage` 와 `passageId`(같은 지문 두 문항이 같은 값). "모름"은 데이터에 넣지 않고 화면이 붙인다.

**쓰기** (`form` · `sentence`):
- `question` — 한국어 지시("[break] 낱말을 알맞은 꼴로 바꾸세요.")
- `template` — 칸 자리를 `{}` 로 표시한 문장. `"He {} the camera a few days ago."` · 영작은 `"{} {} {}, {} {} {} {}."`
- `hint_ko` — 선택. 문장 뜻과 조건("[그는 며칠 전에 카메라를 고장 냈다. → 과거형으로]")
- `answers` — 칸마다 인정하는 답의 목록. `[["broke"]]` · `[["didn't", "did not"]]` · `[["were"], ["sitting"]]`
- 답이 하나로 정해지도록 조건(주어진 낱말, 칸 수, 시제 안내)을 쓴다. 칸 수가 다른 다른 정답은 받지 않는다.

**밑줄**: 지문·발문·선택지 어디서나 `__밑줄 칠 말__` 로 적으면 화면에서 밑줄로 보인다. 768문항 중 `[ ]` 로 표시한 함축 의미 문항은 이번에 바꾸지 않는다.

검사(`validateForm`): 객관식은 지금 `validateItem` 의 선택지·정답 규칙을 그대로, 쓰기는 `template` 의 `{}` 개수 = `answers` 길이, 칸마다 답 1개 이상.

## 6. 화면

- **모름**: 객관식 선택지 ①~④ 아래에 "⑤ 모름". 1차·2차 적응형 모두. 채점은 오답, 기록에는 `dontKnow: true`.
- **제한 시간**: 문항마다 **90초**, 위쪽에 남은 초를 크게. 0초가 되면 "모름"으로 처리하고 다음 문항. 문항을 띄운 시각을 세션에 두어 새로고침해도 남은 시간이 이어진다. 듣기 문항은 **첫 재생이 끝난 때부터** 센다.
- **쓰기 칸**: `template` 의 `{}` 자리에 입력칸. 칸 너비는 답 길이에 맞춘다(가장 긴 인정 답 + 여유). Enter·Tab 으로 다음 칸, 마지막 칸에서 Enter 면 "다음" 단추와 같다. "다음" 단추로 제출(빈칸이 있어도 제출 가능, 빈칸은 틀림).
- **진행 표시**: 1차 "1차 · 14 / 34", 쓰기 블록 "쓰기 · 3 / 11". 적응형은 지금 점 표시 그대로.
- **1차 → 2차 사이 안내 쪽**: "1차 점수 86점 — 2차로 넘어갑니다". 80점 미만이면 "1차 시험이 끝났습니다"와 결과지 단추.

## 7. 채점

**쓰기 답 맞추기** (`checkWrite`): 칸마다 소문자로, 앞뒤 빈칸과 끝의 `.,!?` 를 떼고, 둥근 따옴표(’)를 `'` 로, 빈칸 여러 개를 하나로 바꾼 뒤 인정 답 중 하나와 같으면 맞음. **모든 칸이 맞아야 정답**, 부분 점수 없음.

**1차 점수**: `round(맞힌 수 / 낸 문항 수 × 100)`. **80 이상 통과**. 낸 문항 수는 검수 통과(`ok`) 문항만 세므로 지금은 34, 듣기가 들어오면 46.

**1차 영역별 수준** — 영역은 셋:
- 독해 = `reading`
- 문법 = `grammar` + `form`
- 쓰기 = `sentence`

초3부터 한 학년씩 올라가며, 그 영역에 그 학년 문항이 있으면 **3분의 2 이상** 맞혀야 다음 학년으로 간다(그 학년 문항이 없으면 건너뛴다). 멈춘 곳 바로 아래 학년이 그 영역 수준(중1까지 다 넘으면 중1). 초3에서 멈추면 "초3 수준 아래". 파닉스는 2문항이라 학년을 내지 않고 "2문항 중 N개"만 적는다.

**추천 시작 수준**: 세 영역 수준 중 가장 낮은 학년. 파닉스를 하나라도 틀리면 "파닉스 복습 권장" 한 줄을 더한다.

**2차 쓰기 블록**: "11문항 중 N개" + 틀린 문항의 `point` 목록(겹치면 한 번).

## 8. 결과지

- **1차만 본 학생(80점 미만)**: A4 한 쪽. 머리(학원 로고·이름·학년·응시일) → 1차 점수 → 영역별 수준 표(독해·문법·쓰기·파닉스) → 추천 시작 수준 → 틀린 문항 번호. 모양은 지금 리포트의 글꼴·색을 따르고, 시안1 디자인이 확정되면 그쪽에 맞춘다. 과장하는 말은 쓰지 않는다.
- **2차까지 본 학생**: 지금 리포트 그대로 + 표지에 "1차 점수 N점(통과)" 한 줄 + "쓰기" 칸(점수와 틀린 문법 항목). 원장용 쪽에는 모름·시간 초과 문항 수를 영역별로.
- 결과 저장(`elt:result:<id>`)에 `stage1: { set, score, passed, levels, log }`, `write2: { set, correct, total, missed, log }` 를 더한다.

## 9. 검수 화면

`review.html` 에 "문제지" 보기를 더한다: 1차 A·B, 2차 쓰기 A·B 를 번호 순으로. 객관식은 지금처럼, 쓰기는 문장 틀·인정 답을 고칠 수 있게. 통과·보류 표시는 지금과 같다.

시험 시작 조건: 고른 세트의 1차 문항 중 통과 문항이 **20개 이상**이어야 1차를 연다(모자라면 지금처럼 "문항 검수가 더 필요합니다"). 통과하지 않은 문항은 문제지에서 빼고 번호는 그대로 둔다.

## 10. 문항 만들기

768문항 때와 같은 방식: 대화 안에서 도우미가 직접 쓰고(API 키 없음), **정답을 모르는 다른 도우미가 풀어** 맞춘다.
- 객관식: 고른 선택지를 정답과 비교.
- 쓰기: 푼 도우미가 칸을 채운 답을 `checkWrite` 로 채점. 틀리면 문항이 모호하다는 뜻이니 조건을 고치거나 인정 답을 더한다.
- 수량: 1차 34 × 2 = 68, 2차 쓰기 11 × 2 = 22, 모두 90문항. 모두 `draft` 로 넣고 원장님이 검수.

## 11. 이번에 하지 않는 것

- 1차 듣기 1~12번 — 원장님이 나중에.
- 768문항을 5지선다로 바꾸기 — 4지 + 모름으로 간다.
- 리포트를 시안1 디자인으로 옮기기 — 따로 결정.
- 학생별 세트 기억, 문항 반응 이론(IRT).

## 12. 테스트

`node --test` 에 더한다:
- `checkWrite`: 대소문자·마침표·둥근 따옴표·줄임말 대안·칸 하나 틀림·빈칸.
- 1차 점수와 80점 경계(79 → 미통과, 80 → 통과), 통과 문항만 분모에 넣기.
- 영역별 수준: 3분의 2 규칙, 학년 건너뛰기, "초3 수준 아래", 추천 시작 수준.
- `validateForm`: `{}` 개수와 `answers` 길이 불일치, 빈 답.
- 세트 번갈아 고르기.
- 브라우저 확인: 1차 → 80점 미만 결과지, 1차 → 통과 → 2차 → 쓰기 → 결과지, 90초 시간 초과, 새로고침 뒤 이어하기.
