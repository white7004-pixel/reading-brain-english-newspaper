# 에듀냅 영어 레벨테스트 — 시험판 설계서

작성 2026-09-24 · 폴더 `Desktop\NEW 에듀냅\영어레벨테스트\`

## 0. 한 줄

초등부터 고3까지 한 시험으로 **단어·문법·독해·듣기** 수준을 재고,
영역마다 "어느 학년 어느 학기 몇 단원(주제)까지 이해했는지"와
"우리 학원에서 몇 년이면 고3 과정을 마치는지"를 **학부모용 A4 리포트**로 낸다.

## 1. 정한 것 (원장님 결정, 2026-09-23~24)

| 항목 | 결정 |
|---|---|
| 쓰는 곳 | **에듀냅 기능(모든 학원용)**. 학원마다 연간 진도·교재 추천을 설정한다. 첫 사용 학원은 리딩브레인 |
| 응시 | 학원 태블릿·PC에서 **온라인 응시, 자동채점**. 시험이 끝나면 리포트가 바로 나온다 |
| 방식 | **적응형** — 맞히면 위 학기, 틀리면 아래 학기 문항으로 옮겨 간다. 중3이 고3 과정까지 닿는다 |
| 문항 | **AI가 만들고 원장님이 검수**. 검수를 통과한 문항만 시험에 쓴다 |
| 단원 표시 | **특정 교재명 없이** "학년 · 학기 · 몇 단원(주제)" |
| 자료 출처 | 단어 = 능률 단어 자료(원장님 제공). 고등 독해·듣기·어법 = 서울시교육청 전국연합학력평가 고1·2·3 실제 모의고사. 문법 골격 = 2022 개정 교육과정 언어 형식 + 검정 교과서 연간지도계획 |
| 형태 | 시험판은 **로그인·서버 저장 없음**. 결과는 브라우저에 두고 인쇄·PNG. 검증 뒤 에듀냅 본체(blog-cloud)로 옮긴다 |

원장님이 자료(단어장, 문법 커리큘럼, 학교 기출)를 주기로 했다. 자료가 오면 3장 척도를 그 자료로 고친다.

## 2. 공통 척도 (에듀냅 영어 척도)

모든 학원이 같은 척도를 쓴다. 교재명은 척도에 넣지 않는다.

### 2.1 단계

| 단계 | 뜻 |
|---|---|
| 0 | 초1~2 기초 (파닉스 · 사이트워드) |
| 1 ~ 20 | 초3-1 부터 고3-2 까지 **학기 하나가 한 단계** (초3-1=1, 초6-2=8, 중1-1=9, 중3-2=14, 고1-1=15, 고3-2=20) |

단계 번호 ↔ 학년·학기 변환은 `lib/scale.js` 한 곳에서만 한다.

### 2.2 학기마다 영역별 단원(주제)

한 학기에 영역마다 **4개 단원**을 둔다 (단계 0은 2개). 단원은 순서가 있고, "몇 단원까지"의 기준이다.

| 영역 | 단원의 뜻 | 초안 출처 |
|---|---|---|
| 문법 | 문법 포인트 (예: 중2-1 → 1 현재완료 / 2 조동사 / 3 to부정사 / 4 동명사) | 교육과정 언어 형식 목록으로 학교급을 정하고, 검정 교과서 5~6종 연간지도계획을 겹쳐 학기·순서를 정한다. 고등은 모의고사 어법 빈출 포인트로 확인 |
| 단어 | 어휘대 (그 학기에 알아야 할 낱말 묶음 4개) | 능률 단어 자료를 단계 순서대로 21단계에 나눠 배치 |
| 독해 | 지문 유형·길이 (예: 중1-1 → 1 짧은 안내문 세부 정보 / 2 이야기 흐름 / 3 설명문 주제 / 4 대화 글 목적) | 교과서 지문 수준(초·중), 모의고사 독해 유형·길이(고) |
| 듣기 | 담화 유형·길이·속도 (예: 중2-2 → 1 짧은 대화 세부 / 2 안내 방송 / 3 긴 대화 의도 / 4 담화 주제) | 시도교육청 중학 영어듣기평가 유형(중), 모의고사 듣기 유형(고) |

척도 데이터는 `data/scale.js`: `{ step, grade, term, units: { grammar:[…4], vocab:[…4], reading:[…4], listening:[…4] } }` × 21.
초안은 AI(코드 밖에서 내가 조사해 작성)가 만들고 **원장님 자료로 고친다**. 척도 자체는 검수 화면에서 고치지 않는다 (파일로 고침).

### 2.3 출처 자료의 쓰임

- 교과서·단어장·모의고사의 **문항·지문·예문은 은행에 넣지 않는다.** 순서·수준·유형·길이의 **기준으로만** 쓴다.
- 능률 단어 목록은 척도의 어휘대 배치에만 쓰고, 화면에 목록 전체를 드러내지 않는다.
- 교육청 모의고사 문항을 그대로 넣고 싶어지면 교육청 이용 조건을 먼저 확인한다.

## 3. 문항 은행

### 3.1 문항 하나

```
{ id, section: 'grammar'|'vocab'|'reading'|'listening',
  step: 0..20, unit: 1..4,
  kind,                 // 영역별 세부 유형 (아래)
  passage?: string,     // 독해 지문 · 듣기 대본 (듣기는 화면에 안 보임)
  question: string,
  choices: [4개],  answer: 0..3,
  explain_ko: string,   // 원장용 해설 한 줄
  status: 'draft'|'ok'|'rejected' }
```

| 영역 | kind |
|---|---|
| 단어 | 뜻 고르기, 문맥 빈칸, 영영풀이, 유의어·반의어 |
| 문법 | 빈칸 어법, 틀린 것 고르기, 문장 전환, 어순 |
| 독해 | 세부 정보, 주제·제목, 빈칸, 순서·삽입, 내용 일치, 목적·심경 |
| 듣기 | 세부 정보, 화자 의도, 장소·관계, 다음 말, 담화 주제 |

독해는 지문 하나에 문항 2개(같은 `passage` 를 공유, `group` 으로 묶음). 듣기 대본은 한 문항에 하나.

### 3.2 만들기

- `scripts/gen-items.js` — 학기×단원마다 영역별 **4문항**(독해는 지문 2개 × 2문항) 을 클로드로 만든다. 한 번에 한 학기·한 영역씩 부르고 `json_schema` 로 받는다. 결과는 `data/items.json` 에 `status:'draft'` 로 쌓인다. 이미 `ok` 인 문항은 다시 만들지 않는다.
- 프롬프트에 그 학기의 단원 이름·어휘대·지문 길이·이전 학기 단원(이미 배운 것)을 넣어 **그 단원만** 묻게 한다.
- 총 문항 수 = 21단계 × 4단원 × 4영역 × 4문항 ≈ 1,300문항 (단계 0 은 반). 시험판은 먼저 **중1-1~중3-2(9~14단계)** 만 만들어 흐름을 확인하고, 그다음 나머지를 채운다.
- 이 PC 에는 클로드 API 키가 없다. 키가 없으면 `scripts/gen-items.js` 는 실행을 거부하고 안내만 한다. 화면 확인은 `data/items.sample.json`(손으로 쓴 문항 수십 개) 으로 한다.

### 3.3 검수 화면 `public/review.html`

- 영역·단계 골라 문항을 한 장씩 본다. 본문·선택지·정답·해설을 그 자리에서 고친다.
- **통과 / 버리기** 단추. 통과 → `ok`, 버리기 → `rejected`.
- 저장은 시험판에선 `items.json` 내려받기(원장님이 파일을 바꿔 넣음), 에듀냅에서는 서버 저장으로 바꾼다.
- 어느 단원에 `ok` 문항이 2개 미만이면 위쪽에 "부족한 단원" 목록을 보인다. 시험은 `ok` 2개 미만인 단원을 건너뛴다.

## 4. 시험 흐름 `public/index.html` → `public/test.html`

1. **학생 정보** — 이름(성+OO 또는 이니셜만, 전체 이름이면 안내), 학년(초3~고3), 학원 설정이 없으면 기본값.
2. **영역 순서** — 단어 → 문법 → 독해 → 듣기. 영역마다 시작 전에 안내 한 장. 전체 약 45분.
3. **적응 규칙** (`lib/engine.js`, 순수 함수)
   - 영역마다 **두 마당**으로 간다. 1마당은 학기(단계)를 찾고, 2마당은 그 학기 안에서 단원을 찾는다.
   - **1마당 (단계 찾기)** — 시작 단계 = 학생 학년의 1학기 단계 (초3 → 1, 중1 → 9, 고1 → 15). 초1~2 는 0. 문항은 현재 단계의 `ok` 문항 중 무작위 하나(단원은 가리지 않음). **맞히면 +2 단계, 틀리면 −1 단계.** 0 과 20 에서 막힌다. 방향(오르다↔내리다)이 **3번 바뀌면** 끝. 추정 단계 = 마지막 4문항 단계의 평균을 반올림 (4문항 전에 끝나면 있는 만큼).
   - **2마당 (단원 찾기)** — 추정 단계의 1~4단원을 **차례로 1문항씩**. 틀린 첫 단원의 **앞 단원까지** 가 "몇 단원까지 이해". 4단원을 다 맞히면 다음 단계 1단원을 하나 더 내어 맞히면 "다음 학기 1단원까지" 로 올린다.
   - 영역 문항 수 상한: 단어 15 · 문법 15 · 독해 12 · 듣기 12. 상한에 닿으면 그 자리에서 끝내고 있는 답으로 추정한다. 2마당에 못 들어갔으면 단원은 "확인 못 함" 으로 두고 리포트에는 학기까지만 쓴다.
   - ponytail: 계단식 규칙이다. 응시 데이터가 쌓이면 문항 반응 이론(IRT) 으로 바꿀 자리는 `engine.js` 의 `next()` 와 `estimate()` 둘뿐이다.
4. **듣기** — 대본을 브라우저 음성합성(영어 목소리, 원서 웹앱 AR TEST 와 같은 방식)으로 읽는다. 재생 2번까지. 목소리가 없는 기기면 "이 기기에서는 듣기를 볼 수 없습니다" 하고 듣기를 건너뛴다(리포트에 표시). 에듀냅 본체에선 미리 만든 mp3 로 바꾼다.
5. **채점**은 전부 코드. AI 는 채점에 끼지 않는다.
6. 응시 기록(문항 id·답·정오·단계·단원·걸린 시간)은 `localStorage` `elt:<이름>:<날짜>` 에 저장하고 결과 화면으로 넘긴다.

## 5. 리포트 `public/report.html` (A4 2장)

공통: 에듀냅 스타일(올리브 `#03392A` · 크림 · 금색 · Hahmlet), 학원 이름·로고·연락처는 학원 설정에서. 차트는 CSS 막대. 인쇄 `@page A4`, 장마다 PNG.

**1장 학부모용**
1. 제목 `OOO 학생 영어 레벨테스트 결과` · 응시일 · 학년
2. **영역별 현재 위치** 4줄: "문법 — 중2 1학기 3단원(to부정사)까지 이해" 처럼 학년·학기·단원(주제). 학년보다 위면 금색, 아래면 올리브 진하게.
3. 4영역 막대: 현재 학년(기준선) 대비 추정 단계.
4. **예상 진도 로드맵** — 연도별 표: 올해 / 1년 뒤 / 2년 뒤 … 각 영역이 어느 학기 과정에 있는지, 그리고 한 줄 "우리 학원에서 **중3 1학기에 고3 과정 완료** 예상". 비관·낙관 한 줄씩 작게.
5. 총평 2~3문장 (AI, 6장) — 강한 영역·약한 영역·시작할 단원.

**2장 원장용**
1. 문항표: 영역 · 순서 · 단계(학년·학기) · 단원 · 정오 · 걸린 시간. 오답 행 강조.
2. 영역별 "흔들린 구간" — 맞고 틀림이 섞인 단계 범위.
3. **다음 시작 단원** 영역별 (추정 단원의 다음 단원).
4. 교재 추천 칸 — 학원 설정에 영역×단계 구간의 교재명이 있으면 표시, 없으면 칸 자체를 뺀다.
5. 지도 방향 3개 (AI, 6장).

### 5.1 예상 진도 계산 `lib/progress.js` (순수 함수, 숫자는 전부 코드)

- 학원 설정 `pace` = **연간 진도 단계 수**, 기본 3 (학교의 1.5배). 비관 = pace − 0.5, 낙관 = pace + 0.5.
- 영역마다 `남은 = 20 − 추정 단계`, `년수 = 남은 ÷ pace` (소수 유지).
- 도달 시점 = 응시일 + 년수 → 학생의 그때 학년·학기로 바꿔 "중3 1학기" 처럼 쓴다. 학년은 3월에 오른다.
- 전체 도달 시점 = 가장 느린 영역. 연도별 표는 `추정 단계 + pace × n` 을 학기 이름으로.
- 학생이 이미 고3-2(20)면 "고3 과정 완료" 로 쓰고 년수는 0.

## 6. AI 글 (`api/comment.js`)

- 입력: 계산이 끝난 숫자(영역별 추정 단계·단원 이름·학년 차이·도달 시점·오답 단원 목록). **AI 는 숫자를 만들지 않고 받은 것만 쓴다.**
- 출력 `json_schema`: `{ summary: string(학부모용 2~3문장), directions: [3개 string] }`.
- 말투: 시험지분석과 같이 학부모에게 "~합니다", 과장·비교 없음. 교재명 없음.
- 키가 없거나 실패하면 코드가 **틀 문장**으로 채운다 ("문법은 중2 1학기 수준까지 안정적이며, 3단원부터 시작하면 좋겠습니다"). 리포트는 항상 나온다.
- 클로드 호출은 시험지분석의 `lib/claude.js` 를 복사해 쓴다 (모델·재시도·`fallbacks` 같음).

## 7. 학원 설정 (`localStorage` `elt:academy`, 에듀냅에선 로그인 정보)

```
{ name, logo?, phone, color?,
  pace: 3,
  books?: { grammar: [{from,to,name}], vocab:[…], reading:[…], listening:[…] } }
```
시험판은 첫 화면 아래 접힌 칸에서 한 번 적는다. `books` 는 비워도 된다.

## 9. 오류 처리

- 어느 단원에 `ok` 문항이 없으면 그 단원을 건너뛰고, 영역 전체에 20문항 미만이면 시험 시작 전에 "문항 검수가 더 필요합니다" 로 막는다.
- 응시 중 새로고침: `localStorage` 진행 상태로 이어서 푼다.
- 음성합성 없음: 듣기 건너뜀 + 리포트에 "듣기 미응시".
- AI 실패: 틀 문장. 네트워크 없음도 같다.
- 이름에 전체 이름(한글 3자 이상 또는 영문 두 단어): 안내하고 진행하지 않는다.

## 10. 테스트

- `node --test`: 단계↔학년 변환 왕복, 적응 규칙(맞힘·틀림·정지 조건·추정), 진도 계산(도달 시점·경계 20·비관/낙관), 문항 스키마 검증.
- 화면: 로컬 서버로 학생 정보 → 4영역 → 리포트 2장 → 인쇄 미리보기까지 브라우저로 확인. 문항은 `items.sample.json`.
- 실제 AI: 키가 생기면 중1-1 한 학기 생성 → 검수 화면 → 시험 → 총평까지 한 번 돌린다.

## 11. 하지 않는 것 (지금)

- 말하기·쓰기 영역, 서술형 채점.
- 서버 저장·학생 계정·학부모 링크 (에듀냅 본체에서).
- IRT·문항 난이도 보정, 응시 통계.
- 교재 자동 추천 (학원이 적은 교재명만 보여 준다).
- 척도 편집 화면 (파일로 고친다).

## 12. 순서
