# 1차·2차를 한 시험으로 합치기 — 설계 (2026-10-02 원장 결정)

## 왜
- 1차는 학년 단계마다 문항이 너무 적다(초3 5 · 초4 6 · 초5 8 · 초6 9 · 중1 8, 중2~고3 은 듣기 2). 원장: "1차 문항 수가 너무 적어서 의미가 없다."
- 80점 관문 때문에 중1까지 다 맞혀도 듣기(중2~고3)를 놓치면 78점으로 2차에 못 간다.
- 결과지가 학부모용·원장용 둘로 나뉘어 있다. 원장: "결과리포트 하나로만."

## 결정
1. **한 시험**: 세트 A·B 각각 **9단계 × 10문항 = 90문항**. 단계 = 초3 · 초4 · 초5 · 초6 · 중1 · 중2 · 중3 · 고1 · 고2~3(level 값 `고2`).
2. **누구나 초3부터** 단계 순으로 푼다. **두 단계 연속으로 그 단계 문항의 절반 미만을 맞히면**(10문항이면 4개 이하) 그 단계를 마친 자리에서 시험이 끝난다. 남은 단계는 응시하지 않음.
3. **80점 관문·1차 결과 화면·"2차로" 단추를 없앤다.**
4. **결과리포트 하나**: 표지 → 응시한 영역마다 1쪽 → 마지막 "문항별 결과" 쪽(문항별 ○×, 유형별 맞힌 수, 지도 방향). "학부모용"·"원장용" 글자와 원장용 인쇄 단추를 없애고 인쇄 단추 하나. 교재명은 뺀다.

## 구성 (단계마다 10문항, 같은 단계 안 차례는 듣기 → 파닉스 → 어휘 → 문법 → 어형 → 독해 → 영작)
| 단계 | 듣기 | 파닉스 | 어휘 | 문법 | 어형 | 독해 | 영작 | 문항 출처 |
|---|---|---|---|---|---|---|---|---|
| 초3 | | 2 | 4 | | | 4 | | 1차 파닉스1·독해4 + **새 파닉스1·어휘4** |
| 초4 | | 1 | 3 | 2 | | 4 | | 1차 파닉스1·문법1·독해4 + **새 어휘3·문법1** |
| 초5 | | | 2 | 1 | 2 | 4 | 1 | 1차 그대로 + **새 어휘2** |
| 초6 | | | 1 | 1 | 2 | 4 | 2 | 1차 그대로 + **새 어휘1** |
| 중1~고2~3 (5단계) | 1 | | 3 | 2 | | 3 | 1 | 2차 50문항 그대로 |
- 새로 쓰는 문항: 세트마다 12개(두 세트 24개). 한 도우미가 두 세트를 같이 써서 표제어·소재가 겹치지 않게 한다.
- 초등 어휘: 2차와 같은 꼴(`영→한` 2 : `한→영` 1 비율 근처), 4지선다, 단계 어휘 수준(초3~4 구체 명사·기초 동사, 초5~6 행동 동사·감정 형용사). 2차 어휘·예전 문항 표제어와 겹치지 않는다.
- 새 초3 파닉스 1: 단모음(기존 초3 파닉스와 다른 모음). 새 초4 문법 1: 초4 문법표에서 기존 초4 문법과 다른 항목.
- 1차의 중1 문항 8개와 중2~고3 듣기 10문항은 시험에서 뺀다(파일의 `stage1`·`stage2` 는 그대로 둔다).
- 선택지 수: 초3~초6 4지, 중1~고2~3 어휘 4지·그 밖 5지. 제한 시간: 어휘 20초 · 문법 60초 · 그 밖 90초(듣기는 첫 듣기 뒤부터).

## 자료 모양
- `public/data/forms.json` 에 새 키 **`test`**: `{ "A": [90문항], "B": [90문항] }`. id `t-A-1`…, `no` 1…90, `passageId` `t-A-p1`…, status `draft`(원장 검수 뒤 `ok`). `stage1`·`stage2`·`write2` 는 그대로(옛 자료).
- 합치는 도구(작업 폴더 `merge-test.mjs`): `stage1` 초3~초6 문항 + 새 문항(`out/새초등.json`) + `stage2` 50문항 → 단계·영역 차례로 번호, 정답 자리는 원래대로(새 문항만 섞음), 검사(구성 수·선택지 수·checkOrder·validateTest).
- `forms.sample.json` 에도 `test.A`(연습 문항 몇 개, status ok) — 지금 샘플 1차·2차 문항을 단계 순으로 합친다.

## 시험 열림
- 고른 세트의 `test` 에서 **9단계 모두 통과(ok) 문항이 6개 이상**이면 forms.json, 아니면 샘플. (높은 단계가 비어서 "응시 안 함"으로 끝나는 일을 막는다.)
- 영어 음성이 없는 PC 는 듣기 문항을 빼고 센다(그 단계는 9문항, 멈춤도 남은 문항으로).

## 화면 흐름 (test.js)
- 안내 한 번("초3부터 단계가 올라가며, 어려워져서 계속 틀리면 그 자리에서 끝납니다. 어휘 20초·문법 60초·그 밖 90초") → 문항 → 끝나면 결과리포트로.
- 단계 진행 막대: 9칸(고2 칸 이름 '고2~3').
- 세션: `session.t = { i, log, started }`. 문항을 마칠 때마다 `stopAfter(list, log)` 가 참이면 끝. 예전 1차·2차 진행 중 세션은 처음부터 새 시험으로 시작한다.
- 결과 저장: `result.test = { set, log, stopped: '초5' | null }`.

## 채점·수준 (core/forms.js, 순수 함수)
- `stopAfter(list, log)`: log 에 있는 단계 중 **마친 단계**(그 단계 list 문항을 모두 풂)의 마지막 두 개가 모두 `correct*2 < total` 이면 그 단계 이름, 아니면 null.
- 영역 수준 `testLevels(log)`: 영역 묶음 어휘(vocab) · 문법(grammar+form) · 독해(reading) · 듣기(listening) · 쓰기(sentence). 초3부터 단계마다 그 영역 문항 3분의 2 이상이면 통과, 처음 못 넘은 단계에서 멈춤(`초5 수준 아래`), 그 영역 문항이 없는 단계는 건너뜀, 문항이 하나도 없으면 null(응시하지 않음). 파닉스는 맞힌 수만(`phonicsNote`). — 지금 `stage2Levels` 를 LEVELS 전체로 넓히고 form 을 문법에 넣는 것으로 한다(옛 2차 결과도 같은 답).
- 리포트 est: 통과한 단계의 다음 학년 1학기 `levelStep(level)+2`(초등도 같은 셈, 초5 → 초6 1학기), `○ 수준 아래` 는 그 학년 1학기 `levelStep(○)`(초3 수준 아래 → 초3 1학기). (구현 중 바꿈 10/2: 처음엔 초등을 모두 중1 1학기로 두었으나 학년 대비가 "앞섬"으로 잘못 나와 실제 자리로.)
- `stageText`: '초5' → '초5 과정 수준', '초3 수준 아래' → '초3 과정 전 단계', '고2' → '고2~3 과정 수준'.

## 결과리포트 (report.js / report.html)
- 모든 결과를 같은 모양으로: 표지(종합 수준·영역별 위치·앞으로의 진도·총평) → 영역 쪽(어휘·문법·독해·듣기 중 응시한 것) → **문항별 결과 쪽**: 문항별 표(번호·영역·단계·정오·고른 답·초), 쓰기(영작) 맞힌 수와 틀린 문법 항목, 유형별 맞힌 수, 파닉스 메모, 시간 초과 수, 멈춘 단계("초5 에서 끝남"), 지도 방향(눌러서 고침).
- 예상 진도는 그 영역의 실제 자리(초등 포함)부터 한 해 3학기로 센다. 척도(중1~고3)에 단원이 없는 초등 자리는 "초6 1학기 과정"처럼 적고, 다음 단원 칸은 "○ 과정부터 시작합니다".
- 예전 결과: 1차만 본 결과·1차+2차 결과는 두 log 를 이어 `testLevels` 로 같은 모양. 예전 적응형 결과(sections 에 log 가 있는 것)는 지금 쪽 그대로, 마지막 쪽만 예전 원장용 표.
- 도구 띠: "인쇄 / PDF" 하나 + "표지 PNG".

## 검수 화면 (forms-review)
- 문제지 고르기에 **한 시험 A · 한 시험 B** 를 맨 앞에 둔다(옛 1차·2차는 뒤에 "예전"으로). 열림 기준 문구: "9단계 모두 통과 6개 이상".

## 하지 않는 것
- 적응형으로 단계를 건너뛰기, 학년별 시작점(③안) — 원장이 ①안을 골랐다.
- 초등 듣기 — 듣기는 지금처럼 중1부터.
- 예상 진도에 초등 과정 넣기(척도는 중1~고3).

## 테스트
- `stopAfter`: 두 단계 연속 절반 미만에서 끝, 한 단계만이면 계속, 마치지 않은 단계는 세지 않음, 듣기를 뺀 9문항 단계.
- `testLevels`: 초등부터 수준, 영역이 없는 단계 건너뛰기, 옛 2차 log 와 같은 답.
- 자료: `test.A/B` 각 90, 단계마다 10, checkOrder 0건, 모두 validate 통과, 선택지 수 규칙. 샘플 `test.A` 도 checkOrder·validate.
- 리포트: 새 결과·옛 1차 결과·옛 1차+2차 결과가 빈 화면 없이 그려진다(브라우저 확인).

## 바꿈 (10/2 원장 결정): 초5부터, 파닉스 없음
- 원장: "초1부터 쉬운 수준이라 초5·6 이상 수준부터", "파닉스를 없애고".
- 시험 단계는 **초5 · 초6 · 중1 · 중2 · 중3 · 고1 · 고2~3 = 7단계 × 10문항 = 70문항**. 누구나 초5부터 푼다.
- forms.json `test.A/B` 에서 초3·초4 문항(파닉스 3개 포함) 20개씩 뺌. 남은 문항 `id` 는 그대로(선생님 의견이 id 로 묶임), `no` 만 1~70 으로 다시 매김. 샘플 `test.A` 도 초3·초4 를 빼서 8문항.
- 초3·초4 문항은 validateTest 에서 '수준' 으로 걸러진다. 예전 결과(초3·초4 log)는 testLevels 가 그대로 읽으므로 열린다.
- 초5 도 못 넘으면 "초5 수준 아래"(초5 1학기 자리).

## 바꿈 (10/2 원장 결정): 모두 50문항
- 원장: "총 50문항으로 맞춰줘". 7단계는 그대로, **초5 8문항 · 초6~고2~3 각 7문항 = 50**.
- 영역은 단계마다 다 남기고 같은 영역에서 하나씩 뺐다. 중1~고2~3 은 **듣기1·어휘2(영→한·한→영)·문법1·독해2·영작1**.
  - 어휘: 두 번째 영→한을 뺌. 문법: 단계마다 다른 꼴이 남게(중1 빈칸 어법 · 중2 빈칸 짝 · 중3 틀린 것 · 고1 맞는 문장 개수 · 고2~3 틀린 것). 독해: 내용 불일치를 뺌(고1 은 주제).
  - 초5: 어형 하나·독해 세부 내용 하나 뺌. 초6: 어형 하나·독해 세부 내용 하나·영작 하나 뺌.
- 남은 문항 id 그대로, no 만 1~50. 7문항 단계는 3개 이하로 맞히면 '절반 미만'.
- 시간 안내 약 40분(제한 시간을 다 써도 56분).

## 바꿈 (10/2 원장 결정): 영역별로 묶어 풀기 · 표지 PNG 단추 뺌
- 원장: "테스트를 영역별로 묶어서", 순서는 **듣기 → 어휘 → 문법(어형 포함) → 독해 → 영작**, 영역 안은 초5 → 고2~3 (같은 지문은 붙어 있음).
- 멈춤은 **영역마다 따로**: 그 영역에서 두 단계 연속 절반 미만이면 그 영역의 남은 문항은 건너뛰고 다음 영역으로. 모든 영역을 지나면 결과리포트.
- 문제지 파일(forms.json)은 그대로 단계 차례, 시험 화면이 `byArea` 로 다시 늘어놓는다. 위 띠는 영역 칸(`areaRail`), 다음 문항은 `nextIndex`, 멈춘 영역은 `areaStops` → 결과 `test.stops = { 영역: 멈춘 단계 }`, `test.order = 'area'`.
- 단계 차례로 풀던 진행 중 세션은 새 차례로 처음부터. 예전 결과(`test.stopped`)는 그대로 "○ 단계까지 풀고 끝났습니다".
- 결과리포트 문항표 번호는 푼 차례(1, 2, 3…).
- 원장: "인쇄 누르면 표지까지 같이 나오니 표지 버튼은 없어도 된다" → 표지 PNG 단추와 html-to-image 를 뺐다. 도구 띠는 "인쇄 / PDF" 하나.
