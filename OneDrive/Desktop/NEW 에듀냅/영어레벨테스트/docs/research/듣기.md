### 3.3 표의 각 셀 의미

**형식**: `유형명` / `말 속도 (WPM)` / `회 수` / `화자/등장인물 수`

예시: "목적추론 / 140~150 WPM / 1회 / 3~4명"
- **유형명**: 해당 단원의 주요 듣기 문항 유형
- **말 속도 (WPM)**: 브라우저 음성합성에서 사용할 추정 발화 속도
- **회 수**: 한 번에 들려주는 횟수 (1회 = 한 번만 / 2회 = 두 번 들려줌)
- **화자/인물 수**: 대화에 등장하는 인물 수 또는 설명자 수

### 3.4 난이도 상승 원리

1. **중1**: WPM 140~160, 단순 대화, 1회 제시
2. **중2**: WPM 155~175, 복잡해지는 대화, 일부 2회
3. **중3**: WPM 170~185, 추론 강화, 함정 기초
4. **고1**: WPM 180~190, 함정 심화, 설명문 이중 제시
5. **고2**: WPM 185~190, 함정 최고조, 수능 대비
6. **고3**: WPM 185~190, 수능 기출 문제 수준

### 4.2 주요 설명

**단어 수 범위**: 최소~최대 범위. 대화는 최소값, 설명문은 최대값에 가까움.

**턴 수**: 대화의 "주고받음" 횟수.
- 예: A 말함 → B 말함 → A 말함 = 3턴
- 설명문은 턴 수 제한 없음 (연속 음성)

**화자 수**: 등장하는 사람 수.
- 대화: 2~4명 (일반적으로 2명)
- 설명문: 1명 (강사/안내)
- 혼합형: 3~4명

**어휘 수준**:
- A1: 기초 (I am, hello, colors 등)
- A1+: 기초 강화 (과거형, 간단한 문법)
- A2: 초급 (현재완료, 조건문 등)
- A2+: 초급 강화 (수동태, 관계사 기초)
- B1: 중급 (복잡한 구문, 일상 어휘 확대)
- B1+: 중급 강화 (관계사, 동명사 활용)
- B2: 중상급 (고급 표현, 추상적 개념)
- B2+: 중상급 강화 (전문 용어, 미세한 뉘앙스)
- C1: 고급 (수능 수준, 원어민 뉘앙스)

**speechSynthesis rate 값**:
- `0.75` = 정상 속도의 75% (느림)
- `1.00` = 정상 속도 (기본값)
- `1.10` = 정상 속도의 110% (빠름)

**rate와 WPM 변환 공식** [추정]:
```
WPM ≈ 기본값(120 WPM) × rate

예시:
- rate 0.85 → 약 102 WPM (느린 속도)
- rate 1.00 → 약 120 WPM (보통)
- rate 1.05 → 약 126 WPM (빠른 보통)
```

⚠️ **주의**: 실제 WPM은 음성 엔진, 단어 길이, 음절 구성에 따라 달라짐.
정확한 변환을 위해서는 각 rate 값을 테스트해야 함.

### 6.2 추정치 (Estimate 마크 [추정] 표시)

1. **고등학교 말 속도**: 155~190 WPM 범위는 일반 영어 발화 속도 기준이지만, 실제 모의고사 음성은 측정 필요
2. **rate 값과 WPM 대응**: 가정 기준값 120 WPM로 설정했으나 실제 브라우저 기본값 측정 필요
3. **12학기×4단원 척도**: 중학생 영어 난이도와 고등학교 모의고사 난이도의 격차를 토대로 구성했으나 실제 교육 과정 내용 확인 후 조정 필요

### 6.3 향후 조사 로드맵

**Phase 1** (우선): EBSi 기출문제 50회분(2023~2026) 수집 및 분석

- 말 속도 정량 측정 (음성 파일 분석)
- 배점 분포 재확인

**Phase 2**: 중학교 기출문제 20회분 수집 및 분석
- 20문항의 유형별 분류
- 1회 vs 2회 난이도 비교
- 배점 규칙 파악

**Phase 3**: 음성 합성 rate 값 실제 테스트
- 각 rate 값(0.7~1.1)에 대해 WPM 측정
- 언어별/음성별 차이 기록
- AI 대본 생성 시 최적값 결정

**Phase 4**: 12학기×4단원 척도 검증
- 실제 교과서 난이도와 비교
- 학생 피드백 수집
- 척도 미세 조정
