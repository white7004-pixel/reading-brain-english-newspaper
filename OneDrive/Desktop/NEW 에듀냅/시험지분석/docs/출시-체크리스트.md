## 들어오는 사람 가리기 — 암호 하나

| | 어떻게 |
|---|---|
| 서버 | 환경변수 `APP_PASSWORD` 하나. `Authorization: Bearer <암호>` 를 글자 그대로 맞춰 본다 (`lib/http.js`) |
| 화면 | 처음 한 번 묻고 이 기기에 적어 둔다(`localStorage`). 틀리면 **한 번 더 묻고 그대로 다시 보낸다** — 사진을 다시 고르게 하지 않는다 |
| 이 PC | `.env.local` 에 `APP_PASSWORD` 가 없으면 **그냥 열린다** (`npm run local`) |
| 인터넷 | `APP_PASSWORD` 가 비어 있으면 **500 으로 닫는다.** 열어 두지 않는다 |

암호는 선생님들이 함께 쓰는 하나다. 바꾸고 싶으면 Vercel 에서 값만 바꾸면 되고,

**아직 실제 모델을 한 번도 부르지 못했다.** 지금까지는 전부 가짜 응답으로 확인한 것이다.

- 이 PC 에서 보려면 `.env.local` 에 `ANTHROPIC_API_KEY=...` (**채팅에 붙여넣지 않는다**) → `npm run local`
- 볼 것: ① 문항표가 맞는가 ② **정답이 맞는가** ③ 몇 분 걸리는가 ④ `fallbacks` 베타가 받아들여지는가
- **여기서 정답 정확도가 드러난다.** 돌려 보기 전에는 아무도 모른다

### 경고 — `npx vercel` 을 그냥 치면 **리딩브레인 랜딩페이지**를 잡는다

이 폴더의 git 최상위는 **`C:\Users\white` — 집 폴더 전체**이고, 그 저장소는 Vercel 의
`reading-brain-landing` 프로젝트에 묶여 있다. 그래서 `vercel` · `vercel link` 를
**이름 없이** 치면 CLI 가 묻지도 않고 `reading-brain-landing (linked by git)` 을 고른다.
**2026-10-01 에 실제로 세 번 그랬다.** 그 상태로 `--prod` 를 돌리면
**학부모가 들어가는 랜딩페이지가 시험지분석 화면으로 바뀐다.**

(올라가는 파일은 이 폴더뿐이다 — 집 폴더가 통째로 올라가지는 않는다.
위험한 것은 "어느 프로젝트에 올리느냐"다.)

**반드시 프로젝트를 먼저 만들고 이름으로 집어 묶는다:**

```bash
cd "C:/Users/white/OneDrive/Desktop/NEW 에듀냅/시험지분석"
npx vercel project add reading-brain-exam-analysis
npx vercel link --project reading-brain-exam-analysis --yes

```

프로젝트 이름은 **`reading-brain-exam-analysis`** (원장님 결정, 2026-10-01).
`reading-brain-landing` · `reading-brain-english-newspaper` 와 나란히 선다.
한 번 `.vercel/project.json` 이 생기면 그다음부터는 랜딩페이지를 다시 잡지 않는다.

`vercel link` 가 만드는 `.env.local` 은 그 프로젝트의 토큰일 뿐 우리 API 키가 아니다.
**랜딩페이지에 잘못 묶였을 때 받은 `.env.local` 은 지운다.**

올라가는 것·빠지는 것은 `.vercelignore` 에 적어 뒀다. `public/vendor/pdfjs` 는
올리지 않고 **Vercel 이 npm install 할 때 `postinstall` 로 다시 만든다.**
화면 뿌리는 `public/`, 서버는 `api/extract.js`·`api/report.js` (`vercel.json`).

### 넣을 환경변수 둘

| 이름 | 값 | 왜 |
|---|---|---|
| `APP_PASSWORD` | 원장님이 정하는 암호 | 선생님들이 들어올 때 넣는다. 비어 있으면 **전부 500** |
| `ANTHROPIC_API_KEY` | 원장님 키 | **채팅에 붙여넣지 않는다.** Vercel 화면이나 `npx vercel env add` 로 |

```bash
npx vercel env add APP_PASSWORD production
npx vercel env add ANTHROPIC_API_KEY production   # Store as sensitive? → yes
```
