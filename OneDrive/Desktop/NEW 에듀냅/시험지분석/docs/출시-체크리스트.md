## 에듀냅 연결 — 끝났다 (2026-10-01)

접속 코드를 없애고 **에듀냅이 서명해 주는 학원 토큰**을 받게 바꿨다.

| | 전 | 지금 |
|---|---|---|
| 들어오는 사람 가리기 | 접속 코드(`TRIAL_CODE`) 하나를 모두가 공유 | **에듀냅 학원 토큰** (`Authorization: Edunap …`) |
| 화면이 코드를 묻나 | 물어야 했다 (칸이 없어 막혀 있었다) | **묻지 않는다.** 에듀냅에서 들어오면 끝 |
| API 키 | 이 앱이 따로 받아야 했다 | **에듀냅 서버의 키를 그대로 쓴다** (`ANTHROPIC_API_KEY`) |

**어떻게 도는가**

```
원장님이 에듀냅에서 '시험지 분석'을 누름
        ↓
에듀냅이 학원 토큰을 서명해 주소에 붙여 이 화면을 연다  (…/?t=토큰)
        ↓
화면이 토큰을 받아 두고 주소창에서는 지운다 (sessionStorage 보관)
        ↓
요청마다 Authorization: Edunap <토큰> → 서버가 서명을 확인하고 학원 id·이름을 읽는다
```

- 서명 방식은 에듀냅(`blog-cloud/lib/auth.js`)과 **글자 하나까지 같다.** `lib/edunap.js` 에 옮겨 적었고,
  `test/edunap.test.js` 가 **에듀냅 쪽 코드를 베껴 토큰을 만들어** 확인한다. 저쪽이 바뀌면 여기도 바꾼다
- 서버 환경변수는 **`EDUNAP_SHARED_SECRET`** 하나. 이 PC(`npm run local`)에서는 비밀이 없어 그냥 열린다
- 토큰이 없거나 시간이 지나면 **"에듀냅에서 다시 들어와 주세요"**

## 출시를 막는 것 — 이제 하나

### 클로드 API 키로 실제 시험지 한 벌 돌려 보기

**아직 실제 모델을 한 번도 부르지 못했다.** 지금까지는 전부 가짜 응답으로 확인한 것이다.
에듀냅 키를 쓸 것이므로 **따로 받을 키는 없지만, 돌려 보는 일은 남아 있다.**

- 이 PC 에서 보려면 `.env.local` 에 `ANTHROPIC_API_KEY=...` (**채팅에 붙여넣지 않는다**) → `npm run local`
- 볼 것: ① 문항표가 맞는가 ② **정답이 맞는가** ③ 몇 분 걸리는가 ④ `fallbacks` 베타가 받아들여지는가
- **여기서 정답 정확도가 드러난다.** 돌려 보기 전에는 아무도 모른다

## 아직 정하지 않은 것 — 어디에 올릴까

| 길 | 뜻 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| **(가) 따로 올린다** | 이 폴더를 그대로 Vercel 프로젝트 하나로. 에듀냅이 링크로 연다 | **지금 바로 된다.** 코드 손댈 것 없음 | 배포가 둘, 비밀값을 양쪽에 넣어야 함 |
| (나) 에듀냅 안에 넣는다 | `blog-cloud` 에 화면·API 를 합친다 | 배포 하나, 토큰 넘기기가 자연스럽다 | `blog-cloud` 라우팅·정적 파일에 맞춰 옮기는 일이 있다 |

**빨리 내려면 (가)** 를 권한다. 나중에 (나)로 옮겨도 서버 코드는 그대로 쓴다.

(가)로 갈 때 정하실 것 — Vercel 프로젝트 이름 / 에듀냅 쪽에 이 주소를 띄우는 자리 /
**`EDUNAP_SHARED_SECRET` 은 에듀냅과 같은 값** / `ANTHROPIC_API_KEY` 는 원장님이 직접 입력.

## 출시 뒤에 해도 되는 것

| 할 일 | 왜 급하지 않나 |
|---|---|
| 토큰 1시간 만료 뒤 이어 쓰기 | 지금은 "다시 들어와 주세요". 길게 쓰실 때 불편하면 그때 고친다 |
| 학원 이름·로고를 에듀냅에서 받아 채우기 | 토큰에 이름이 들어 있다. 지금은 원장님이 한 번 적으시면 된다 |
| 영어 문법표 원장님 검수 | `[학원분류]` 라 쓰는 데 지장 없다 |
| 교과서 목차 넣기 | 없으면 AI 가 시험지에 적힌 단원을 그대로 쓴다 |
| **1단계 학교별 기출 은행** | 설계서만 있다. **지금부터 쌓아야 내년에 경향이 나온다 — 출시 직후 1순위** |
| 2단계 예상문제·적중률 | 기출이 2회 쌓인 뒤에나 가능 |
| 서답형 번호 (`no` 를 문자열로) | **기출 은행 저장 층 만들기 직전**에 고친다 |

```
② (가)/(나) 정하기 — 빨리 내려면 (가)                      (원장님)

```

②는 지금 정하시면 되고, **①이 끝나야 출시해도 되는지 알 수 있다.**
