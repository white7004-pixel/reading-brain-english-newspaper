# 에듀냅 시험지 분석 — 시험판 설계서

작성 2026-09-15 · 폴더 `Desktop\NEW 에듀냅\시험지분석\`

## 0. 한 줄

원장님이 **영어 시험지 사진**을 올리면 AI가 문항표를 만들고, 원장님이 한 번 확인하면
**학교 시험 분석 A4**와 **학생별 개인 리포트 A4**(오답 원인·지도 방향)가 나온다.

## 1. 정한 것 (원장님 결정)

| 항목 | 결정 |
|---|---|
| 과목 | ~~영어만~~ → 2026-09-19 **과목별** (국어·영어·수학·과학·사회·역사). AI가 머리글에서 과목을 알아보고, 과목마다 영역표·오답 원인·글 예시가 따로 있다 (`lib/rules.js` GUIDE, `public/lib.js` SUBJECTS) |

| 만드는 방식 | 두 번 나눠 부르기 + 정해진 A4 틀 (AI가 이미지를 그리지 않는다) |

## 2. 조사에서 가져온 기준

네이버 블로그 영어 시험 분석 글을 읽고 형식만 뽑았다 (문장·이미지는 가져오지 않음).
조사 원본: 세션 스크래치패드 `시험지분석-조사보고서.md` (빈도 %는 근거가 약해 쓰지 않는다).

- 좋은 분석은 **숫자로 말한다** — "중상 이상 57%", "5점 문항 5개가 변별".
- **왜 어려웠는지 문항 번호를 짚는다** — 함정 선택지, 학년보다 높은 문법·지문.
- 공개용은 시험지 원문을 거의 싣지 않는다 (일부만·모자이크). 우리도 **시험지 원문 이미지는 리포트에 넣지 않는다.**
- 캡처 프롬프트 요구: 시험 날짜·출제범위 생략, 총평, 문항마다 영역·난이도(상중하), 오답 원인, 지도 방향, 학원 로고, 입시전문학원 느낌.

## 3. 화면 흐름

한 페이지(`index.html`) 안에서 단계가 넘어간다.

1. ~~학원 정보 단계~~ — 2026-09-19 없앰. 에듀냅에서는 로그인한 학원 정보, 시험판은 올리기 칸 아래 접힌 칸(`localStorage`).
2. **시험지 올리기** — 시험지 사진 또는 PDF 1~6쪽(쪽 순서대로)만. PDF 는 브라우저에서 pdf.js 로 쪽마다 JPEG(긴 변 2000px)로 바꿔 사진과 같은 길로 보낸다 (2026-09-19). pdf.js 는 `npm install` 때 `public/vendor/pdfjs` 로 복사(git 제외, 버전은 package.json 고정). 정답지 사진은 0~2장. 확인 표 위에 AI가 읽은 과목·학교·학년·학기·시험이 나오고, 못 읽은 학교·학년은 금색.
   - 올리기 전에 브라우저에서 JPEG 로 줄인다 (긴 변 1800→1400→1100px, Vercel 요청 4.5MB 제한 안쪽).
3. **확인 표** — 문항 한 줄씩: 번호 · 객관식/서술형 · 배점 · 대영역 · 세부유형 · 난이도 · 정답 · 판단 근거.
   - 칸을 눌러 고친다. AI가 자신 없는 칸은 금색. 번호도 고칠 수 있고 행을 추가·삭제할 수 있다.
   - 배점 합계가 100이 아니면 표 위에 경고. 번호가 겹치거나 비면 경고하고 리포트를 만들지 않는다.
4. **학생 입력** — 한 줄에 한 명: `김OO 4, 9, 25` 또는 고른 답까지 `김OO 4(③), 9(②), 25`.
   - 이름은 성+OO 또는 이니셜로만 받는다 (전체 이름을 쓰면 안내 문구).
5. **결과** — 학교 분석 A4, 학생별 A4. 글자는 화면에서 바로 고칠 수 있다 (`contenteditable`).
6. **내려받기** — 장마다 PNG(카톡용), 전체 인쇄/PDF(브라우저 인쇄, `@page A4`).

## 4. AI 판단 기준 (규칙 파일 `lib/rules.js`)

### 4.1 영역 분류 (영어)

| 대영역 | 세부유형 |
|---|---|
| 어휘 | 문맥 어휘, 영영풀이, 품사·파생어, 숙어·표현 |
| 어법 | 문법 포인트명으로 적는다 (시제, 수일치, to부정사, 동명사, 분사, 관계사, 접속사, 수동태, 비교, 가정법, 도치 …) · 개수 고르기 |
| 대화문 | 대화 흐름·응답, 의사소통 기능 표현 |
| 독해 | 주제·제목·요지, 내용 일치/불일치, 빈칸, 순서, 문장 삽입, 무관한 문장, 지칭, 목적·심경, 요약, 답할 수 없는 질문 |
| 서술형 | 조건 영작, 문장 변형·전환, 배열 영작, 빈칸 쓰기, 요약 쓰기, 우리말 해석 |
| 듣기 | (시험지에 있을 때만) |

### 4.2 난이도 (확인 표·학교 분석은 5단계, 학생 리포트는 상·중·하 3단계)

하 / 중하 / 중 / 중상 / 상. 판단 근거를 **한 줄**로 남긴다. 근거로 쓰는 것:
- 배점 (학교가 매긴 무게)
- 학년 대비 문법·어휘·구문 수준
- 지문 길이와 추론 단계 수
- 함정 선택지 (비슷한 형태, 부분만 맞는 선택지)
- 서술형 조건 개수

3단계 표시: 하·중하 → 하, 중 → 중, 중상·상 → 상.

### 4.3 정답

- 정답지 사진이 있으면 그것을 따른다.
- 없으면 AI가 풀어 정답을 적고, 자신 없으면 금색. 서술형은 모범답안 요지만.

### 4.4 오답 원인 분류

| 원인 | 뜻 |
|---|---|
| 어휘 부족 | 핵심 단어·표현 뜻을 몰라 틀림 |
| 문법 개념 미흡 | 해당 문법 규칙을 모르거나 헷갈림 |
| 구문 해석 오류 | 긴 문장 구조를 잘못 끊어 읽음 |
| 단서 놓침·추론 오류 | 지문의 근거를 못 찾거나 잘못 연결 |
| 선택지 함정 | 부분만 맞는 선택지를 고름 |
| 조건 누락 | 서술형 조건(단어 수·형태 등)을 빠뜨림 |
| 시간 부족·실수 | 쉬운 문항인데 틀림, 마지막 문항 몰림 |

- 학생이 **고른 답**을 넣으면 그 선택지가 왜 매력적이었는지로 원인을 좁힌다.
- 고른 답이 없으면 문항 특성으로 가장 가능성 큰 원인을 고르고, 문장은 "~했을 가능성이 큽니다" 처럼 추정으로 쓴다.
- 문항당 원인 1개, 설명 1~2문장, 학부모가 이해할 말로.

### 4.5 숫자는 AI가 쓰지 않는다

분포 %, 문항 수, 서술형 비율, 중상 이상 비율, 영역별 정답률, 추정 점수는 **확인된 표로 코드가 계산**한다 (`public/lib.js`).
추정 점수 = 배점 합 − 오답 문항 배점 (서술형 부분점수는 반영 안 함 — 리포트에 작게 표기).
AI 글에 숫자가 필요하면 계산된 값을 프롬프트로 넘겨 그대로 쓰게 한다.

## 5. A4 구성

공통: 상단 로고·학원 이름·대표 색 띠, 하단 연락처. 흰 종이에 에듀냅 제목 글꼴(Hahmlet)·올리브·금색 선이 기본, 대표 색으로 바뀜. 모든 리포트는 A4 한 장 고정. 차트는 HTML/CSS 막대로 그린다 (라이브러리 없음).

**학교 시험 분석 (1장)**
1. 제목: `OO중 2학년 1학기 중간고사 영어 분석`
2. 총평 2~3문장 + 전체 난이도 배지
3. 핵심 숫자 3개: 문항 수 / 서술형 배점 비율 / 중상 이상 비율
4. 영역 분포 막대 · 난이도 분포 막대
5. 문항표 (번호·영역·세부유형·난이도·배점) — 한 줄 10칸 격자
6. 변별 문항 3개: 번호·유형·왜 어려웠나
7. 다음 시험 대비 전략 (영역별 한 문장)

**학생 개인 리포트 (1장)**
1. 학생 이니셜 · 학교·학년·시험
2. 추정 점수 · 오답 수 · 약점 영역
3. 시험 총평 요약 2문장
4. 문항표 — 오답 행 강조
5. 영역별 정답률 막대
6. 오답 분석: 번호 · 영역/세부유형 · 난이도 · 원인 · 설명 (7개부터 2단)
7. 학원 지도 방향 3개 (구체적 수업 활동으로)

## 6. 구조

```
시험지분석/
  public/index.html      화면 (단계·확인 표)
  public/style.css       에듀냅 스타일 · A4 틀 · 인쇄 CSS
  public/app.js          사진 줄이기, API 호출, 표 편집, 렌더, A4 자동 맞춤, PNG 내려받기
  public/report.js       A4 틀 (학교 분석·학생 리포트)
  public/lib.js          4.5의 계산 (순수 함수, 브라우저·서버 공용)
  api/extract.js         POST 사진 → 문항표 JSON
  api/report.js          POST 확인된 표·학생 → 글(총평·변별·전략·오답 원인·지도 방향) JSON
  lib/claude.js          클로드 호출 (blog-cloud 와 같은 방식)
  lib/rules.js           4장의 기준 → 시스템 프롬프트, JSON 스키마, 요청 검증
  lib/http.js            접속 코드 확인·오류 응답
  scripts/local.js       로컬 서버 (npm run local)
  test/*.test.js         node --test
  package.json, vercel.json
```

- 런타임 Node 20, Vercel 함수 2개. 의존성은 `@anthropic-ai/sdk` 하나.
- 모델 `claude-opus-5`, 적응형 사고, 스트리밍 + `finalMessage`, 구조화 출력(JSON 스키마)으로 받는다.
- PNG 내려받기는 CDN의 `html-to-image` 한 개. PDF는 브라우저 인쇄.

### 호출 1 — `/api/extract`
입력: 사진들(base64), 정답지 사진(선택), 학교·학년·학기·시험.
출력: `items[]` = `{no, kind, points, area, subtype, difficulty, answer, reason, unsure[]}` + `notes`(읽지 못한 쪽 등).

### 호출 2 — `/api/report`
입력: 확인된 `items`, 계산된 숫자, 시험 정보, 학생들 `{label, wrong:[{no, chosen?}]}`.
출력: `school {overview, keyItems[{no, why}], strategy[{area, tip}]}`, `students[{label, summary, causes[{no, cause, explain}], directions[]}]`.
학생은 5명씩 나눠 부르고, 학교 분석 포함 동시에 3개까지만 부른다. 학생 표기는 AI에 `학생1..` 로만 보낸다.

## 7. 오류·안전

- **접속 코드**: 이 PC(127.0.0.1)에서만 쓰는 동안은 없다 (2026-09-19 원장님 결정). 인터넷(Vercel)에 올릴 때는 `TRIAL_CODE` 가 없으면 서버가 열리지 않으므로, 배포 때 코드 입력 칸을 다시 붙인다. 에듀냅 안으로 옮기면 로그인이 대신한다.
- 사진·학생 정보는 서버에 저장하지 않고 로그에도 남기지 않는다 (토큰 수만).
- 사진이 흐리거나 시험지가 아니면 `notes` 로 알려 주고 확인 표에서 해당 문항을 금색으로.
- 거절·시간 초과·과부하: "잠시 후 다시 시도해 주세요" + 다시 시도 버튼. 확인 표에서 고친 내용은 페이지 안에 남아 있어 다시 입력하지 않는다.
- 학생 전체 이름 입력 시 경고.

## 8. 검증

- `test/*.test.js`: 분포·비율·점수·3단계 변환 계산, 요청 검증, AI 답 읽기.
- **실제 시험지 3~5세트**로 AI 문항표를 원장님(또는 강사) 분석과 비교해 영역·난이도·정답 일치율을 본다. 일치율이 낮은 칸은 규칙(`rules.js`)을 고친다.
- 휴대폰으로 찍은 사진(기울어짐·필기 있음) 1세트 포함.
- 화면: 휴대폰 폭에서 올리기·확인 표가 쓸 수 있는지, A4 인쇄가 한 장에 맞는지.

## 9. 이번에 하지 않는 것

- 로그인·저장·기록 보기·다년 비교 (에듀냅으로 옮길 때)
- 영어 외 과목
- 문항 출처(교과서/외부 지문) 판정 — 교과서 원문 없이 추정하면 틀리기 쉬움
- 분석 결과 → 블로그 글 연결
- 여러 학생 PNG 묶음(zip) — 인쇄 한 번으로 PDF 묶음 대체

## 10. 만들면서 바뀐 것 (2026-09-15)

- 시험지 사진 1~6장 + 정답지 0~2장 (Vercel 요청 4.5MB 제한).
- 계산 파일은 `public/lib.js` (브라우저·서버·테스트 공용).
- 에듀냅(edunap.kr) 스타일 적용: 앱 화면은 올리브·크림·금색·Hahmlet, A4는 흰 종이 + 에듀냅 제목 글꼴·기본 색.
- 리포트는 각각 A4 한 장 고정: 칸 격자·2단·자동 글자 맞춤, 그래도 넘치면 경고.
- AI 글 길이 규칙 축소. 변별 문항 3개, 지도 방향 3개.
- 문항표: 번호 편집, 행 추가/삭제, 번호 중복·빈 번호면 리포트를 만들지 않음 (서버도 중복 번호를 막는다).
- 학생 이름은 AI에 `학생1..` 로만 전달하고, 받은 뒤 원장님 표기로 되돌린다.
- 학생 5명씩 한 번, 동시에 3개까지 호출 (학교 분석 포함).

## 정답지 (2026-10-01 원장님 결정)

**정답지는 받지 않는다.** 올리기 화면에서 칸을 없앴다.
AI 가 문항을 직접 풀어 `answer` 를 적고, 확신이 서지 않으면 `unsure` 에 `answer` 를 넣어
확인 표에서 금색으로 뜬다. 지문이 잘려 보이거나 그림·표가 있어야 풀 수 있는 문항도 마찬가지다.
원장님이 그 칸만 보고 고치면 된다.
