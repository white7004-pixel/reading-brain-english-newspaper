# 시험 분석 공유물 (A4 1장 → 카드뉴스 3장) — 설계서

작성 2026-09-30 · 폴더 `Desktop\NEW 에듀냅\시험지분석\`
앞 설계서: `2026-09-15-시험지분석-design.md` (문항표·A4 리포트 본체)

## 0. 한 줄

확인한 문항표에서 **공개용 A4 분석지 1장**을 만들고, 같은 숫자를 그대로 **카드뉴스 3장**으로 쪼개
학부모 단톡방·학원 블로그에 올릴 수 있게 한다.

## 1. 정한 것 (원장님 결정, 2026-09-30)

| 항목 | 결정 |
|---|---|
| 결과물 | 카톡·블로그용 **이미지 카드** (A4 1장을 먼저 만들고 쪼개서 3장) |
| 학생 결과 | **넣지 않는다.** 학교 시험 분석만 공개한다 |
| 과목 | 국어·영어·수학·과학·사회·역사 (본체와 같음) |
| 카드 크기 | 1080×1350 (카톡·블로그·인스타 공통으로 무난한 세로) |

## 2. 조사에서 가져온 것 (2026-09-30)

네이버 블로그 본문이 막혀 **실제 학원 글은 열어 보지 못했다.** 학원용 가이드·교육 플랫폼 7곳만 봤으므로
"몇 %가 이렇게 한다"는 수치는 쓰지 않는다. 그중 어디서나 공통으로 확인된 것만 반영한다.

- 넣는 것: 학교·학년·과목·시험명 / 한 줄 총평 / 영역(단원)별 비중 / 난이도 분포 / 어려웠던 문항
- 넣지 않는 것: 학생 이름·점수, 시험지 원문 이미지, "최고·1등" 같은 단정

## 3. A4 분석지 1장 (공개용)

| 자리 | 내용 | 출처 |
|---|---|---|
| 머리 | 학원 로고·이름, `학교 학년 학기 시험 과목 분석` | 학원 정보(로그인) + meta |
| 총평 | 한 줄 평, 전체 난이도, 핵심 숫자 3개 (문항 수 · 서술형 배점 비율 · 중상 이상 비율) | AI 글(overview) + `examStats` |
| 가운데 | 영역별 문항 막대, 난이도 분포 막대 | `examStats.byArea` / `byDifficulty` |
| 아래 | 문항별 격자 (번호 · 배점 · 난이도 · 영역) | 문항표 |
| 끝 | 변별 문항 3개와 이유, 다음 시험 대비 전략, 학원 이름·연락처 | AI 글(keyItems·strategy) |

기존 학교 분석 A4(`schoolPage`)와 내용은 같고, **학생 리포트와 달리 공유를 전제로 한다.**
따라서 별도 파일로 두지 않고 같은 데이터로 카드를 파생시킨다 (4장).

## 4. 카드뉴스 3장

같은 `ctx`(학원·meta·문항표·통계)와 같은 AI 글에서 만든다. **카드에서 숫자를 새로 계산하지 않는다.**

1. **한눈에** — 학교·시험명, 한 줄 총평, 핵심 숫자 3개, 전체 난이도 뱃지
2. **무엇이 나왔나** — 영역별 비중, 난이도 분포
3. **다음 시험 준비** — 변별 문항 3개, 대비 전략, 학원 이름·연락처

각 카드는 `1080×1350` 고정. 글이 많으면 A4와 같은 `--fit` 배율로 줄인다.

## 5. 구조

- `public/share.js` — 새 파일. `sharePage(ctx, school)` (A4 1장) 과 `shareCards(ctx, school)` (카드 3장)
- `public/app.js` — 리포트 생성 뒤 공유물도 함께 그린다. `PNG 받기` 는 지금 방식 그대로, **카드 3장 한 번에 받기** 버튼 추가
- `public/report.js` — 건드리지 않는다 (학생 리포트·기존 A4 유지). 공통 조각(막대·뱃지·격자)은 `report.js` 에서 export 해 share.js 가 가져다 쓴다
- `public/style.css` — `.card-news` 크기·여백만 추가. 인쇄 CSS 는 건드리지 않는다

## 6. 지킬 것

- 학생 이름·점수·시험지 원문 사진은 **어느 카드에도 넣지 않는다.** (`share.js` 는 `student` 데이터를 받지 않는다)
- 모든 글자는 `esc()` 를 지난다.
- 숫자는 `public/lib.js` 계산만 쓴다.

## 7. 검증

- 카드 3장에 들어간 숫자가 A4 와 같은지 자동 검사 (`test/share.test.js` — 카드 HTML 에 통계 값이 그대로 있는지)
- 학생 이름이 어떤 카드에도 없는지 자동 검사
- 브라우저에서 가짜 시험지로 3장 렌더 → 1080×1350 확인 → PNG 저장 확인
