# 시험지분석 입력 항목 재설계

**날짜** 2026-10-03
**정한 사람** 원장님 (대화로 하나씩 확인)

## 왜 다시 만드나

지금 입력은 중등 영어 25문항을 기준으로 짜였다. 쓰다 보니 셋이 걸린다.

1. **중등에는 칸이 너무 많다.** 번호·유형·배점·단원·영역·세부유형·난이도·출처·정답·한 줄 설명·대표 — 열한 칸을 25줄 채워야 한다. 원장님이 좋다고 하신 중등 카드(하버드브레인식)는 **번호·무엇을 물었나·어려움** 세 칸이면 만들어진다.
2. **고등에는 칸이 모자란다.** 출제원이 `교과서 변형`·`학교 프린트`로 갈리는데 우리 목록에 없다. 영어 `쓰기` 영역도 없다.
3. **두 단계로 끊겨 있다.** `STEP 01 시험 정보` → `STEP 02 문항표`. 한 장으로 펴면 한 번에 끝난다.

경쟁사 화면(이김수학·에스키·패스파인더·하버드브레인)을 **항목의 바탕**으로만 쓴다. 순서·말·묻는 방식은 우리 것으로 다시 짰다. 문장·유형 이름·브랜드를 베끼지 않는다.

## 하는 것 / 안 하는 것

**한다**
- 시험 입력 항목·순서·말을 다시 짠다
- 분석 깊이 세 단계(간단·보통·자세히)를 넣는다 — 적는 칸과 결과물이 함께 달라진다
- 교과서(출판사·저자) 고르는 칸을 넣는다
- 출제원·영역 선택지를 넓힌다
- 카드뉴스 색을 다섯 → 여덟 벌로 늘린다

**안 한다**
- 학원 로고·이름·연락처 설정 — **로그인에 이미 저장돼 있다** (2026-10-03 원장 결정)
- 담당 교사 칸 — 학부모께 드리는 자료에 쓸 자리가 없고 사람 이름이 들어간다
- 사진·PDF 자동 추출 고치기 — **직접 입력이 기본**이고, 자동 추출은 나중에 붙인다 (2026-10-03 원장 결정)
- 카드 디자인은 **여섯 그대로** 둔다 (어두운 판 / 밝은 띠 / 번지는 색 / 세로 분할 / 편집 / 빛)

## 1 · 흐름

두 단계를 한 장으로 편다.

```
┌─────────────────────────────────────┐
│  [ 간단 ]   [ 보통 ]   [ 자세히 ]   │  ← 학년을 고르면 알아서 (중등→보통, 고등→자세히)
├─────────────────────────────────────┤
│  ㄱ 어느 시험인가                    │
│  ㄴ 무엇으로 냈나                    │
│  ㄷ 어떻게 생겼나                    │
│  ㄹ 문항마다 ─── 표 ───              │
├─────────────────────────────────────┤
│  [ 분석 자료 만들기 ]                │
└─────────────────────────────────────┘
```

깊이 고르개는 **맨 위**에 둔다. 아래 칸이 그에 맞춰 늘고 준다. 깊이를 바꿔도 **이미 적은 값은 지우지 않는다** — 칸만 숨긴다. 간단으로 내렸다가 다시 자세히로 올리면 적어 둔 배점이 그대로 돌아온다.

## 2 · 항목

묻는 차례는 **원장님이 그걸 아는 차례**다. 시험지 표지만 봐도 아는 것 → 범위 → 생김새 → 문항.

### ㄱ 어느 시험인가

| 칸 | 모양 | 깊이 | 비고 |
|---|---|---|---|
| 학교 | 자유 입력 | 전부 | |
| 학년 | 중1~고3 고르기 | 전부 | 이 값이 깊이 기본값을 정한다 |
| 언제 | `1학기` + `중간고사` 한 줄 | 전부 | 지금은 두 칸으로 떨어져 있다 |
| 본 날 | 날짜 | 전부 | |
| 푼 시간 | 분 | 보통·자세히 | 이미 있다 |

### ㄴ 무엇으로 냈나

| 칸 | 모양 | 깊이 | 비고 |
|---|---|---|---|
| 교과서 | 출판사·저자 고르기 **+ 직접 입력** | 전부 | 아래 목록 |
| 나온 단원 | 칩으로 여러 개 + 직접 추가 | 보통·자세히 | 교과서를 고르면 목차가 칩으로 — 목차가 없으면 직접만 |
| 교과서 말고 쓴 것 | 자유 입력, 쉼표로 나눔 | 자세히 | 부교재·프린트 이름 |

### ㄷ 어떻게 생겼나

| 칸 | 모양 | 깊이 | 비고 |
|---|---|---|---|
| 고르는 문항 | 숫자 | 전부 | 지금 `선택형 문항 수` |
| 짧게 쓰는 문항 | 숫자 | 전부 | 지금 `단답형 문항 수` |
| 길게 쓰는 문항 | 숫자 | 전부 | 지금 `서술형 문항 수` |
| 만점 | 숫자, **배점 합계가 자동으로 들어가고 고칠 수 있다** | 보통·자세히 | 새로 |

### ㄹ 문항마다

| 칸 | 간단 | 보통 | 자세히 | 새 이름 |
|---|:--:|:--:|:--:|---|
| 번호 | ● | ● | ● | |
| 무엇을 물었나 | ● | ● | ● | 지금 `세부유형` |
| 어려움 | ● | ● | ● | 지금 `난이도` |
| 배점 | | ● | ● | |
| 영역 | | ● | ● | |
| 어디서 가져왔나 | | ● | ● | 지금 `출처` |
| 단원 | | ● | ● | |
| 대표 | | ● | ● | |
| 답 | | | ● | 지금 `정답` |
| 한 줄 설명 | | | ● | |

`유형`(고르는/짧게 쓰는/길게 쓰는)은 **표에서 뺀다.** ㄷ에서 개수를 받으므로 번호를 매길 때 정해진다 — 앞쪽은 `객관식`, 서답형 번호는 단답형·서술형 개수대로. 값(`it.kind`)은 그대로 들어가므로 통계는 지금과 같다. 틀리게 매겨졌으면 번호를 고치면 다시 잡힌다.

### 말을 바꾸는 표

| 지금 | 새로 | 왜 |
|---|---|---|
| 출처 | 어디서 가져왔나 | '출처'는 인용 느낌이고, 묻는 건 출제 재료다 |
| 난이도 | 어려움 | 학부모 카드에서 이미 `쉬움·보통·어려움`으로 쓴다 |
| 세부유형 | 무엇을 물었나 | 원장님이 적을 때 생각하는 말 그대로 |
| 선택형 / 단답형 / 서술형 | 고르는 / 짧게 쓰는 / 길게 쓰는 | 학교마다 부르는 말이 달라 헷갈린다 |

**통계·내부 값은 바꾸지 않는다.** 화면에 보이는 이름만 바꾼다. `lib.js` 의 `KINDS`·`SOURCES`·`AREAS` 값이 그대로여야 지금 통계와 리포트가 깨지지 않는다.

## 3 · 선택지 넓히기

### 어디서 가져왔나 (출제원)

지금 `SOURCES = ['교과서', '부교재', '모의고사', 'EBS', '외부', '기출변형']`.

여기에 **둘을 더한다.**

| 값 | 중등 | 고등 | 왜 |
|---|:--:|:--:|---|
| 교과서 | ● | ● | |
| **교과서 변형** | ● | ● | 중등 시험지에 제일 많다. 지금은 `기출변형`과 뭉뚱그려진다 |
| **학교 프린트** | ● | ● | 선생님이 나눠 준 유인물에서 나온 문항 |
| 부교재 | ● | ● | |
| 외부 | ● | ● | 에스키의 '외부지문'에 해당 |
| 모의고사 | | ● | |
| EBS | | ● | |
| 기출변형 | ● | ● | 다른 학교·지난 해 기출을 바꾼 것 |

`SOURCES_BY_LEVEL` 에 중등·고등 각각 넣는다.

### 영역 (영어)

지금 `['어휘', '어법', '대화문', '독해', '듣기']` → **`쓰기`를 더한다.**

`쓰기` 세부유형(중등·고등 공통 시작값): `조건 영작`, `배열 영작`, `빈칸 채워 쓰기`, `문장 바꿔 쓰기`, `요약문 쓰기`

`어법` 아래에 있던 `배열 영작`·`조건 영작`은 **그대로 둔다** — 어법을 묻는 영작과 쓰기를 묻는 영작이 다르고, 원장님이 어느 쪽으로 볼지 고르게 두는 편이 낫다.

### 교과서 목록

웹에서 찾은 것(2026-10-03). **확정 목록이 아니다** — 틀리면 고친다. 없는 교과서는 직접 적는다.

**중학교 영어 (2022 개정)**
동아출판 윤정미 · 동아출판 이병민 · NE능률 김기택 · 비상교육 황종배 · 천재교과서 소영순 · 천재교과서 이상기 · 미래엔 · YBM · 지학사

**고등 공통영어1 (2022 개정)**
YBM 박준언 · YBM 김은형 · NE능률 민병천 · NE능률 오선영 · 천재교과서 강상구 · 천재교과서 조수경 · 동아출판 · 비상교육 · 미래엔 · 지학사

단원 목차는 **아직 없다.** 교과서를 골라도 칩이 안 나오면 직접 적는다. 원장님이 쓰시는 교과서부터 목차를 채워 넣는다.

## 4 · 깊이와 결과물

| | 카드뉴스 | A4 | 슬라이드 |
|---|:--:|:--:|:--:|
| 간단 | 3장 | 1장 | 3장 |
| 보통 | 5장 | 2장 | 5장 |
| 자세히 | 8장 | 3장 | 8장 |

기출 적중을 켜면 각각 +1장.

**간단 3장**
1. 한눈에 — 문항 수 · 어려움 도넛 · 문항 띠
2. 문항 한눈표 — 번호 / 무엇을 물었나 / 어려움 *(새 장)*
3. 다음 준비 — 총평 한 줄

**보통 5장** — 지금과 같다 (한눈에 / 출제 구조 / 갈린 구간 / [기출 적중] / 다음 준비)

**자세히 8장** — 보통 다섯에 셋을 더한다
6. 어디서 가져왔나 — 출제원 여덟 갈래 비중 *(새 장)*
7. 문항 한눈표 — 번호 / 영역 / 무엇을 물었나 / 어려움 / 배점 / 출처 *(새 장)*
8. 총평 — 출제 경향 · 감점 요인 · 다음 준비 세 토막 *(새 장)*

**장수만 늘고 디자인은 같다.** 고등이라고 다른 모양을 쓰지 않는다.

깊이를 '간단'으로 두면 배점·영역·출처가 비어 있으므로 '출제 구조'·'갈린 구간' 장은 **만들지 않는다.** 칸이 비어서 못 만드는 것이지 일부러 빼는 것이 아니다.

## 8 · 지키는 것

전부터 지켜 온 것을 그대로 지킨다.

- 학생 이름을 **받지도 적지도 않는다** — 학교 시험지 분석이다
- 학부모께 가는 카드·슬라이드에 **지문·선택지 원문을 넣지 않는다**. 원문은 학원용 해설지에만
- 적중률은 **늘 분모를 달고** 나간다. `11/25` 로 적고 "100% 적중" 같은 말을 쓰지 않는다
- 학원 교재 사진은 **브라우저 밖으로 나가지 않는다**
