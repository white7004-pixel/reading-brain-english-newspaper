# 참고앱 분석 — 클럽하와이 '시험 분석' (이김수학)

2026-10-01 · 원장님이 주신 자료: 화면 녹화 171초(2644×1408) · **실제 리포트 PDF 8쪽**
(소래중 1학년 수학) · 설정 화면 사진 3장 · 학교 추가 화면 사진 1장.

**이 글은 짜임새만 본다.** 저쪽 문장·분류 이름·브랜드를 베끼지 않는다.
저쪽은 수학 학원용이고 우리는 과목이 여섯이다. 쓰임이 다른 곳은 그대로 적어 둔다.

## 1. 저쪽이 어떻게 도는가 — 네 단계

```
+ 학교 추가
  1 기본 정보   학교 이름 · 학년 · 과목 · 세부과목 · 출제 단원(칩 11개 중 고르기, 직접 추가 가능)
  2 시험지·문항  PDF 올리기 → AI 문항표 → 원장님이 확인
  3 분석 글     AI 가 쓴 글을 원장님이 읽고 고침
  4 리포트 발송  링크 복사 · 인쇄/PDF 저장
```

- 오른쪽 위에 **`AI 분석 남은 횟수 50회`**. 3단계로 넘어갈 때 1회가 깎인다
  (녹화에서 50 → 49). 단추에도 **"확인 완료 · 분석 글 만들기 (남은 횟수 1회 사용)"** 라고 적혀 있다
- 단계 머리글은 **눌러서 오갈 수 있다**. 끝난 단계는 ✓
- 각 단계에 **저장**이 따로 있다 (중간에 닫아도 남는다)

### 2단계 문항표 확인 — 우리와 가장 많이 다른 곳

| 칸 | 저쪽 | 우리 |
|---|---|---|
| 문항 번호 | **`1`…`19`, `논술형1`, `논술형2-1`, `논술형2-2`, `논술형2-3`, `논술형3`** | `no: int` — **못 담는다** |
| 배점 | 숫자 | 같다 |
| 유형 | 고르기 (개념형·계산형·활용형·추론형 — 수학) | `kind`(객관식·서술형) + `area` + `subtype` |
| 난이도 | **원장님이 고른다** (하·중하·중·중상·상 다섯 칸 라디오) | AI 가 매기고 원장님이 고친다 |
| 단원 | **여러 개 고를 수 있다** (칩, 1개가 기본) | `unit` 하나 |
| 대표 문항 | **원장님이 1~3개 체크** | 없다 (AI 가 `keyItems` 를 고른다) |

화면 위에 안내 셋이 늘 떠 있다 — ① 모든 문항의 난이도를 선택 ② 대표 문항을 1~3개 체크
③ 단원은 1개가 기본. 그리고 **`✓ 배점 합계 100점`** 칩이 붙어 있다.
못 채우면 단추가 꺼지고 빨간 글씨로 무엇이 빠졌는지 말한다.

### 3단계 분석 글

"학부모님이 그대로 읽는 글입니다. 끝까지 읽어 보시고, 고칠 곳이 있으면 아래 **분석 글 수정하기**를 눌러 주세요."
글 토막마다 **`리포트에서 보기`** 링크가 붙어 그 글이 리포트 어디에 들어가는지 보여 준다.

### 4단계 발송

리포트는 **웹 링크**다 — 위에 `이김수학 문의 : 02-898-3774` 와 `[링크 복사] [인쇄 · PDF로 저장]`.
좌우 화살표로 쪽을 넘기는 슬라이드 보기. 인쇄를 누르면 **머리글·바닥글 끄는 법**을 브라우저별로
알려 주는 안내창이 뜨고 "다음부터 이 안내를 보지 않기"가 있다.

## 2. 리포트 8쪽 — 실제 PDF

| 쪽 | 내용 |
|---|---|
| 1 | **표지** — `2026 2학기 중간고사` 알약, 로고 자리, `중학교 1학년 · 수학`, **학교명 + "중간고사 분석 리포트"**, 표지 설명 두 줄, 가로줄, **목차 01~06**, 맨 아래 `작성 / 학교 / 학년 / 과목` |
| 2 | **① 총평 및 학습전략** — 문단 셋(구성·변별·학습방향). 숫자는 굵게+강조색 |
| 3 | **② 문항별 상세 분석** — 위에 통계칩 셋(`출제 유형 4가지` `최고 배점 6점` `최다 출제 단원 …`) + 전 문항표(번호·배점·유형·난이도·단원) |
| 4 | **③ 출제 유형·난이도 분석** — 통계칩 셋 + 도넛(유형) + 막대(난이도) + **교차표(유형 × 난이도, 총계 줄·칸)** + 문단 |
| 5 | **④ 출제 유형별 상세 분석** — 유형별 **배점 분포** 100% 누적막대, 유형별 **난이도 분포** 100% 누적막대 + 문단 |
| 6 | **⑤ 대표 문항 분석** — 카드마다 `대표 문항 N` · `문항 번호 : 논술형2-1` · 문단 · 칩 넷(배점·난이도·유형·출제 단원) |
| 7 | **⑥ 출제 단원 분석** — 도넛(단원 비중) + 문단 + **단원별 유형 비중** 누적막대 |
| 8 | **뒷표지** — 알약·학교/학년/과목·로고·학원명·**원포인트 문구**·문의 전화 |

**쪽마다 통계칩 셋이 다르다**(그 쪽 주제에 맞는 숫자). 맨 아래 바닥글은
`이김수학 소래중 1학년 수학(중1) 중간고사 분석 리포트` + 쪽번호.

**섹션마다 AI 문단이 붙는다.** 표만 두지 않는다.

## 3. 우리가 가져올 것 · 가져오지 않을 것

### 가져온다 — 다섯은 넣었고 하나가 남았다 (2026-10-01)

| | 한 일 | 커밋 |
|---|---|---|
| ① 번호를 글자로 | `noText`·`noNum`·`byNoOrder`. 확인 표는 글자 입력, 고정 검사의 가짜 번호도 실제 표기로 | 87e9061 |
| ② 배점 합계 칩 | **이미 있었다** — `updateTotal` 이 "100점이 아닙니다"로 경고한다. 넣지 않음 | — |
| ③ 교차표 | `crossTab` → 영역 × 난이도, 둘째 장 | 87e9061 |
| ④ 표지·뒷표지 | 목차는 실제로 들어간 자리만. **기본은 꺼짐**(종이값은 원장님 몫) | 13aa194 |
| ⑤ 대표 문항 | 원장님이 확인 표에서 고름 → AI 에 못 박음. 카드+칩 넷, why 200자 | f955cd7 |
| ⑥ 단원 여러 개 | **안 한다 — 원장님이 지금처럼 하나만 적기로 정하셨다 (2026-10-01)** | — |


1. **문항 번호를 글자로** — `논술형2-1` 이 실제로 쓰인다. 우리 `no: int` 로는 못 담는다.
   미뤄 둔 일이었는데 **증거가 나왔으니 지금 한다.**
2. **배점 합계 칩** — 확인 표에 `✓ 배점 합계 100점`. AI 가 배점을 잘못 읽으면 바로 드러난다.
3. **교차표** — 우리는 영역·난이도를 따로만 보여 준다. **영역 × 난이도** 한 장이면
   "어느 영역에서 어렵게 냈나"가 바로 보인다. 숫자는 이미 다 있다.
4. **표지·뒷표지** — 학부모가 가장 먼저·마지막으로 보는 쪽이 우리에겐 없다.
   뒷표지에 학원 이름·한 줄 문구·전화.
5. **대표 문항** — 우리 `keyItems` 는 한 줄짜리다. 번호·배점·난이도·영역 칩과
   **왜 이 문항인가** 문단으로 키운다. 다만 **고르는 사람은 원장님**이다(저쪽과 같다).
6. ~~**단원 여러 개**~~ — 가져오지 않기로 정했다. 아래 "가져오지 않는다" 표로 옮겼다.

### 가져오지 않는다

| 저쪽 | 왜 안 하나 |
|---|---|
| 난이도를 원장님이 전부 고르게 | 24문항을 손으로 다 고르는 건 일이 많다. **AI 가 매기고 원장님이 고친다**(지금 그대로). 대신 **대표 문항만 원장님이 고른다** |
| 문제 조건을 리포트에 그대로 적기 (`점 A(a-1, 1/2a-2)`) | 수학은 몰라도 **영어는 지문·선택지가 저작물**이다. 시험지에 전재·복제 금지가 찍혀 있다. 우리는 학원용 해설에만 남긴다 |
| `AI 분석 남은 횟수` | 에듀냅 요금제가 정해지면 그때. 지금 지어내지 않는다 |
| 단원을 여러 개 고르게 | **원장님 결정 (2026-10-01): 지금처럼 `unit` 하나만 적는다.** 둘을 적으면 단원 비중의 합이 100%를 넘고, 어느 쪽으로 셀지 규칙이 하나 더 는다. 저쪽 리포트의 도넛도 58.3+41.7=100 이라 결국 대표 단원 하나로 센 것이다 |
| 유형을 개념형·계산형·활용형·추론형으로 | 수학 분류다. 우리는 과목 여섯이라 `area`+`subtype` 이 맞다. **수학 과목에 한해 참고값으로 둘 수는 있다 — 원장님 뜻을 듣고** |

### 우리가 더 가진 것 (버리지 않는다)

학생 개인 리포트 · 정사각 공유 카드 · **학원용 문항 해설** · 출처(교과서/부교재/외부/기출변형) ·
배점 눈금(표준·응용·고난도) · **우리 학원은 이렇게 대비했습니다** · 영어 세부유형.

## 4. 나중에 — 원장님 뜻을 물을 것

- **리포트 링크** (저쪽의 `링크 복사`). 지금 우리는 인쇄·PNG 뿐이다. 링크로 주려면
  저장할 자리가 필요하다(1단계 기출 은행과 같은 층).
- **인쇄 안내창** (머리글·바닥글 끄기). 작은 일이고 효과가 크다.
- **4단계 마법사**로 화면을 나눌지. 지금 우리는 한 화면에 쭉 이어져 있다.
