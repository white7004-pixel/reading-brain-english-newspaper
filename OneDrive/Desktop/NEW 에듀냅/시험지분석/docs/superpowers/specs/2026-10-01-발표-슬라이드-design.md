# 발표 슬라이드 (프리미엄 다크) 설계

2026-10-01 · 원장님 결정: **① 발표 슬라이드 한 벌로 만든다 ② 지문 원문은 넣지 않는다**

참고 자료: 원장님이 주신 PATHFINDER 영어학원 분석 슬라이드 3장
(상동고 고2 영어, 11장짜리 중 3/11 · 7/11 · 11/11).
**짜임새와 분위기만 본다.** 저쪽 문장·브랜드·문구를 베끼지 않는다.

---

## 1. 왜 만드는가

지금 우리 산출물은 **A4 인쇄용**과 **정사각 카드**뿐이다. 둘 다 좋지만,
설명회·상담에서 넘기며 말하는 자리에 쓸 것이 없다. 참고 자료가 바로 그 자리의 물건이다.

A4 리포트·정사각 카드·학원용 해설은 **그대로 둔다.** 슬라이드는 네 번째 산출물이다.

---

## 2. 저쪽에서 배운 것

| | 저쪽 | 우리가 할 것 |
|---|---|---|
| 분위기 | 짙은 남색 바탕 + 흰 카드 + 파랑 강조, 뒤에 희미한 영어 단어 | **학원 대표색에서 뽑은 짙은 바탕** + 흰 카드. 대표색이 강조색 |
| 장 구성 | 표지 → 난도 흐름 → 이유 3가지 → 적중 근거 → 변별력 문항 → 심층분석 → 총평 | 거의 그대로 (아래 3장) |
| 난도 흐름 | 문항 번호별 난이도 꺾은선. **앞은 파랑, 뒤는 빨강** | **우리 문항표로 바로 그린다.** 숫자가 이미 있다 |
| 총평 | 01~07 블록이 깔린 **대시보드 한 장** | 그대로. 블록은 우리 자료에 맞춘다 |
| 핵심 키워드 | 흰 카드에 체크리스트 넷 | AI 에게 받는다 (`keywords`) |
| 어려웠던 이유 | 조건 해석 / 개념 연결 / 풀이 구성 — 제목 + 설명 | AI 에게 받는다 (`whyHard`). **저쪽 세 이름을 쓰지 않는다** |
| 메시지 띠 | 큰 한 문장 | AI 에게 받는다 (`message`) |
| 지문 원문 | 영어 지문을 통째로 싣는다 | **싣지 않는다 (원장님 결정).** 시험지에 전재·복제 금지가 찍혀 있다 |

## 3. 장 구성

크기는 **1280 × 720 (16:9)**. `.page.slide` 로 `.page` 틀을 그대로 쓴다
(`--fit` 자동 줄이기·인쇄·PNG 내보내기가 이미 붙어 있다).

| # | 장 | 무엇으로 그리나 |
|---|---|---|
| 1 | **표지** | 학원 이름 · `${학년도} ${학교} ${학년} ${과목}` · 큰 제목 · 한 줄 총평(`overview`) · 핵심 키워드 넷(`keywords`) |
| 2 | **시험 한눈에** | 핵심 수치 넷(`kpi`) + 난이도 도넛 + 시험 정보 한 줄 |
| 3 | **난도 흐름** | `difficultyFlow(items)` 꺾은선. 뒤쪽 구간은 빨강 |
| 4 | **시험 구성** | 유형 · 배점 눈금 · 출처 · 영역별 (지금 A4 의 표를 그대로) |
| 5 | **영역 × 난이도** | `crossTable` |
| 6 | **이번 시험이 어려웠던 이유** | `whyHard` 셋 (제목 + 설명) |
| 7 | **우리 학원은 이렇게 대비했습니다** | `academy.prep` — **적어 두셨을 때만** |
| 8 | **대표 문항** | `keyItems` 요약 (번호·영역·난이도 칩) |
| 9~11 | **심층분석** | 대표 문항마다 한 장, **최대 3장**. `why` 문단 + 칩 넷. 지문은 없다 |
| 12 | **학습 방향** | `strategy` |
| 13 | **총평 대시보드** | 01~07 블록 한 장 (아래) |

보통 **11~12장**이 된다 (대비·심층분석 수에 따라).

### 총평 대시보드 블록

```
01 전체 난이도 및 출제 경향   도넛 + 한 줄
02 이번 시험의 특징            trends 에서 셋
03 대표 변별 문항              keyItems 번호·영역
04 난도 흐름                   꺾은선(작게)
05 어려웠던 이유               whyHard 제목만
06 학습 방향                   strategy
07 이번 시험이 주는 메시지     message 한 문장 + 학습 방향 카드들 + 학원 연락처
```

## 4. 새로 받을 AI 칸 셋

`SCHOOL_SCHEMA` 에 더한다. 지금 칸은 건드리지 않는다 (A4 가 쓰고 있다).

| 칸 | 모양 | 규칙 |
|---|---|---|
| `keywords` | `arr(str)` | 이번 시험을 한마디로 줄인 말 **넷**. 각 12자 이내 (예: "후반부 난도 상승") |
| `whyHard` | `arr(obj({ title, detail }))` | **셋**. title 10자 이내, detail 한 문장 60자 이내. 받은 통계로 말할 수 있는 것만 |
| `message` | `str` | 학부모에게 남기는 한 문장, 60자 이내. 공부 방향을 말하고 겁주지 않는다 |

`keyItems[].why` 는 이미 200자라 심층분석 장에 그대로 쓴다.

## 5. 새로 만드는 순수 함수 (public/lib.js)

```js
// 문항 번호 차례대로 난이도를 0~4 로. 뒤쪽 구간(hardFrom 이후)은 따로 표시한다.
difficultyFlow(items) → { points: [{x, y, no, difficulty, hard}], hardFrom }
// hardFrom: 난이도가 처음으로 중상 이상이 연달아 둘 나오는 자리 (없으면 null)

// 도넛 한 바퀴를 conic-gradient 로 그릴 조각들
donutSlices(rows) → [{ label, count, pct, from, to }]
```

둘 다 숫자만 다룬다. 그림은 `slides.js` 가 SVG·CSS 로 그린다.

## 6. 지키는 것

- 숫자는 **`examStats` 에서만** 온다. 슬라이드가 따로 세지 않는다
- 모든 글은 `esc` 를 지난다
- **학생 이름·점수는 슬라이드에 없다.** 학교 분석 자료다
- **지문·선택지 원문을 싣지 않는다** (원장님 결정, 2026-10-01)
- 적중률을 말할 때는 분모와 기준을 함께 — "100% 적중" 같은 말은 쓰지 않는다
- 저쪽 문장·분류 이름·브랜드를 베끼지 않는다
