# 교육과정 단원 자료 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 국어·영어·수학의 2022 개정 교육과정 영역·성취기준을 자료로 갖추고, 단원 후보와 세부 포인트로 AI 계약과 확인 표에 물린다.

**Architecture:** 자료는 `public/curriculum/{과목}.js` 에 `export default` 한 순수 데이터 모듈로 둔다 (브라우저와 Node 가 같은 파일을 import 한다 — 지금 `lib/rules.js` 가 `public/lib.js` 를 import 하는 것과 같은 방식). `public/curriculum.js` 는 그 자료를 읽어 `areasFor` · `unitsFor` · `pointsFor` 세 함수만 내주는 얇은 층이다. 화면과 프롬프트는 이 세 함수만 부른다.

**Tech Stack:** Node ≥20.11 ESM · `node --test` · 바닐라 JS · `curriculum-kr-secondary` MCP (자료 출처)

**Spec:** `docs/superpowers/specs/2026-10-01-교육과정-단원자료-design.md`

## Global Constraints

- 성취기준 문장은 MCP 가 준 `summary` 를 **그대로** 넣는다. 다듬지 않는다. (구분점 `⋅` 은 U+22C5 이며 `·` 로 바꾸지 않는다)
- 자료의 모든 줄은 출처가 있다. 교육과정에서 받은 것과 `[학원분류]` 를 한 파일에 섞지 않는다.
- 교과서 목차는 원장님이 목차를 주시기 전에는 채우지 않는다. `교과서: []` 로 둔다.
- **`area`(영역) 칸과 `SUBJECTS` 는 건드리지 않는다.** 확인 표의 select·AI enum·리포트 영역별 표가 모두 거기에 걸려 있다. 교육과정 영역은 `단원 후보`와 `세부 포인트`로만 쓴다.
- 학년을 모르면 지금 동작 그대로다. 자료가 없다고 리포트가 깨지지 않는다.
- 커밋은 이 폴더로 한정(`git add -- .`)하고 브랜치를 바꾸지 않는다. **푸시하지 않는다.**
- 고등 범위: 공통국어1·2, 화법과 언어, 독서와 작문, 문학 / 공통수학1·2, 대수, 미적분Ⅰ, 확률과 통계 / 공통영어1·2, 영어Ⅰ, 영어Ⅱ, 영어 독해와 작문.

```js
// 교육과정 자료를 학년으로 찾아 주는 얇은 층. 계산도 화면도 여기서 하지 않는다.
// 모르는 과목·학년이면 빈 배열을 준다 — 부르는 쪽이 지금 동작으로 물러설 수 있게.
import 국어 from './curriculum/국어.js';

const 자료 = { 국어 };
export const GRADES = ['중1', '중2', '중3', '고1', '고2', '고3'];

const 과정들 = (과목, 학년) => (자료[과목]?.과정 ?? []).filter((c) => c.학년.includes(학년));
const 모아서 = (list) => [...new Set(list)];

export const areasFor = (과목, 학년) => 모아서(과정들(과목, 학년).flatMap((c) => c.영역.map((d) => d.이름)));

// 단원 후보: 그 학년 교과서 목차가 있으면 그것, 없으면 교육과정 영역
export const unitsFor = (과목, 학년) => {
  const 목차 = (자료[과목]?.교과서 ?? []).filter((b) => b.학년 === 학년).flatMap((b) => b.단원);
  return 목차.length ? 모아서(목차) : areasFor(과목, 학년);
};

export const pointsFor = (과목, 학년) =>
  모아서(과정들(과목, 학년).flatMap((c) => c.영역.flatMap((d) => d.성취기준.map((s) => s.요약))));
```
