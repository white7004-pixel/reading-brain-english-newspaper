# 학원 설문지 만들기 — 설계 문서

작성일 2026-09-03

## 무엇을 만드는가

다른 학원 원장님들이 **문항을 골라 자기 학원 설문지를 만드는 도구**.
특정 학원 전용 설문지가 아니다. 학원명·사진·문항을 원장이 직접 채운다.

## 결정된 것

| 항목 | 결정 |
|---|---|
| 형태 | 웹 페이지 `index.html` 한 파일. 빌드 도구·라이브러리·서버 없음 |
| 결과물 | ① 인쇄용 A4 설문지 ② 설정이 담긴 설문 링크 — 둘 다 |
| 응답 저장 | 지금은 화면 표시 + CSV 내려받기. 구글 시트 연결은 주소 한 줄로 켜지는 자리만 마련 |
| 사진 | 3장. 인터넷 주소로 넣은 것은 링크에도 실림, 로컬 파일은 인쇄·미리보기용 |
| 브랜드 | 중립 색. 특정 학원 색·문구를 넣지 않는다 |

## 문항 창고 (7묶음)

원장이 준 종이 설문 3종과 관찰지 1종, 퇴원 방지 매뉴얼 1종을 재구성했다.

| 묶음 | 대상 | 문항 형식 |
|---|---|---|
| 담임 선생님 수업평가 | 학생 | 척도 18 + 서술 2 |
| 과목·선생님별 강의개선 | 학생 | 척도 10 + 서술 1, 선생님마다 반복 |
| 차량 | 학생 | 척도 3 + 서술 1 |
| 학원 전반 | 학생 | 척도 2 + 세줄 2 + 서술 1 |
| 학생 만족도 조사 | 학생 | 서술 7 + 선택(이유칸) 5 |
| 퇴원 징후 관찰지 | 교사 | 3단 징후 44 + 서술 2 |
| 학부모용 | 학부모 | 척도 11 + 서술 3 |

원본에서 고친 것과 그 이유는 아래 '판단 기록'에 남긴다.

## 문항 형식 다섯 가지

- `척도` — 5점 (전혀 그렇지 않다 ~ 매우 그렇다)
- `징후` — 3단 (해당 없음 / 조금 보임 / 분명히 보임), 0·1·2점
- `선택` — 보기 중 하나. `이유:true` 면 이유 적는 칸이 함께 나온다
- `서술` — 여러 줄 글
- `세줄` — 세 칸 (좋은 점 3가지 같은 문항)

## 구조

```
index.html
├─ 창고        문항 데이터. 이 목록만 고치면 화면이 따라간다
├─ 만들기 화면  5단계 폼 → 설정 객체
├─ 설문 화면    설정 → 문항 렌더 (미리보기 / 응답 / 인쇄 공용)
└─ 완료 화면    CSV 내려받기, 관찰지는 판정 표시
```

설정은 JSON → UTF-8 → base64url 로 인코딩해 `?s=` 뒤에 붙인다.
`?s=` 가 있으면 응답 모드, 없으면 만들기 모드로 열린다.
설정 객체는 짧은 키를 쓴다 (`n` 학원명, `t` 제목, `q` 문항 id, `s` 선생님, `u` 시트 주소 …).

소제는 묶음 첫 문항에만 적고, 시작할 때 뒤 문항으로 채운다.
채워 두지 않으면 첫 문항을 고르지 않았을 때 앞 소제가 잘못 따라붙는다.

## 관찰지 판정

비율로 재지 않는다. 44문항 대부분이 해당되지 않는 것이 정상이라, 비율로 재면
"이번 달까지만 하겠다" 한 줄이 2%로 묻힌다.

| 판정 | 기준 |
|---|---|
| 즉시 상담 | 중단 의사 항목이 '분명히 보임', 또는 '분명히 보임' 3개 이상 |
| 주의 | '분명히 보임' 1개 이상, 중단을 비치는 말, 또는 '조금 보임' 5개 이상 |
| 관찰 유지 | 그 밖 |

## 판단 기록 — 원본에서 고친 것

- **체벌 문항 삭제.** "우리들을 위한 매(처벌)은 적당하다" → 삭제.
  체벌은 법으로 금지돼 있어, 설문지에 이 문항이 있다는 사실만으로 문제가 된다.
  대신 "지적하실 때 마음이 상하지 않게 말해 주신다" 를 넣었다.
- **다른 학원 이름·내부 규정 제거.** 예시에 남아 있던 학원명, 특정 중학교 난이도 평가 금지 조항,
  재등록 불가 원칙, 부서장 조직 체계는 그 학원 사정이므로 옮기지 않았다.
- **척도 통일.** `매우좋음~매우나쁨` 과 서술문이 섞여 있던 것을 동의 척도 한 종류로 맞췄다.
  두 설문을 한 표에서 함께 볼 수 있게 된다.
- **선택지 정렬.** `딱 좋아요 / 조금 많아요 / 너무 많아요 / 거의 없어요` 처럼
  많음·적음이 뒤엉킨 보기를 한 줄로 정렬했다.
- **한 문항에 한 가지만.** "가끔 잘 파악하고 계신지 모르겠다" 처럼 두 뜻이 든 선택지를 갈랐다.
- **남을 평가하는 문항 분리.** "우리반 학생들의 수업태도에 문제가 있다" 는
  선생님 평가에 섞이면 점수가 흐려지므로 '수업 환경' 으로 뺐다.
- **역문항 유지.** 5점만 찍는 응답을 걸러내는 장치이므로 2문항 남기고 `역:true` 로 표시했다.
  집계할 때 뒤집어야 한다는 것을 내려받은 파일에 적어 둔다.
- **빈칸 수 축소.** 장점·단점 각 10칸은 실제로 1~2칸만 채워진다. 3칸으로 줄였다.
  칸을 줄이면 중요한 것부터 쓴다. "단점" 은 "이런 점은 고쳐지면 좋겠습니다" 로 바꿨다.
- **아이가 판단할 수 있는 말로.** "정말 나를 아끼고 생각해주신다" → 관찰할 수 있는 행동으로.
  "커뮤니티, 환경 등" → 친구 관계·자리·기다리는 시간처럼 실제 상황으로.

## 하지 않은 것

- 카드뉴스 내려받기 — 원장 판단으로 뺐다
- 응답 자동 집계·대시보드 — 시트 연결 후에 볼 일
- 학생 이름을 받을지는 설문마다 원장이 정한다. 학생이 선생님을 평가하는 설문은 무기명이 기본
