# 리딩브레인 웹설문 — 사용법

학부모·학생 설문 링크를 카톡으로 보내면, 답이 자동으로 모이고 결과 화면에서 바로 봅니다.
파일은 모두 `survey/` 폴더에 있습니다.

## 주소

배포: Vercel `white7004-3063s-projects` / 프로젝트 `readingbrain-survey`. 다시 올리기 = survey 폴더에서 check.js 를 뺀 파일 전부(html·js·png·jpg·vercel.json)를
`readingbrain-survey` 라는 폴더에 모아 `vercel deploy --prod --yes --scope white7004-3063s-projects`.

| 누구 | 주소 |
|---|---|
| 학부모 | `https://readingbrain-survey.vercel.app/parent` |
| 학생 | `https://readingbrain-survey.vercel.app/student` |
| 원장님 결과 | `https://readingbrain-survey.vercel.app/results` (비밀번호) |

- 학부모 설문은 같은 폰으로 두 번 낼 수 없습니다.
- 학생 설문은 학원 태블릿 한 대로 돌려 쓸 수 있게, 끝나면 **"다음 친구 시작"** 단추가 나옵니다.

## 처음 한 번만 하실 일

1. **Supabase** → Reading Brain 조직의 `reading-brain` 프로젝트(서울) → 왼쪽 `SQL Editor`
2. `supabase/001_academy_survey.sql` 내용을 통째로 붙여 넣고,
   **맨 아래 `여기에-비밀번호`** 를 원하는 결과 비밀번호로 바꾼 뒤 `Run`
3. 같은 프로젝트 → `Project Settings` → `API Keys` 에서 **anon public 키**를 복사해
   `survey/config.js` 의 `key` 칸에 붙여 넣기 (`url` 은 넣어 둠) (anon 키는 원래 공개용이라 페이지에 들어가도 괜찮습니다)

`config.js` 가 비어 있는 동안은 **연습 모드**입니다. 답이 그 기기 브라우저에만 저장되고, 결과 비밀번호는 `demo` 입니다.

## 비밀번호를 바꾸려면

SQL Editor 에서 아래 한 줄만 실행합니다.

```sql
update academy_survey.settings set password_hash = extensions.crypt('새-비밀번호', extensions.gen_salt('bf')) where id = 1;
```

## 문항을 고치려면

`survey/questions.js` 만 고칩니다. 설문 화면과 결과 화면이 함께 따라갑니다.
이미 받은 답과 짝이 맞도록 **각 문항의 `id` 는 바꾸지 마십시오.** 글자(`label`)는 바꿔도 됩니다.
고친 뒤 `node survey/check.js` 로 문항 수·이름을 확인합니다(문항 수를 바꾸면 이 파일 숫자도 같이 고칩니다).

## 강사 설문 넣기

`questions.js` 의 `// teacher:` 자리에 학생 설문과 같은 모양으로 `teacher: { ... }` 를 넣으면
`/teacher` 주소와 결과 화면의 "강사 설문" 탭이 생깁니다. 서버(SQL)는 이미 teacher 를 받게 되어 있습니다.

## 결과 화면

**전체 보기**(맨 처음 열리는 탭) — 설문마다 카드 하나:
총 응답·오늘 응답·평균, 날짜별 응답 막대(최근 14일), 확인 필요 의견 수,
**QR코드 · 링크 복사 · QR 안내문 인쇄**(로고·제목·큰 QR 이 들어간 A4 한 장). 교실·상담실에 붙여 두면 카메라로 찍어 바로 답합니다.


- 위 탭에서 학부모/학생 설문을 고르고, **결과 | 설문지** 칸을 바꿔 봅니다.
- **설문지** 칸: 학부모·학생 폰에 보이는 화면 그대로의 미리보기(눌러 봐도 저장되지 않음) + 섹션별 전체 문항·보기·필수 여부 + 링크·QR.
- 학년·커리큘럼으로 걸러 볼 수 있습니다 (커리큘럼은 여러 개 고른 답을 고른 반마다 셉니다).
- 학생 설문의 "공부 말고 불편한 상황" 문항에 글이 있으면 맨 위 노란 칸 **"확인이 필요한 의견"** 에 따로 뜹니다.
- `엑셀(CSV) 받기` — 5점 문항은 숫자(5=매우 만족 / 매우 그렇다)로 내려옵니다.
