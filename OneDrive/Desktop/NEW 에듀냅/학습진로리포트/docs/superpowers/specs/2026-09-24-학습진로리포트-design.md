# 에듀냅 학습·진로 성향 리포트 — 설계서

작성 2026-09-24 · 폴더 `Desktop\NEW 에듀냅\학습진로리포트\`
참고 사례: 크몽 "사주 기반 학습 진로 성향 분석 PDF 리포트"(eunicepicks, 39,000원, 13~17쪽, 6개 섹션) — 형식만 참고, 문장·이미지는 가져오지 않는다.

## 0. 한 줄

원장님이 학생의 **생년월일시·MBTI·혈액형**과 **학년·학교 유형·학업 상황·부모 고민**을 넣으면,
사주·별자리 계산 결과를 바탕으로 AI가 **학습 성향·학교 환경·진로 방향·부모 코칭** 리포트(A4 6~8쪽)와
**원장님 상담 메모** 1쪽을 쓴다. 학원 이름·로고가 들어간 채로 인쇄(PDF)한다.

## 1. 정한 것 (원장님 결정, 2026-09-24)

| 항목 | 결정 |
|---|---|
| 쓰는 곳 | 에듀냅 카탈로그의 도구 하나. 원장님이 **학부모 상담 도구**로 쓴다 (mycode.ai.kr 에서도 팔 수 있게 API는 열어 둠 — 이번엔 안 만듦) |
| 만드는 방식 | **A안**: `시험지분석`과 같은 틀의 독립 앱 (HTML/JS 화면 + Vercel `api/*.js` + Claude). 사주 계산은 MYCODE 엣지 함수를 부른다 |
| 전달 | **즉시 자동**. 신청 → 바로 화면 → 인쇄/PDF. 검수·이메일 발송 없음 |
| 데이터 층 | 사주(만세력) + 서양 별자리 + MBTI + 혈액형 네 겹. 점수·유형 판정은 **MYCODE 규칙 코드를 그대로 옮겨** 계산하고, 글은 AI가 쓴다 |
| 학원 정보 | 에듀냅 안에서는 로그인한 학원 정보. 시험판은 접힌 칸에 한 번 저장 (`localStorage`, 시험지분석과 동일) |
| 저장 | 서버 저장 없음. 학생 정보는 AI 호출에만 쓰고 로그에 남기지 않는다 |
| 문구 원칙 | "합격·등급·대학을 보장·단정하지 않는다", "이해를 돕는 참고 자료" 를 첫 장에 고정. 영재 판정·IQ 추정 표현 금지 |

## 2. 화면 흐름 (한 페이지 `public/index.html`)

1. **STEP 01 학생 정보** — 아래 3번 입력 항목. 이름은 성+OO 또는 이니셜만 (전체 이름이면 안내 문구, 시험지분석과 같은 규칙).
2. **STEP 02 계산 확인** — 사주 여덟 글자·오행 분포·일간·띠·별자리·학습자 유형·재능 영역 점수를 표로 보여 준다. 태어난 시각을 모르면 시주 없이 계산했다고 표시. 여기서 "리포트 쓰기"를 누른다.
3. **STEP 03 리포트** — A4 틀에 7개 섹션. 글자는 화면에서 바로 고칠 수 있다 (`contenteditable`). 마지막 장 "원장님 상담 메모"는 인쇄 전 체크박스로 뺄 수 있다 (학부모 배포본).
4. **인쇄/PDF** — 브라우저 인쇄(`@page A4`). 장마다 PNG 저장(카톡용, `html-to-image`, 시험지분석과 동일).

## 4. 계산 층 (결정적 — AI가 아니라 코드가 정한다)

### 4.1 사주
`api/saju.js` → MYCODE Supabase 엣지 함수 `calculate-manseryeok` (로그인 불필요, `verify_jwt=false`) 를 서버에서 부른다.
요청 `{birthYear, birthMonth, birthDay, birthHour?, isLunar, isLeapMonth}` → 응답 `{year, month, day, hour?, summary:{elements, dominantElement, yin, yang}}`.
Vercel 환경변수 `MYCODE_SUPABASE_URL`, `MYCODE_SUPABASE_ANON_KEY` (MYCODE 프런트에 이미 공개된 anon 키).
실패하면 "생년월일을 확인해 주세요" (UserError). 서버 없이 화면에서 직접 부르지 않는다 — 키와 주소를 한 곳에 둔다.

### 4.2 MYCODE 규칙 코드 이식
MYCODE `src/lib/` 의 네 파일을 **한 번 트랜스파일해서** `lib/mycode/` 에 JS로 둔다 (원본 경로와 날짜를 파일 머리에 적는다).

| 원본 | 무엇을 주나 |
|---|---|
| `childAstrology.ts` | 양력 월일 → 별자리·원소·특성·학습 포인트·주의점·재능 보정치 |
| `childGiftedness.ts` | 오행 분포 + MBTI + 혈액형 + 별자리 보정 → 재능 영역 6개 점수(언어·수리·공간·대인·실행·집중), 학습자 유형, 강점 과목, 집중 시간대 |
| `childAdvanced.ts` | 기본 사주 해설, 영재성 지수, 진로 적성(계열·직업군), 해외 적합도 |
| `childLifeSaju.ts` | 성격·건강·대인·재물·주의 시기 등 생활 해설 |

이식 방법: `npx esbuild --format=esm` 으로 타입만 벗긴다. 로직은 손대지 않는다. MYCODE 쪽이 바뀌면 같은 명령으로 다시 뽑는다 (`scripts/import-mycode.js`, 원본 경로는 환경변수).
`familySaju.ts` 의 `FamilySajuSummary` 모양은 4.1 응답을 같은 모양으로 맞추는 어댑터 `lib/mycode/adapt.js` 가 만든다.

### 4.3 계산 결과 묶음 (`facts`)
AI 에게 주는 것은 원문 생년월일이 아니라 이 묶음이다.
```
{ pillars, elements, dominantElement, yinYang, animal, dayStem,
  astro: {sign, element, modality, trait, study, caution},
  giftedness: {domains[{key,label,score}], learnerType, learnerDesc, strongSubjects, focusTime, headline},
  advanced: {basics, giftedIndex, career:{tracks, jobs}, overseas},
  life: childLifeReading 결과(성격·건강·대인·재물·주의 시기 문장),
  mbti, bloodType, grade, schoolType, situation, concern, traits }
```

## 5. AI 층 (`lib/rules.js` → `api/report.js`, 시험지분석의 `askJson` 재사용)

### 5.1 부르기
Claude 한 번 (`claude-opus-5`, JSON 스키마 출력, 시스템 프롬프트 캐시, 안전 분류기 대체 모델). `max_tokens` 12,000. 입력은 4.3 `facts` 만.

### 5.2 섹션 7개 (스키마 고정)

| # | 섹션 | 길이 | 담을 것 |
|---|---|---|---|
| 1 | 핵심 기질 요약 | 300~400자 + 한 줄 표어 | 일간·오행·별자리·MBTI가 **같은 방향을 가리키는 것 2~3개**, 엇갈리는 것 1개 |
| 2 | 학습 성향 | 600~800자 | 자기주도형/관리형, 강점 과목(암기·이해·분석 중 어디), 집중 시간대, 잘 맞는 학습 방식(인강·학원·소수정예·과외), 칭찬형/경쟁형 동기 |
| 3 | 학교 환경 적합도 | 표 + 300자 | 일반고 / 외고·국제고 / 자사고 / 영재고·과학고 / 예체능 — 각각 적합·보통·비추천과 한 줄 이유. **초등·중1~2는 "고교 선택은 아직 이르다"로 톤을 낮춘다** |
| 4 | 진로 방향·전형 적합도 | 500~700자 | 문·이과·예체능 결, 수시(학생부)·정시(수능) 어느 쪽이 성향에 맞는지, 학년에 맞는 다음 1년 할 일 3개 |
| 5 | 직업 방향성 | 400~600자 | 계열 2~3개, 직업군 예시 4~6개(계산 층 `career` 를 벗어나지 않는다), "지금 성적이 아니라 기질 기준"임을 명시 |
| 6 | 부모 코칭 가이드 | 500~700자 | 이 아이에게 통하는 말 3개, 피할 말 3개, 갈등이 잦은 장면과 대처, 부모님 고민에 대한 직접 답 |
| 7 | 원장님 상담 메모 | 300~400자 | 학부모께 이렇게 말씀하시라는 상담 포인트 3개, 우리 학원에서의 배치·수업 방식 제안, 다음 상담 때 확인할 것 |

### 5.3 글쓰기 규칙 (시스템 프롬프트)
- 학부모가 읽는다. 명리 용어(십신·용신 등)는 쓰지 않거나 괄호로 풀어 쓴다. 오행은 "나무·불·흙·쇠·물의 기운"으로.
- **계산 층이 준 사실만** 쓴다. 점수·유형·직업군을 새로 만들지 않는다.
- 단정 금지: "~한 편입니다", "~할 가능성이 큽니다". 합격·등급·대학·IQ·영재 판정 표현 금지. "운이 좋다/나쁘다" 금지.
- 부모님 고민·아이 특징이 있으면 1·2·6번 섹션에서 **그 문장을 직접 받아** 답한다.
- 학년별 톤: 초등은 습관·환경 중심, 중등은 학습 방식·고교 방향, 고등은 전형·1년 계획.
- 존댓말, 한 문단 3~4문장, 섹션마다 소제목 2~3개.

### 5.4 자신 없는 곳
스키마에 `unsure: string[]` — 시각을 몰라 시주가 없거나 MBTI·혈액형이 비어 판단이 약한 항목을 적는다. 화면에서 금색 표시 (시험지분석과 같은 관례).

## 6. 리포트 틀 (`public/report.css`, A4)

- 1장 표지: 학원 로고·이름, "OO 학생 학습·진로 성향 리포트", 작성일, **면책 문구**(1장 문구 원칙), 네 겹 데이터 그림(오행 분포 막대 + 재능 6각 점수 — SVG를 코드로 그린다).
- 2장 계산 요약: 사주 표(년·월·일·시), 오행 개수, 별자리, MBTI, 혈액형, 학습자 유형.
- 3~7장: 섹션 1~6. 3번 섹션은 표.
- 마지막 장: 섹션 7 (체크 해제 시 인쇄에서 빠짐, `.hidden-print`).
- 색은 학원 대표 색 하나 + 검정. 글꼴 Hahmlet(제목)·본문 시스템 글꼴. 이모지 없음.

## 7. 파일 구조

```
학습진로리포트/
  public/ index.html  app.js  style.css  report.css  lib.js(선택지 상수·이름 검사)
  api/    saju.js(만세력 호출 + 규칙 계산 → facts)  report.js(AI)
  lib/    http.js  claude.js  rules.js(스키마·프롬프트)  mycode/(이식 JS 4개 + adapt.js)
  scripts/ local.js  import-mycode.js
  test/   rules.test.js(스키마·프롬프트 금칙어)  adapt.test.js(응답→요약 변환)  saju.test.js(고정 생년월일 → 기대 오행)
  docs/superpowers/specs, plans
  package.json  vercel.json(functions maxDuration 300)
```
`lib/http.js`, `lib/claude.js`, `scripts/local.js` 는 시험지분석에서 복사한다 (같은 것을 두 번 만들지 않기 위해 나중에 공용 패키지로 뺄 수 있다 — 이번엔 안 함).

## 9. 테스트 (`node --test`)

- `adapt.test.js`: 엣지 함수 응답 예시 → `FamilySajuSummary` 모양, 시각 없을 때 `hour: null`.
