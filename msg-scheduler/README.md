# 예약 메시지 발송기 (msg-scheduler)

정해진 시간에 **카카오톡 · 문자(SMS/LMS) · 카카오워크 · 슬랙** 채팅창으로 메시지를 자동 발송하는 앱입니다.

만들게 된 이유는 이겁니다 — **새벽에 문득 생각났는데, 지금 보내면 상대를 깨우고, 아침이 되면 잊어버립니다.**
그래서 홈 화면은 "지금 적어두고 아침에 보내기"를 세 번의 터치로 끝내도록 만들었습니다.

```
①  적는다            ②  [내일 오전 9시]      ③  [김선생님]
   ↓                     탭 한 번               탭 한 번
   "교재 주문 확인 부탁"                          ↓
                                          [8/19(수) 09:00에 예약하기]
```

```
┌─ 웹 관리 화면 ─┐      ┌─ 스케줄러 ─┐      ┌─ 채널 어댑터 ─┐
│ 예약 등록/수정  │ ───▶ │ 20초마다   │ ───▶ │ 슬랙 / 카카오톡  │
│ 채널 설정      │      │ 시각 확인  │      │ 카카오워크 / 문자 │
│ 발송 기록      │ ◀─── │ 재시도·복구 │ ◀─── │ 기타 웹훅       │
└──────────────┘      └───────────┘      └────────────────┘
```

## 바로 실행하기

의존성 패키지가 없습니다. Node.js 20.6 이상만 있으면 됩니다.

```bash
cd msg-scheduler
cp .env.example .env      # 필요한 값만 채우세요 (나중에 화면에서 입력해도 됩니다)
npm start                 # http://localhost:3000
```

브라우저에서 `http://localhost:3000` 을 열고 **채널 설정 → 새 예약** 순서로 진행하면 됩니다.

```bash
npm test                  # 단위 테스트 (31개)
npm run dev               # 파일 변경 시 자동 재시작
```

## 빠른 예약 — 새벽에 생각났을 때

홈 화면(빠른 예약)은 이름 짓기도, 반복 주기 고르기도 없이 **메시지 → 시간 → 받는 곳** 세 단계뿐입니다.

- **시간은 버튼으로**: `1시간 뒤` `오늘 오전 9시` `내일 오전 9시` `내일 오후 1시` `다음 월요일 오전 9시`.
  이미 지난 후보는 목록에서 자동으로 빠지므로, 새벽 3시에는 **몇 시간 뒤인 "오늘 오전 9시"** 가 맨 앞에 나옵니다.
  확인 버튼에 `8/19(수) 09:00에 예약하기` 처럼 실제 시각이 찍혀서, 졸린 눈으로도 잘못 누를 일이 없습니다.
- **심야 발송 경고**: 발송 시각이 밤 10시~오전 7시에 걸리면
  `🌙 8/19(수) 03:30은 한밤중이라 상대방을 깨울 수 있습니다` 안내와 함께 **[아침 9시에 보내기]** 버튼을 띄웁니다.
- **받는 곳(주소록)**: `김선생님(문자)` `학원 공지방(슬랙)` 처럼 한 번만 등록해두면 다음부터는 탭 한 번입니다.
  마지막에 보낸 곳은 다음에 열 때 미리 선택되어 있습니다.
- **자동 임시저장**: 적다가 잠들어도, 앱을 닫아도 내용이 남아 있습니다. 예약을 마치면 지워집니다.
- **이름 자동 생성**: 예약 이름은 메시지 첫 줄에서 알아서 만듭니다.
- **홈 화면에 추가**: 폰 브라우저의 "홈 화면에 추가"를 하면 앱처럼 전체 화면으로 열립니다.

기준 시각(오전/점심/저녁이 몇 시인지)과 심야 구간은 **설정** 탭에서 바꿀 수 있습니다.

## 화면

폰에서 한 손으로 쓰는 것을 기준으로 만들었습니다.

- **하단 탭바**: 엄지가 닿는 자리에 메뉴를 뒀습니다. 넓은 화면에서는 상단 탭으로 바뀝니다.
- **다크 모드**: 기기 설정을 그대로 따라갑니다. 새벽에 눈이 부시지 않습니다.
- **바텀시트**: 받는 곳 추가는 아래에서 올라오는 시트로 열리고, 배경을 누르거나 ESC로 닫힙니다.
- **큰 확인 버튼**: 화면 폭 전체를 쓰는 버튼에 실제 발송 시각이 찍힙니다.
- **홈 화면 설치(PWA)**: 폰 브라우저의 "홈 화면에 추가"로 앱처럼 전체 화면 실행이 됩니다.
- 접근성: 시스템의 "동작 줄이기" 설정을 켜두면 애니메이션이 꺼집니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 빠른 예약 | 메시지 + 시간 버튼 + 받는 곳 탭 한 번으로 1회 예약 |
| 받는 곳 | 자주 보내는 사람·대화방을 이름으로 저장, 최근 사용처 자동 선택 |
| 심야 경고 | 밤 10시~오전 7시 발송이면 아침으로 미루는 대안 제시 |
| 반복 예약 | 매일 / 평일 / 매주 특정 요일 / 매월 특정 일 / 매시간, 또는 cron 직접 입력 |
| 1회 예약 | 특정 날짜·시각에 한 번만 발송하고 자동으로 꺼짐 |
| 다중 채널 | 예약 하나를 여러 채널에 동시 발송 (예: 슬랙 + 문자) |
| 치환자 | `{{date}}` `{{time}}` `{{datetime}}` `{{weekday}}` 를 발송 시점 값으로 채움 |
| 자동 재시도 | 실패 시 1분 → 5분 → 15분 간격으로 3회 재시도 |
| 누락 복구 | 서버가 꺼져 있던 동안 지나간 예약을 최대 2시간까지 거슬러 올라가 발송 |
| 중복 방지 | 같은 분에 두 번 나가지 않도록 분 단위 키로 차단 |
| 타임존 | 모든 시각을 `Asia/Seoul` 기준으로 계산 (서머타임 지역도 벽시계 기준) |
| 발송 기록 | 성공/실패/재시도 이력과 실제 전송된 본문을 화면에서 확인 |
| 모바일 | 새벽에 폰으로 쓰는 걸 전제로 만든 화면. PWA로 홈 화면 설치 가능 |

## 채널별 준비물

### 슬랙 — 가장 간단합니다
1. https://api.slack.com/apps 에서 앱 생성 → **Incoming Webhooks** 활성화
2. 보낼 채널을 지정해 Webhook URL 발급
3. 채널 설정 → 슬랙 → `Incoming Webhook URL` 붙여넣기 → 저장 → **테스트 발송**

여러 채널로 나눠 보내려면 `전송 방식`을 `bot`으로 바꾸고 봇 토큰(`xoxb-`, `chat:write` 권한)을 넣은 뒤
예약마다 채널(`#공지` 또는 `C0123ABCD`)을 지정하세요. 봇을 해당 채널에 초대해야 합니다.

### 카카오워크
1. 카카오워크 개발자센터에서 봇 생성 → **App Key** 발급
2. 채널 설정 → 카카오워크 → App Key 입력
3. 받는 사람은 **이메일** 또는 **대화방 ID** 로 지정 (이메일이 편합니다)

### 문자(SMS/LMS)
- **국내**: [솔라피](https://solapi.com) — API Key/Secret 발급 + **발신번호 사전등록** 필수
- **해외**: 트윌리오 — Account SID / Auth Token / 발신번호

90바이트(한글 45자)를 넘으면 자동으로 LMS로 전환됩니다. 여러 명에게 보내려면 번호를 콤마로 구분하세요.

### 카카오톡 ⚠️ 정책 제약이 있습니다
카카오는 **임의의 상대에게 자유롭게 메시지를 보내는 API를 제공하지 않습니다.** 가능한 것은 두 가지입니다.

| 방식 | 가능 여부 | 필요 조건 |
| --- | --- | --- |
| **나에게 보내기** (메모) | 바로 사용 가능 | 카카오 로그인 + `talk_message` 동의항목 |
| **친구에게 보내기** | 조건부 | 위 + `friends` 동의항목 + 앱 심사, 상대가 내 앱에 가입·동의한 친구여야 함 |
| 일반 친구/단톡방에 자유 발송 | **불가** | API 자체가 없음 |

불특정 다수(학부모·고객)에게 카카오톡으로 보내야 한다면 **알림톡/친구톡(카카오 비즈메시지)** 을 대행사를 통해
계약하거나, 이 앱에서는 **문자(SMS/LMS)** 채널을 쓰는 것이 현실적인 방법입니다.

설정 방법:
1. [카카오 개발자센터](https://developers.kakao.com)에서 앱 생성
2. 카카오 로그인 활성화 → Redirect URI에 `http://localhost:3000/oauth/kakao/callback` 등록
3. 동의항목에서 **카카오톡 메시지 전송(talk_message)** 켜기
4. 채널 설정 → 카카오톡 → REST API 키 / Redirect URI 입력 → **설정 저장**
5. **[카카오 인증하기]** 클릭 → 로그인하면 토큰이 자동 저장됩니다 (이후 refresh token으로 자동 갱신)
6. 예약의 대상에서 `memo`(나에게) 또는 `friends`(친구 UUID 지정) 선택

카카오톡 텍스트 템플릿은 200자 제한이라, 긴 메시지는 자동으로 여러 건으로 나눠 `(1/3)` 표기와 함께 보냅니다.

### 기타 웹훅
디스코드, MS Teams, 사내 알림 서버 등 URL 하나로 받는 곳이면 무엇이든 됩니다.
본문 템플릿의 `{{message}}` 자리에 메시지가 들어갑니다.

- 디스코드: `{"content":"{{message}}"}`
- MS Teams: `{"text":"{{message}}"}`

## 예약 시각 지정

간편 설정(매일/평일/매주/매월/매시간)으로 대부분 해결되고, 더 복잡한 조건은 cron 식을 직접 씁니다.

```
분 시 일 월 요일        요일: 0=일 … 6=토

0 8 * * *          매일 08:00
30 9 * * 1-5       평일 09:30
0 19 * * 2,4       매주 화·목 19:00
0 10 25 * *        매월 25일 10:00
*/30 9-18 * * 1-5  평일 09~18시 30분마다
```

[발송 예정 시각 확인] 버튼으로 앞으로 5번의 발송 시각을 미리 볼 수 있습니다.

## 배포와 운영

24시간 켜져 있는 곳에서 돌려야 예약이 제때 나갑니다. 노트북에서 실행하면 덮는 순간 멈춥니다.
새벽에 적어둔 메시지가 아침에 나가야 하므로, 이 부분이 특히 중요합니다.

**systemd (리눅스 서버)**

```ini
# /etc/systemd/system/msg-scheduler.service
[Unit]
Description=예약 메시지 발송기
After=network.target

[Service]
WorkingDirectory=/opt/msg-scheduler
ExecStart=/usr/bin/node server.js
Restart=always
EnvironmentFile=/opt/msg-scheduler/.env

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now msg-scheduler
```

**보안**: `.env`의 `APP_PASSWORD`를 설정하면 관리 화면 접속 시 비밀번호를 묻습니다.
외부에 공개할 때는 반드시 설정하고, HTTPS 리버스 프록시(nginx, Caddy) 뒤에 두세요.
카카오 Redirect URI도 실제 도메인으로 바꿔 등록해야 합니다.

**데이터**: 예약·설정·기록은 `data/db.json` 한 파일에 저장됩니다. 이 파일만 백업하면 됩니다.
API 키가 평문으로 들어 있으므로 파일 권한(`chmod 600`)에 유의하고 git에 올리지 마세요(`.gitignore`에 이미 포함).

## 구조

```
msg-scheduler/
├── server.js              HTTP 서버 + REST API + 카카오 OAuth 콜백
├── src/
│   ├── scheduler.js       20초 주기 실행기 (재시도·누락 복구·중복 방지)
│   ├── quick.js           빠른 예약 시각 계산 (프리셋·심야 판정·아침 대안)
│   ├── cron.js            5필드 cron 파서 / 간편설정 변환 / 한국어 설명
│   ├── time.js            타임존 변환 (KST 벽시계 ↔ UTC)
│   ├── store.js           JSON 파일 저장소 (원자적 쓰기)
│   ├── env.js             .env 파싱 및 환경변수 → 채널 설정 주입
│   └── channels/          채널 어댑터 (slack, kakaotalk, kakaowork, sms, webhook)
├── public/                관리 화면 (빌드 도구 없는 순수 HTML/CSS/JS)
└── test/run-tests.js      단위 테스트
```

**채널 추가**는 `src/channels/` 에 `meta`와 `send()`를 내보내는 파일을 만들고
`src/channels/index.js` 에 등록하면 화면과 API에 자동으로 나타납니다.

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/bootstrap` | 화면 초기 데이터(설정·예약·주소록·시각 후보) 한 번에 |
| GET | `/api/quick/presets` | 지금 고를 수 있는 발송 시각 후보 (지난 건 제외) |
| POST | `/api/quick/check` | 고른 시각이 심야인지 확인하고 아침 대안 제시 |
| POST | `/api/quick` | 빠른 예약 등록 (메시지 + 시각 + 받는 곳) |
| GET/POST | `/api/recipients` | 받는 곳 조회 / 등록 |
| PUT/DELETE | `/api/recipients/:id` | 받는 곳 수정 / 삭제 |
| GET/POST | `/api/jobs` | 예약 목록 조회 / 생성 |
| PUT/DELETE | `/api/jobs/:id` | 예약 수정 / 삭제 |
| POST | `/api/jobs/:id/run` | 지금 즉시 발송 |
| POST | `/api/jobs/:id/toggle` | 켜기/끄기 |
| GET/PUT | `/api/settings` | 타임존·채널 설정 (비밀값은 마스킹되어 내려감) |
| POST | `/api/channels/:key/test` | 채널 연결 테스트 발송 |
| GET/DELETE | `/api/logs` | 발송 기록 조회 / 비우기 |
| POST | `/api/cron/preview` | cron 해석 + 다음 5회 발송 시각 |
