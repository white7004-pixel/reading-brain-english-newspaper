# 시작하기 — 10분 안에 첫 예약까지

개발 지식 없이 따라 할 수 있게 적었습니다. 순서대로만 하시면 됩니다.

## 1단계. 컴퓨터에 준비 (한 번만)

1. **Node.js 설치**: https://nodejs.org/ko 에서 **LTS(왼쪽 초록 버튼)** 를 받아 설치합니다.
   전부 "다음"만 눌러도 됩니다.
2. **이 프로그램 내려받기**: GitHub 저장소에서 `Code → Download ZIP` 을 눌러 받고,
   압축을 풀어 `msg-scheduler` 폴더를 바탕화면 등 편한 곳에 둡니다.

## 2단계. 실행

- **윈도우**: `msg-scheduler` 폴더 안의 **`start-windows.bat`** 를 더블클릭
- **맥**: 터미널에서 `msg-scheduler` 폴더로 이동 후 `./start.sh`

잠시 후 브라우저가 자동으로 열리며 앱이 나타납니다. (안 열리면 주소창에 `localhost:3000`)

> ⚠️ **검은 창(터미널)을 닫으면 예약 발송이 멈춥니다.** 최소화만 해두세요.
> 예약이 제때 나가려면 이 컴퓨터가 켜져 있어야 합니다.

## 3단계. 카카오워크 연결 (직원·강사에게 자동 발송)

여기는 **원장님만 할 수 있는 부분**입니다 (관리자 권한 필요).

1. 카카오워크 **관리자 페이지**(워크스페이스 관리) 접속
2. **봇 관리**에서 봇 추가 — 이름은 자유 (예: "리딩브레인 알리미")
3. 발급된 **App Key**를 복사
4. 앱의 **설정 탭 → 카카오워크** 에 App Key 붙여넣기 → **설정 저장**
5. **테스트 발송**을 눌러 받는 사람 이메일(워크스페이스 가입 이메일)로 확인

도착하면 연결 끝입니다. 이후 **받는 곳 추가**로 "김선생님(카카오워크)"처럼
등록해두면 예약할 때 탭 한 번으로 선택됩니다.

## 4단계. 첫 예약

1. **빠른 예약** 탭에서 보낼 내용 입력
2. 시간 버튼 선택 (예: **내일 오전 9시**)
3. 받는 곳 선택 → **예약하기**

끝. 정해진 시각에 자동으로 나갑니다. **예약 목록** 탭에서 확인·수정·중지할 수 있습니다.

## 다른 채널도 쓰려면

| 채널 | 준비물 | 소요 |
| --- | --- | --- |
| 슬랙 | Incoming Webhook URL | 5분 |
| 텔레그램 | @BotFather 봇 토큰 | 5분 |
| 문자(SMS) | 솔라피 가입 + 발신번호 등록 | 하루 (번호 심사) |
| LINE | Messaging API 채널 | 10분 |
| 카카오톡(나에게) | 개발자센터 앱 + 카카오 인증 | 15분 |

자세한 방법은 `README.md`의 "채널별 준비물"에 있습니다.

## 폰에서도 쓰려면

같은 와이파이라면 바로 됩니다:

1. 서버 켠 컴퓨터에서 윈도우는 `cmd` → `ipconfig`, 맥은 시스템 설정 → 네트워크에서
   **IPv4 주소** 확인 (예: `192.168.0.10`)
2. 폰 브라우저에서 `http://192.168.0.10:3000` 접속
3. 공유(사파리) 또는 메뉴(크롬) → **홈 화면에 추가** → 앱처럼 사용

밖에서도(외출 중, LTE) 쓰려면 클라우드 서버나 도메인이 필요합니다 — `README.md`의
"배포와 운영"을 참고하시거나, 그 단계가 되면 도움을 요청하세요.

## 자주 묻는 것

- **컴퓨터를 꺼두면?** 그동안 예약은 못 나갑니다. 다시 켜면 2시간 이내에 놓친
  예약은 자동으로 보충 발송되고, 그보다 오래된 것은 "발송 누락"으로 기록만 남습니다.
- **데이터는 어디에?** `msg-scheduler/data/db.json` 파일 하나입니다. 이 파일만
  백업하면 됩니다.
- **비밀번호를 걸고 싶으면?** `.env.example`을 복사해 `.env`로 만들고
  `APP_PASSWORD=원하는비밀번호` 한 줄을 넣고 재시작하세요.
