# 몽글 펫 퀘스트 리디자인 설계

## 목표

몽글을 시작이 어려운 ADHD 성인을 위한 펫 성장형 생산성 앱으로 재구성한다. 사용자는 실제 할 일을 작은 퀘스트로 수행하고, 완료 직후 펫과 방이 성장하는 보상을 받는다. 앱은 죄책감이나 처벌 대신 작은 시작, 즉각적인 긍정 반응, 수집과 개인화를 통해 재방문 동기를 만든다.

## 제품 원칙

- 관리보다 시작을 우선한다. 홈에서 가장 중요한 행동은 `3분 시작`이다.
- 실패를 처벌하지 않는다. 연속 기록이 끊겨도 펫이 아프거나 퇴화하지 않는다.
- 보상은 즉각적이되 업무 흐름을 끊지 않는다. 완료 반응은 1~2초 안에 건너뛸 수 있다.
- 핵심 생산성 기능은 무료이고 광고가 없다.
- 할 일, 집중, 보상 기록은 오프라인에서 동작하는 로컬 우선 구조를 유지한다.
- 귀여운 시각 언어를 사용하되 정보 계층과 조작 방식은 성인용 유료 앱 수준으로 정돈한다.

## 핵심 사용 흐름

1. 사용자가 홈의 빠른 입력란에 할 일을 추가한다.
2. 앱이 에너지, 우선순위, 예상 시간을 기준으로 지금 할 퀘스트 하나를 추천한다.
3. 사용자가 `3분 시작`을 누르면 집중 세션이 시작된다.
4. 사용자가 퀘스트를 완료하면 코인, 경험치, 먹이를 한 번만 받는다.
5. 펫이 짧게 반응하고 성장 진행률이 갱신된다.
6. 코인으로 방과 소품을 꾸미고, 경험치로 펫의 표정과 행동을 해금한다.

## 정보 구조

하단 내비게이션은 네 탭으로 구성한다.

### 오늘

- 펫의 현재 표정, 이름, 레벨, 오늘 획득한 하트
- 현재 에너지에 맞춘 추천 퀘스트 한 개
- 추천 퀘스트의 예상 시간과 보상
- `3분 시작` 주 행동
- 한 줄 빠른 할 일 추가
- 남은 오늘 퀘스트 목록과 완료 목록
- 완료 직후 간결한 보상 오버레이

### 펫

- 기본 펫의 현재 성장 단계와 친밀도
- 보유 먹이와 먹이 주기
- 보유 코인
- 기본 방과 소품 배치
- 잠긴 펫, 진화, 시즌 소품의 프리미엄 미리보기

### 집중

- 추천 퀘스트를 이어서 시작
- 3분 시작과 일반 집중 타이머
- 일시정지, 연장, 종료
- 완료 시 퀘스트 보상 외 집중 보너스

### 나

- 완료 수, 집중 시간, 작은 승리 기록
- 알림, 에너지, 화면, 데이터 설정
- 프리미엄 기능과 구독 안내
- 백업 및 동기화 상태의 향후 확장 자리

## 시각 방향

선택된 방향은 `B2 귀여운 펫 게임`이다.

- 밝은 라일락과 크림 배경을 사용한다.
- 핑크는 보상과 핵심 행동에 제한적으로 사용한다.
- 둥근 카드, 부드러운 그림자, 큰 펫 일러스트를 사용한다.
- 홈의 펫 영역은 화면을 장식하는 배경이 아니라 상태와 동기를 전달한다.
- 이모지는 임시 구현에만 사용한다. 출시용 자산은 일관된 전용 펫 일러스트와 모션 세트로 교체한다.
- 텍스트 대비, 48px 터치 영역, 키보드 포커스, 모션 감소 설정을 유지한다.

## 보상 도메인

### 통화

- 경험치: 펫 레벨과 행동 해금에 사용한다.
- 코인: 방과 소품 구매에 사용한다.
- 먹이: 친밀도 반응을 얻는 소비 아이템이다.
- 하트: 오늘의 긍정적 진행을 보여주는 일일 지표이며 결제 통화가 아니다.

### 기본 보상

- 일반 퀘스트 완료: 경험치 10, 코인 5
- 3분 집중을 포함한 완료: 경험치 15, 코인 7, 먹이 획득 확률 제공
- 더 긴 집중 세션은 정해진 상한 안에서 추가 보상을 준다.
- 난이도나 긴 작업에 과도한 보상을 주지 않아 사용자가 할 일을 부풀릴 유인을 줄인다.

정확한 수치는 별도 순수 함수에 두어 테스트와 조정이 가능하게 한다. 첫 버전에서는 확률 보상의 난수를 주입 가능하게 만들어 테스트를 결정적으로 유지한다.

### 중복 방지와 복구

- 보상 기록은 완료된 작업 ID와 완료 시각을 고유 키로 사용한다.
- 같은 완료 이벤트에는 보상을 한 번만 지급한다.
- 작업 저장과 보상 저장이 분리되어 실패하면 미정산 완료 이벤트를 남긴다.
- 다음 앱 시작이나 저장 재시도에서 미정산 이벤트를 다시 계산한다.
- 보상 애니메이션이 실패해도 작업 완료와 보상 데이터는 유지된다.

## 상태와 컴포넌트 경계

- 기존 `Task`와 저장소를 퀘스트 원본으로 재사용한다.
- 게임 상태는 작업 모델에 섞지 않고 별도 `PetGameState` 저장소에 둔다.
- `RewardLedger`는 완료 이벤트와 지급 결과를 저장한다.
- `rewardPolicy`는 작업과 집중 결과를 입력받아 보상을 반환하는 순수 함수다.
- `PetHero`는 펫 상태만 표현하고 작업 저장을 알지 못한다.
- `FeaturedQuest`는 추천 작업과 시작 콜백만 받는다.
- `QuestList`는 작업 완료를 요청하며 직접 보상을 계산하지 않는다.
- 화면 조정 계층이 작업 완료, 보상 원장 기록, 위젯 갱신을 연결한다.

## 무료와 프리미엄

### 무료

- 할 일과 집중 타이머 무제한
- 기본 펫 1종과 기본 성장 단계
- 기본 방과 소품
- 일일 퀘스트와 기본 보상
- 로컬 저장
- 광고 없음

### 프리미엄

- 추가 펫과 진화 형태
- 시즌별 방, 의상, 소품
- AI 할 일 쪼개기와 시작 행동 추천
- 에너지 패턴과 고급 집중 통계
- 반복 일정과 고급 알림
- 클라우드 동기화와 백업
- 위젯 테마와 월간 성장 리포트

첫 구현에서는 결제 처리 없이 프리미엄 미리보기와 잠금 상태만 제공한다. 결제 버튼은 실제 결제 연동 전 구매로 오인되지 않도록 `출시 준비 중`으로 표시한다.

## 첫 구현 범위

1. B2 디자인 토큰과 공용 카드/버튼 스타일
2. 오늘 화면의 펫 히어로, 추천 퀘스트, 빠른 추가, 퀘스트 목록
3. 결정적인 보상 계산과 중복 방지 원장
4. 기본 펫 레벨, 표정, 친밀도 상태
5. 펫 화면과 제한된 기본 방 꾸미기
6. 집중 완료와 추가 보상 연결
7. 네 탭 내비게이션 재구성
8. 프리미엄 잠금 미리보기
9. 접근성, 작은 화면, 데이터 복구, 전체 회귀 테스트

제외 범위는 실제 Play Billing, 서버 계정, 클라우드 동기화, 푸시 서버, 생성형 AI 호출, 시즌 콘텐츠 운영 시스템, 출시용 최종 일러스트 제작이다.

## 테스트와 검증

- 보상 정책의 경계값과 상한을 단위 테스트한다.
- 동일 완료 이벤트가 한 번만 정산되는지 저장소 통합 테스트한다.
- 작업 저장 성공 후 보상 저장 실패와 재시도를 검증한다.
- 홈에서 추가, 추천, 집중 시작, 완료, 보상, 펫 갱신의 전체 흐름을 컴포넌트 테스트한다.
- 무료 기능이 잠금 처리되지 않고 프리미엄 항목만 미리보기인지 검증한다.
- 키보드, 스크린 리더 이름, 48px 터치 영역, 모션 감소를 확인한다.
- Pixel 7 크기와 좁은 화면에서 시각 회귀를 확인한다.
- 전체 테스트, 타입 검사, 프로덕션 빌드를 통과해야 완료로 간주한다.

## 출시 품질 기준

- 앱 시작 후 두 번 이하의 조작으로 첫 집중을 시작할 수 있다.
- 홈을 처음 본 사용자가 추천 퀘스트와 시작 버튼을 즉시 구분할 수 있다.
- 할 일 완료 후 보상이 한 번만 지급된다.
- 네트워크 없이 핵심 루프가 동작한다.
- 실패나 장기간 미사용 때문에 펫 또는 획득 아이템이 손실되지 않는다.
- 결제 연동 전에는 실제 구매가 가능한 것처럼 표현하지 않는다.
