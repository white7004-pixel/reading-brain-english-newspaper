# 🧠 리딩브레인 콘텐츠 스튜디오

리딩브레인 영어학원 AI 콘텐츠 자동 생성 웹 애플리케이션.
영자신문을 중심으로 학원 운영에 필요한 콘텐츠(네이버 블로그, 인스타그램, 소식지, 상담 문자)를 AI로 한 번에 생성합니다.

## ✨ 주요 기능

| 탭 | 기능 |
|---|---|
| 📰 **영자신문** | 주제·레벨(CEFR)별 수업용 영자신문 생성 — 기사, 단어장, 이해도 퀴즈, 교사용 팁 포함. 정답 숨기기(학생용/교사용 전환), 인쇄/PDF 내보내기 지원 |
| ✍️ **네이버 블로그** | 학부모 대상 정보성 포스트 + SEO 키워드 + 해시태그 10종 |
| 📸 **인스타그램** | 카드뉴스 슬라이드 5장 구성 + 캡션 + 해시태그 |
| 💌 **학원 소식지** | 월간 가정통신문 자동 작성 |
| 💬 **상담 문자** | 목적별 학부모 문자 시안 3종 (톤별) |

### 업그레이드 포인트
- **영자신문 전용 탭**: 실제 신문 레이아웃(마스트헤드, 2단 조판, 드롭캡)으로 미리보기 → 그대로 인쇄/PDF
- **정답 숨기기 토글**: 같은 신문을 학생용/교사용으로 전환
- **생성 기록**: 최근 생성물 20건 자동 저장(브라우저), 클릭 한 번으로 복원
- **데모 모드**: API 키 없이도 전체 기능 체험 가능
- **텍스트 복사**: 모든 콘텐츠를 붙여넣기 좋은 형태로 클립보드 복사

## 🚀 실행 방법

```bash
npm install
npm run dev
# http://localhost:3000 접속
```

## 🔑 AI 생성 연결 (선택)

API 키 없이도 데모 콘텐츠로 모든 기능을 체험할 수 있습니다.
실제 AI 생성을 사용하려면 둘 중 하나를 설정하세요.

1. **서버 환경변수** (배포 시 권장)
   ```bash
   ANTHROPIC_API_KEY=sk-ant-... npm run dev
   ```
2. **화면 내 설정**: 좌측 사이드바 ⚙️ 설정에서 API 키 입력 (브라우저에만 저장)

모델은 기본값 `claude-sonnet-5`이며 `CLAUDE_MODEL` 환경변수로 변경할 수 있습니다.

## 📦 배포 (Vercel)

```bash
npx vercel
```
환경변수 `ANTHROPIC_API_KEY`를 Vercel 프로젝트 설정에 추가하면 모든 방문자가 AI 생성을 사용할 수 있습니다.

## 🛠 기술 스택

- Next.js 15 (App Router) + React 19 + TypeScript
- Anthropic Claude API (`@anthropic-ai/sdk`)
- 별도 DB 없이 브라우저 localStorage로 기록/설정 저장

## URL 호환

기존 콘텐츠 스튜디오와 동일하게 `?tab=` 파라미터를 지원합니다.
예: `/?tab=nblog` → 네이버 블로그 탭으로 바로 이동
