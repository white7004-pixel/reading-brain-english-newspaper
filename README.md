# 리딩브레인 영어 학교시험 분석

리딩브레인 영어학원용 학교 내신(영어) 시험 분석 웹 애플리케이션.
내신 기출 문항을 입력하면 출제 경향 분석 차트와 학습 전략 리포트를 자동으로 생성합니다.

## 주요 기능

- **시험 등록** — 학교·학년·연도·시험(중간/기말)·시험 범위 관리
- **문항 분석 입력** — 문항별 유형(어법·빈칸추론·서술형 등 17종), 출처(교과서/부교재/모의고사/외부지문/변형), 난이도, 형식, 배점, 출제 포인트 메모
- **자동 분석 대시보드** — 유형별 출제 분포, 출처 분포, 난이도 분포, 객관식 vs 서술형 배점 구성, 핵심 지표(서술형 비중·고난도 비율·교과서 외 출처 비율)
- **학습 전략 리포트** — 출제 경향 기반 학습 전략 코멘트 자동 생성, 인쇄용 리포트(문항 구성표 포함)
- **학교별 경향 추이** — 같은 학교의 시험 회차별 핵심 지표(서술형 비중·고난도·교과서 외 출처) 추이 라인 차트와 유형별 출제 횟수 비교표
- **문항별 난이도 맵** — 문항 하나하나의 난이도(상·중·하)를 칩 그리드로 시각화, 체감 난이도 별점과 고난도 문항 유형 집중 분석
- **인스타 카드뉴스 내보내기** — 분석 결과를 정사각(1080×1080) PNG 슬라이드 7장(표지 훅 → 총평 → 난이도 맵 → 유형 → 출처 → 서술형 → 대비 전략+CTA)으로 다운로드, 인스타그램 캐러셀 게시용
- **데이터 관리** — 브라우저(localStorage) 저장, JSON 백업/복원, 예시 데이터 제공
- 라이트/다크 모드, 모바일 반응형 지원

## 단일 파일 버전 (설치 없이 사용)

`standalone/reading-brain-app.html` 파일 하나에 앱 전체가 들어 있습니다.
더블클릭으로 열거나, 아무 웹호스팅에 업로드하거나, HTML을 지원하는 곳에 그대로 붙여넣으면 됩니다.
소스(`src/`)를 수정한 뒤에는 `npm run build` 후 dist의 CSS/JS를 다시 인라인하면 갱신됩니다.

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

빌드 결과물은 정적 파일이므로 GitHub Pages, Netlify 등 어디에나 배포할 수 있습니다
(`vite.config.ts`의 `base: './'` 설정으로 하위 경로에서도 동작).

## 기술 스택

- Vite + React 18 + TypeScript
- 차트: 외부 라이브러리 없이 SVG 직접 렌더링 (호버 툴팁, 접근성 레이블 포함)
- 저장소: localStorage (서버 불필요)
