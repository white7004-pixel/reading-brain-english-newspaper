# 리딩브레인 영어학원 학습영상 분석 웹앱 — 중고등특목2관

학생이 **문법 하브루타 · 독해 읽고해석 · 단어 구술테스트** 활동 영상을 촬영(또는 업로드)하면,
발화 내용을 분석해 **성취도 점수와 개선점**을 알려주는 웹앱입니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📹 영상 촬영 | 브라우저에서 바로 카메라 촬영 + 실시간 음성 전사 (Web Speech API) |
| 📂 영상 업로드 | 촬영해 둔 영상 파일 업로드 + 전사 내용 직접 입력 |
| 📊 활동별 분석 | 활동마다 5개 영역 루브릭으로 자동 채점 (총점·등급) |
| 🕸️ 성취도 차트 | 영역별 레이더 차트 + 세부 점수 막대 |
| 📈 성장 기록 | 결과를 저장해 회차별 점수 추이 그래프로 확인 |
| 🤖 AI 심층 피드백 | Anthropic API 키 등록 시 전사 내용 기반 맞춤 피드백 (선택) |

### 활동별 채점 영역

- **문법 하브루타**: 발화 지속력 · 질문 생성력 · 문법 용어 활용 · 논리 전개 · 유창성
- **독해 읽고 해석**: 낭독 분량 · 영어 낭독 비율 · 해석 완성도 · 문장 완성도 · 유창성
- **단어 구술테스트**: 암기량 · 응답 속도 · 정확도(단어 리스트 입력 시 정답률 매칭) · 영·한 짝짓기 · 유창성

## 실행 방법

정적 웹앱이므로 별도 서버가 필요 없습니다.

```bash
# 로컬 실행 (카메라/마이크 권한 때문에 http 서버 필요)
python3 -m http.server 8000
# → http://localhost:8000 접속
```

GitHub Pages에 배포하면 바로 사용할 수 있습니다 (Settings → Pages → 해당 브랜치 선택).

## 이용 안내

- 실시간 전사는 **크롬/엣지** 브라우저에서 가장 잘 작동합니다.
- 영상과 분석 데이터는 **브라우저 안에서만** 처리·저장되며 서버로 전송되지 않습니다.
- 독해 활동은 영어 낭독 시 `English`, 해석 시 `한국어`로 인식 언어를 전환하세요.
- AI 피드백용 API 키는 localStorage에만 저장됩니다. 공용 PC에서는 사용 후 삭제하세요.
