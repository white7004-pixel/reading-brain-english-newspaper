# 관리형 독서실 관제 프로그램 (Study Room Monitor)

태블릿 캠 기반 관리형 독서실을 위한 실시간 관제 대시보드 웹 애플리케이션입니다.
별도의 빌드 과정 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

```bash
# 방법 1: index.html을 브라우저로 바로 열기
open study-room/index.html

# 방법 2: 간단한 로컬 서버 (권장)
cd study-room
python3 -m http.server 8000
# → http://localhost:8000 접속
```

## 주요 기능

### 관리자 대시보드
- **상단 통계 카드**: 평균 성취율 · 출석률 · 학습중 인원 · 경고 대상 · 평균 순공 시간 (실시간 자동 계산)
- **학생 실시간 카드**: 상태 배지(학습중/수면중/외출중/외출지각/하원), LIVE 캠 영역,
  태블릿 번호·배터리, 학습 모드(스파르타/집중/자율), 등하원 시간,
  진행률·성취율 게이지, 학습효율 및 진행/순공/외출/기타 시간
- **AI 감지 오버레이**: 졸음 감지(빨간 점선 박스), 자리 이탈(보라 점선 박스) — 실시간 시뮬레이션
- **검색·필터·정렬**: 이름/학교 검색, 지점·모드 필터, 이름순/성취율/효율/경고순 정렬
- **개인정보 보호**: 이름 가림 토글 (강서아 → 강O아)
- **학생 상세 모달**: 카드 클릭 시 상세 지표 + 학생앱 메시지/학부모 알림/깨우기 알림 전송

### 학생앱 미리보기
학생별 순공 타이머, 진행률/성취율, 오늘의 학습 플랜, 원장님 메시지 화면

### 보고서
일일 학습 보고서 — 등원 인원, 총 순공 시간, 최고 성취 학생, 경고 대상 요약 + 학생별 상세 테이블

### AI 감지 로그
졸음·자리 이탈 이벤트가 시간순으로 기록되는 실시간 로그

### 알림
AI 감지 이벤트·메시지 전송 내역이 좌측 하단 알림 패널에 누적 (뱃지 카운트)

## 구조

```
study-room/
├── index.html      # 화면 구조 (관리자/학생앱/보고서/AI감지)
├── css/style.css   # 전체 스타일
└── js/
    ├── data.js     # 학생 모의 데이터 (실서비스에서는 API/웹소켓으로 대체)
    └── app.js      # 렌더링·필터·정렬·모달·알림·실시간 시뮬레이션
```

## 참고

- 순수 HTML/CSS/JavaScript로 작성되어 의존성이 없습니다.
- 3초 간격으로 학습 시간 증가, 배터리 소모, AI 감지 이벤트가 시뮬레이션됩니다.
- `data.js`의 `STUDENTS` 배열을 수정하면 학생 구성을 바꿀 수 있습니다.
